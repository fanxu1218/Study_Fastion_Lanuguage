# 第 13 课：循环中动态等待

- 日期：2026-09-17
- 课程序号：第 13 课
- 知识点：循环中动态等待

## 用途

在协程循环中按每轮状态改变等待时间。

## 核心概念

每次循环都创建新的 WaitForSeconds，可读取当轮 delay；退出条件保持显式。

## 最小代码或操作示例

```text
IEnumerator Practice()
{
    while (enabled) {
        yield return new WaitForSeconds(delay);
        delay += 0.5f;
    }
}
```

## 3～5 分钟练习

给 delay 设置最大值 3 秒。

## 参考答案

delay = Mathf.Min(delay + 0.5f, 3f);
