# 第 22 课：禁用对象时恢复timeScale

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：`OnDisable` 清理

## 用途或适用场景

暂停菜单对象被禁用时避免游戏永久停在零时间缩放。

## 核心概念

本课只增加“`OnDisable` 清理”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```csharp
void OnDisable() { Time.timeScale = 1f; }
```

## 3～5 分钟练习

暂停后禁用菜单对象，再观察游戏。

## 参考答案

对象禁用时恢复为 1；正常暂停按钮逻辑保持不变。
