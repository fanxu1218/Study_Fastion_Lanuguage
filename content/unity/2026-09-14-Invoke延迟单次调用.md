# 第 10 课：Invoke延迟单次调用

- 日期：2026-09-14
- 课程序号：第 10 课
- 知识点：延迟调用与取消

## 用途

在几秒后触发一次简单方法，例如恢复按钮或隐藏提示。

## 核心概念

`Invoke` 以方法名延迟调用；对象禁用或流程终止时可用 `CancelInvoke` 明确取消。

## 最小代码或操作示例

```csharp
void StartCooldown()
{
    Invoke(nameof(FinishCooldown), 2f);
}

void FinishCooldown() { enabled = true; }
void OnDisable() { CancelInvoke(); }
```

## 3～5 分钟练习

把延迟改为 3 秒，并只取消 `FinishCooldown`。

## 参考答案

调用 `Invoke(nameof(FinishCooldown), 3f)` 与 `CancelInvoke(nameof(FinishCooldown))`。

## 与上一课的联系

上一课在禁用时清理协程；本课处理更轻量的单次延迟任务及清理。
