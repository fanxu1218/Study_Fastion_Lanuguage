# 第 26 课：避免重复暂停覆盖恢复速度

- 日期：2026-10-14
- 课程序号：第 26 课
- 知识点：同一轮暂停只记录一次 previousScale

## 用途或适用场景

保护上一课的恢复值，使菜单收到两次 Pause 调用后仍能恢复原速度。

## 核心概念

第一次 Pause 保存实际 timeScale；第二次调用时菜单已经拥有本轮暂停，只需返回。pausedByMenu 继续表示尚待清理的菜单操作，恢复仍在原 OnDisable 中完成。练习前提是同一菜单负责本轮暂停。

## 最小代码或操作示例

替换第 25 课原 Pause，保留 previousScale、pausedByMenu 和清除标记的 OnDisable：

```csharp
void Pause()
{
    if (pausedByMenu) return;
    previousScale = Time.timeScale;
    Time.timeScale = 0f;
    pausedByMenu = true;
}
```

不新增第二个暂停菜单或其他 timeScale 写入方。

## 3～5 分钟练习

按已学调用方式设 timeScale=0.5，连续 Pause 两次，再禁用菜单；重新启用后用 0.25 再做一轮。

## 参考答案

两轮分别恢复为 0.5、0.25，OnDisable 清除标记；不会把第二次调用看到的 0 保存为恢复值。多系统同时暂停的协调不属于本课契约。

## 与上一课的联系

继承第 24 课恢复守卫、第 25 课恢复后清标记；本课只阻止同一轮重复记录 previousScale。下一课可在练习项目中用日志记录这一整轮暂停和恢复调用。
