# 第 29 课：把暂停恢复提取为独立方法

- 日期：2026-10-20
- 课程序号：第 29 课
- 知识点：从生命周期回调委托已有恢复逻辑

## 用途或适用场景

让时间缩放恢复路径有明确的方法边界。

## 核心概念

OnDisable仍由引擎调用，只委托给RestoreTimeScale。原pausedByMenu守卫、previousScale和日志保持原意；单菜单拥有暂停的前提不变。

## 最小代码或操作示例

在原组件内用下列两个方法替换原OnDisable，Pause及其字段保留：

```csharp
void RestoreTimeScale()
{
    if (pausedByMenu)
    {
        Time.timeScale = previousScale;
        pausedByMenu = false;
        Debug.Log("Restored=" + Time.timeScale, this);
    }
}

void OnDisable()
{
    RestoreTimeScale();
}
```

不手工调用OnDisable，也不在其他脚本另存时间缩放。
