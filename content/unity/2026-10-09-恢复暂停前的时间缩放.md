# 第 23 课：恢复暂停前的时间缩放

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：保存原 `timeScale`

## 用途或适用场景

菜单关闭时恢复进入暂停前的速度，而不是固定写回 1。

## 核心概念

只保存暂停前的 `Time.timeScale`，业务时间缩放仍由 Unity 全局值提供。

## 最小代码或操作示例

```csharp
float previousScale = 1f;
void Pause() { previousScale = Time.timeScale; Time.timeScale = 0f; }
void OnDisable() { Time.timeScale = previousScale; }
```

## 3～5 分钟练习

先设为 0.5，再暂停并禁用菜单。

## 参考答案

禁用后恢复为 0.5，而不是 1。

## 与上一课的联系

第 22 课禁用对象时固定恢复为 1；本课只保留暂停前速度；下一课可防止未暂停时误恢复。
