# 第 3 课：Update与按时间旋转

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：每帧更新、角速度与 Time.deltaTime

## 用途

让 Cube 按每秒固定角度连续转动。

## 核心概念

- Update 在启用的组件上逐帧执行，Time.deltaTime 表示本帧对应的时间间隔（秒）。
- 每帧角度=每秒角度×时间；不是每帧固定转同样的角度。此处演示普通 Transform 动画，不处理刚体物理。

## 最小代码或操作示例

```csharp
using UnityEngine;
public class SpinCube : MonoBehaviour
{
    private void Update()
    {
        transform.Rotate(0f, 90f * Time.deltaTime, 0f, Space.Self);
    }
}
```

## 3～5 分钟练习

保存为 SpinCube.cs，挂到 Cube；不要同时挂载其他旋转脚本。预测 2 秒约转多少度，再将速度改成 45。

## 参考答案

```text
90 度/秒时，2 秒约转 180 度；45 度/秒时，2 秒约转 90 度。实际帧采样可能略有偏差，暂停时也不会继续按现实时间推进。
```
