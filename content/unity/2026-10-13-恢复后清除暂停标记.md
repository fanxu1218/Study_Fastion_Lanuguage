# 第 25 课：恢复后清除暂停标记

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：在恢复 timeScale 后清除 pausedByMenu

## 用途或适用场景

菜单恢复过一次后再次启用、禁用时，不把旧的暂停记录用于新一轮生命周期。

## 核心概念

继续使用 previousScale 和 pausedByMenu。标记只说明本菜单是否还有一次待清理的暂停操作；恢复后把它设为 false。Time.timeScale 仍是实际时间缩放的唯一来源。

## 最小代码或操作示例

将上一课菜单脚本中的 `OnDisable` 替换为下面片段；保留已有 `Pause()`、`previousScale` 和 `pausedByMenu`：

```csharp
void OnDisable()
{
    if (pausedByMenu)
    {
        Time.timeScale = previousScale;
        pausedByMenu = false;
    }
}
```

## 3～5 分钟练习

沿用上一课的速度设置方式：先设 timeScale=0.5，调用一次 Pause()，再禁用菜单；重新启用菜单但不暂停，把 timeScale 改为 0.25，再禁用菜单。记录两次禁用后的值。

## 参考答案

第一次禁用恢复为 0.5 并清除标记；第二次没有新的暂停，保持 0.25。练习中的 Pause() 每轮只调用一次。

## 与上一课的联系

继承第 24 课的 pausedByMenu 守卫和第 23 课的 previousScale；本课只在恢复后清除标记。完成两次禁用练习后，下一课可检查同一轮重复调用 Pause() 是否覆盖 previousScale。
