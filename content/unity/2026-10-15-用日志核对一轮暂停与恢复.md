# 第 27 课：用日志核对一轮暂停与恢复

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：带对象上下文的 Debug.Log

## 用途或适用场景

观察上一课重复暂停守卫和 OnDisable 恢复是否按预期执行。

## 核心概念

Debug.Log 记录调用路径；传入 this 可从 Console 定位当前组件。日志读取实际 Time.timeScale 和原 previousScale，不增加第二个速度来源。本课仍限定一个菜单负责本轮暂停。

## 最小代码或操作示例

替换原两个方法，其余字段与调用入口保留：

```csharp
void Pause()
{
    if (pausedByMenu)
    {
        Debug.Log("Pause ignored: already paused", this);
        return;
    }
    previousScale = Time.timeScale;
    Time.timeScale = 0f;
    pausedByMenu = true;
    Debug.Log("Paused; saved=" + previousScale, this);
}

void OnDisable()
{
    if (pausedByMenu)
    {
        Time.timeScale = previousScale;
        pausedByMenu = false;
        Debug.Log("Restored=" + Time.timeScale, this);
    }
}
```

沿用原 using UnityEngine，不手动调用 OnDisable。

## 3～5 分钟练习

设置 0.5 后连续 Pause 两次，再禁用菜单；在 Console 查看三条路径消息，点击日志定位对象。

## 参考答案

出现 Paused saved=0.5、一次 ignored、Restored=0.5；显示格式可能受区域设置影响。重新启用但不暂停再禁用，不应产生恢复日志；引擎运行结果需实际记录。
