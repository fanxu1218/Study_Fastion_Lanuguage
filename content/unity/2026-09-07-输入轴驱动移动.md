# 第 5 课：输入轴驱动移动

- 日期：2026-09-07
- 课程序号：第 5 课
- 知识点：Input.GetAxis 与 deltaTime

## 用途

用键盘水平移动一个物体。

## 核心概念

Input.GetAxis 与 deltaTime用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```csharp
float x = Input.GetAxis("Horizontal");\ntransform.Translate(Vector3.right * x * speed * Time.deltaTime);
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

右键沿本地 X 正向，左键沿负向，位移按秒计算。
