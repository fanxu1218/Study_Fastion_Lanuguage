# 第 24 课：避免未暂停时误恢复速度

- 日期：2026-10-12
- 课程序号：第 24 课
- 知识点：暂停标记守卫

## 用途或适用场景

对象未执行暂停就被禁用时，不覆盖其他系统设置的时间缩放。

## 核心概念

本课只沿用上一课的已有数据与命名，并增加上述单一知识点。

## 最小代码或操作示例

```csharp
bool pausedByMenu;
void Pause() { previousScale = Time.timeScale; Time.timeScale = 0f; pausedByMenu = true; }
void OnDisable() { if (pausedByMenu) Time.timeScale = previousScale; }
```

## 3～5 分钟练习

按示例完成一次最小操作，并核对结果。

## 参考答案

已暂停时恢复原值；未暂停时保持当前 `timeScale`。
