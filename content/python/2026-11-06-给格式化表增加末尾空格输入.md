# 第 44 课：给格式化表增加末尾空格输入

- 日期：2026-11-06
- 课程序号：第 44 课
- 知识点：新表行与独立数量期望同步

## 用途或适用场景

扩展第43课循环而不修改格式化实现。

## 核心概念

新增行带自己的固定期望；循环自动多执行一次，调用方仍需独立约定4。末尾空格属于原文，不应被格式化函数删除。

## 最小代码或操作示例

保留第42课三行format_cases和第43课循环，在表的最后一行之后、结束方括号前追加：
```python
    ("trailing-space", ["1. Go "], "有效条目：1\n1. Go "),
```
将函数外原数量断言替换为：
```python
assert checked_count == 4, f"完成数量不符：期望4，实际{checked_count}"
```
不再追加第二次检查调用。保留return len(format_cases)、原三份期望和完成提示，正常python3运行，不用-O。

## 3～5 分钟练习

只删掉新行期望末尾的空格，应该在哪里失败？随后恢复。

## 参考答案

应在trailing-space对应的逐行assert失败，不能打印4项完成；恢复末尾空格后再检查四行。
