# 第 32 课：为空的有效清单显示明确提示

- 日期：2026-10-21
- 课程序号：第 32 课
- 知识点：由列表数量选择展示分支

## 用途或适用场景

区分读回成功但没有有效记录与实际存在记录。

## 核心概念

valid_count 已从 valid_lines 派生；零条只说明本次筛选结果为空。提示不改文件，也不把缺文件或读取错误当作空清单。

## 最小代码或操作示例

在第 31 课 len 之后，用下面分支替换原数量 print，保留读取和筛选：

```python
if valid_count == 0:
    print("暂无有效学习条目")
else:
    print(f"有效条目：{valid_count}")
```

saved_text、saved_lines、valid_lines 的来源不变，不另存 has_items。

## 3～5 分钟练习

用内存副本的 `"1. Python\n   \n  2. Rust\n"`、`"   \n"`、""，重新拆行/筛选/计数后执行分支。

## 参考答案

三项依次输出有效条目：2、暂无有效学习条目、暂无有效学习条目。读取异常仍按原错误报告，不能用此提示替代失败。
