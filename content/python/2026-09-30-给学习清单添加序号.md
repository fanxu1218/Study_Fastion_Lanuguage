# 第 23 课：给学习清单添加序号

- 日期：2026-09-30
- 课程序号：第 23 课
- 知识点：`enumerate()`

## 用途或适用场景

在逐条输出待补主题时同时显示从 1 开始的序号。

## 核心概念

`enumerate(iterable, start=1)` 同时产生序号和值，不需要手动维护计数器。

## 最小代码或操作示例

```python
missing = {"异常", "测试"}
for index, topic in enumerate(sorted(missing), start=1):
    print(f"{index}. {topic}")
```

## 3～5 分钟练习

加入“部署”，确认输出序号连续。

## 参考答案

排序后循环会输出 1、2、3 三个连续序号。
