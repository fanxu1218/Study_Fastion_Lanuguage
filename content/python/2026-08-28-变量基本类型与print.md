# 第 1 课：变量、基本类型与 print

- 日期：2026-08-28
- 课程序号：第 1 课
- 知识点：变量、常用基本类型与 `print()` 输出

## 知识点

使用变量保存数据，认识字符串、整数、浮点数和布尔值，并用 `print()` 查看程序结果。

## 用途

变量是 Python 程序组织数据的起点。后续的判断、循环、函数和数据处理都会读取或修改变量。

## 核心概念

- Python 使用 `变量名 = 值` 创建变量，不需要提前声明类型。
- `str` 表示文本，`int` 表示整数，`float` 表示小数，`bool` 表示真假。
- `type()` 可以查看一个值当前的类型。
- 变量名应表达含义，例如 `lesson_count`，不要只写难以理解的单字母。

## 示例代码

```python
course_name = "Python"
lesson_count = 1
study_minutes = 10.0
is_weekday = True

print(course_name)
print(f"第 {lesson_count} 课，学习 {study_minutes} 分钟")
print(type(is_weekday))
```
