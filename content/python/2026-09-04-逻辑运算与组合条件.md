# 第 6 课：逻辑运算与组合条件

- 日期：2026-09-04
- 课程序号：第 6 课
- 知识点：and、or、not 与短路判断

## 用途

同时检查练习时长和完成情况。

## 核心概念

and 要求两边都成立；or 只需一边成立；not 取反。对本课布尔条件，短路表示结果已确定时不继续计算右侧。

## 最小代码或操作示例

```python
minutes = 5
finished = True
if minutes >= 3 and finished:
    print("达标")
else:
    print("继续练习")
```

## 3～5 分钟练习

将 minutes 改为 2，再把 and 改为 or，比较输出。

## 参考答案

and 时输出“继续练习”；or 时因 finished 为 True 输出“达标”。not finished 为 False。
