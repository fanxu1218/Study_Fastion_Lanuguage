# 第 48 课：用独立函数调用原格式化检查

- 日期：2026-11-12
- 课程序号：第 48 课
- 知识点：测试入口与被测函数分离

## 用途或适用场景

让第47课恢复的四行表有一个明确的测试调用入口。

## 核心概念

def定义入口，调用时才执行函数体；数量断言仍放在四行内容检查之后，不能用固定数量代替逐行断言。

## 最小代码或操作示例

保留第46、47课原四行format_cases、format_valid_lines和check_format_valid_lines。把原文件末尾数量检查及打印替换为：
```python
def test_format_valid_lines():
    checked_count = check_format_valid_lines()
    assert checked_count == 4, f"完成数量不符：期望4，实际{checked_count}"
    print(f"{checked_count}项格式化检查完成")

test_format_valid_lines()
```
在所有原定义之后放置这段，正常python3运行，预期4项格式化检查完成；不用-O，也无需安装测试框架。

## 3～5 分钟练习

## 参考答案

不会。定义不是调用；恢复末尾一次调用，再看逐行断言和数量检查都实际完成。
