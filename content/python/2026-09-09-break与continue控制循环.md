# 第 9 课：break与continue控制循环

- 日期：2026-09-09
- 课程序号：第 9 课
- 知识点：break 与 continue

## 用途

在循环中跳过无效数据，或找到目标后立即停止。

## 核心概念

`continue` 跳到下一轮，`break` 结束整个循环；两者都只影响当前所在的循环。

## 最小代码或操作示例

```python
for score in [0, 72, 90]:
    if score == 0:
        continue
    print(score)
    if score >= 90:
        break
```

## 3～5 分钟练习

把列表改成 `[60, 90, 100]`，预测会输出哪些值。

## 参考答案

输出 `60` 和 `90`；遇到 90 后执行 `break`，不会再处理 100。
