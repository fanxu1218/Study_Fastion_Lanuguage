# 第 54 课：按文档核对一份保留空格的输出

- 日期：2026-11-20
- 课程序号：第 54 课
- 知识点：调用方使用独立期望验证函数契约

## 用途或适用场景

把第53课文档中的“保留每行原文”落实为一次直接调用。

## 核心概念

期望文本先按文档写出，再与真实返回比较；不能从函数输出复制期望来证明契约。原四行回归与本次独立演练分别保留。

## 最小代码或操作示例

在原模块同目录新建未存在的check_contract.py，formatter.py和原四行检查均不改：
```python
from formatter import format_valid_lines

lines = ["1. Python", "  2. Rust"]
expected = "有效条目：2\n1. Python\n  2. Rust"
actual = format_valid_lines(lines)
assert actual == expected, f"契约不符：actual={actual!r}，expected={expected!r}"
print("原文保留契约检查完成")
```
正常运行python3 check_contract.py，再运行python3 run_checks.py；分别应出现契约检查完成和原4项完成，不用-O或-OO。

## 3～5 分钟练习

把expected第二行Rust前的两个空格删去，是否应修改formatter来让它通过？完成后恢复。

## 参考答案

不应；该期望违背既有保留原文契约，应得到AssertionError。恢复两个空格后独立演练及原四行都通过。
