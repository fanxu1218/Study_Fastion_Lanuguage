# 第 59 课：按顺序运行三条已有检查

- 日期：2026-11-27
- 课程序号：第 59 课
- 知识点：subprocess.run以check=True传播首个失败

## 用途或适用场景

把第58课文档入口、独立契约与原四项检查组织为一个本地任务。

## 核心概念

run会等待当前子进程结束；check=True使非零退出抛出异常，后续循环不再执行。sys.executable沿用当前Python解释器；三个子入口仍各自负责原检查，不合并统计。

## 最小代码或操作示例

在formatter.py等文件所在目录，新建check_all.py；从该目录执行python3 check_all.py：
```python
import subprocess
import sys

if __name__ == "__main__":
    for script in ("check_doctest.py", "check_contract.py", "run_checks.py"):
        subprocess.run([sys.executable, script], check=True)
```
参数列表直接传给程序，不需要shell。保留三个原入口；仅当三次调用都成功时，本入口才正常结束。

## 3～5 分钟练习

在个人副本只把formatter.py空列表文档的预期改错，再运行check_all.py；观察后恢复原预期并重跑。

## 参考答案

文档组应非零，显示Expected/Got及CalledProcessError，后两条检查不会启动。恢复后分别看到2个文档示例、独立契约和4项格式化检查通过；不将它们合并成同一覆盖数。
