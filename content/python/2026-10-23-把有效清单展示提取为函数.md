# 第 34 课：把有效清单展示提取为函数

- 日期：2026-10-23
- 课程序号：第 34 课
- 知识点：由参数驱动清单展示

## 用途或适用场景

把有效清单展示提取为函数。

## 核心概念

函数内从传入列表派生数量；展示不修改列表，也不承担文件读取。有效原行仍由前面的筛选步骤提供。

## 最小代码或操作示例

在原展示分支处改为函数定义及一次调用，读回和valid_lines筛选保留：

```python
def show_valid_lines(valid_lines):
    valid_count = len(valid_lines)
    if valid_count == 0:
        print("暂无有效学习条目")
    else:
        print(f"有效条目：{valid_count}")
        for line in valid_lines:
            print(line)

show_valid_lines(valid_lines)
```

移除第31课原顶层valid_count及第33课旧展示分支，避免重复输出。

## 3～5 分钟练习

在内存中分别调用show_valid_lines([])和show_valid_lines(["1. Python", "  2. Rust"])。

## 参考答案

前者仅输出暂无有效学习条目；后者先输出有效条目：2，再按原顺序输出两行，第二行前两空格保留。函数不写回文件。
