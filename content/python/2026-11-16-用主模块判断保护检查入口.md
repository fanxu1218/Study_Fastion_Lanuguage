# 第 50 课：用主模块判断保护检查入口

- 日期：2026-11-16
- 课程序号：第 50 课
- 知识点：直接运行与导入的入口区别

## 用途或适用场景

让第49课format_checks可以被导入而不自动检查。

## 核心概念

直接运行时__name__为__main__；普通导入时为模块名。定义仍加载，受保护的调用仅在直接运行时执行。

## 最小代码或操作示例

保持formatter.py原纯函数、format_checks.py原四行表与两个检查函数，只把末尾调用替换为：
```python
if __name__ == "__main__":
    test_format_valid_lines()
```
在同目录正常运行python3 format_checks.py，应打印4项格式化检查完成；再运行python3 -c "import format_checks"，应无输出。不得用-O。

## 3～5 分钟练习

导入后显式调用format_checks.test_format_valid_lines()，会执行吗？

## 参考答案

会，保护的是末尾自动入口，函数本身仍可调用。
