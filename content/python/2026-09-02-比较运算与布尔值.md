# 第 4 课：比较运算与布尔值

- 日期：2026-09-02
- 课程序号：第 4 课
- 知识点：比较运算、bool 与边界值

## 用途

把计算结果变成可判断的条件。

## 核心概念

- == 判断相等，= 用于赋值；!= 判断不等。
- <、<=、>、>= 比较大小，结果为 True 或 False。

## 最小代码或操作示例

```python
score = 60
print(score >= 60)
print(score == 100)
```

## 3～5 分钟练习
