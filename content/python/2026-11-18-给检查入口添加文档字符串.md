# 第 52 课：给检查入口添加文档字符串

- 日期：2026-11-18
- 课程序号：第 52 课
- 知识点：函数首条字符串与__doc__

## 用途或适用场景

让第51课调用方可以读取原检查入口的用途。

## 核心概念

函数体第一条字符串是文档字符串；读取__doc__得到文档，不会执行函数内断言。

## 最小代码或操作示例

在format_checks.py的test_format_valid_lines函数中，紧接def行、原checked_count赋值之前插入一行：
```python
    """执行四项格式化检查并打印完成数量。"""
```
其余函数体、四行表和入口保护不变。在同目录正常运行：
```sh
python3 -c "import format_checks; print(format_checks.test_format_valid_lines.__doc__)"
python3 run_checks.py
```
第一条只输出文档；第二条仍输出一次4项格式化检查完成。不用-O，不复制实现。

## 3～5 分钟练习

把该字符串放到checked_count赋值后，还会自动成为此函数的__doc__吗？

## 参考答案

不会；函数文档字符串必须位于函数体首条语句。放回首行，原检查调用保持不变。
