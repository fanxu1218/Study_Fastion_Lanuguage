# 第 58 课：为文档示例增加自动化入口

- 日期：2026-11-26
- 课程序号：第 58 课
- 知识点：testmod结果映射为进程退出码

## 用途或适用场景

让第57课受控失败可以被外层命令可靠识别。

## 核心概念

doctest.testmod检查传入模块的文档，返回failed/attempted；失败数非零时退出1。文档2项、契约演练和原4项继续分开。

## 最小代码或操作示例

在formatter.py同目录新建check_doctest.py：
```python
import doctest
import formatter

if __name__ == "__main__":
    result = doctest.testmod(formatter, verbose=True)
    if result.failed:
        raise SystemExit(1)
```
运行python3 check_doctest.py，再分别运行python3 check_contract.py和python3 run_checks.py。formatter仍保留原导入守卫及两个文档示例，不把doctest混入生产函数。

## 3～5 分钟练习

在个人副本只将空列表文档预期改错，入口应返回什么？随后恢复。

## 参考答案

应打印该组Expected/Got并非零退出；恢复后入口0退出且2个示例通过，再运行独立契约及原4项。不能修改函数来迎合错期望。
