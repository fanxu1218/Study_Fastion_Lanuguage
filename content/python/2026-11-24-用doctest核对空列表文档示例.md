# 第 56 课：用doctest核对空列表文档示例

- 日期：2026-11-24
- 课程序号：第 56 课
- 知识点：同一文档里的第二个边界示例

## 用途或适用场景

让第55课可执行文档同时覆盖原函数的无数据返回。

## 核心概念

同一个文档字符串可以有多组>>>示例；示例数与原四行回归数量分别统计，空列表期望来自既有契约。

## 最小代码或操作示例

在formatter.py的format_valid_lines原文档字符串内，保留第55课示例，结束三引号前追加：
```python
    >>> print(format_valid_lines([]))
    暂无有效学习条目
```
同目录依次执行：
```sh
python3 -m doctest -v formatter.py
python3 check_contract.py
python3 run_checks.py
```
首条现在应为2个文档示例通过；独立契约和原4项仍各自通过。不加NORMALIZE_WHITESPACE，不用-O/-OO，函数体不改。

## 3～5 分钟练习

把空样本预期改为“有效条目：0”，doctest应通过吗？随后恢复。

## 参考答案

不应；原空列表返回“暂无有效学习条目”。失败不能用改函数凑期望，恢复文档后重新运行三条命令。
