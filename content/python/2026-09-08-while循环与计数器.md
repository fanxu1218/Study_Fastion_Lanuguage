# 第 8 课：while循环与计数器

- 日期：2026-09-08
- 课程序号：第 8 课
- 知识点：while 循环

## 用途

在条件成立期间重复执行操作，例如完成固定次数的练习。

## 核心概念

`while` 每轮开始前检查条件；循环体必须让条件逐步趋向不成立，避免无限循环。

## 最小代码或操作示例

```python
round_number = 1
while round_number <= 3:
    print(f"第 {round_number} 轮")
    round_number += 1
```

## 3～5 分钟练习

把总轮数改为 5，并让输出从“第 0 轮”开始。

## 参考答案

把初始值改成 `0`，条件改成 `round_number < 5`，会输出第 0～4 轮。
