# 第 37 课：用断言检查格式化函数的返回文本

- 日期：2026-10-28
- 课程序号：第 37 课
- 知识点：assert与固定期望文本

## 用途或适用场景

assert与固定期望文本，用于继续完成本路线原示例的下一步。

## 核心概念

assert比较实际返回值与独立写出的期望；条件不成立会抛AssertionError。检查函数返回值不需要捕获终端输出，断言不用于代替业务输入校验。

## 最小代码或操作示例

保留第36课format_valid_lines，在同一文件定义后增加以下检查；原文件读取流程不改：

```python
assert format_valid_lines([]) == "暂无有效学习条目"
assert format_valid_lines(["1. Go"]) == "有效条目：1\n1. Go"
assert format_valid_lines(["1. Python", "  2. Rust"]) == (
    "有效条目：2\n1. Python\n  2. Rust"
)
print("三项格式化检查完成")
```

使用正常python3命令运行，不加-O；优化模式会移除assert。保留字符串内的反斜杠n转义。

## 3～5 分钟练习

把两条列表的期望中Rust前两个空格删去，运行后再恢复，哪条断言应失败？

## 参考答案

第三条应失败，因为原行前导空格属于返回文本；失败后不应显示完成提示。恢复后再运行三项。
