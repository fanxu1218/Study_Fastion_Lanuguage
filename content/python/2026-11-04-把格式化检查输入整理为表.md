# 第 42 课：把格式化检查输入整理为表

- 日期：2026-11-04
- 课程序号：第 42 课
- 知识点：固定输入与固定期望的成对记录

## 用途或适用场景

为原三项断言准备可逐行复用的输入表。

## 核心概念

表保存输入、期望和名称；期望仍是手写的独立字符串，不能用被测函数计算。本课只整理数据，原检查入口仍承担实际断言。

## 最小代码或操作示例

沿第40课检查函数和第41课调用方数量断言，在check_format_valid_lines之前新增；本课暂不替换三项断言：

```python
format_cases = [
    ("empty", [], "暂无有效学习条目"),
    ("single", ["1. Go"], "有效条目：1\n1. Go"),
    ("leading-space", ["1. Python", "  2. Rust"],
     "有效条目：2\n1. Python\n  2. Rust"),
]
```

保留format_valid_lines、三项带消息assert、return 3及函数外固定数量检查；正常python3运行，不加-O。表本身不会执行检查。

## 3～5 分钟练习

把第三行期望改为format_valid_lines(该行输入)，还有独立对照吗？

## 参考答案

没有，错误实现会同时产生实际与期望。恢复固定文本，并逐字保留Rust前两个空格。
