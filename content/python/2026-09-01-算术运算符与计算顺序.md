# 第 3 课：算术运算符与计算顺序

- 日期：2026-09-01
- 课程序号：第 3 课
- 知识点：算术运算符、整除、取余与括号

## 用途

用于价格、时长和数量等基础计算。

## 核心概念

- `+ - * /` 表示基础运算，`//` 是整除，`%` 是取余，`**` 是乘方。
- 乘除优先于加减，括号内先计算。

## 最小代码示例

```python
price = 12
count = 3
total = price * count - 5
print(total)
```

## 3～5 分钟练习

把 125 分钟换算成小时和剩余分钟。

## 参考答案

```python
minutes = 125
print(minutes // 60, minutes % 60)
```
