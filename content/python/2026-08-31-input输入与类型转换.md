# 第 2 课：input 输入与类型转换

- 日期：2026-08-31
- 课程序号：第 2 课
- 知识点：使用 `input()` 接收文本，并用 `int()`、`float()` 转换类型

## 知识点

从终端读取用户输入，把默认得到的字符串转换成数字，再参与简单计算。

## 用途

交互式脚本需要接收姓名、数量、价格等输入。明确输入的类型，才能正确完成加减乘除，而不是把文本直接拼接起来。

## 核心概念

- `input()` 会暂停程序并返回用户输入的字符串。
- `int(text)` 把整数文本转换成整数，`float(text)` 把小数文本转换成浮点数。
- 转换后的数字才能进行数值计算。
- 输入内容不符合目标类型时会抛出 `ValueError`，后续课程再学习如何处理异常。

## 最小代码示例

```python
name = input("你的名字：")
minutes_text = input("今天学习多少分钟：")
minutes = int(minutes_text)

print(f"{name} 今天学习 {minutes} 分钟")
print(f"两天共学习 {minutes * 2} 分钟")
```

## 3～5 分钟练习

读取商品单价和数量，把单价转换为 `float`、数量转换为 `int`，然后输出总价。

## 参考答案

```python
price = float(input("商品单价："))
count = int(input("购买数量："))
total = price * count

print(f"总价：{total} 元")
```
