# 第 39 课：为格式化断言补充失败消息

- 日期：2026-10-30
- 课程序号：第 39 课
- 知识点：assert的第二个表达式

## 用途或适用场景

为格式化断言补充失败消息，用于在已有示例中练习assert的第二个表达式。

## 核心概念

assert 条件, 消息在条件为假时把消息交给AssertionError。用消息描述独立用例即可定位；它不改变格式化函数，也不替代业务校验。

## 最小代码或操作示例

保留第37课三个期望，用以下内容替换第38课检查函数，函数外原调用与完成提示保留：

```python
def check_format_valid_lines():
    assert format_valid_lines([]) == "暂无有效学习条目", "empty：空列表提示"
    assert format_valid_lines(["1. Go"]) == "有效条目：1\n1. Go", "single：单行文本"
    assert format_valid_lines(["1. Python", "  2. Rust"]) == (
        "有效条目：2\n1. Python\n  2. Rust"
    ), "leading-space：保留Rust前两个空格"
```

字符串内保留反斜杠n；正常python3运行，不加-O。

## 3～5 分钟练习

在副本删掉第三项期望里的两个空格，失败信息应定位到哪项？随后恢复。

## 参考答案

应出现leading-space及AssertionError，完成提示不应执行。恢复后重新调用检查函数；消息不是新的正确值来源。
