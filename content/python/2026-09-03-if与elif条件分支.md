# 第 5 课：if与elif条件分支

- 日期：2026-09-03
- 课程序号：第 5 课
- 知识点：缩进代码块与从上到下的条件选择

## 用途

根据分数输出一条评价。

## 核心概念

- if 判断条件；elif 只在前面的条件不成立时继续判断；else 接住剩余情况。
- Python 用缩进划分代码块。同一条条件链只执行第一个命中的分支。

## 最小代码或操作示例

```python
score = 75
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("继续练习")
```

## 3～5 分钟练习

依次把 score 改成 59、60、90，先预测再运行；解释为什么 >=90 应放在 >=60 前面。

## 参考答案

```text
59 输出“继续练习”，60 输出“及格”，90 输出“优秀”。若先判断 >=60，90 也会命中，后面的优秀分支不会执行。
```
