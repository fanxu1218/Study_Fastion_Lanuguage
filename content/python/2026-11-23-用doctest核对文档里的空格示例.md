# 第 55 课：用doctest核对文档里的空格示例

- 日期：2026-11-23
- 课程序号：第 55 课
- 知识点：标准库doctest执行文档中的交互示例

## 用途或适用场景

把第54课独立期望写进纯函数文档，并自动核对示例输出。

## 核心概念

doctest识别文档字符串中的>>>调用并比较紧随其后的预期输出；默认空格有意义。保留原四项回归，本课文档示例不计入那四项。

## 最小代码或操作示例

在formatter.py的format_valid_lines原文档字符串内、结束三引号前加入以下内容，保持所示缩进；原函数体不改：
```python
    >>> print(format_valid_lines(["1. Python", "  2. Rust"]))
    有效条目：2
    1. Python
      2. Rust
```
在同目录正常执行，不用-O/-OO，也不启用NORMALIZE_WHITESPACE：
```sh
python3 -m doctest -v formatter.py
python3 check_contract.py
python3 run_checks.py
```
第一条应显示1个文档示例通过，后两条仍分别完成独立契约与原4项。Rust前两格是预期输出自身的一部分，不能与文档整体缩进一起删掉。

## 3～5 分钟练习

只在文档预期输出中删去Rust前两个空格，再运行doctest会怎样？随后恢复并回归。

## 参考答案

doctest报告期望与实际不同并以非零退出；函数仍保留原空格。恢复文档示例后1项通过，原四项及check_contract.py仍通过。
