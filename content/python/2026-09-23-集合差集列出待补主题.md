# 第 19 课：集合差集列出待补主题

- 日期：2026-09-23
- 课程序号：第 19 课
- 知识点：集合差集

## 用途或适用场景

在子集判断失败后，列出学习计划中尚未覆盖的主题。

## 核心概念

`week_b - week_a` 只保留 `week_b` 中存在、`week_a` 中不存在的元素；差集生成新集合，不改变原集合。

## 最小代码或操作示例

```python
week_a = {"函数", "集合", "文件"}
week_b = {"集合", "文件", "异常"}
missing = week_b - week_a
print(missing)  # {'异常'}
```

## 3～5 分钟练习

把“测试”加入 `week_b`，打印待补主题。

## 参考答案

执行 `week_b.add("测试")` 后再计算 `week_b - week_a`，结果包含“异常”和“测试”；集合输出顺序不固定。

## 与上一课的联系

沿用第 18 课的 `week_a`、`week_b`；上课用 `==` 判断主题是否完全相同，本课只新增 `-` 列出 `week_b` 中尚未覆盖的主题；下一课可检查待补主题与已完成主题是否完全不相交。
