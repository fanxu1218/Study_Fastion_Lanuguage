- 日期：2026-10-27

## 用途或适用场景

让清单格式化函数返回文本，让本次练习的结果可以按同一条件复查。

## 核心概念

return把结果交给调用方；函数内部不再print。数量与原行仍只从本次列表计算，文件读取和有效行筛选沿旧流程。

## 最小代码或操作示例

用下列定义替换第34课show_valid_lines；将原show_valid_lines(valid_lines)改为print(format_valid_lines(valid_lines))。移除第35课临时调用或同步改用新名称：

```python
def format_valid_lines(valid_lines):
    valid_count = len(valid_lines)
    if valid_count == 0:
        return "暂无有效学习条目"
    text = f"有效条目：{valid_count}"
    for line in valid_lines:
        text += f"\n{line}"
    return text

first_lines = ["1. Python", "  2. Rust"]
result = format_valid_lines(first_lines)
print(result)
print(format_valid_lines([]))
```

result是生成时的字符串，不会随着列表后续变化自动重算。这里不写文件。

## 3～5 分钟练习

只执行result = format_valid_lines(["1. Go"])而不print，函数会向终端输出内容吗？

## 参考答案

不会。result保存“有效条目：1
1. Go”；调用方决定何时print。空列表返回原零条提示，两条列表的前导空格保留。
