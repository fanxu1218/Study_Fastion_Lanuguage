# 第 45 课：用可见表示定位格式化空格差异

- 日期：2026-11-09
- 课程序号：第 45 课
- 知识点：f字符串的repr转换

## 用途或适用场景

在四行格式化表失败时看清换行和边缘空格。

## 核心概念

f字符串中的!r使用repr表示值，使字符串引号和换行转义可见。它只改变诊断文本，不修改actual或expected，也不trim输入。

## 最小代码或操作示例

保留第43课循环及第44课四行表。在check_format_valid_lines内用下列断言替换原一行消息，actual仍只求值一次：
```python
        assert actual == expected, (
            f"{name}：actual={actual!r}, expected={expected!r}"
        )
```
保留循环后的return len(format_cases)、函数外一次调用和固定数量4。正常python3运行，不用-O。只在个人反例副本临时删去trailing-space期望的末尾空格，观察后恢复。

## 3～5 分钟练习

错误期望删去末尾空格后，消息中两份文本的结尾应有什么区别？

## 参考答案

actual的Go后还有空格再接结束引号，expected没有该空格；两边换行显示为反斜杠n。恢复原期望后四项应完成。
