# 第 43 课：遍历固定表执行格式化检查

- 日期：2026-11-05
- 课程序号：第 43 课
- 知识点：解包每行并执行同一断言

## 用途或适用场景

让第42课准备的数据表真正驱动原三项检查。

## 核心概念

for按行取出名称、输入和期望，每行调用一次被测函数。return放在循环之后；调用方仍独立要求3项，避免表被误删后悄悄缩小覆盖。

## 最小代码或操作示例

保留第42课format_cases和原format_valid_lines。用下列函数替换原check_format_valid_lines的三条手写断言：

```python
def check_format_valid_lines():
    for name, lines, expected in format_cases:
        actual = format_valid_lines(lines)
        assert actual == expected, f"{name}：格式化结果不符"
    return len(format_cases)
```

第41课函数外一次调用、固定数量期望3与完成提示保持。三个固定期望不改，尤其保留Rust前两个空格；正常python3运行，不使用-O。

## 3～5 分钟练习

把return缩进到循环体内，会留下什么问题？

## 参考答案

第一行之后立即返回，后两行不执行；返回数量仍可能是3，因此必须同时核对循环和return位置，不能只看数量提示。
