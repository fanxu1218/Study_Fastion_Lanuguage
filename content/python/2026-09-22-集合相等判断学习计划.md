# 第 18 课：集合相等判断学习计划

- 日期：2026-09-22
- 课程序号：第 18 课
- 知识点：集合的值相等判断

## 用途或适用场景

在确认两组学习主题的包含关系后，判断它们是否恰好相同。

## 核心概念

`==` 比较集合的元素，不比较书写顺序；两边元素完全相同时才为 `True`。

## 最小代码或操作示例

```python
week_a = {"函数", "集合", "文件"}
week_b = {"集合", "文件", "异常"}
print(week_a == week_b)  # False
```

## 3～5 分钟练习

把 `week_b` 改成与 `week_a` 相同的三个主题，但调整书写顺序，再输出比较结果。

## 参考答案

```python
week_b = {"文件", "函数", "集合"}
print(week_a == week_b)  # True
```

## 与上一课的联系

沿用第 17 课的 `week_a`、`week_b`；上一课用 `<=` 检查包含关系，本课只新增 `==` 检查是否完全相同；若结果为 `False`，下一课可列出 `week_b` 中尚未包含在 `week_a` 的主题。
