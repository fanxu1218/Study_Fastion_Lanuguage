# 第 49 课：把纯格式化函数移入独立模块

- 日期：2026-11-13
- 课程序号：第 49 课
- 知识点：用from导入同目录函数

## 用途或适用场景

让第48课检查入口复用同一份纯函数定义。

## 核心概念

同目录.py文件可以作为模块；from导入指定函数名。模块顶层语句会在首次导入时执行，所以纯函数模块只保留原定义，不放测试调用。

## 最小代码或操作示例

沿第47课四行表和第48课入口，在新个人目录保留原文件副本：
```text
formatter.py：只移入原format_valid_lines完整定义，函数体不改，不放检查或print。
format_checks.py：保留format_cases、check_format_valid_lines及test_format_valid_lines。
从format_checks.py删除已移动的那份函数定义；末尾保留一次test_format_valid_lines()。
```
在format_checks.py开头加入：
```python
from formatter import format_valid_lines
```
在两文件所在目录正常运行python3 format_checks.py，应仍输出4项格式化检查完成。不用-O，不安装框架，不命名为python.py或覆盖已有文件。

## 3～5 分钟练习

若formatter.py末尾也放一次test_format_valid_lines()，导入就会只注册而不执行吗？

## 参考答案

不会只注册，顶层调用会执行，而且纯函数模块没有该检查定义。把测试表和调用留在format_checks.py，formatter.py只保留原纯函数。
