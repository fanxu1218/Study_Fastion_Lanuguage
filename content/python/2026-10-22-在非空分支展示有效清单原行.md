# 第 33 课：在非空分支展示有效清单原行

- 日期：2026-10-22
- 课程序号：第 33 课
- 知识点：分支内遍历派生列表

## 用途或适用场景

在保留零条提示的同时查看真实清单文本。

## 核心概念

for 读取 valid_lines 的原行，顺序与首尾空格保持不变；数量仍由 len 派生，不根据显示编号计数。

## 最小代码或操作示例

用下面代码替换第 32 课展示分支，前面的读回、拆行、筛选与 valid_count 不变：

```python
if valid_count == 0:
    print("暂无有效学习条目")
else:
    print(f"有效条目：{valid_count}")
    for line in valid_lines:
        print(line)
```

不再执行旧展示分支，避免重复输出；print 的换行不写回文件。

## 3～5 分钟练习

在内存副本用 "1. Python\n   \n  2. Rust\n" 与全空白文本，重新执行原拆行/筛选/计数和展示。

## 参考答案

前者先输出数量2，再输出两条原行，第二条前面两个空格保留；后者只输出暂无有效学习条目。文件读取失败仍报告原异常。
