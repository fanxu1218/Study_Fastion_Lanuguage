# 第 21 课：排序展示待补主题

- 日期：2026-09-28
- 课程序号：第 21 课
- 知识点：`sorted()`

## 用途或适用场景

把集合中的待补主题按固定顺序展示，避免每次输出顺序不同。

## 核心概念

`sorted(missing)` 返回新的列表，不改变原集合；这里的字符串按默认比较顺序排列，并非中文拼音排序。

## 最小代码或操作示例

```python
week_a = {"函数", "集合", "文件"}
week_b = {"集合", "文件", "异常", "测试"}
missing = week_b - week_a
assert missing.isdisjoint(week_a)
print(sorted(missing))  # ['异常', '测试']
```

## 3～5 分钟练习

把“部署”加入 `week_b`，重新计算并打印排序后的待补主题。

## 参考答案

```python
week_b.add("部署")
missing = week_b - week_a
print(sorted(missing))  # ['异常', '测试', '部署']
```
