# 第 51 课：从另一个模块显式调用检查

- 日期：2026-11-17
- 课程序号：第 51 课
- 知识点：导入模块后使用限定名称调用

## 用途或适用场景

复用第50课已保护的检查入口。

## 核心概念

import加载模块定义；模块名.函数名明确调用来源。主模块保护不阻止调用方主动执行函数。

## 最小代码或操作示例

保留formatter.py和format_checks.py原四行表、检查函数及入口保护。在同目录新建未存在的run_checks.py：
```python
import format_checks

if __name__ == "__main__":
    format_checks.test_format_valid_lines()
```
运行python3 run_checks.py，应输出一次4项格式化检查完成；python3 -c "import run_checks"应无输出。正常运行，不用-O，不复制检查实现。

## 3～5 分钟练习

将显式调用放到入口保护外，导入run_checks会怎样？

## 参考答案

导入时会执行该顶层调用；把调用留在保护内，定义仍可显式复用。
