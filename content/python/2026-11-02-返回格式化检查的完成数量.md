# 第 40 课：返回格式化检查的完成数量

- 日期：2026-11-02
- 课程序号：第 40 课
- 知识点：所有断言之后的return值

## 用途或适用场景

在原清单检查入口向调用方返回完成数量。

## 核心概念

检查函数可在三项断言都完成后返回数量。return放在中间会提前结束函数；数量来自本课固定三项清单，不能单凭返回3证明断言执行。

## 最小代码或操作示例

保留第38课显式入口及第39课三个带消息断言；只在函数最后增加return，并替换函数外原调用和完成提示：

```python
def check_format_valid_lines():
    assert format_valid_lines([]) == "暂无有效学习条目", "empty：空列表提示"
    assert format_valid_lines(["1. Go"]) == "有效条目：1\n1. Go", "single：单行文本"
    assert format_valid_lines(["1. Python", "  2. Rust"]) == (
        "有效条目：2\n1. Python\n  2. Rust"
    ), "leading-space：保留Rust前两个空格"
    return 3

checked_count = check_format_valid_lines()
print(f"{checked_count}项格式化检查完成")
```

第36课format_valid_lines与原文件流程不变；字符串保留反斜杠n，正常python3运行，不加-O。

## 3～5 分钟练习

只把return 3移到第一项断言之前，打印3能证明什么？

## 参考答案

只能证明返回了3，三项均没运行。恢复到全部断言之后；故意改错第三项期望仍应失败且不打印完成。
