# 第 30 课：把有效清单行收集到新列表

- 日期：2026-10-16
- 课程序号：第 30 课
- 知识点：条件筛选后 append 原始行

## 用途或适用场景

从上一课 saved_lines 派生非空白记录，保留原清单供核对。

## 核心概念

复用 strip 的空白判断；append 保存原 line，避免连带改掉缩进或首尾格式。新列表只是本次读取的处理结果，不写回 plan.txt，也不在本课重编号。

## 最小代码或操作示例

接在原 saved_lines = saved_text.splitlines() 后：

```python
valid_lines = []
for line in saved_lines:
    if line.strip() != "":
        valid_lines.append(line)
print(valid_lines)
```

保留原 UTF-8 读取步骤和 saved_lines。

## 3～5 分钟练习

在内存副本使用 `"1. Python\n   \n  2. Rust\n"`，再测试空文本；比较两个列表，不改磁盘文件。

## 参考答案

valid_lines 为 ["1. Python", "  2. Rust"]，第二行前的两个空格保留；saved_lines 仍有空白项。空文本得到空列表。
