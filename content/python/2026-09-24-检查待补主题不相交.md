- 日期：2026-09-24

- 知识点：`set.isdisjoint()`

## 用途或适用场景

核对待补主题是否确实没有出现在已完成的学习计划里。

## 核心概念

两个集合没有共同元素时，`isdisjoint()` 返回 `True`；它不修改任何一个集合。

## 最小代码或操作示例

```python
week_a = {"函数", "集合", "文件"}
week_b = {"集合", "文件", "异常"}
missing = week_b - week_a
print(missing.isdisjoint(week_a))  # True
print(missing.isdisjoint(week_b))  # False
```

## 3～5 分钟练习

把“测试”加入 `week_b`，重新计算 `missing`，再检查它与 `week_a` 是否不相交。

## 参考答案

```python
week_b.add("测试")
missing = week_b - week_a
print(missing.isdisjoint(week_a))  # True
```
