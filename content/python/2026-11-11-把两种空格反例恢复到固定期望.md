# 第 47 课：把两种空格反例恢复到固定期望

- 日期：2026-11-11
- 课程序号：第 47 课
- 知识点：反例结束后的原表回归

## 用途或适用场景

结束第45、46课诊断练习，恢复原四行检查起点。

## 核心概念

反例中的错误期望只用于观察消息；回归起点必须保留输入原文，四行内容比较和固定数量检查分别完成。

## 最小代码或操作示例

沿第45课!r消息和第46课前导反例，恢复format_cases中的两行：
```python
    ("leading-space", ["1. Python", "  2. Rust"],
     "有效条目：2\n1. Python\n  2. Rust"),
    ("trailing-space", ["1. Go "], "有效条目：1\n1. Go "),
```
保留empty/single两行、原format_valid_lines、check_format_valid_lines中单次actual及循环后return。正常python3运行，不用-O，要求原四项完成及checked_count == 4。

## 3～5 分钟练习

前导行恢复后完成数4，但末尾期望仍少空格，是否可能正常完成？

## 参考答案

在原断言启用且四行实际执行时不应正常完成；末尾行应失败。确认未用-O且未把return提前，再恢复空格。

## 与上一课的联系

继承第45课可见表示和第46课前导反例；本课只把两行恢复为独立正确期望并回归四项。下一课可将这份已恢复表交给一个独立测试函数调用。
