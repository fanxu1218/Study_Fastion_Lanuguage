# 第 38 课：把三项格式化断言收进检查函数

- 日期：2026-10-29

## 用途或适用场景

把三项格式化断言收进检查函数，用于在已有示例中验证函数调用与验证入口。

## 核心概念

定义检查函数不会自动运行其中断言，必须显式调用。把三项检查收在一个入口中，可在演示前验证返回文本；生产格式化函数仍不打印。

## 最小代码或操作示例

保留第36课format_valid_lines，用以下内容替换第37课文件末尾的三项断言与完成提示；原读文件流程保留：

```python
def check_format_valid_lines():
    assert format_valid_lines([]) == "暂无有效学习条目"
    assert format_valid_lines(["1. Go"]) == "有效条目：1\n1. Go"
    assert format_valid_lines(["1. Python", "  2. Rust"]) == (
        "有效条目：2\n1. Python\n  2. Rust"
    )

check_format_valid_lines()
print("三项格式化检查完成")
```

运行正常python3命令，不加-O。缩进中的三项属于函数体，最后两行在函数外；字符串中保留反斜杠n。

## 3～5 分钟练习

只保留函数定义，去掉最后的调用，运行无报错是否代表检查通过？

## 参考答案

不能；断言没有执行。恢复显式调用后，故意删掉第三项期望中Rust前的空格，应失败且不打印完成；恢复后再运行。
