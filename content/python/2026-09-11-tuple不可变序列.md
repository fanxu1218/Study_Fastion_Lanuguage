# 第 11 课：tuple不可变序列

- 日期：2026-09-11
- 课程序号：第 11 课
- 知识点：元组创建与解包

## 用途

保存一组创建后不应修改的固定数据。

## 核心概念

元组有顺序但不可原地增删，可通过解包把位置映射到变量。

## 最小代码或操作示例

```python
lesson = ("Python", 5)
title, minutes = lesson
print(title, minutes)
```

## 3～5 分钟练习

创建三元素元组并解包。

## 参考答案

例如 `name, level, done = ("列表", 1, False)`。

## 与上一课的联系
