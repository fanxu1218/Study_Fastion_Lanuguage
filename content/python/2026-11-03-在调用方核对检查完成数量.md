# 第 41 课：在调用方核对检查完成数量

- 日期：2026-11-03
- 课程序号：第 41 课
- 知识点：返回值的独立固定期望

## 用途或适用场景

发现检查入口意外返回了错误数量。

## 核心概念

调用方应把返回值与固定清单数量比较，然后才打印完成提示。它与函数内部三项内容断言职责不同，数量正确仍不能代替内容检查。

## 最小代码或操作示例

沿第39课三项消息断言和第40课return 3，保留check_format_valid_lines函数全文，只替换函数外原调用与提示：

```python
checked_count = check_format_valid_lines()
assert checked_count == 3, f"完成数量不符：期望3，实际{checked_count}"
print(f"{checked_count}项格式化检查完成")
```

继续使用第36课format_valid_lines和原文件流程；正常python3运行，不使用-O，函数只调用一次。

## 3～5 分钟练习

只把函数最后的return 3临时改成return 2，会在哪一步失败？完成后恢复。

## 参考答案

内部三项仍完成，但调用方数量断言抛AssertionError，完成提示不执行。恢复3后再运行；不能删除内部断言。
