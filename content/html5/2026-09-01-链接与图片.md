# 第 2 课：链接与图片

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：`a`、`img`、相对路径与替代文本

## 用途

链接连接页面和资源，图片提供视觉信息，替代文本改善可访问性。

## 核心概念

- `<a href="...">` 创建链接。
- `<img src="..." alt="...">` 嵌入图片并描述内容或用途。
- 相对路径以当前文档位置为基准。

## 最小代码示例

```html
<a href="courses.html">查看课程</a>
<img src="images/python-logo.png" alt="Python 路线标志">
```

## 3～5 分钟练习

创建返回首页的链接，并添加一张带有意义 `alt` 的课程封面。

## 参考答案

```html
<a href="index.html">返回首页</a>
<img src="images/course-cover.jpg" alt="编程课程封面">
```
