# 第 21 课：有效提交后追加练习记录

- 日期：2026-09-29
- 课程序号：第 21 课
- 知识点：有效提交后的 DOM 追加

## 用途或适用场景

校验通过后把练习时长追加到页面，不重新加载文档。

## 核心概念

继续使用第 20 课 form、input、error；不引入未定义的 name/minutes。统一在 submit 中 preventDefault，再按已有 reportValidity 区分失败与成功；本课只在成功分支追加列表项。

## 最小代码或操作示例

```html
<!-- 保留第 20 课原表单和错误区域，表单之后新增： -->
<ul id="records"></ul>
<script>
// 替换第 20 课原 script；同一表单只注册一个 submit 处理器。
const form = document.querySelector('#lessonForm');
const input = document.querySelector('#minutes');
const error = document.querySelector('#minutes-error');
const records = document.querySelector('#records');
form.addEventListener('submit', event => {
  event.preventDefault();
  if (!form.reportValidity()) {
    input.setAttribute('aria-invalid', 'true');
    input.setAttribute('aria-errormessage', 'minutes-error');
    error.hidden = false;
    return;
  }
  const li = document.createElement('li');
  li.textContent = `${input.value} 分钟`;
  records.append(li);
});
input.addEventListener('input', () => {
  input.removeAttribute('aria-invalid');
  input.removeAttribute('aria-errormessage');
  error.hidden = true;
});
</script>
```

## 3～5 分钟练习

提交 0 和 5，观察列表与错误区域。

## 参考答案

0 不新增记录并显示原错误；5 追加“5 分钟”；本课暂不清空输入，也不再次注册旧 submit 处理器。

## 与上一课的联系

继承第 20 课 form/input/error 与失败分支；本课只增加 records 及成功追加；下一课在 records.append(li) 后调用 form.reset。
