# 第 7 课：select下拉选择

- 日期：2026-09-08
- 课程序号：第 7 课
- 知识点：select、option 与 label

## 用途

让用户从有限选项中选择每日练习时长。

## 核心概念

`label` 的 `for` 对应 `select` 的 `id`；提交表单时发送被选中 `option` 的 `value`。

## 最小代码或操作示例

```html
<label for="minutes">练习时长</label>
<select id="minutes" name="minutes">
  <option value="5">5 分钟</option>
  <option value="10">10 分钟</option>
</select>
```

## 3～5 分钟练习

增加“15 分钟”选项，并让它成为默认值。

## 参考答案

添加 `<option value="15" selected>15 分钟</option>`。

## 与上一课的联系

上一课用输入类型约束自由填写的数据；本课用固定选项进一步减少无效输入。
