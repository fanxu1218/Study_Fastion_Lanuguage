# 第 15 课：input时清除自定义消息

- 日期：2026-09-18
- 课程序号：第 15 课
- 知识点：input时清除自定义消息

## 用途或适用场景

用户重新编辑后立即清除上一次业务校验消息。

## 核心概念

setCustomValidity('') 清空自定义错误；浏览器原生 required、min 等约束仍继续生效。

## 最小代码或操作示例

```text
const input = document.querySelector('#minutes');
input.addEventListener('input', () => input.setCustomValidity(''));
```

## 3～5 分钟练习

输入变化后再调用 checkValidity。

## 参考答案

在监听器末尾加入 `input.checkValidity();`。

## 与上一课的联系

继承上一课的 checkValidity 主动检查；本课只在重新输入时清除旧消息；完成后下一课可在提交时调用 reportValidity。
