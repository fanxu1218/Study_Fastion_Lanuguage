# 第 22 课：追加记录后重置表单

- 日期：2026-09-30
- 课程序号：第 22 课
- 知识点：HTMLFormElement.reset

## 用途或适用场景

成功追加后恢复表单默认值，失败时保留输入。

## 核心概念

在同一个成功分支读取 input.value、追加记录后再 reset；form 是上一课 querySelector 得到的同一表单对象，不使用元素 ID 作为隐式全局变量。

## 最小代码或操作示例

```js
// 替换第 21 课成功分支的末尾；其余处理器保持：
const li = document.createElement('li');
li.textContent = `${input.value} 分钟`;
records.append(li);
form.reset();
```

## 3～5 分钟练习

提交 5，查看输入框和列表；再输入 0 提交。

## 参考答案

列表保留“5 分钟”，成功后输入恢复默认空值；失败分支不会 reset，0 保留供修改。

## 与上一课的联系

继承第 21 课 input、form、records 与成功追加；本课只加 form.reset；下一课用同一个 input 对象把焦点移回字段。
