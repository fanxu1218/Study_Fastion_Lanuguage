# 第 29 课：从记录数量派生空列表说明

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：HTMLElement.hidden

## 用途或适用场景

删除最后一项后显示“暂无练习记录”，添加后自动隐藏。

## 核心概念

空说明由 records.childElementCount 派生，不另存布尔业务状态。说明放在 ul 外；hidden 控制是否呈现，不把状态消息区域隐藏。

## 最小代码或操作示例

在原 ul#records 旁新增：

```html
<p id="empty-hint">暂无练习记录</p>
```

在原脚本取得 records 后追加：

```js
const emptyHint = document.getElementById('empty-hint');
function refreshEmptyHint() {
  emptyHint.hidden = records.childElementCount !== 0;
}
refreshEmptyHint();
```

在原 records.append(li) 后、以及第 28 课 li.remove() 后各调用一次 refreshEmptyHint()。原数量消息、校验、reset 和 focus 保留；不要给每行再创建空说明。

## 3～5 分钟练习

从空列表添加两项、逐项删除，再提交一个无效输入；核对空说明和状态消息。

## 参考答案

空说明依次显示、隐藏、隐藏、显示；无效输入不改变列表或说明。ul 内始终只放记录 li，数量读取保持原意义。
