# 第 3 课：有序与无序列表

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：ul、ol 与 li

## 用途

表达材料清单和有先后关系的操作步骤。

## 核心概念

- ul 表示无序集合，ol 表示有序步骤。
- 每个条目放在 li 中；编号由浏览器生成，不必写进文本。

## 最小代码或操作示例

```html
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<title>学习计划</title>
<h1>今日学习</h1>
<ul><li>笔记本</li><li>浏览器</li></ul>
<ol><li>阅读课程</li><li>完成练习</li></ol>
</html>
```

## 3～5 分钟练习

给步骤列表增加“核对答案”，并让工具清单增加“编辑器”。

## 参考答案

```html
<ul><li>笔记本</li><li>浏览器</li><li>编辑器</li></ul>
<ol><li>阅读课程</li><li>完成练习</li><li>核对答案</li></ol>
```
