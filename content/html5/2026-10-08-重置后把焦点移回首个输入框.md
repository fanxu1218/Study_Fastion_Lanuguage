# 第 23 课：重置后把焦点移回首个输入框

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：HTMLElement.focus

## 用途或适用场景

追加并重置后，让下一次录入从原时长输入开始。

## 核心概念

在上一课同一个成功分支中，使用已定义 input 引用 focus。不写未声明的 lessonForm/minutes 变量，不依赖浏览器按 ID 建立隐式全局名。

## 最小代码或操作示例

```js
// 第 22 课 records.append(li) 后：
form.reset();
input.focus();
```

## 3～5 分钟练习

提交 5，再直接输入 10，观察当前焦点。

## 参考答案

第一条记录保留；reset 后焦点回到 input，即 id=minutes 的时长字段；下一次输入无需再次点击字段。

## 与上一课的联系

继承第 22 课 form.reset 与第 21 课 input 引用；本课只加 input.focus；下一课在成功分支更新常驻状态区，焦点仍留给输入。
