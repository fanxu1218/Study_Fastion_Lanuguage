# 第 24 课：礼貌播报新增练习记录

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：aria-live="polite"

## 用途或适用场景

把成功追加的结果交给辅助技术在合适时机呈现，避免主动移动焦点到消息。

## 核心概念

状态区域预先存在；写入状态文字必须在 form.reset 前读取本次 input.value。aria-live 是呈现提示，不保证所有辅助技术在同一时机或次数播报。

## 最小代码或操作示例

```html
<!-- 放在原表单之后，页面初始就存在： -->
<p id="status" aria-live="polite"></p>
<script>
// 在第 21 课脚本的查询区新增：
const status = document.querySelector('#status');
// 在同一个 submit 成功分支 records.append(li) 后、form.reset 前新增：
status.textContent = `已添加 ${input.value} 分钟`;
// 继续执行 form.reset(); input.focus();
</script>
```

## 3～5 分钟练习

有效提交 20，记录状态文字与焦点；用屏幕阅读器记录实际播报。

## 参考答案

可见状态为“已添加 20 分钟”；焦点仍在 input。若未开启或未测试辅助技术，朗读结果应写未验证。

## 与上一课的联系

继承第 23 课成功追加、form.reset 与 input.focus；本课只增加预先存在的 status 礼貌区域并更新文字；下一课将状态区拆成前缀和详情，要求整体呈现。
