# 第 8 课：checkbox多项选择

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：checkbox 与表单值

## 用途

让用户从多个互不排斥的学习主题中选择任意多项。

## 核心概念

同名复选框可以提交多个值；每个输入都应由对应的 `label` 提供可点击说明。

## 最小代码或操作示例

```html
<label><input type="checkbox" name="topic" value="html"> HTML</label>
<label><input type="checkbox" name="topic" value="css"> CSS</label>
```

## 3～5 分钟练习

增加 JavaScript 选项，并让 HTML 默认选中。

## 参考答案

为 HTML 输入添加 `checked`，再加入值为 `js` 的同名复选框。

## 与上一课的联系

上一课用 `select` 从有限选项中选一个；本课允许同时选择多个独立选项。
