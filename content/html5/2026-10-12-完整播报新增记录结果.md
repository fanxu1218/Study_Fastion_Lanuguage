# 第 25 课：完整播报新增记录结果

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：aria-atomic="true"

## 用途或适用场景

只更新详情片段时也让辅助技术获得状态前缀和完整结果。

## 核心概念

状态区仍用上一课同一个 id=status；增加 atomic 和详情 span。只更新 statusDetail，保留前缀；标准允许合并变化，不能把 atomic 写成朗读次数保证。

## 最小代码或操作示例

```html
<!-- 替换第 24 课的状态区域： -->
<p id="status" aria-live="polite" aria-atomic="true">
  练习结果：<span id="status-detail"></span>
</p>
<script>
// 将上一课 const status 替换为：
const statusDetail = document.querySelector('#status-detail');
// 同一成功分支中，将 status.textContent 更新替换为：
statusDetail.textContent = `已添加 ${input.value} 分钟`;
// 更新仍放在 form.reset(); input.focus(); 之前。
</script>
```

## 3～5 分钟练习

提交 20，用屏幕阅读器核对更新详情时是否包含“练习结果”前缀，记录实际结果。

## 参考答案

可见区域为“练习结果：已添加 20 分钟”；期望整体呈现，实际组合需测试；不是只宣布“20”。

## 与上一课的联系

继承第 24 课同一 status 区域与成功分支更新时机；本课只增加 atomic 并演示详情片段变化；下一课给这个结果区声明 status 角色。
