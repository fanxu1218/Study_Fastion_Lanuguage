# 第 27 课：为已实现的可选详情增加断言

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：实现分支的固定期望测试对象

## 用途或适用场景

补齐 DetailText 的已实现分支，避免只检查默认详情。

## 核心概念

测试对象显式实现协议和可选方法，返回已知固定文字；断言比较独立的期望字符串。保留上一课未实现对象的检查，两个分支都必须真正执行。

## 最小代码或操作示例

在协议与 DetailText 已声明之后、main 外增加专用教学对象：

```objective-c
@interface DetailFixture : NSObject <LessonSummarizing>
@end
@implementation DetailFixture
- (NSString *)displaySummary { return @"测试课程"; }
- (NSString *)detailText { return @"基础说明"; }
@end
```

在原 main 自动释放池中、上一课断言之后追加：

```objective-c
id<LessonSummarizing> detailed = [[DetailFixture alloc] init];
NSCAssert([detailed respondsToSelector:@selector(detailText)],
          @"测试对象必须实现可选方法");
NSCAssert([DetailText(detailed) isEqualToString:@"基础说明"],
          @"应保留实现者返回的详情");
```

Debug 构建且不定义 NS_BLOCK_ASSERTIONS，源文件仍导入 Foundation。

## 3～5 分钟练习

运行原缺失分支与本课断言；在副本把测试对象返回值改成“其他说明”，检查失败后恢复。

## 参考答案

原期望通过，修改实现者返回值后最后一个断言失败；默认详情检查仍独立运行。不要用“函数等于它自己的返回值”代替固定期望。
