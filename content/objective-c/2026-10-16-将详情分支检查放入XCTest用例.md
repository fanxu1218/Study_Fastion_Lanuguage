# 第 28 课：将详情分支检查放入XCTest用例

- 日期：2026-10-16
- 课程序号：第 28 课
- 知识点：XCTestCase 与 test 方法

## 用途或适用场景

让 DetailText 的缺失/已实现分支分别出现在测试报告中。

## 核心概念

Objective-C 继续使用 XCTest；Xcode16+ 的 Swift Testing 建议针对 Swift，不将其 API 混入本课。test 方法无参数、返回 void，XCTAssertEqualObjects 比较对象内容并记录失败。

## 最小代码或操作示例

先在练习项目把原协议声明移入 LessonDetails.h，并加入函数声明（不重复定义协议）：

```objective-c
#import <Foundation/Foundation.h>
@protocol LessonSummarizing <NSObject>
@property (nonatomic, readonly) NSString *displaySummary;
@optional
- (NSString *)detailText;
@end
NSString *DetailText(id<LessonSummarizing> item);
```

将第 25 课原 DetailText 函数原样移到 LessonDetails.m，文件导入该头；原 main 改为导入该头。新增 Objective-C Unit Testing Bundle，选择无 Host Application，将 LessonDetails.m 加入测试 target 一次，含 main 的文件不加入。

在测试 target 的 DetailTextTests.m 编写；DetailFixture 沿用第 27 课实现，移到此文件并导入 LessonDetails.h：

```objective-c
#import <XCTest/XCTest.h>
#import "LessonDetails.h"

@interface NoDetailFixture : NSObject <LessonSummarizing>
@end
@implementation NoDetailFixture
- (NSString *)displaySummary { return @"测试课程"; }
@end

@interface DetailTextTests : XCTestCase
@end
@implementation DetailTextTests
- (void)testMissingDetail {
    XCTAssertEqualObjects(DetailText([[NoDetailFixture alloc] init]), @"暂无详情");
}
- (void)testImplementedDetail {
    XCTAssertEqualObjects(DetailText([[DetailFixture alloc] init]), @"基础说明");
}
@end
```

DetailFixture 的完整声明/实现放在上述测试类之前。用 Product > Test 运行；每个二进制只编译一份 DetailText。

## 3～5 分钟练习

运行两项，再只把已实现分支的期望改为“其他说明”，观察独立失败后恢复。

## 参考答案

原期望两项通过；改错只使 testImplementedDetail 失败。缺少测试 target、符号链接失败或未实际运行时，不能把普通编译记成测试通过。
