# 第 25 课：把可选详情读取提取为函数

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：协议参数的函数提取

## 用途或适用场景

在多个展示位置复用同一可选方法检查与默认详情规则。

## 核心概念

函数接收既有 `id<LessonSummarizing>`，返回上一课已经确定的详情文字。可选方法的能力检查仍在真正调用之前执行。未实现方法时显示默认详情；实现者返回的内容保持原样。

## 最小代码或操作示例

保留既有 `LessonSummarizing <NSObject>` 协议和 `@optional - (NSString *)detailText;`，在协议声明后、`main` 外增加函数，再更新原 `PrintAll`：

```objective-c
NSString *DetailText(id<LessonSummarizing> item) {
    return [item respondsToSelector:@selector(detailText)]
        ? [item detailText] : @"暂无详情";
}

void PrintAll(NSArray<id<LessonSummarizing>> *items) {
    for (id<LessonSummarizing> item in items) {
        NSLog(@"%@ | %@", item.displaySummary, DetailText(item));
    }
}
```

在已有入口继续 `PrintAll(items);`，`items` 仍包含前两课的 `Lesson` 与 `LessonCard`。只保留一份 `PrintAll` 定义。

## 3～5 分钟练习

保持一个对象实现 `detailText`、另一个不实现，运行同一个 `PrintAll(items)`；再让第二个展示位置直接调用 `DetailText(item)`。

## 参考答案

实现者显示其方法返回值，未实现者显示“暂无详情”；两个位置遵循同一规则，摘要 `displaySummary` 不受影响。
