# 第 26 课：为默认详情建立函数断言

- 日期：2026-10-14
- 课程序号：第 26 课
- 知识点：C 函数中的 NSCAssert

## 用途或适用场景

把上一课 DetailText 的未实现分支变成可重复检查的输出契约。

## 核心概念

NSCAssert 用在 main 等 C 函数中，条件为假时报告断言失败；不用于 Objective-C 方法体。练习使用 Debug 构建并确保没有定义 NS_BLOCK_ASSERTIONS，断言不能替代真实业务错误处理。

## 最小代码或操作示例

保留第 25 课协议、DetailText、PrintAll 和两个对象。在原 main 的自动释放池内、PrintAll(items) 后追加：

```objective-c
BOOL checkedMissing = NO;
for (id<LessonSummarizing> item in items) {
    if (![item respondsToSelector:@selector(detailText)]) {
        checkedMissing = YES;
        NSCAssert([DetailText(item) isEqualToString:@"暂无详情"],
                  @"未实现可选方法时应返回默认详情");
    }
}
NSCAssert(checkedMissing, @"测试必须包含一个未实现 detailText 的对象");
```

isEqualToString 比较文字内容，不能用对象指针 == 比较字符串。

## 3～5 分钟练习

保持一个对象不实现可选方法运行；在教学副本临时把 DetailText 默认文字改成“空”，确认断言失败后恢复。

## 参考答案

原默认文字通过；改成“空”时断言报告失败。若两个对象都实现方法，checkedMissing 断言失败，避免未执行分支检查却宣称通过。
