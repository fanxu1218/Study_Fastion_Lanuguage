# 第 4 课：for循环与整数累加

- 日期：2026-09-04
- 课程序号：第 4 课
- 知识点：NSInteger、循环条件与递增

## 用途

计算若干次练习的累计值。

## 核心概念

for 先初始化，再检查条件；每轮结束后递增。NSInteger 日志使用 long 转换匹配 %ld。

## 最小代码或操作示例

```objective-c
#import <Foundation/Foundation.h>
int main(int argc, const char * argv[]) {
    @autoreleasepool {
        NSInteger total = 0;
        for (NSInteger n = 1; n <= 5; n++) { total += n; }
        NSLog(@"总和：%ld", (long)total);
    }
    return 0;
}
```

## 3～5 分钟练习

将 n <= 5 改成 n < 5，再说明 n++ 的作用。

## 参考答案

总和由 15 变为 10；n++ 推进计数，不推进则可能一直满足条件。
