# 第 22 课：把协议数组传给统一展示函数

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：轻量泛型协议数组

## 用途或适用场景

展示函数只依赖协议，不区分具体类。

## 核心概念

本课只增加“轻量泛型协议数组”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```objective-c
void PrintAll(NSArray<id<LessonSummarizing>> *items) {
  for (id<LessonSummarizing> item in items) NSLog(@"%@", item.displaySummary);
}
```
