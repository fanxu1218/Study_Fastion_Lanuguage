# 第 14 课：只读方法返回摘要

- 日期：2026-09-18
- 课程序号：第 14 课
- 知识点：只读方法返回摘要

## 用途或适用场景

把对象内部属性组合成稳定的只读摘要。

## 核心概念

实例方法通过 self 读取属性并返回 NSString；不暴露属性写入口。

## 最小代码或操作示例

```text
- (NSString *)summary {
    return [NSString stringWithFormat:@"%@ · %ld 分钟", self.title, (long)self.minutes];
}
```

## 3～5 分钟练习

在调用处打印 summary。

## 参考答案

`NSLog(@"%@", lesson.summary);`
