# 第 15 课：只读属性提供摘要

- 日期：2026-09-21
- 课程序号：第 15 课
- 知识点：只读属性提供摘要

## 用途或适用场景

让调用方用属性语法读取上一课的摘要。

## 核心概念

只读属性声明 getter，内部仍使用现有 summary 方法；格式化逻辑只有一份。

## 最小代码或操作示例

```text
// .h
@property (nonatomic, readonly) NSString *displaySummary;
// .m
- (NSString *)displaySummary { return [self summary]; }
```

## 3～5 分钟练习

在调用方读取 lesson.displaySummary。

## 参考答案

得到与 [lesson summary] 相同的文字。

## 与上一课的联系

沿用第 14 课返回格式化文字的 `summary` 方法；本课只新增只读 `displaySummary` 属性 getter；完成练习后下一课可比较属性点语法与 getter 消息发送。
