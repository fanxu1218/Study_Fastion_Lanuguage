# 第 2 课：对象指针与基础类型

- 日期：2026-09-02
- 课程序号：第 2 课
- 知识点：NSString 指针、NSInteger 与 BOOL

## 用途

区分对象引用和直接保存的基础值。

## 核心概念

- NSString * 保存对象指针，字符串字面量带 @。
- NSInteger 是整数类型；BOOL 使用 YES/NO；%@ 输出对象。

## 最小代码或操作示例

```objective-c
#import <Foundation/Foundation.h>
int main(int argc, const char * argv[]) {
    @autoreleasepool {
        NSString *topic = @"类型";
        NSInteger minutes = 5;
        BOOL finished = NO;
        NSLog(@"%@ %ld %d", topic, (long)minutes, (int)finished);
    }
    return 0;
}
```

## 3～5 分钟练习

把 minutes 增加到 10，finished 改为 YES，并预测输出。

## 参考答案

```objective-c
minutes = 10;
finished = YES;
NSLog(@"%@ %ld %d", topic, (long)minutes, (int)finished);
// 日志正文：类型 10 1
```
