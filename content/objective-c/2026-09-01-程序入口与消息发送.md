# 第 1 课：程序入口与消息发送

- 日期：2026-09-01
- 课程序号：第 1 课
- 知识点：`main`、`@autoreleasepool` 与消息发送语法

## 用途

Objective-C 程序从 `main` 函数开始执行。方括号表达式用于向对象发送消息，是阅读和编写 Objective-C 代码的基础。

## 核心概念

- `main` 是命令行程序的入口函数。
- `@autoreleasepool` 管理当前作用域内的自动释放对象。
- `[receiver message]` 表示向接收者发送消息。
- `NSString` 是 Foundation 提供的字符串类型。

## 最小代码示例

```objective-c
#import <Foundation/Foundation.h>

int main(int argc, const char * argv[]) {
    @autoreleasepool {
        NSString *language = @"Objective-C";
        NSLog(@"正在学习 %@", language);
    }
    return 0;
}
```
