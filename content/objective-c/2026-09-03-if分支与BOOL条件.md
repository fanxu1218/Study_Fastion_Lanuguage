# 第 3 课：if分支与BOOL条件

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：数值比较、BOOL 与分支顺序

## 用途

根据一次练习是否达标输出反馈。

## 核心概念

- 比较运算生成条件；BOOL 保存 YES 或 NO。
- 多个分数区间使用 if / else if / else，先检查较严格的条件。

## 最小代码或操作示例

```objective-c
#import <Foundation/Foundation.h>
int main(int argc, const char * argv[]) {
    @autoreleasepool {
        NSInteger score = 60;
        BOOL passed = score >= 60;
        if (passed) {
            NSLog(@"通过");
        } else {
            NSLog(@"继续练习");
        }
    }
    return 0;
}
```

## 3～5 分钟练习

替换条件块，增加分数 >=90 输出“优秀”；用 59、60、90 核对日志正文。

## 参考答案

```objective-c
if (score >= 90) { NSLog(@"优秀"); }
else if (score >= 60) { NSLog(@"通过"); }
else { NSLog(@"继续练习"); }
// 59：继续练习；60：通过；90：优秀。
```
