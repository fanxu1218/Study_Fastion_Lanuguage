# 第 23 课：调用可选协议方法前先检查

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：`respondsToSelector:`

## 用途或适用场景

协议对象可能不实现可选能力时安全调用。

## 核心概念

只为现有协议数组增加可选方法检查，统一展示方法保持不变。

## 最小代码或操作示例

```objective-c
@optional
- (NSString *)detailText;

if ([item respondsToSelector:@selector(detailText)]) { NSLog(@"%@", item.detailText); }
```

## 3～5 分钟练习

让一个对象实现 `detailText`，另一个不实现。

## 参考答案

只输出实现者的详情，两者的摘要仍正常展示。
