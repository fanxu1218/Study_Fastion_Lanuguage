# 第 29 课：用setUp为每个详情测试准备对象

- 日期：2026-10-20
- 课程序号：第 29 课
- 知识点：XCTest实例级setUp

## 用途或适用场景

让两项详情测试各自从全新的已知对象起步。

## 核心概念

-setUp 在每个测试方法之前运行，+setUp 才是测试类级别。只准备内存夹具，不共享可变业务状态；继承父类准备逻辑。

## 最小代码或操作示例

保留第 28 课头文件、target和两个夹具定义；用以下测试类替换原类，不重复编译 DetailText：

```objective-c
@interface DetailTextTests : XCTestCase
@property (nonatomic, strong) NoDetailFixture *plainItem;
@property (nonatomic, strong) DetailFixture *detailedItem;
@end
@implementation DetailTextTests
- (void)setUp {
    [super setUp];
    self.plainItem = [[NoDetailFixture alloc] init];
    self.detailedItem = [[DetailFixture alloc] init];
}
- (void)testMissingDetail {
    XCTAssertEqualObjects(DetailText(self.plainItem), @"暂无详情");
}
- (void)testImplementedDetail {
    XCTAssertEqualObjects(DetailText(self.detailedItem), @"基础说明");
}
@end
```

继续在Product > Test执行同一测试target，使用ARC。

## 3～5 分钟练习

在setUp放断点，依次运行两项测试，核对进入次数和每次创建的新对象。

## 参考答案

每项开始前都进入一次实例setUp；不是整类只执行一次。断点次数不代替两项XCTest断言结果，未执行则记录未验证。
