# 第 11 课：指定初始化方法

- 日期：2026-09-15
- 课程序号：第 11 课
- 知识点：init 方法与属性初始化

## 用途

创建 Lesson 时一次提供必需标题和时长。

## 核心概念

实例初始化方法以 init 开头；调用 super 初始化成功后再写入自身属性。

## 最小代码或操作示例

```objective-c
- (instancetype)initWithTitle:(NSString *)title minutes:(NSInteger)minutes {
  self = [super init];
  if (self) { _title = [title copy]; _minutes = minutes; }
  return self;
}
```
