# 第 49 课：为范围文本检查增加独立入口

- 日期：2026-11-16
- 课程序号：第 49 课
- 知识点：void函数组织一组固定断言

## 用途或适用场景

让第48课恢复的四份文本检查有单一入口。

## 核心概念

void入口只组织调用；四个独立期望和断言仍完整执行，不能用一次打印代替。

## 最小代码或操作示例

在checkRangeText之后、main之前新增：
```cpp
void testRangeText(const std::vector<Lesson>& lessons,
                   const std::vector<Lesson>& noLessons,
                   const std::vector<Lesson>& sameMinutes,
                   const std::vector<Lesson>& backward) {
    checkRangeText("mixed", minutesRange(lessons), "2..30分钟");
    checkRangeText("empty", minutesRange(noLessons), "暂无课程");
    checkRangeText("same", minutesRange(sameMinutes), "7..7分钟");
    checkRangeText("backward", minutesRange(backward), "2..30分钟");
}
```
main保留原四份数据和打印，将原末尾四次checkRangeText替换为一次testRangeText(lessons, noLessons, sameMinutes, backward)。沿第47、48课编译及分流，使用未存在的结果文件；正常退出、原四行及空错误流分别核对。

## 3～5 分钟练习

只定义testRangeText却不调用，打印四行能证明检查执行吗？

## 参考答案

不能；main需实际调用一次该入口，原其他范围检查保留。
