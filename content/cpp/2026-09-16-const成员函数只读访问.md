# 第 13 课：const成员函数只读访问

- 日期：2026-09-16
- 课程序号：第 13 课
- 知识点：const成员函数只读访问

## 用途

让只读 Lesson 对象也能安全读取时长。

## 核心概念

成员函数末尾的 const 承诺不修改对象的可观察状态。

## 最小代码或操作示例

```text
struct Lesson {
  int minutes;
  int duration() const { return minutes; }
};
```

## 3～5 分钟练习

增加返回是否完成的 const 成员函数。

## 参考答案

bool done() const { return minutes >= 10; }
