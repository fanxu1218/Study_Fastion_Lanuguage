# 第 37 课：提取接收固定期望的范围断言

- 日期：2026-10-29
- 课程序号：第 37 课
- 知识点：只读结果参数与独立期望

## 用途或适用场景

提取接收固定期望的范围断言，用于在已有示例中验证只读结果参数与独立期望。

## 核心概念

辅助函数接收实际MinutesRange和明确写出的最小/最大期望，不重新计算输入。这样减少重复字段判断，仍能发现统计实现返回错误值。

## 最小代码或操作示例

保留第35课顺序与第36课changed夹具，在这些检查之前定义：

```cpp
void assertMinutesRange(const MinutesRange& actual,
                        int expectedMinimum, int expectedMaximum) {
    assert(actual.hasLessons);
    assert(actual.minimum == expectedMinimum);
    assert(actual.maximum == expectedMaximum);
}
```

第36课checkChangedMinutesRange中保留changed和range生成，只把三条字段断言替换为：

```cpp
assertMinutesRange(range, 2, 31);
```

该辅助方法用于非空夹具；原空列表检查不替换。沿原main四项调用，c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check后运行。

## 3～5 分钟练习

把expectedMaximum也取为actual.maximum，会失去哪项保障？

## 参考答案

最大值检查会变成自比较。必须保留独立期望31；2改1的旧练习仍应由minimum检查发现。
