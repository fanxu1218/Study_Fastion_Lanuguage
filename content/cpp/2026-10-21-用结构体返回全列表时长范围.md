# 第 31 课：用结构体返回全列表时长范围

- 日期：2026-10-21
- 课程序号：第 31 课
- 知识点：计算函数返回结果对象

## 用途或适用场景

使同一范围统计能供不同调用方展示或检查。

## 核心概念

MinutesRange 同时返回是否有数据与两个时长。空结果的两个零仅为不读取的存储值，只有 hasLessons 为真才有最短/最长含义；空列表判断留在计算函数内保护 front。

## 最小代码或操作示例

保留原 Lesson、vector/algorithm/iostream。将第 30 课 printMinutesRange 替换为下列声明与函数：

```cpp
struct MinutesRange {
    bool hasLessons;
    int minimum;
    int maximum;
};

MinutesRange minutesRange(const std::vector<Lesson>& lessons) {
    if (lessons.empty()) return {false, 0, 0};
    int minMinutes = lessons.front().minutes;
    int maxMinutes = lessons.front().minutes;
    for (const Lesson& lesson : lessons) {
        minMinutes = std::min(minMinutes, lesson.minutes);
        maxMinutes = std::max(maxMinutes, lesson.minutes);
    }
    return {true, minMinutes, maxMinutes};
}
```

在 main 中用以下代码替换原 printMinutesRange(lessons) 调用：

```cpp
const MinutesRange range = minutesRange(lessons);
if (range.hasLessons) {
    std::cout << "全列表范围：" << range.minimum << "～"
              << range.maximum << " 分钟\n";
} else {
    std::cout << "暂无课程\n";
}
```

不改变原首尾统计和列表建立过程；返回值不是自动随列表更新的视图。

## 3～5 分钟练习

继续测试 5/30/2/10、单项 7、空列表；说明空结果能否显示 0～0。

## 参考答案

前两项为 2～30、7～7；空列表显示暂无课程，不能展示零时长范围。函数只读取输入，显示由调用方决定。
