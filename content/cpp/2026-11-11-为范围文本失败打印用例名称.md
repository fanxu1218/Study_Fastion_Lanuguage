# 第 46 课：为范围文本失败打印用例名称

- 日期：2026-11-11
- 课程序号：第 46 课
- 知识点：标准错误中的具名诊断

## 用途或适用场景

使第45课共用checkRangeText失败时能看到具体输入行。

## 核心概念

std::cerr写入标准错误流；诊断只在文本不等时输出，assert仍终止失败检查。实际文本只计算一次，固定期望继续由调用方提供。

## 最小代码或操作示例

沿第44课四份固定文本和第45课辅助函数，在main前用下列定义替换原checkRangeText，保留<iostream>：
```cpp
void checkRangeText(const std::string& name,
                    const MinutesRange& range,
                    const std::string& expected) {
    const std::string actual = formatMinutesRange(range);
    if (actual != expected) {
        std::cerr << name << ": actual=[" << actual
                  << "], expected=[" << expected << "]\n";
    }
    assert(actual == expected);
}
```
在main原位置只替换四次文本调用：
```cpp
checkRangeText("mixed", minutesRange(lessons), "2..30分钟");
checkRangeText("empty", minutesRange(noLessons), "暂无课程");
checkRangeText("same", minutesRange(sameMinutes), "7..7分钟");
checkRangeText("backward", minutesRange(backward), "2..30分钟");
```
保留原四个统计入口和四次打印，c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check后运行；正常四行标准输出不变，标准错误为空。

## 3～5 分钟练习

仅在反例副本把empty期望改为暂无课程后加一个空格，消息应包含什么？随后恢复。

## 参考答案

应含empty及actual=[暂无课程]、expected=[暂无课程 ]，随后assert失败；恢复期望后四行原输出不变。
