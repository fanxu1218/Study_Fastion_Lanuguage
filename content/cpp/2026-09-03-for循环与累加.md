# 第 4 课：for循环与累加

- 日期：2026-09-03
- 课程序号：第 4 课
- 知识点：初始化、继续条件与循环更新

## 用途

用一个循环计算连续整数总和。

## 核心概念

- for 先初始化，再检查条件，执行循环体，最后更新计数器并重复。
- 累加器在循环外初始化；<= 包含上界，< 不包含上界。

## 最小代码或操作示例

```cpp
#include <iostream>
int main() {
    int total{0};
    for (int i{1}; i <= 3; ++i) {
        total += i;
    }
    std::cout << total << '\n'; // 6
}
```

## 3～5 分钟练习

求 1 到 5 的总和；再把条件改成 i < 5，比较结果。

## 参考答案

```text
i <= 5 时结果为 15；i < 5 时只累计 1、2、3、4，结果为 10。total 不能每轮重置为 0。
```
