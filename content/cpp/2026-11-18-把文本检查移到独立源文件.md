# 第 51 课：把文本检查移到独立源文件

- 日期：2026-11-18
- 课程序号：第 51 课
- 知识点：检查入口通过头文件跨文件调用

## 用途或适用场景

在第50课计算实现分离后，单独组织原四项文本检查。

## 核心概念

共享声明让main调用唯一检查实现；被移走的函数体不能同时留在原源文件。

## 最小代码或操作示例

同目录新建range_text_checks.h：
```cpp
#ifndef RANGE_TEXT_CHECKS_H
#define RANGE_TEXT_CHECKS_H
#include "minutes_range.h"
void testRangeText(const std::vector<Lesson>& lessons,
                   const std::vector<Lesson>& noLessons,
                   const std::vector<Lesson>& sameMinutes,
                   const std::vector<Lesson>& backward);
#endif
```
新建range_text_checks.cpp，include该头文件、<iostream>及<assert.h>，完整移入原checkRangeText和testRangeText两函数体。lesson.cpp include新头文件并删除已移动函数体，保留其余范围检查、四份数据、打印和main一次调用；minutes_range.cpp不变。
```sh
c++ -std=c++11 -UNDEBUG lesson.cpp minutes_range.cpp range_text_checks.cpp -o separated-checks
./separated-checks
```
用未占用输出名；预期正常退出、原四行和空错误流。

## 3～5 分钟练习

只把testRangeText移走，忘记它依赖的checkRangeText声明/实现，会发生什么？

## 参考答案

新源文件无法按本课结构完成编译；将两份原函数一起移入检查源文件，每个定义只留一份。
