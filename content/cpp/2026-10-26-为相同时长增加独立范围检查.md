- 日期：2026-10-26

## 用途或适用场景

最小值等于最大值的多项夹具，继续使用本路线的原练习。

## 核心概念

多项课程可能具有同一时长；非空结果仍成立，minimum与maximum应相等。边界检查复用唯一minutesRange实现。

## 最小代码或操作示例

保留第33课checkMinutesRanges及原固定lessons，在main前新增：

```cpp
void checkEqualMinutesRange() {
    const std::vector<Lesson> sameMinutes(2, Lesson{"C++", 7});
    const MinutesRange range = minutesRange(sameMinutes);
    assert(range.hasLessons);
    assert(range.minimum == 7);
    assert(range.maximum == 7);
}
```

在main原checkMinutesRanges(lessons);之后追加checkEqualMinutesRange();，不把新的7/7夹具传给期望2/30的旧检查。仍使用c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check并运行。

## 3～5 分钟练习

将新夹具两项时长都改为9，哪些期望需要一起改？先推演再验证。

## 参考答案

minimum和maximum均改为9，hasLessons仍为真；原2/30固定检查不改。练习结束恢复7/7及对应期望。
