# 第 30 课：将全列表时长统计提取为只读函数

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：const 引用参数封装已有统计

## 用途或适用场景

让原 lessons 统计通过一个函数调用完成。

## 核心概念

const std::vector<Lesson>& 借用原列表并禁止通过该参数修改元素；返回 void 的函数负责当前展示。空列表判断也移入函数，保持 front 的有效前提。

## 最小代码或操作示例

保留原 Lesson、<vector>、<iostream>、<algorithm>；在 Lesson 定义后、main 前增加：

```cpp
void printMinutesRange(const std::vector<Lesson>& lessons) {
    if (lessons.empty()) {
        std::cout << "暂无课程\n";
        return;
    }
    int minMinutes = lessons.front().minutes;
    int maxMinutes = lessons.front().minutes;
    for (const Lesson& lesson : lessons) {
        minMinutes = std::min(minMinutes, lesson.minutes);
        maxMinutes = std::max(maxMinutes, lesson.minutes);
    }
    std::cout << "全列表范围：" << minMinutes << "～"
              << maxMinutes << " 分钟\n";
}
```

将 main 中第 29 课全列表统计块替换为 printMinutesRange(lessons);，保留 lessons 的建立过程。

## 3～5 分钟练习

分别传入时长为 5/30/2/10、单项 7、空列表的练习数据。

## 参考答案

得到 2～30、7～7、暂无课程；原列表顺序和元素不变。空列表不会进入 front。
