# 第 24 课：安全读取课程列表首项

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：`vector::front()`

## 用途或适用场景

确认列表非空后读取第一节课程。

## 核心概念

只在上一课 `empty()` 判断的非空分支调用 `front()`。

## 最小代码或操作示例

```cpp
if (!lessons.empty()) { std::cout << lessons.front().title << "\n"; }
```

## 3～5 分钟练习

分别用空列表和含一项列表运行。

## 参考答案

空列表不读取；非空列表输出首项标题。

## 与上一课的联系
