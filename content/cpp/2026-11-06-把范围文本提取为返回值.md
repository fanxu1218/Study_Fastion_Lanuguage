# 第 43 课：把范围文本提取为返回值

- 日期：2026-11-06
- 课程序号：第 43 课

## 用途或适用场景

让第42课四行展示有可直接比较的文本产出。

## 核心概念

统计仍由minutesRange负责；新函数只按hasLessons格式化结果，不输出换行。std::to_string将整数转为字符串，打印函数继续负责输出。

## 最小代码或操作示例

沿第41课四份输入及第42课固定输出，保留<string>与<iostream>，在printMinutesRange前新增，并替换原打印函数：
```cpp
std::string formatMinutesRange(const MinutesRange& range) {
    if (!range.hasLessons) return "暂无课程";
    return std::to_string(range.minimum) + ".." +
           std::to_string(range.maximum) + "分钟";
}

void printMinutesRange(const MinutesRange& range) {
    std::cout << formatMinutesRange(range) << "\n";
}
```
const引用只读已有结构体；std::to_string自C++11可用。保留四个检查入口和四次打印，以c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check编译运行，仍与原四行比较。

## 3～5 分钟练习

在formatMinutesRange返回值末尾加换行，会影响什么？

## 参考答案

打印函数已另加换行，会多出空行；格式化文本与输出分隔符职责应保持明确。
