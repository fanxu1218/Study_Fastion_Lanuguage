# 第 28 课：遍历整个课程列表求最长时长

- 日期：2026-10-15
- 课程序号：第 28 课
- 知识点：遍历中的最大值归约

## 用途或适用场景

让上一课首尾比较扩展为整个 lessons 的最长时长计算。

## 核心概念

先在非空分支用第一项初始化，再遍历所有课程更新最大值；不把初始值硬写为 0。std::max 已学过，本课只增加重复比较累积结果的方式，不引入迭代器或比较器。

## 最小代码或操作示例

保留 `Lesson`、`lessons`、`<algorithm>`，在原非空分支追加：

```cpp
int maxMinutes = lessons.front().minutes;
for (const Lesson& lesson : lessons) {
    maxMinutes = std::max(maxMinutes, lesson.minutes);
}
std::cout << "全列表最长：" << maxMinutes << " 分钟\n";
```

原 shorter/longer 仍只表示首尾范围，空列表分支保持原提示。

## 3～5 分钟练习

沿用首尾 5/10，在中间加入 30；再测试单项 7 与空列表。

## 参考答案

全列表最长为 30，而首尾较长值仍为 10；单项结果 7；空列表不执行新增代码，也不访问 front。
