# 第 29 课：遍历课程列表求最短时长

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：与最大值并列的最小值归约

## 用途或适用场景

在同一次 lessons 遍历中得到全列表时长范围。

## 核心概念

minMinutes 与 maxMinutes 都从首项初始化，并在非空分支内处理每条记录。std::min 已学过；本课只把同样的归约方式用于最小值。

## 最小代码或操作示例

保留原 Lesson、lessons、<algorithm> 和空列表提示，把第 28 课非空分支中的归约块替换为：

```cpp
int minMinutes = lessons.front().minutes;
int maxMinutes = lessons.front().minutes;
for (const Lesson& lesson : lessons) {
    minMinutes = std::min(minMinutes, lesson.minutes);
    maxMinutes = std::max(maxMinutes, lesson.minutes);
}
std::cout << "全列表范围：" << minMinutes << "～"
          << maxMinutes << " 分钟\n";
```

原 shorter/longer 仍只表示首尾范围；不要把上述代码移出非空保护。

## 3～5 分钟练习

在 5、30、10 中间再加入 2；测试单项 7 和空列表。

## 参考答案

全列表为 2～30，单项为 7～7；空列表只显示原提示，不读取 front。原首尾范围仍为 5～10。
