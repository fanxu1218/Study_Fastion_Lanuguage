# 第 58 课：为其余编译单元生成依赖后链接

- 日期：2026-11-27
- 课程序号：第 58 课
- 知识点：三个目标文件与各自依赖文件对应

## 用途或适用场景

完成第57课尚未参与编译的两个源文件，并链接同一批目标。

## 核心概念

每个源文件各自执行-MMD编译，分别生成.o和.d；链接使用三个.o，不把.d当链接输入。这里仍手动构建，不引入Make。

## 最小代码或操作示例

沿第57课成功生成的lesson57-build/lesson.o和lesson.d；源码、头文件从那次编译后须未改动。确认下列新增文件均未占用，逐条执行，任一步非零即停：
```sh
c++ -std=c++11 -UNDEBUG -MMD -MF lesson57-build/minutes_range.d -MT lesson57-build/minutes_range.o -c minutes_range.cpp -o lesson57-build/minutes_range.o
c++ -std=c++11 -UNDEBUG -MMD -MF lesson57-build/range_text_checks.d -MT lesson57-build/range_text_checks.o -c range_text_checks.cpp -o lesson57-build/range_text_checks.o
c++ lesson57-build/lesson.o lesson57-build/minutes_range.o lesson57-build/range_text_checks.o -o lesson57-build/checks
./lesson57-build/checks
```
读回两个新.d，核对左侧目标及右侧实际包含链。若前提不成立，先按第57课重新编译lesson.cpp，不复用可能陈旧的.o。

## 3～5 分钟练习

能把minutes_range.d替代minutes_range.o传入最后链接吗？

## 参考答案

不能；.d是文本依赖关系，.o才是编译输出。正常程序应保留2..30分钟、暂无课程、7..7分钟和原检查；成功链接也不表示依赖文件已被自动构建工具使用。
