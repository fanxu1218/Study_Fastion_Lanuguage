# 第 36 课：用新时长输入检查范围变化

- 日期：2026-10-28
- 课程序号：第 36 课
- 知识点：独立夹具与固定期望

## 用途或适用场景

独立夹具与固定期望，用于继续完成本路线原示例的下一步。

## 核心概念

输入变化后的正确范围需要独立固定期望。新的最大时长不能靠与旧输出比较猜测，也不应修改旧夹具让已有边界检查失去起点。

## 最小代码或操作示例

保留第34课相等和第35课顺序检查，在main前新增：

```cpp
void checkChangedMinutesRange() {
    const std::vector<Lesson> changed{
        {"C++", 5}, {"C++", 31}, {"C++", 2}, {"C++", 10}
    };
    const MinutesRange range = minutesRange(changed);
    assert(range.hasLessons);
    assert(range.minimum == 2);
    assert(range.maximum == 31);
}
```

在main已有三个检查调用之后增加checkChangedMinutesRange();。原5/30/2/10夹具和旧断言不改；沿c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check后运行。

## 3～5 分钟练习

把新夹具2改为1而不改期望，应由哪条检查发现？随后恢复。

## 参考答案

本函数的minimum==2应失败，旧夹具仍成立。恢复后各检查重新执行；不要用NDEBUG禁用断言。

## 与上一课的联系
