# 第 45 课：用具名函数复用范围文本检查

- 日期：2026-11-10
- 课程序号：第 45 课
- 知识点：const引用实参与固定字符串期望

## 用途或适用场景

整理第44课四个重复文本assert。

## 核心概念

辅助函数只比较已算出的范围文本，不修改输入或生成期望。const引用避免复制已有结构与字符串。

## 最小代码或操作示例

沿第43课formatMinutesRange及第44课四个文本比较，在main之前新增：
```cpp
void checkRangeText(const MinutesRange& range,
                    const std::string& expected) {
    assert(formatMinutesRange(range) == expected);
}
```
在main原位置，用下列四行替换第44课四个文本assert：
```cpp
checkRangeText(minutesRange(lessons), "2..30分钟");
checkRangeText(minutesRange(noLessons), "暂无课程");
checkRangeText(minutesRange(sameMinutes), "7..7分钟");
checkRangeText(minutesRange(backward), "2..30分钟");
```
保留原<assert.h>、<string>、原四个统计入口和四次打印；仍以c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check编译运行，对照原四行输出。

## 3～5 分钟练习

能把expected改为函数内部formatMinutesRange(range)的结果吗？

## 参考答案

不能，两边将来自同一实现；继续传四份固定期望，空结果不含换行。
