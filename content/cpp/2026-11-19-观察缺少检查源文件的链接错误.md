# 第 52 课：观察缺少检查源文件的链接错误

- 日期：2026-11-19
- 课程序号：第 52 课
- 知识点：声明可见与定义参与链接的区别

## 用途或适用场景

验证第51课三源文件结构中range_text_checks.cpp的职责。

## 核心概念

头文件声明让调用通过语法检查；链接时仍需唯一函数定义。缺实现与缺声明的首个错误属于不同阶段。

## 最小代码或操作示例

在第51课个人副本保持所有源码不变，选择未占用的输出名。先故意少列检查源文件：
```sh
c++ -std=c++11 -UNDEBUG lesson.cpp minutes_range.cpp -o missing-checks
```
此命令预期非零，记录testRangeText对应的首个未解析符号/undefined symbol错误；具体文字随工具链变化。不要运行该失败输出名。再恢复完整输入：
```sh
c++ -std=c++11 -UNDEBUG lesson.cpp minutes_range.cpp range_text_checks.cpp -o linked-checks
./linked-checks
```
编译成功后再运行，原断言通过、四行输出及空错误流应保持。Microsoft LNK2019文档说明同一链接原理，非要求Clang输出LNK2019。
