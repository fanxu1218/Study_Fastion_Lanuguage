# 第 3 课：if条件分支

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：if、else 与比较表达式

## 用途

根据分数选择不同输出。

## 核心概念

- 条件为真执行 if 块，否则执行 else 块。
- >= 包含边界；花括号明确每个分支的作用范围。

## 最小代码或操作示例

```cpp
#include <iostream>
int main() {
    int score{60};
    if (score >= 60) {
        std::cout << "及格\n";
    } else {
        std::cout << "继续练习\n";
    }
}
```

## 3～5 分钟练习

增加 >=90 的优秀分支，并测试 59、60、90。

## 参考答案

```cpp
// 放入 main，替换原分支：
if (score >= 90) { std::cout << "优秀\n"; }
else if (score >= 60) { std::cout << "及格\n"; }
else { std::cout << "继续练习\n"; }
```
