# 第 50 课：用头文件连接范围实现与检查

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：声明与定义分离的最小多文件组合

## 用途或适用场景

保持第49课检查入口，单独保存纯范围计算与格式化。

## 核心概念

头文件共享类型和函数声明，函数体在一个cpp中定义；两个cpp共同编译链接，不能靠include实现文件复制定义。

## 最小代码或操作示例

在原纯内存副本同目录新建minutes_range.h：
```cpp
#ifndef MINUTES_RANGE_H
#define MINUTES_RANGE_H
#include <string>
#include <vector>
struct Lesson { std::string title; int minutes; };
struct MinutesRange { bool hasLessons; int minimum; int maximum; };
MinutesRange minutesRange(const std::vector<Lesson>& lessons);
std::string formatMinutesRange(const MinutesRange& range);
#endif
```
新建minutes_range.cpp，先include该头文件和<algorithm>，再移入原minutesRange、formatMinutesRange完整函数体，不改语义。lesson.cpp改为include该头文件，移除已经移动的两份类型定义及两函数体，保留原检查、打印与main；每个定义只留一份。
```sh
c++ -std=c++11 -UNDEBUG lesson.cpp minutes_range.cpp -o split-lesson-check
./split-lesson-check
```
使用未占用的新输出名；编译成功再运行，仍应正常退出、输出原四行且错误流为空。

## 3～5 分钟练习

只编译lesson.cpp，声明存在就等于函数体已链接吗？

## 参考答案

不等于；本课需要同时编译minutes_range.cpp提供唯一函数定义。
