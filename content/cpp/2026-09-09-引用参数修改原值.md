# 第 8 课：引用参数修改原值

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：引用与引用参数

## 用途

让函数直接修改调用方持有的变量，避免复制较大的对象。

## 核心概念

`T&` 是已有对象的别名；通过引用参数写入会反映到调用方的原对象。

## 最小代码或操作示例

```cpp
void addMinute(int& minutes) {
    minutes += 1;
}

int minutes = 10;
addMinute(minutes);
```

## 3～5 分钟练习

调用两次 `addMinute`，再输出 `minutes`。

## 参考答案

最终输出 `12`，因为两次调用修改的是同一个变量。
