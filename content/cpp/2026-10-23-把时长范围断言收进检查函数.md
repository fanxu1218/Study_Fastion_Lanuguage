# 第 33 课：把时长范围断言收进检查函数

- 日期：2026-10-23
- 课程序号：第 33 课
- 知识点：固定夹具与独立检查入口

## 用途或适用场景

把时长范围断言收进检查函数。

## 核心概念

检查函数复用同一minutesRange实现，把断言与展示分开。此函数约定接收原5/30/2/10固定夹具，不把它误作任意数据的通用验证器。

## 最小代码或操作示例

保留第31课类型与函数、<assert.h>，在main前新增：

```cpp
void checkMinutesRanges(const std::vector<Lesson>& lessons) {
    assert(!lessons.empty());
    const MinutesRange allRange = minutesRange(lessons);
    assert(allRange.hasLessons);
    assert(allRange.minimum == 2);
    assert(allRange.maximum == 30);
    const std::vector<Lesson> noLessons;
    assert(!minutesRange(noLessons).hasLessons);
    const std::vector<Lesson> oneLesson(1, lessons.front());
    const MinutesRange oneRange = minutesRange(oneLesson);
    assert(oneRange.hasLessons);
    assert(oneRange.minimum == lessons.front().minutes);
    assert(oneRange.maximum == lessons.front().minutes);
}
```

在原lessons构造后，用checkMinutesRanges(lessons);替换第32课追加的断言块，原展示保留。仍用c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check再运行。

## 3～5 分钟练习

将固定夹具30改为31但不改期望，运行检查后恢复。

## 参考答案

最大值断言应失败；恢复原夹具后重跑通过。NDEBUG会禁用这些断言，不能用该模式认定检查有效。
