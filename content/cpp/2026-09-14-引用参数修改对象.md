# 第 11 课：引用参数修改对象

- 日期：2026-09-14
- 课程序号：第 11 课
- 知识点：引用参数与 `const` 引用

## 用途

让函数直接修改调用方对象，或无复制地只读访问对象。

## 核心概念

`T&` 表示可修改引用，`const T&` 表示只读引用；引用必须绑定到有效对象。

## 最小代码或操作示例

```cpp
struct Lesson { int minutes; };

void extend(Lesson& lesson) {
  lesson.minutes += 5;
}
```

## 3～5 分钟练习

写一个只读函数，接收 `const Lesson&` 并返回分钟数。

## 参考答案

`int duration(const Lesson& lesson) { return lesson.minutes; }`
