# 第 22 课：统计课程列表数量

- 日期：2026-09-30
- 课程序号：第 22 课
- 知识点：`vector::size()`

## 用途或适用场景

遍历显示标题后核对列表实际保存的课程数。

## 核心概念

`size()` 返回元素数量；不要通过最后一次循环次数另存一份业务事实。

## 最小代码或操作示例

```cpp
std::cout << "共 " << lessons.size() << " 节\n";
for (const Lesson& lesson : lessons) {
  std::cout << lesson.title << '\n';
}
```

## 3～5 分钟练习

再 `push_back` 一节课程并输出数量。

## 参考答案

加入第二节后 `lessons.size()` 返回 `2`。
