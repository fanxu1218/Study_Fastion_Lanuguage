# 第 54 课：只重编译改动的检查源文件

- 日期：2026-11-23
- 课程序号：第 54 课
- 知识点：源文件改动与目标文件复用边界

## 用途或适用场景

用第53课三份目标文件观察一次仅修改检查实现的重建。

## 核心概念

未变的源码及其依赖可复用同轮目标文件；改动.cpp必须重新编译该单元，再链接全部目标文件。头文件变化可能影响多个单元，不能套用本课单文件条件。

## 最小代码或操作示例

在原个人副本，仅把range_text_checks.cpp中checkRangeText调用的用例名"mixed"改为"mixed-range"，不改头文件、输入或期望。确认lesson53-build来自上一课同一工具链且lesson54-build未存在，逐条执行，任一步失败就停止：
```sh
mkdir lesson54-build
cp lesson53-build/lesson.o lesson54-build/lesson.o
cp lesson53-build/minutes_range.o lesson54-build/minutes_range.o
c++ -std=c++11 -UNDEBUG -c range_text_checks.cpp -o lesson54-build/range_text_checks.o
c++ lesson54-build/lesson.o lesson54-build/minutes_range.o lesson54-build/range_text_checks.o -o lesson54-build/rebuilt-checks
./lesson54-build/rebuilt-checks
```
新增名称只影响失败诊断；正常仍为原四行输出与空错误流。若上一课没有成功目标文件，先按第53课完整编译，不假设旧文件有效。

## 3～5 分钟练习

若改的是minutes_range.h中声明或结构体布局，还能只重编译range_text_checks.cpp吗？

## 参考答案

不能；应重新编译所有受该头文件变更影响的源文件，再链接。此课复用成立的条件是两个被复用单元的源码及依赖都未改变。
