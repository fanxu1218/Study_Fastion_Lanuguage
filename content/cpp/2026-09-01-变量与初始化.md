# 第 2 课：变量与初始化

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：变量类型、初始化与 `const`

## 用途

变量保存运行数据，初始化确保变量从一开始就有明确值。

## 核心概念

- 声明变量时写出类型和名称。
- 花括号提供初始值；不需修改的值可声明为 `const`。

## 最小代码示例

```cpp
#include <iostream>
#include <string>
int main() {
    const std::string language{"C++"};
    int lesson{2};
    std::cout << language << " 第 " << lesson << " 课\n";
}
```

## 3～5 分钟练习

声明单价 `double` 和数量 `int`，输出总价。

## 参考答案

```cpp
double price{12.5};
int count{3};
std::cout << price * count << '\n';
```
