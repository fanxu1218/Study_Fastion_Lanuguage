# 第 35 课：检查输入顺序变化不改变时长范围

- 日期：2026-10-27
- 课程序号：第 35 课
- 知识点：归约结果与列表顺序的独立性

## 用途或适用场景

检查输入顺序变化不改变时长范围，让本次练习的结果可以按同一条件复查。

## 核心概念

minutesRange只读取各项时长；同一批元素倒序后最小值和最大值应一致。用两份固定夹具对照即可，不需要为了统计而排序输入。

## 最小代码或操作示例

保留第33课原检查及第34课相等边界。在main前新增：

```cpp
void checkOrderIndependentRange() {
    const std::vector<Lesson> forward{
        {"C++", 5}, {"C++", 30}, {"C++", 2}, {"C++", 10}
    };
    const std::vector<Lesson> backward{
        {"C++", 10}, {"C++", 2}, {"C++", 30}, {"C++", 5}
    };
    const MinutesRange first = minutesRange(forward);
    const MinutesRange second = minutesRange(backward);
    assert(first.hasLessons && second.hasLessons);
    assert(first.minimum == 2 && first.maximum == 30);
    assert(second.minimum == first.minimum);
    assert(second.maximum == first.maximum);
    assert(forward.front().minutes == 5);
    assert(backward.front().minutes == 10);
}
```

在main已有两次检查之后调用checkOrderIndependentRange();。沿c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check并运行。

## 3～5 分钟练习

两份夹具都只断言彼此相等，却都错误返回0/0，会漏掉什么？

## 参考答案

会漏掉正确值要求；本例还独立断言原夹具为2/30。首项检查只观察该位置，完整只读约束主要由const引用实现。
