# 第 39 课：提取空列表结果的独立检查

- 日期：2026-11-02
- 课程序号：第 39 课
- 知识点：无结果标记不读取范围字段

## 用途或适用场景

复用空范围检查，避免误读无效范围字段。

## 核心概念

空列表的契约是hasLessons为false。辅助检查只断言这个标记，不把minimum/maximum当作有效范围，也不访问front。

## 最小代码或操作示例

沿第37课非空辅助方法与第38课固定期望，在检查函数之前新增：

```cpp
void assertNoMinutesRange(const MinutesRange& actual) {
    assert(!actual.hasLessons);
}
```

只把原checkMinutesRanges中assert(!minutesRange(noLessons).hasLessons);替换为：

```cpp
assertNoMinutesRange(minutesRange(noLessons));
```

保留原noLessons、单项及所有非空夹具，main四个入口不变。c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check后运行。

## 3～5 分钟练习

把该辅助方法用于单项非空列表，会发生什么？

## 参考答案

应失败；它只适用于空结果。恢复原调用，不能修改minutesRange把非空伪造为空。
