# 第 40 课：在展示前区分空结果与有效范围

- 日期：2026-11-03
- 课程序号：第 40 课
- 知识点：先判断结果标记再读取范围字段

## 用途或适用场景

把已测试的范围结果交给调用方展示。

## 核心概念

hasLessons决定minimum和maximum是否有业务含义。空结果的占位数值不能显示成真实0分钟；展示只读取结果，不重新统计列表。

## 最小代码或操作示例

沿第38课非空固定期望和第39课空结果检查，在MinutesRange定义之后、main之前新增；沿原iostream：

```cpp
void printMinutesRange(const MinutesRange& range) {
    if (range.hasLessons) {
        std::cout << range.minimum << ".." << range.maximum << "分钟\n";
    } else {
        std::cout << "暂无课程\n";
    }
}
```

在原main四个检查调用之后追加：

```cpp
printMinutesRange(minutesRange(lessons));
const std::vector<Lesson> noLessons;
printMinutesRange(minutesRange(noLessons));
```

原lessons仍为5/30/2/10夹具；应输出2..30分钟与暂无课程两行。c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check后运行，不改minutesRange。

## 3～5 分钟练习

空列表显示0..0分钟为什么不符合原契约？

## 参考答案

hasLessons=false时那两个字段不是有效范围；调用方必须走暂无课程分支，不能从占位值推导业务含义。
