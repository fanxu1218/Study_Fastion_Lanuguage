# 第 9 课：const引用避免复制

- 日期：2026-09-10
- 课程序号：第 9 课
- 知识点：const 引用参数

## 用途

读取较大对象时避免复制并禁止意外修改。

## 核心概念

`const T&` 引用原对象，但只允许读取。

## 最小代码或操作示例

```cpp
void printTitle(const std::string& title) {
  std::cout << title << '\n';
}
```

## 3～5 分钟练习

尝试在函数内给 `title` 赋值。

## 参考答案

编译失败，因为常量引用不允许修改对象。
