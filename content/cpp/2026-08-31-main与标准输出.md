# 第 1 课：main 与标准输出

- 日期：2026-08-31
- 课程序号：第 1 课
- 知识点：`main()`、`iostream` 与 `std::cout`

## 用途

每个可执行 C++ 程序都从 `main()` 开始。标准输出能帮助我们看到程序结果和调试信息。

## 核心概念

- `#include <iostream>` 引入输入输出工具。
- `main()` 是程序入口。
- `std::cout` 把内容写到终端。
- `return 0` 表示程序正常结束。

## 最小代码示例

```cpp
#include <iostream>

int main() {
    std::cout << "C++ 第 1 课" << '\n';
    return 0;
}
```
