# 第 7 课：vector动态序列

- 日期：2026-09-08
- 课程序号：第 7 课
- 知识点：std::vector

## 用途

保存运行时可继续增加的一组练习时长。

## 核心概念

`std::vector<T>` 保存同类型元素，`push_back` 在尾部增加数据，范围 `for` 可顺序遍历。

## 最小代码或操作示例

```cpp
#include <iostream>
#include <vector>

std::vector<int> minutes{10, 15};
minutes.push_back(20);
for (int value : minutes) std::cout << value << '\n';
```
