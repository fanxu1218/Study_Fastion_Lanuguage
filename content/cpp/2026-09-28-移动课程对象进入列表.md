## 核心概念

`push_back(std::move(moved))` 选择接收右值的重载；插入后使用列表中的对象，不断言被移动对象的字符串内容。需 C++11 或更新标准。

## 最小代码或操作示例

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>
struct Lesson { std::string title; int minutes; };
int main() {
  Lesson source{"C++", 5};
  Lesson copied = source;
  Lesson moved = std::move(source);
  std::vector<Lesson> lessons;
  lessons.push_back(std::move(moved));
  std::cout << copied.title << " " << lessons[0].title << '\n'; // C++ C++
}
```

## 3～5 分钟练习

把 `minutes` 改为 10，输出列表第一项的时长。

## 参考答案

把初始对象改为 `Lesson source{"C++", 10};`，再输出 `lessons[0].minutes`，结果是 `10`；不要检查移动后的 `moved.title`。
