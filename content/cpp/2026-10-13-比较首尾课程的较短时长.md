# 第 26 课：比较首尾课程的较短时长

- 日期：2026-10-13
- 课程序号：第 26 课
- 知识点：`std::min` 的双参数重载

## 用途或适用场景

在非空课程列表中比较首尾两课，得到较短的练习时长。

## 核心概念

`std::min(a, b)` 比较两个相同类型的值并返回较小者。本课只比较 `front().minutes` 与 `back().minutes`，不计算整个列表的最短课；首尾访问仍受 `empty()` 保护。用 `int` 接收结果值，沿用既有整数时长。

## 最小代码或操作示例

在第 25 课现有文件的 include 区加入 `#include <algorithm>`，保留 `Lesson`、`lessons` 和插入课程的代码，将展示分支改为：

```cpp
if (!lessons.empty()) {
  int shorter = std::min(lessons.front().minutes, lessons.back().minutes);
  std::cout << shorter << " 分钟\n";
} else {
  std::cout << "暂无课程\n";
}
```

`lessons` 仍是已有 `std::vector<Lesson>`，`Lesson` 保留 `title` 和 `minutes`。

## 3～5 分钟练习

让原列表首项为 5 分钟、末项为 10 分钟；分别再测试只有 1 项和空列表。

## 参考答案

首尾 5 与 10 时输出 `5 分钟`；单项时首尾指向同一项，输出它的时长；空列表输出“暂无课程”，不调用 `front` 或 `back`。

## 与上一课的联系

继承第 24 课的首项、第 25 课的末项和既有 `empty()` 判断；本课只新增 `std::min` 比较两项时长；下一课可用同一组首尾值求较长时长。
