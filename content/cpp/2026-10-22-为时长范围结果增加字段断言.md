# 第 32 课：为时长范围结果增加字段断言

- 日期：2026-10-22
- 课程序号：第 32 课
- 知识点：assert 检查函数返回契约

## 用途或适用场景

检查全列表、单项和空列表的结构化结果。

## 核心概念

assert(false) 会中止程序，定义 NDEBUG 时断言会被关闭。断言只观察已有结果，不放入必须执行的业务操作；空结果不检查 minimum/maximum 的业务含义。

## 最小代码或操作示例

保留第 31 课 Lesson、MinutesRange、minutesRange；顶部加入：

```cpp
#include <assert.h>
```

在 main 中原 lessons 构造之后追加（原示例时长5/30/2/10不变）：

```cpp
const MinutesRange allRange = minutesRange(lessons);
assert(allRange.hasLessons);
assert(allRange.minimum == 2);
assert(allRange.maximum == 30);

const std::vector<Lesson> noLessons;
const MinutesRange emptyRange = minutesRange(noLessons);
assert(!emptyRange.hasLessons);

const std::vector<Lesson> oneLesson(1, lessons.front());
const MinutesRange oneRange = minutesRange(oneLesson);
assert(oneRange.hasLessons);
assert(oneRange.minimum == lessons.front().minutes);
assert(oneRange.maximum == lessons.front().minutes);
```

单项夹具前提是上述原 lessons 非空。使用 c++ -std=c++11 -UNDEBUG lesson.cpp -o lesson-check 后运行 ./lesson-check；不要把启用 NDEBUG 的构建当作断言验收。

## 3～5 分钟练习

把 allRange.maximum 的期望改成29，观察失败后恢复30。

## 参考答案

错误期望触发断言终止；恢复后全部契约满足。空结果只断言 hasLessons=false，不输出虚假的0～0范围。
