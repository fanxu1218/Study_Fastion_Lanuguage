# 第 13 课：重新启用避免重复调度

- 日期：2026-09-17
- 课程序号：第 13 课
- 知识点：重新启用避免重复调度

## 用途

验证组件重新启用后不会重复注册同一回调。

## 核心概念

onEnable 先用 isScheduled 检查；onDisable 用同一函数引用撤销，形成对称生命周期。

## 最小代码或操作示例

```text
onEnable(): void {
  if (!this.isScheduled(this.tick)) this.schedule(this.tick, 1)
}
onDisable(): void { this.unschedule(this.tick) }
```

## 3～5 分钟练习

连续禁用、启用两次并观察计数。

## 参考答案

每秒只增加一次，说明没有叠加重复调度。
