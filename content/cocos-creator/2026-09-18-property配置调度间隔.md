# 第 14 课：property配置调度间隔

- 日期：2026-09-18
- 课程序号：第 14 课
- 知识点：property配置调度间隔

## 用途或适用场景

让不同组件实例在 Inspector 中使用不同调度间隔。

## 核心概念

@property 把数值暴露给编辑器；schedule 仍使用同一个 tick 回调，生命周期清理不变。

## 最小代码或操作示例

```text
@property
interval = 1

onEnable(): void {
  if (!this.isScheduled(this.tick)) this.schedule(this.tick, this.interval)
}
```

## 3～5 分钟练习

把默认间隔改为 2 秒。

## 参考答案

将 `interval = 1` 改为 `interval = 2`。
