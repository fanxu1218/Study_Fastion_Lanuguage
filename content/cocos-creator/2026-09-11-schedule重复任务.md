# 第 9 课：schedule重复任务

- 日期：2026-09-11
- 课程序号：第 9 课
- 知识点：schedule 与时间间隔

## 用途

让组件按固定间隔重复执行轻量任务。

## 核心概念

`schedule` 注册重复回调，组件停用时应沿用上一课的清理边界。

## 最小代码或操作示例

```ts
private tick = (): void => { console.log('练习') }
protected onEnable(): void {
  this.schedule(this.tick, 1)
}
```

## 3～5 分钟练习

把间隔改为 0.5 秒并运行 2 秒。

## 参考答案

约触发 4 次；禁用组件后由清理逻辑停止。

## 与上一课的联系

上一课统一清理调度；本课注册可被清理的重复任务。
