# 第 4 课：property暴露移动速度

- 日期：2026-09-04
- 课程序号：第 4 课
- 知识点：装饰器与组件属性

## 用途

在 Inspector 调整节点速度。

## 核心概念

@property 标注可编辑字段；节点实例保存自己的配置值。保持 Creator 3.x 工程现有 TypeScript 设置。

## 最小代码或操作示例

```ts
import { _decorator, Component } from "cc";
const { ccclass, property } = _decorator;
@ccclass("ConfigurableMove")
export class ConfigurableMove extends Component {
  @property
  speed: number = 40;
  update(dt: number): void {
    const p = this.node.position;
    this.node.setPosition(p.x + this.speed * dt, p.y, p.z);
  }
}
```

## 3～5 分钟练习

挂到两个可见节点，禁用上一课重复移动脚本；将 Speed 分别设置为 20 和 -20。

## 参考答案

从相同 X 出发，2 秒局部位移约为 +40 和 -40；不必为不同速度创建不同脚本类。

## 与上一课的联系

上一课按时间移动，本课保留算法，只把速度改为组件输入。
