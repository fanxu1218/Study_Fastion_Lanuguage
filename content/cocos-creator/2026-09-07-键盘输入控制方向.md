## 核心概念

输入事件与按键状态用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```ts
private direction: number = 0;\nonKeyDown(event: EventKeyboard): void { if (event.keyCode === KeyCode.ARROW_LEFT) { this.direction = -1; } }
```

## 3～5 分钟练习
