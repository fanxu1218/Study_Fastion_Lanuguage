# 第 23 课：在onEnable中恢复调度

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：`onEnable` 调度

## 用途或适用场景

组件重新启用时恢复当前实例的计数回调。

## 核心概念

只在 `onEnable` 注册已有 `tick`，与上一课的 `onDisable` 成对。

## 最小代码或操作示例

```ts
protected onEnable(): void {
  this.schedule(this.tick, this.interval)
}
```

## 3～5 分钟练习

禁用再启用一个节点，观察该实例恢复计数。

## 参考答案

重新启用的实例恢复调度，另一个实例不受影响。

## 与上一课的联系

第 22 课在 `onDisable` 取消调度；本课只在 `onEnable` 恢复；下一课可防止重复注册。

时效校验：2026-10-09（Cocos Creator 3.8 LTS；Scheduler 文档仍提供 `schedule`/`unschedule`，未见废弃。）
