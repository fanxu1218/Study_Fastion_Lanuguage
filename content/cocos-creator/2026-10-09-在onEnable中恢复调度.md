# 第 23 课：在onEnable中恢复调度

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：`onEnable` 调度

## 用途或适用场景

组件重新启用时恢复当前实例的计数回调。

## 核心概念

把第 21 课 `start` 中的计数调度移到 `onEnable`，删除原 `start` 中的计数调度语句；保留已有 `tick`、`count` 和 `interval`，与上一课 `onDisable` 的取消成对。继续保留第 15 课的 0.1 秒下限。

## 最小代码或操作示例

```ts
protected onEnable(): void {
  this.schedule(this.tick, Math.max(this.interval, 0.1))
}
```

## 3～5 分钟练习

禁用再启用一个节点，观察该实例恢复计数。

## 参考答案

重新启用的实例恢复调度，另一个实例不受影响。

## 与上一课的联系

第 22 课在 `onDisable` 取消调度；本课只在 `onEnable` 恢复；下一课可验证同一回调重复调度时不会叠加任务。
