# 第 21 课：停止单个实例的计数回调

- 日期：2026-09-30
- 课程序号：第 21 课
- 知识点：`unschedule(callback)`

## 用途或适用场景

只停止当前组件实例的计数，不影响另一个节点上的同类实例。

## 核心概念

调度和取消必须使用同一个回调引用；组件实例各自持有自己的调度。

## 最小代码或操作示例

```ts
private tick = (): void => { this.count += 1; };
start(): void { this.schedule(this.tick, this.interval); }
stopCounting(): void { this.unschedule(this.tick); }
```

## 3～5 分钟练习

停止节点 A，继续观察节点 B 的计数。

## 参考答案

A 不再增加，B 按自己的间隔继续增加。

## 与上一课的联系
