# 第 8 课：unscheduleAllCallbacks生命周期清理

- 日期：2026-09-10
- 课程序号：第 8 课
- 知识点：组件禁用时清理调度

## 用途

组件退出使用时停止其延迟和重复任务。

## 核心概念

在明确生命周期边界清理当前组件注册的自定义调度。

## 最小代码或操作示例

```ts
protected onDisable(): void {
  this.unscheduleAllCallbacks();
}
```

## 3～5 分钟练习

注册每秒打印，禁用组件后观察。

## 参考答案

进入 `onDisable` 后不再由该组件触发打印。
