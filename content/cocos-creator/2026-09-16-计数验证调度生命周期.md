# 第 12 课：计数验证调度生命周期

- 日期：2026-09-16
- 课程序号：第 12 课
- 知识点：计数验证调度生命周期

## 用途

记录 tick 次数，验证启用与禁用边界。

## 核心概念

计数属于组件状态；调度仍用同一回调引用并在禁用时撤销。

## 最小代码或操作示例

```text
private count = 0
private tick = (): void => { this.count += 1 }
onDisable(): void { this.unschedule(this.tick) }
```

## 3～5 分钟练习

增加只读 getCount 方法。

## 参考答案

getCount(): number { return this.count }
