# 第 13 课：筛选已完成课程

- 日期：2026-09-17
- 课程序号：第 13 课
- 知识点：筛选已完成课程

## 用途

遍历课程数组时只处理完成状态为真的元素。

## 核心概念

For Each Loop 负责顺序遍历，Branch 根据结构体字段决定是否执行输出。

## 最小代码或操作示例

```text
1. For Each Loop 遍历 Lessons。
2. Break ST_Lesson 读取 Completed。
3. 用 Branch 只在 True 分支打印 Title。
```

## 3～5 分钟练习

在 False 分支累计未完成数量。

## 参考答案

False 分支把 PendingCount 加一，Completed 后打印总数。
