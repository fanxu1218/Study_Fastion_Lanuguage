# 第 3 课：蓝图实例变量

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：变量默认值与 Instance Editable

## 用途

让同一个 Actor 蓝图的两个关卡实例输出不同的课程名称。

## 核心概念

- 蓝图定义共享结构；放进关卡的每个实例可以拥有自己的变量值。
- Instance Editable 允许在关卡 Details 中改实例值；改一个实例不等于修改蓝图默认值。

## 最小代码或操作示例

```text
1. 打开上一课 BP_LessonActor，在 My Blueprint 中新增 String 变量 LessonName。
2. 勾选 Instance Editable，编译后将默认值设为“基础课”。
3. 在 Event Graph 中放置 Event BeginPlay 和 Print String。
4. 将 LessonName 以 Get 方式拖入图表，连接到 Print String 的 In String；
   将 BeginPlay 的执行引脚连接到 Print String。
5. 编译保存，在关卡放置两个该蓝图实例。
6. 在两个实例的 Details 中分别将 LessonName 改为“第一组”“第二组”，运行。
```

## 3～5 分钟练习

预测屏幕或 Output Log 中出现的两条文字；停止运行，只把第二个实例改为“复习组”，再次运行。

## 参考答案

```text
首次应有“第一组”和“第二组”，显示顺序不应作为契约；第二次为“第一组”和“复习组”。蓝图默认值仍是“基础课”。
```
