# 第 4 课：Branch与布尔实例配置

- 日期：2026-09-04
- 课程序号：第 4 课
- 知识点：Boolean 与执行引脚

## 用途

让 Actor 根据开关决定是否输出课程名称。

## 核心概念

Branch 用 Condition 选择 True/False 执行路径；数据引脚提供值，执行引脚决定节点何时工作。

## 最小代码或操作示例

```text
1. 沿用 BP_LessonActor，新增 Boolean 变量 ShowLesson，勾选 Instance Editable，默认 true。
2. 在 BeginPlay 与 Print String 之间插入 Branch。
3. 将 ShowLesson 的 Get 连接到 Condition，True 连接原 Print String。
4. False 留空；LessonName 继续连接 In String。
5. 编译，在关卡两个实例中分别将 ShowLesson 设为 true、false，然后运行。
```

## 3～5 分钟练习

把第二个实例也改成 true，再运行并对比日志。

## 参考答案

首次只有开启实例输出；第二次两个实例均输出自己的 LessonName。输出顺序不作为契约。
