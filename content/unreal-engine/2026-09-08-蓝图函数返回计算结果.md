# 第 6 课：蓝图函数返回计算结果

- 日期：2026-09-08
- 课程序号：第 6 课
- 知识点：Blueprint Function 与返回值

## 用途

把练习分钟数转换成秒数，并在多个执行流中复用结果。

## 核心概念

函数可以接收输入并返回输出，适合无延迟、需要立即得到结果的可复用计算。

## 最小代码或操作示例

```text
1. 新建函数 MinutesToSeconds。
2. 添加 Integer 输入 Minutes 和 Integer 输出 Seconds。
3. 将 Minutes 乘以 60，连接到 Return Node 的 Seconds。
```

## 3～5 分钟练习

在 `BeginPlay` 调用函数，输入 5，并用 `Print String` 输出结果。

## 参考答案

返回并输出 `300`；函数内不需要 Delay 节点。
