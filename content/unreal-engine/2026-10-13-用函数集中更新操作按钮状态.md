# 第 25 课：用函数集中更新操作按钮状态

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：用一个蓝图函数复用已有状态更新链

## 用途或适用场景

筛选条件多次改变时，每次都同时更新操作按钮的可用属性和工具提示文本。

## 核心概念

沿用 WBP_LessonCount 和现有操作 Button，只把第 23、24 课已有分支移入函数。函数输入 ResultCount 直接取本次筛选数组的 Length，不另外缓存一个业务数量。

## 最小代码或操作示例

```text
1. 在 WBP_LessonCount 的 My Blueprint 中新建函数 UpdateActionState。
2. 添加 Integer 输入 ResultCount，用 ResultCount > 0 连接 Branch。
3. True：现有操作 Button → Set Is Enabled(true)
         → Set Tool Tip Text（空 Text）。
4. False：同一 Button → Set Is Enabled(false)
          → Set Tool Tip Text（“没有可操作课程”）。
5. 在已有筛选更新流程中，取得 Length 后调用 UpdateActionState；
   CountText 继续使用已有 ShowCount / SetText 链，不重新创建 Widget。
```

移走原位置重复的按钮分支；函数中仍只有原来的两项属性更新。

## 3～5 分钟练习

用已学 MinMinutes 筛选产生 0、2、0 三次结果，每次把实际 Length 传入函数。在蓝图调试中检查 Is Enabled 和 Tool Tip Text 属性。

## 参考答案

数量 0 时 Is Enabled=false、提示属性为禁用原因；数量 2 时 Is Enabled=true、提示为空；回到 0 时原因重新设置。文本控件仍是原 CountText。工具提示属性的验收不依赖禁用控件能否触发悬停。

## 与上一课的联系

继承第 24 课可用时清空提示和第 23 课零结果原因文本；本课只将已有节点链封装为 UpdateActionState。下一课可把点击处理接到同一操作 Button，而不再复制筛选状态。
