# 第 5 课：自定义事件复用执行流

- 日期：2026-09-07
- 课程序号：第 5 课
- 知识点：Custom Event

## 用途

把重复提示逻辑封装为蓝图事件。

## 核心概念

Custom Event用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```text
1. 新建 Custom Event：ShowMessage。\n2. 添加 String 输入 Message 并连接 Print String。\n3. BeginPlay 调用它并传入 LessonName。
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

开始时输出实例课程名；其他事件也可调用同一执行流。
