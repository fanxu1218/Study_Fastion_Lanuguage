# 第 18 课：把筛选数量转换为文本

- 日期：2026-09-24
- 课程序号：第 18 课
- 知识点：`To Text (Integer)` 节点

## 用途或适用场景

把上一课算出的课程数量交给文本显示，不在筛选函数中拼字符串。

## 核心概念

`Length` 输出整数；`To Text (Integer)` 将该整数变成可显示的 `Text`。课程数组及筛选规则保持不变。

## 最小代码或操作示例

```text
1. 沿用第 17 课 MinMinutes=10 的 Result → Length 输出 B。
2. 将 B 连接到 To Text (Integer) 的 Value 输入。
3. 将 Return Value 接到 Print Text 的 In Text，并开启 Print to Screen。
```

## 3～5 分钟练习

分别对 `MinMinutes=0` 和 `10` 执行显示。

## 参考答案

上一课的两条已完成课程示例分别显示 `2`、`1`；底层 `Lessons` 不变。

## 与上一课的联系

继承第 17 课的两次 `GetCompletedLessons` 调用及 `Length` 结果；本课只新增整数转 `Text` 并输出；下一课可把文本放入正式 UI 控件。
