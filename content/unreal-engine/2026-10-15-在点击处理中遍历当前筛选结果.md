# 第 27 课：在点击处理中遍历当前筛选结果

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：OnClicked 消费筛选函数返回的数组

## 用途或适用场景

让同一操作按钮打印当前条件对应的课程标题，而不是只打印固定点击消息。

## 核心概念

复用原 Lessons、MinMinutes 与 GetCompletedLessons，点击时按当前条件取得本地筛选结果，直接遍历返回数组；不另存手工维护的数量或标题列表。这里没有仓库或网络查询，Print String 仍只是开发观察。

## 最小代码或操作示例

在同一 WBP_LessonCount 的现有 OnClicked 图中替换固定日志：

```text
1. 使用原筛选流程已能调用的 GetCompletedLessons，
   输入仍连接同一 Lessons 和当前 MinMinutes。
2. OnClicked 执行链调用该函数，把返回 Result 接到 For Each Loop 的 Array。
3. Loop Body 中将 Array Element 接 Break ST_Lesson，读取 Title。
4. 用原 Print String 输出该 Title（需要时沿用已有 Text/String 转换）。
5. 保留原筛选变化 → Length → UpdateActionState/CountText 更新流程。
```

若筛选函数原来在其他拥有者上，沿用现有对象引用调用，不创建第二份 Lessons。

## 3～5 分钟练习

用第 16 课两条已完成课程 5/15 分钟，MinMinutes=10 时点击一次；改为 20 后核对按钮禁用。

## 参考答案

阈值 10 只打印 15 分钟那条的实际 Title；阈值 20 结果为空且按钮禁用。没有把点击日志当作保存或业务处理成功，也没有复制第二份数据源。

## 与上一课的联系

继承第 25 课 UpdateActionState、第 26 课同一 OnClicked，以及第 12～16 课已学循环/结构体/筛选函数；本课只把固定日志替换为返回数组消费。下一课可在遍历完成出口输出本次处理结束消息。
