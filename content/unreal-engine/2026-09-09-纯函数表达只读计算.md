# 第 7 课：纯函数表达只读计算

- 日期：2026-09-09
- 课程序号：第 7 课
- 知识点：Blueprint Pure Function

## 用途

把不修改对象状态的即时计算显示为没有执行引脚的蓝图节点。

## 核心概念

纯函数只根据输入返回结果，不应产生可观察副作用；需要修改变量或控制时序时应保留普通函数。

## 最小代码或操作示例

```text
1. 打开上一课的 MinutesToSeconds 函数。
2. 在 Details 中勾选 Pure。
3. 把返回值直接连接到 Print String 的输入转换节点。
```

## 3～5 分钟练习

新建纯函数 `IsLongLesson`，输入分钟数，大于等于 30 时返回 true。

## 参考答案

用 `Minutes >= 30` 的布尔结果连接返回值，不在函数内写入实例变量。
