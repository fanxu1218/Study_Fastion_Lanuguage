# 第 23 课：为禁用按钮补充原因提示

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：Widget Tool Tip Text

## 用途或适用场景

零结果禁用操作按钮时说明不可用原因。

## 核心概念

只给上一课的同一 Button 设置提示文本，可用状态仍由筛选数量决定。

## 最小代码或操作示例

```text
当筛选数量为 0 时，对操作 Button 调用 Set Tool Tip Text，文本设为“没有可操作课程”。
```

## 3～5 分钟练习

分别用 0 和 2 条结果悬停按钮。

## 参考答案

零结果按钮禁用并显示原因；有结果时按钮启用。

## 与上一课的联系

第 22 课在零结果时禁用按钮；本课只补充禁用原因；下一课可在恢复可用时清理提示。

## 时效校验

时效校验：2026-10-09（Unreal Engine 5.8；官方 Blueprint API 当前提供 Widget `Set Tool Tip Text`。）
