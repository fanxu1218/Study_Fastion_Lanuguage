# 第 28 课：在标题遍历完成后输出结束消息

- 日期：2026-10-16
- 课程序号：第 28 课
- 知识点：For Each Loop 的 Completed 出口

## 用途或适用场景

在上一课逐条标题日志后增加一次“本轮遍历结束”。

## 核心概念

Loop Body为每个数组元素执行；Completed在整个同步遍历结束后继续。它不表示异步保存、网络请求或真实业务交付完成，本课仍只有开发日志。

## 最小代码或操作示例

在同一 WBP_LessonCount 的原 OnClicked 图中操作：

```text
1. 保留 GetCompletedLessons 的 Lessons/MinMinutes 输入和返回数组。
2. 保留 Loop Body → Break ST_Lesson → Print String(Title)。
3. 从同一 For Each Loop 的 Completed 引脚接第二个 Print String：
   “本次标题遍历结束”。
4. 保留原筛选数量→UpdateActionState/CountText，不新增计数变量。
```

不要把结束消息串在 Loop Body 的标题日志后，否则每条都会输出一次。

## 3～5 分钟练习

用已有5/15分钟两条完成课程，阈值0点击一次，再阈值10点击一次；检查结束消息次数。

## 参考答案

分别打印两条/一条标题，每次点击后各一条结束消息；阈值20时原按钮禁用，无用户点击流程。结束消息不宣称其他操作成功。
