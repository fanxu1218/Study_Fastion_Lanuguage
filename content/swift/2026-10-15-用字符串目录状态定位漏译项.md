# 第 27 课：用字符串目录状态定位漏译项

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：String Catalog 的 State 列

## 用途或适用场景

把上一课语言运行记录中的一项异常追溯到原目录翻译条目。

## 核心概念

State 列记录翻译维护状态；New 与已翻译标记帮助定位待处理项，但绿色勾不证明实际语言和复数输出已经通过。仍使用 lesson.count 与 lesson.unavailable，不在 Swift 中硬编码另一份译文。

## 最小代码或操作示例

在原 Xcode 15+ 应用的 Localizable.xcstrings 中操作：

```text
1. 对照第26课六格运行记录，选择一个真实异常项；无异常则做只读核对。
2. 选对应键 lesson.count 或 lesson.unavailable，再选对应语言。
3. 查看该语言值与 State；数量键继续展开原 One/Other 变体。
4. 确有漏译时，在练习副本补上对应译文，保留数值占位符。
5. Build 后用原 Scheme 语言、相同 count 再运行，把前后实际输出记入原表。
```

无漏译时不制造缺失项；未操作的步骤记“不适用”。

## 3～5 分钟练习

分别查看英文单数/复数和默认键的状态；对照上一课实际输出，记录“目录状态”和“运行结果”两列。

## 参考答案

翻译值、变体和运行记录可逐项对应。目录已翻译但运行不符时仍保留问题，继续检查语言选择、target 归属和实际构建，不直接标通过。
