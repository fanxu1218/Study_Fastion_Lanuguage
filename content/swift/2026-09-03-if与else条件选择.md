# 第 3 课：if与else条件选择

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：Bool 条件与多分支顺序

## 用途

用练习分数生成不同的反馈文字。

## 核心概念

- Swift 的 if 条件需要 Bool；代码块使用花括号。
- 条件从上向下判断，同一条链中只执行首个匹配分支。

## 最小代码或操作示例

```swift
let score = 75
if score >= 90 {
    print("优秀")
} else if score >= 60 {
    print("通过")
} else {
    print("继续练习")
}
```

## 3～5 分钟练习

在 Swift 命令行或 Playground 中分别测试 59、60、90；把优秀分支放到 >=60 后会怎样？

## 参考答案

```text
正确顺序输出依次是“继续练习”“通过”“优秀”。若先检查 >=60，90 会提前命中并输出“通过”。
```

## 与上一课的联系

上一课认识 Int 和 Bool；本课让 Int 比较产生的 Bool 决定执行哪一段代码。
