# 第 7 课：Set去重与成员判断

- 日期：2026-09-09
- 课程序号：第 7 课
- 知识点：Set 与 contains

## 用途

保存不重复的已完成课程名称，并快速判断某项是否存在。

## 核心概念

`Set` 中每个元素唯一且没有固定顺序；`contains` 返回成员是否存在。

## 最小代码或操作示例

```swift
var completed: Set<String> = ["变量", "循环"]
completed.insert("循环")
print(completed.contains("变量"))
```

## 3～5 分钟练习

插入“函数”，再输出集合的 `count`。

## 参考答案

集合新增一项，`count` 为 `3`；重复插入“循环”不会增加数量。

## 与上一课的联系

上一课用字典建立键值关系；本课用集合只表达元素是否存在。
