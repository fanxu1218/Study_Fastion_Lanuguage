# 第 25 课：用字符串目录配置数量复数

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：String Catalog 的复数变体

## 用途或适用场景

让同一课程数量在英文中分别显示单数 lesson 与复数 lessons。

## 核心概念

沿用已有 `count: Int?`、`available`、`message` 和 `lesson.count` 键。字符串目录负责按语言选择复数形式；数量依然只有 `count` 这一个来源。用带插值的 `String(localized:defaultValue:)` 保留数值信息，供目录的复数规则使用。

## 最小代码或操作示例

在原应用中使用 Xcode 15 或更新版本，部署目标至少 macOS 12 / iOS 15：

1. 已有 `Localizable.strings` 时右键选择 Migrate to String Catalog，保留已有键和值；没有该表时选择 File > New > File from Template > String Catalog，建立 `Localizable.xcstrings` 并加入原应用 target。
2. 将上一课数量分支替换为下面代码，保留 `import Foundation` 与原 `count`：

```swift
let unavailable = NSLocalizedString("lesson.unavailable", comment: "No lesson")
let available = count.map { value in
    String(localized: "lesson.count",
           defaultValue: "\(value) lessons available",
           comment: "Available lesson count")
}
let message = available ?? unavailable
print(message)
```

3. Product > Build 后选中目录中的 `lesson.count`。在英文项上 Control-click > Vary by Plural：One 填 `%lld lesson available`，Other 填 `%lld lessons available`；保留编辑器为插值生成的 `%lld`。
4. 中文数量项设为 `可用 %lld 节`，默认键 `lesson.unavailable` 继续使用“暂无可用课程”。在运行 Scheme 的 Options 中选择英文 App Language，再运行原入口。

## 3～5 分钟练习

将 `count` 分别设为 `1`、`3` 和 `nil`；再切回中文，核对数量文案。

## 参考答案

英文分别显示 `1 lesson available`、`3 lessons available`；`nil` 使用已有默认键的语言值；中文非空分别显示“可用 1 节”“可用 3 节”。默认键的翻译也应在同一目录中存在。
