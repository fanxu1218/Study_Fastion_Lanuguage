# 第 10 课：结构体与成员方法

- 日期：2026-09-14
- 课程序号：第 10 课
- 知识点：`struct`、存储属性与方法

## 用途

表示轻量值数据，并把相关行为放在同一类型中。

## 核心概念

结构体是值类型；实例方法可读取属性，修改属性的方法需标记 `mutating`。

## 最小代码或操作示例

```swift
struct Lesson {
    var minutes: Int

    mutating func extend() {
        minutes += 5
    }
}
```

## 3～5 分钟练习

增加只读 `title` 属性，并创建一个实例。

## 参考答案

加入 `let title: String`，再写 `var lesson = Lesson(minutes: 5, title: "Swift")`。
