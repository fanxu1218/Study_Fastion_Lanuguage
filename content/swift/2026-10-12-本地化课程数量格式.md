# 第 24 课：本地化课程数量格式

- 日期：2026-10-12
- 课程序号：第 24 课
- 知识点：`String.localizedStringWithFormat`

## 用途或适用场景

让含数量的提示使用本地化格式字符串。

## 核心概念

`localizedStringWithFormat` 把已有 Int 数量代入本地化格式。沿用第 23 课的字符串资源管理方式，先把 `lesson.count` 的中文值设为 `可用 %ld 节`；`%ld` 与这里的 Int 参数匹配。`lesson.unavailable` 仍为“暂无可用课程”。

## 最小代码或操作示例

在原 Swift 文件中保留 `import Foundation`、`count: Int?` 和 `unavailable`，确保上述键已加入应用资源，再追加：

```swift
let format = NSLocalizedString("lesson.count", comment: "Available lesson count")
let available = count.map { String.localizedStringWithFormat(format, $0) }
let message = available ?? unavailable
```

## 3～5 分钟练习

把 `count` 分别设为 `3` 和 `nil`，在含字符串资源的原应用入口运行。

## 参考答案

`count == 3` 时显示“可用 3 节”；`nil` 时显示“暂无可用课程”。如果显示 `lesson.count`，说明该键未加入实际运行的应用资源，应修正资源配置再验证。
