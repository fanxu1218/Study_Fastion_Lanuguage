# 第 15 课：穷尽switch读取加载状态

- 日期：2026-09-21
- 课程序号：第 15 课
- 知识点：穷尽switch读取加载状态

## 用途或适用场景

让每种 LoadState 都有可见描述。

## 核心概念

switch 对枚举逐项匹配关联值；不使用 default 以便新增状态时得到编译提醒。

## 最小代码或操作示例

```text
func text(_ state: LoadState) -> String {
    switch state {
    case .loading: return "加载中"
    case .ready(let count): return "共 \(count) 节"
    case .failed(let message): return message
    }
}
```

## 3～5 分钟练习

传入 .ready(count: 3)。

## 参考答案

返回“共 3 节”。

## 与上一课的联系
