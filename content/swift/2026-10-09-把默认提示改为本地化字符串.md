# 第 23 课：把默认提示改为本地化字符串

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：`NSLocalizedString`

## 用途或适用场景

让默认课程提示可随应用语言切换。

## 核心概念

只替换上一课的硬编码默认值，`Optional` 合并逻辑保持不变。

## 最小代码或操作示例

```swift
let unavailable = NSLocalizedString("lesson.unavailable", comment: "No lesson")
let message = count.map { "可用 \($0) 节" } ?? unavailable
```

## 3～5 分钟练习

在字符串表中加入中文默认值。

## 参考答案

`count == nil` 时读取本地化值，非空数量分支不变。

## 与上一课的联系

第 22 课把默认提示抽成常量；本课只把常量改为本地化查找；下一课可本地化数量格式。
