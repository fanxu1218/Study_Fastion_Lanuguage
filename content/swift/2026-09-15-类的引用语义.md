# 第 11 课：类的引用语义

- 日期：2026-09-15
- 课程序号：第 11 课
- 知识点：class 与引用共享

## 用途

理解多个变量指向同一个课程对象时的状态变化。

## 核心概念

类是引用类型；赋值复制引用，任一引用修改属性都会反映到同一实例。

## 最小代码或操作示例

```swift
final class Lesson {
    var minutes = 5
}
let first = Lesson()
let same = first
same.minutes += 5
print(first.minutes)
```

## 3～5 分钟练习

用 `first === same` 检查是否同一实例。

## 参考答案

`print(first === same)` 输出 `true`。
