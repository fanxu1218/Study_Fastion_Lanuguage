# 第 9 课：函数参数与返回值

- 日期：2026-09-11
- 课程序号：第 9 课
- 知识点：函数定义

## 用途

把可重复计算封装为带输入和输出的函数。

## 核心概念

参数标签提高调用可读性，箭头后的类型声明返回值。

## 最小代码或操作示例

```swift
func score(for minutes: Int) -> Int {
    minutes * 2
}
let result = score(for: 5)
```

## 3～5 分钟练习

让函数最多返回 100。

## 参考答案

返回 `min(minutes * 2, 100)`。

上一课用字典保存值；本课封装对值的重复计算。
