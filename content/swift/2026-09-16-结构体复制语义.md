# 第 12 课：结构体复制语义

- 日期：2026-09-16
- 课程序号：第 12 课
- 知识点：结构体复制语义

## 用途

对照上一课的类，观察值类型赋值后的独立修改。

## 核心概念

结构体赋值会复制值；修改副本不会改变原实例。

## 最小代码或操作示例

```text
struct Lesson { var minutes = 5 }
let first = Lesson()
var copy = first
copy.minutes += 5
print(first.minutes)
```

## 3～5 分钟练习

打印 copy.minutes 并比较。

## 参考答案

first 为 5，copy 为 10。
