# 第 22 课：把默认提示抽成常量

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：可复用默认值

## 用途或适用场景

避免多个空值分支重复硬编码相同文案。

## 核心概念

本课只增加“可复用默认值”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```swift
let unavailable = "暂无可用课程"
let message = count.map { "可用 \($0) 节" } ?? unavailable
```

## 3～5 分钟练习

把 `count` 分别设为 `nil` 和 `3`。

## 参考答案

只在 `nil` 时使用常量，非空值仍显示数量。

## 与上一课的联系

第 21 课用 `??` 合并提示；本课只抽取默认常量；下一课可做本地化。
