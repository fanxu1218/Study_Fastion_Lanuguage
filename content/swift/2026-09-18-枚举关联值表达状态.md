# 第 14 课：枚举关联值表达状态

- 日期：2026-09-18
- 课程序号：第 14 课
- 知识点：枚举关联值表达状态

## 用途或适用场景

用一个类型表达加载中、成功数量和失败消息。

## 核心概念

每个 case 可携带不同关联值；switch 必须覆盖所有状态。

## 最小代码或操作示例

```text
enum LoadState {
    case loading
    case ready(count: Int)
    case failed(message: String)
}
```

## 3～5 分钟练习

用 switch 输出 ready 的 count。

## 参考答案

在 `.ready(let count)` 分支中打印 count。

## 与上一课的联系

继承上一课对 struct 与 class 的建模选择；本课只增加有限状态及关联数据；完成后下一课可写穷尽 switch。
