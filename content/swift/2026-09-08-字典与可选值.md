# 第 6 课：字典与可选值

- 日期：2026-09-08
- 课程序号：第 6 课
- 知识点：Dictionary 与可选绑定

## 用途

按课程名称查找练习时长，并安全处理不存在的键。

## 核心概念

字典下标返回可选值，因为指定键可能不存在；`if let` 只在取到值时进入分支。

## 最小代码或操作示例

```swift
let minutes = ["Swift": 20, "Kotlin": 15]
if let value = minutes["Swift"] {
    print(value)
}
```

## 3～5 分钟练习

查询不存在的“Rust”，并在没有结果时输出 0。

## 参考答案

使用 `print(minutes["Rust"] ?? 0)`，会输出 `0`。
