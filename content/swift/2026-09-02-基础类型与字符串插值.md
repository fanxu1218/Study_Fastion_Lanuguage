# 第 2 课：基础类型与字符串插值

- 日期：2026-09-02
- 课程序号：第 2 课
- 知识点：Int、Double、Bool、String

## 用途

用明确类型描述一条学习记录。

## 核心概念

- 类型标注写在冒号后；Swift 不隐式把 Int 转成 Double 参与混合运算。
- 字符串中的 \(表达式) 插入计算结果。

## 最小代码或操作示例

```swift
let course: String = "Swift"
let minutes: Int = 5
let speed: Double = 1.5
let finished: Bool = false
print("\(course)：\(Double(minutes) * speed)，完成：\(finished)")
```

## 3～5 分钟练习

声明单价 Double 与数量 Int，输出总价。

## 参考答案

```swift
let price: Double = 12.5
let count: Int = 2
print("总价：\(price * Double(count))") // 25.0
```
