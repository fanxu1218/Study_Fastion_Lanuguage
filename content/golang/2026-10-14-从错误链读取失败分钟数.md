# 第 27 课：从错误链读取失败分钟数

- 日期：2026-10-14
- 课程序号：第 27 课
- 知识点：errors.AsType[*MinutesError]

## 用途或适用场景

从上一课携带 Minutes 的错误链中取出具体包装值。

## 核心概念

当前官方建议多数类型匹配场景使用 AsType。方括号里的 *MinutesError 指定要寻找的错误类型；返回匹配值和 ok。AsType 自 Go 1.26 可用，旧 As 仍支持；本课不引入泛型函数定义。

## 最小代码或操作示例

保留 lesson.go 的 MinutesError、Error/Unwrap、哨兵及 message。在第 26 课 TestMessage 的 second 之后追加，继续沿用 fmt/errors 导入：

```go
outer := fmt.Errorf("save lesson: %w", second)
typed, ok := errors.AsType[*MinutesError](outer)
if !ok {
    t.Fatal("missing MinutesError")
}
if typed.Minutes != -3 {
    t.Fatalf("minutes=%d", typed.Minutes)
}
```

先用 go version 确认至少 1.26，再执行原 go test lesson.go lesson_test.go。类型查询沿完整错误链进行，不解析错误文本。

## 3～5 分钟练习

把 second 改为 Minutes=80、根错误 errTooLong，并把期望分钟数改成 80；保留已有 errors.Is 和提示测试。

## 参考答案

AsType 找到同一个 *MinutesError 并返回其 Minutes；errors.Is 仍识别 errTooLong，message 仍为“最多 60 分钟”。不匹配时必须先处理 ok=false，不读取 nil 指针字段。
