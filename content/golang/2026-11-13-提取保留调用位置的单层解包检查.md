# 第 48 课：提取保留调用位置的单层解包检查

- 日期：2026-11-13
- 课程序号：第 48 课
- 知识点：断言辅助函数与t.Helper组合

## 用途或适用场景

复用第47课七行中原有的Unwrap检查。

## 核心概念

辅助函数只移动一项断言；t.Helper使失败文件/行指向调用方。整链Is检查及固定表仍留在原子测试，不改变错误链。

## 最小代码或操作示例

沿第46课诊断与第47课恢复表，在原_test.go同一package中加入：
```go
func checkUnwrap(t *testing.T, err error, want error) {
    t.Helper()
    if errors.Unwrap(err) != want {
        t.Fatal("单层解包不符")
    }
}
```
把TestWrappingComparison的t.Run中原单层Unwrap的if整段替换为：
```go
checkUnwrap(t, row.err, row.inner)
```
保留原testing/errors导入、Is(root)消息、七行及sameText/文字相等检查。先go test -run '^TestWrappingComparison$' -v，再go test ./...；沿原Go1.26+，本课不再提取第二项断言。

## 3～5 分钟练习

删除t.Helper后比较逻辑会改变吗？

## 参考答案

不会改变Unwrap比较，但失败位置会指向辅助函数内部；保留Helper更便于定位原表调用。
