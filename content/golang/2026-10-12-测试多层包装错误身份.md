# 第 25 课：测试多层包装错误身份

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：两层 `%w` 错误链测试

## 用途或适用场景

核对课程时长校验的错误身份与对应提示。

## 核心概念

第二次 `%w` 包装接收第一层错误，`errors.Is` 沿链继续查找同一个 `errMinutes`；测试仍按第 22 课提示契约判断，不解析错误字符串。

## 最小代码或操作示例

保留第 24 课测试文件 import，在 `TestMessage` 中追加：

```go
first := fmt.Errorf("validate: %w", errMinutes)
second := fmt.Errorf("save lesson: %w", first)
if !errors.Is(second, errMinutes) {
    t.Fatal("lost identity")
}
if got := message(second); got != "请输入正数分钟" {
    t.Fatalf("message=%q", got)
}
```

继续执行 `go test lesson.go lesson_test.go`。

## 3～5 分钟练习

用已有 `errTooLong` 作为根错误重做两层包装，并核对提示。

## 参考答案

根错误身份仍被识别；`errMinutes` 的提示是“请输入正数分钟”，`errTooLong` 的提示是“最多 60 分钟”。
