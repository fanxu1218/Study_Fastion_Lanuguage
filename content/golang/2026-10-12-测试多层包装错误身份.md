# 第 25 课：测试多层包装错误身份

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：多层 `%w` 错误链

## 用途或适用场景

确认错误经过两层上下文包装后仍可识别根错误。

## 核心概念

本课只沿用上一课的已有数据与命名，并增加上述单一知识点。

## 最小代码或操作示例

```go
first := fmt.Errorf("validate: %w", errTooShort)
second := fmt.Errorf("save lesson: %w", first)
if !errors.Is(second, errTooShort) { t.Fatal("lost identity") }
```

## 3～5 分钟练习

按示例完成一次最小操作，并核对结果。

## 参考答案

根错误经过两层包装后仍能被 `errors.Is` 识别。
