# 第 28 课：验证错误链不含分钟包装时的结果

- 日期：2026-10-15
- 课程序号：第 28 课
- 知识点：AsType 的不匹配分支契约

## 用途或适用场景

验证没有 MinutesError 的错误链仍保留身份，但不会产生虚构的分钟数。

## 核心概念

errors.AsType 不匹配时返回目标类型的零值与 false；对 *MinutesError 来说零值是 nil。先检查 ok，不能在失败分支读取 typed.Minutes。类型匹配与 errors.Is 的错误身份检查相互独立。

## 最小代码或操作示例

在原 lesson_test.go 中增加独立测试，沿用 testing/errors/fmt 导入：

```go
func TestMissingMinutesWrapper(t *testing.T) {
    outer := fmt.Errorf("save lesson: %w", errMinutes)
    typed, ok := errors.AsType[*MinutesError](outer)
    if ok || typed != nil {
        t.Fatal("unexpected MinutesError")
    }
    if !errors.Is(outer, errMinutes) {
        t.Fatal("lost root identity")
    }
    if got := message(outer); got != "请输入正数分钟" {
        t.Fatalf("message=%q", got)
    }
}
```

使用 Go 1.26+ 执行原 `go test lesson.go lesson_test.go`，保留上一课匹配成功的测试。

## 3～5 分钟练习

将本测试根错误改成 errTooLong，同时改身份和文案期望；保持不加入 MinutesError。

## 参考答案

ok 仍为 false、typed 为 nil，但 errors.Is 能识别 errTooLong，message 输出“最多 60 分钟”。无法取得分钟数不等于根错误消失。
