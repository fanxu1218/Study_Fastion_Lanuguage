# 第 14 课：接口值的nil判断

- 日期：2026-09-17
- 课程序号：第 14 课
- 知识点：接口值的nil判断

## 用途

区分 nil 接口与包含 nil 指针的接口值。

## 核心概念

接口值同时包含动态类型和值；只有两部分都为空时，接口才等于 nil。

## 最小代码或操作示例

```text
var lesson *Lesson = nil
var item any = lesson
fmt.Println(item == nil)
```

## 3～5 分钟练习

直接声明 var empty any 并比较 nil。

## 参考答案

empty == nil 为 true；item == nil 为 false。
