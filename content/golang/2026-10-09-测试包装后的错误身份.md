# 第 24 课：测试包装后的错误身份

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：一次 `%w` 包装的测试

## 用途或适用场景

核对课程时长校验的错误身份与对应提示。

## 核心概念

仍使用 `errMinutes` 和 `errTooLong`，把新增包装对象放到第 23 课的测试函数中；提示函数按 errors.Is 检查身份，所以文字上下文不会改变文案。

## 最小代码或操作示例

在 `lesson_test.go` 的 import 增加 `"errors"` 和 `"fmt"`，在 `TestMessage` 表格后追加：

```go
wrapped := fmt.Errorf("validate minutes: %w", errMinutes)
if !errors.Is(wrapped, errMinutes) {
    t.Fatal("lost identity")
}
if got := message(wrapped); got != "请输入正数分钟" {
    t.Fatalf("message=%q", got)
}
```

继续运行上一课的 `go test lesson.go lesson_test.go`。

## 3～5 分钟练习

把 `errTooLong` 也用相同方式包装，并在表格中加入其提示断言。

## 参考答案

`errors.Is` 分别识别原 `errMinutes` / `errTooLong`；提示分别为“请输入正数分钟”和“最多 60 分钟”；包装文本只补充上下文。
