# 第 2 课：变量与零值

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：`var`、短变量声明与零值

## 用途

保存程序数据，并理解未显式初始化的变量仍有确定值。

## 核心概念

- `var name type` 声明变量，未赋值时使用零值。
- 函数内可用 `:=` 推断类型。
- 整数、布尔和字符串零值分别是 `0`、`false`、空字符串。

## 最小代码示例

```go
package main
import "fmt"
func main() {
	var count int
	language := "Go"
	fmt.Println(language, count)
}
```

## 3～5 分钟练习

声明未赋值的 `bool`，再用 `:=` 声明课程序号并输出。

## 参考答案

```go
var finished bool
lesson := 2
fmt.Println(finished, lesson)
```
