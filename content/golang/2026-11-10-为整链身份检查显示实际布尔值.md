# 第 45 课：为整链身份检查显示实际布尔值

- 日期：2026-11-10
- 课程序号：第 45 课
- 知识点：单次Is结果与固定期望诊断

## 用途或适用场景

让第44课同文错误的身份失败可直接定位。

## 核心概念

展示文字不能代替链身份；保存一次errors.Is结果再用于比较与消息，避免诊断重复计算。

## 最小代码或操作示例

沿第43课七行cases和第44课文字比较，在TestWrappingComparison的t.Run内仅替换原整链身份if：
```go
if got := errors.Is(row.err, root); got != row.wantRoot {
    t.Fatalf("Is(root)=%v, want=%v; err=%v",
        got, row.wantRoot, row.err)
}
```
保留前面的Unwrap独立检查、七行固定期望、sameText的两项身份检查与两份Error文字相等检查。先go test -run '^TestWrappingComparison$' -v，再运行全部旧测试；沿原Go1.26+。

## 3～5 分钟练习

临时把wrapped-same-text的wantRoot改true，应该看到什么？观察后恢复。

## 参考答案

该子测试应显示Is(root)=false, want=true；它包装sameText而非root。恢复false，不用比较Error文字替换Is。

## 与上一课的联系
