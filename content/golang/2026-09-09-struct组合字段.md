# 第 8 课：struct组合字段

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：结构体定义与字段访问

## 用途

把课程名称和练习时长组合成一个明确的数据类型。

## 核心概念

`struct` 把相关字段组织在一起；复合字面量可以按字段名初始化，点号用于读取字段。

## 最小代码或操作示例

```go
type Lesson struct {
    Name    string
    Minutes int
}

lesson := Lesson{Name: "Go", Minutes: 20}
fmt.Println(lesson.Name)
```

## 3～5 分钟练习

把 `Minutes` 增加 5 并输出。

## 参考答案

执行 `lesson.Minutes += 5`，输出结果为 `25`。
