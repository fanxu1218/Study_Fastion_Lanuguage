# 第 43 课：对照同文错误的非包装格式化

- 日期：2026-11-06
- 课程序号：第 43 课
- 知识点：同一根错误的百分号v反例

## 用途或适用场景

验证文字保留不等于错误链保留。

## 核心概念

%v把sameText格式化成文字，不建立Unwrap链；%w保留的也是sameText自身，而不是同文字root。

## 最小代码或操作示例

沿第41课sameText与第42课wrappedSameText，在TestWrappingComparison同一初始化区域追加：
```go
brokenSameText := fmt.Errorf("save: %v", sameText)
if errors.Is(brokenSameText, sameText) {
    t.Fatal("非包装错误不应保留sameText身份")
}
```
在cases原六行之后追加：
```go
{"broken-same-text", brokenSameText, nil, false},
```
保留good/broken/root/nil/same-text/wrapped-same-text、两项独立断言及所有旧测试。先go test -run '^TestWrappingComparison/broken-same-text$' -v，再运行全部测试；沿Go1.26+。

## 3～5 分钟练习

brokenSameText与wrappedSameText文字相同，就可共享wantUnwrap吗？

## 参考答案

不能。前者nil，后者sameText；两者对root均为false，需逐项保留独立期望。
