# 第 42 课：包装同文错误并保留独立身份

- 日期：2026-11-05
- 课程序号：第 42 课
- 知识点：正确包装只保留实际被包装的根

## 用途或适用场景

区分包装成功和匹配到了指定root两件事。

## 核心概念

给sameText加%w会保留sameText身份，但不会把它变成root。Unwrap应返回sameText，Is对root仍为false。

## 最小代码或操作示例

沿第40课nil行及第41课sameText，在TestWrappingComparison的sameText初始化后追加：

```go
wrappedSameText := fmt.Errorf("save: %w", sameText)
if !errors.Is(wrappedSameText, sameText) {
    t.Fatal("未保留实际包装的根错误")
}
```

在原cases五行后追加，沿已有fmt、errors导入及匿名结构：

```go
{"wrapped-same-text", wrappedSameText, sameText, false},
```

保留两项独立表断言和全部旧测试。先go test -run '^TestWrappingComparison/wrapped-same-text$' -v确认目标执行，再go test -v；沿原Go1.26+项目。

## 3～5 分钟练习

该行wantRoot写true，会把什么混为一谈？

## 参考答案

把sameText身份与root身份混同；文字相同也仍是不同错误。实际包装根单独由errors.Is(wrappedSameText, sameText)核对。
