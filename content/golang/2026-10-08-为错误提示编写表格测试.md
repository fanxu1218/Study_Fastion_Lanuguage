# 第 23 课：为错误提示编写表格测试

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：表格驱动测试

## 用途或适用场景

核对课程时长校验的错误身份与对应提示。

## 核心概念

沿用第 22 课的 `errMinutes`、`errTooLong` 和 `message(err)`；每一行同时保存输入错误和预期提示，遍历后逐项比较。测试文件必须名为 `lesson_test.go`，与既有 main 包代码放在同一目录。

## 最小代码或操作示例

下面是测试文件全部内容；`message` 与两个哨兵错误仍由上一课的同包代码提供：

```go
package main

import "testing"

func TestMessage(t *testing.T) {
    cases := []struct {
        err error
        want string
    }{
        {errMinutes, "请输入正数分钟"},
        {errTooLong, "最多 60 分钟"},
        {nil, ""},
    }
    for _, tc := range cases {
        if got := message(tc.err); got != tc.want {
            t.Fatalf("message(%v)=%q, want %q", tc.err, got, tc.want)
        }
    }
}
```

在该目录执行 `go test lesson.go lesson_test.go`（`lesson.go` 是保存第 22 课代码的文件名）。

## 3～5 分钟练习

把一个 `errors.New("other")` 输入加入表格；按第 22 课默认分支填写预期值，所需 `errors` 放入测试文件的 import。

## 参考答案

新增 `{errors.New("other"), "时长校验失败"}`，全部断言通过；`nil` 对应空提示，两个校验错误的文案保持原样。
