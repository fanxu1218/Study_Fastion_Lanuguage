# 第 15 课：error接口返回失败

- 日期：2026-09-18
- 课程序号：第 15 课
- 知识点：error接口返回失败

## 用途或适用场景

让函数把可预期的失败交给调用方处理。

## 核心概念

error 是内建接口；成功返回 nil，失败返回具体错误值，调用方显式检查。

## 最小代码或操作示例

```text
func validate(minutes int) error {
\tif minutes <= 0 { return errors.New("minutes must be positive") }
\treturn nil
}
```

## 3～5 分钟练习

调用 validate 并打印错误。

## 参考答案

`if err := validate(0); err != nil { fmt.Println(err) }`
