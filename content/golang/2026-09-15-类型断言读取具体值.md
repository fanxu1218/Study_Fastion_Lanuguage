# 第 12 课：类型断言读取具体值

- 日期：2026-09-15
- 课程序号：第 12 课
- 知识点：接口值与类型断言

## 用途

在确实需要具体类型能力时安全取回接口中的值。

## 核心概念

逗号 ok 形式的类型断言在类型不匹配时返回 false，避免 panic。

## 最小代码或操作示例

```go
value, ok := item.(Lesson)
if ok {
	fmt.Println(value.Name())
}
```

## 3～5 分钟练习

断言为 `*Lesson` 并处理失败分支。

## 参考答案

`lesson, ok := item.(*Lesson); if !ok { return }`
