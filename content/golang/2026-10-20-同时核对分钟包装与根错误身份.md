# 第 30 课：同时核对分钟包装与根错误身份

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：表格行同时验证类型数据与错误身份

## 用途或适用场景

让同一输入同时检查 AsType 与 Is 的独立契约。

## 核心概念

分钟包装承载数据，根错误表达身份；两项都应检查。Is 在类型不命中时仍能识别根错误，因此身份断言放在未命中提前返回之前。

## 最小代码或操作示例

将第 29 课同名测试替换为下列版本，保留原导入及 MinutesError/message：

```go
func TestMinutesTypeCases(t *testing.T) {
    cases := []struct {
        name string
        err error
        wantOK bool
        wantMinutes int
        wantRoot error
    }{
        {"wrapped", fmt.Errorf("save: %w", &MinutesError{Minutes: -3, Err: errMinutes}), true, -3, errMinutes},
        {"root-only", fmt.Errorf("save: %w", errMinutes), false, 0, errMinutes},
    }
    for _, tc := range cases {
        t.Run(tc.name, func(t *testing.T) {
            if !errors.Is(tc.err, tc.wantRoot) {
                t.Fatal("lost expected root identity")
            }
            typed, ok := errors.AsType[*MinutesError](tc.err)
            if ok != tc.wantOK { t.Fatalf("ok=%v", ok) }
            if !ok {
                if typed != nil { t.Fatal("expected nil") }
                return
            }
            if typed.Minutes != tc.wantMinutes {
                t.Fatalf("minutes=%d", typed.Minutes)
            }
        })
    }
}
```

用 Go1.26+ 执行 go test lesson.go lesson_test.go。

## 3～5 分钟练习

新增一行：Minutes=80、Err=errTooLong、wantRoot=errTooLong，其余期望对应填写。

## 参考答案

该行类型命中、分钟为80、根身份为errTooLong；root-only 仍不命中 MinutesError，但 Is 通过。把任一 wantRoot 改错应使对应子测试失败。
