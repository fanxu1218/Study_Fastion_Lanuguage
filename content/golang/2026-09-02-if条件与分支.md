# 第 3 课：if条件与分支

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：布尔条件、花括号与 else

## 用途

根据输入数据选择执行路径。

## 核心概念

- if 条件不需要圆括号，但分支需要花括号。
- else 与前一个分支的右花括号写在同一行。

## 最小代码或操作示例

```go
package main
import "fmt"
func main() {
    score := 60
    if score >= 60 {
        fmt.Println("及格")
    } else {
        fmt.Println("继续练习")
    }
}
```

## 3～5 分钟练习

加入 >=90 的优秀分支并核对 59、60、90。

## 参考答案

```go
// 替换 main 中的 if
if score >= 90 {
    fmt.Println("优秀")
} else if score >= 60 {
    fmt.Println("及格")
} else {
    fmt.Println("继续练习")
}
```
