# 第 38 课：用同一表对照整链身份与单层解包

- 日期：2026-10-30
- 课程序号：第 38 课
- 知识点：Is查找和Unwrap观察的成对期望

## 用途或适用场景

用同一表对照整链身份与单层解包，用于在已有示例中练习Is查找和Unwrap观察的成对期望。

## 核心概念

同一包装值可同时检查单层返回与整链身份；预期分别写出，不能用Unwrap结果计算Is期望来形成自证。

## 最小代码或操作示例

沿第36课断链反例及第37课Unwrap，在原_test.go追加，保留原七行及两个独立测试：

```go
func TestWrappingComparison(t *testing.T) {
    root := errors.New("disk")
    goodInner := fmt.Errorf("save: %w", root)
    brokenInner := fmt.Errorf("save: %v", root)
    cases := []struct {
        name string
        err error
        inner error
        wantRoot bool
    }{
        {"good", fmt.Errorf("submit: %w", goodInner), goodInner, true},
        {"broken", fmt.Errorf("submit: %w", brokenInner), brokenInner, false},
    }
    for _, row := range cases {
        t.Run(row.name, func(t *testing.T) {
            if errors.Unwrap(row.err) != row.inner {
                t.Fatal("单层解包不符")
            }
            if errors.Is(row.err, root) != row.wantRoot {
                t.Fatal("整链身份不符")
            }
        })
    }
}
```

沿errors、fmt、testing导入及Go1.26+项目；go test -run '^TestWrappingComparison$' -v后go test -v。

## 3～5 分钟练习

把broken的wantRoot错填true，哪项检查失败？

## 参考答案

broken子测试的整链身份检查失败；单层仍可取得brokenInner，不能由非nil单层结果推定根可达。恢复false。
