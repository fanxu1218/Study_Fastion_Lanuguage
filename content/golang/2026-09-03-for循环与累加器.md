# 第 4 课：for循环与累加器

- 日期：2026-09-03
- 课程序号：第 4 课
- 知识点：三段式 for 与循环作用域

## 用途

求连续整数的总和，认识 Go 的重复执行入口。

## 核心概念

- Go 使用 for 表达循环，三段式分别是初始化、条件、更新。
- i++ 是更新语句；sum 声明在循环外，以保存各轮结果。

## 最小代码或操作示例

```go
package main
import "fmt"
func main() {
    sum := 0
    for i := 1; i <= 3; i++ {
        sum += i
    }
    fmt.Println(sum) // 6
}
```

## 3～5 分钟练习

改成计算 1 到 5 的总和，然后预测 i < 5 的结果。

## 参考答案

```text
i <= 5 输出 15；i < 5 输出 10。循环变量 i 从 1 开始，条件是否包含等号决定是否累计最后的 5。
```
