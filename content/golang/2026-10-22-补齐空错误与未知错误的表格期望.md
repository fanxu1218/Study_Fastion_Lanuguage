# 第 32 课：补齐空错误与未知错误的表格期望

- 日期：2026-10-22
- 课程序号：第 32 课
- 知识点：nil 与未知错误的独立展示契约

## 用途或适用场景

让原类型、身份和提示测试覆盖非分钟错误输入。

## 核心概念

nil 表示没有错误，未知错误仍保留自身身份并走通用提示。两者都不应匹配 *MinutesError；Is 与 AsType 分别核对身份和类型。

## 最小代码或操作示例

在第 31 课 TestMinutesTypeCases 中，cases 定义前增加：

```go
unexpected := errors.New("unexpected storage failure")
```

在同一表格原三行之后追加：

```go
{"nil", nil, false, 0, nil, ""},
{"unknown", unexpected, false, 0, unexpected, "时长校验失败"},
```

字段顺序仍为 name/err/wantOK/wantMinutes/wantRoot/wantMessage；保留原 Is、message 断言在 !ok 提前 return 之前，并继续检查 typed==nil。使用 Go1.26+ 执行原 go test 命令。

## 3～5 分钟练习

将 nil 行期望文案改成通用提示，运行后恢复空字符串。

## 参考答案

nil 子测试必须失败；恢复后五行通过。errors.Is(nil,nil) 为true，unknown 与自身匹配；两行 AsType 都返回nil/false，不读取分钟字段。
