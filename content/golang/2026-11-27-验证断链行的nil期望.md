# 第 58 课：验证断链行的nil期望

- 日期：2026-11-27
- 课程序号：第 58 课
- 知识点：普通格式化不保留可解包对象

## 用途或适用场景

检验第57课broken-inner这一层的独立期望依据。

## 核心概念

brokenInner由%v生成文字，未用%w包装root；errors.Unwrap因此得到nil。它显示disk不意味着仍持有root身份。

## 最小代码或操作示例

在个人副本原TestUnwrapOneLevel内，原broken-inner调用前仅补：
```go
// brokenInner 使用 %v，仅有文字；本层独立期望为 nil。
```
先运行go test -run '^TestUnwrapOneLevel$' -v lesson.go lesson_test.go。仅为演练把原checkUnwrap(t, "broken-inner", brokenInner, nil)的期望临时改为root，重跑同项；观察后恢复nil，再运行原go test -v lesson.go lesson_test.go。保留原七行表、其他三层检查及同文对照，不新增同名测试。

## 3～5 分钟练习

临时期望root时，两侧nil标记及错误文字各是什么？

## 参考答案

actualNil=true、wantNil=false，actual=<nil>、want=disk；应非零且名称为broken-inner，失败行对应原调用。恢复nil后该项及全部旧测试通过，不能按Error文字回填期望。
