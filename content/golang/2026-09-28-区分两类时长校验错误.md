# 第 20 课：区分两类时长校验错误

- 日期：2026-09-28
- 课程序号：第 20 课
- 知识点：为第二类失败定义独立错误身份

## 用途或适用场景

分别提示“非正数”和“超过上限”的练习时长。

## 核心概念

为上限错误添加独立 sentinel，并继续用 `%w` 包装、`errors.Is` 分支；不解析错误字符串。需要 Go 1.13 或更新版本。

## 最小代码或操作示例

```go
package main
import (
    "errors"
    "fmt"
)
var errMinutes = errors.New("minutes must be positive")
var errTooLong = errors.New("minutes must be at most 60")
func validate(minutes int) error {
    if minutes <= 0 { return fmt.Errorf("minutes=%d: %w", minutes, errMinutes) }
    if minutes > 60 { return fmt.Errorf("minutes=%d: %w", minutes, errTooLong) }
    return nil
}
func main() {
    err := validate(90)
    if errors.Is(err, errMinutes) { fmt.Println("请输入正数分钟") }
    if errors.Is(err, errTooLong) { fmt.Println("最多 60 分钟") }
}
```

## 3～5 分钟练习

分别用 `-3`、`5` 调用 `validate`，观察提示。

## 参考答案

`-3` 只输出“请输入正数分钟”；`5` 不输出任何错误提示。
