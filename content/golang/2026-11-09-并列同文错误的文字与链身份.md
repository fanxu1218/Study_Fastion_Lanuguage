# 第 44 课：并列同文错误的文字与链身份

- 日期：2026-11-09
- 课程序号：第 44 课
- 知识点：Error文本相同而Unwrap不同

## 用途或适用场景

把第42、43课的两条同文错误放在同一比较中。

## 核心概念

Error返回用于展示的文字；Unwrap和Is检查错误链。两条文字相同仍可能分别有链和无链，不能用字符串相等替代身份判断。

## 最小代码或操作示例

沿第42课wrappedSameText与第43课brokenSameText，在TestWrappingComparison两者都已创建之后、cases之前追加：
```go
if wrappedSameText.Error() != brokenSameText.Error() {
    t.Fatal("本组对照应保留相同展示文字")
}
```
保留两项既有errors.Is对sameText的检查及原七行cases，逐项对应：wrapped-same-text的inner为sameText，broken-same-text为nil；两者wantRoot均false。先go test -run '^TestWrappingComparison$' -v，再运行全部旧测试；沿Go1.26+。

## 3～5 分钟练习

两条文字相同，为什么两行对root仍都是false？

## 参考答案

它们都没有包装root：正确包装的是另一个身份sameText，普通格式化没有链。root与sameText仅文字相同。
