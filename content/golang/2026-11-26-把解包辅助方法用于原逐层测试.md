# 第 57 课：把解包辅助方法用于原逐层测试

- 日期：2026-11-26
- 课程序号：第 57 课
- 知识点：同一身份契约在原测试中复用

## 用途或适用场景

将第56课写明契约的checkUnwrap用于已有逐层检查。

## 核心概念

helper接收本层独立期望并报告调用行；替换重复比较时仍保留正确包装、断链和同文对照，不新增同名测试。

## 最小代码或操作示例

在原lesson_test.go只用下面完整函数替换已有TestUnwrapOneLevel，原import及checkUnwrap保持：
```go
func TestUnwrapOneLevel(t *testing.T) {
    root := errors.New("disk")
    goodInner := fmt.Errorf("save: %w", root)
    good := fmt.Errorf("submit: %w", goodInner)
    brokenInner := fmt.Errorf("save: %v", root)
    broken := fmt.Errorf("submit: %w", brokenInner)
    checkUnwrap(t, "good-outer", good, goodInner)
    checkUnwrap(t, "good-inner", goodInner, root)
    checkUnwrap(t, "broken-outer", broken, brokenInner)
    checkUnwrap(t, "broken-inner", brokenInner, nil)
    if good.Error() != broken.Error() {
        t.Fatal("本例两条错误文字应相同")
    }
}
```
运行原go test -v lesson.go lesson_test.go；原七行及其他旧测试不变，不再新建同名函数。

## 3～5 分钟练习

在个人副本只把good-outer的期望改为root，运行该项观察调用行与名称，然后恢复。

## 参考答案

应非零且含good-outer：一层应得到goodInner。恢复后原全部测试通过；Error文字仅用于保留原同文对照。
