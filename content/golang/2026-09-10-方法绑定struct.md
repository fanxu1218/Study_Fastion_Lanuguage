# 第 9 课：方法绑定struct

- 日期：2026-09-10
- 课程序号：第 9 课
- 知识点：值接收者方法

## 用途

把与结构体相关的行为放在类型旁边。

## 核心概念

接收者位于 `func` 与方法名之间；值接收者不修改原值。

## 最小代码或操作示例

```go
type Lesson struct { Title string }
func (l Lesson) Label() string { return "课程：" + l.Title }
```

## 3～5 分钟练习

创建 `Lesson` 并打印 `Label()`。

## 参考答案

`fmt.Println(Lesson{Title: "Go"}.Label())`。
