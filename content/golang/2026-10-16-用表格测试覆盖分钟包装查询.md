# 第 29 课：用表格测试覆盖分钟包装查询

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：testing.T.Run 的具名子测试

## 用途或适用场景

把前两课的类型查询契约整理为一组独立子测试。

## 核心概念

复用已学表格测试，每行给出错误、是否应命中及命中时的分钟数；t.Run(name, func) 为每行注册具名子测试，便于从报告定位失败输入。先比较 ok，再读字段。未知分钟数不填假值，未命中行的 wantMinutes 不参与断言。

## 最小代码或操作示例

在原 lesson_test.go 增加，沿用 errors/fmt/testing 与原 MinutesError：

```go
func TestMinutesTypeCases(t *testing.T) {
    cases := []struct {
        name string
        err error
        wantOK bool
        wantMinutes int
    }{
        {"wrapped", fmt.Errorf("save: %w", &MinutesError{Minutes: -3, Err: errMinutes}), true, -3},
        {"root-only", fmt.Errorf("save: %w", errMinutes), false, 0},
    }
    for _, tc := range cases {
        t.Run(tc.name, func(t *testing.T) {
            typed, ok := errors.AsType[*MinutesError](tc.err)
            if ok != tc.wantOK { t.Fatalf("ok=%v", ok) }
            if !ok {
                if typed != nil { t.Fatal("expected nil") }
                return
            }
            if typed.Minutes != tc.wantMinutes {
                t.Fatalf("minutes=%d", typed.Minutes)
            }
        })
    }
}
```

用 Go1.26+ 执行原 go test lesson.go lesson_test.go；保留原 message/errors.Is 用例。
