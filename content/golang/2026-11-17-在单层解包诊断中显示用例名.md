# 第 50 课：在单层解包诊断中显示用例名

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：辅助函数接收名称并格式化失败消息

## 用途或适用场景

让第49课反例报告能直接对应原七行表。

## 核心概念

传入row.name只增强诊断；Unwrap比较与t.Helper的调用方定位不变。

## 最小代码或操作示例

在原_test.go用下列函数替换第48课helper：
```go
func checkUnwrap(t *testing.T, name string, err error, want error) {
    t.Helper()
    if errors.Unwrap(err) != want {
        t.Fatalf("单层解包不符：%s", name)
    }
}
```
原子测试调用改为checkUnwrap(t, row.name, row.err, row.inner)。先运行原全部测试；再在个人副本仅把good行inner临时改为nil，运行go test -run '^TestWrappingComparison/good$' -v，应非零且含“单层解包不符：good”，文件/行仍指向helper调用。恢复goodInner，再运行原全部测试。

## 3～5 分钟练习

能把t.Fatalf换成t.Fatal("单层解包不符：%s", name)吗？

## 参考答案

不应这样替换；Fatal不是格式化方法，%s需Fatalf处理，否则诊断不符合本课约定。

## 与上一课的联系
