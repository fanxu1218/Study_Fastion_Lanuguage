# 第 62 课：用资源提供关闭结果说明

- 日期：2026-09-30
- 课程序号：第 62 课
- 知识点：`accessibilityDescription(Resource)`

## 用途或适用场景

让关闭结果的无障碍说明随应用资源统一管理。

## 核心概念

沿用上一课的结果文字，只把硬编码说明替换为字符串资源；本机 API 20 声明提供 `Resource` 重载且自 API 12 可用。

## 最小代码或操作示例

```arkts
Text(this.handle.isClosed() ? '资源已关闭' : this.errorMessage)
  .accessibilityDescription($r('app.string.close_result_description'))
```

## 3～5 分钟练习

在 `resources/base/element/string.json` 添加“资源关闭操作结果”资源并引用。

## 参考答案

资源名保持 `close_result_description`，组件只读取 `$r(...)`，不复制业务关闭状态。

## 与上一课的联系

第 61 课已加入硬编码无障碍说明；本课只改为资源引用；下一课可为成功与失败分别提供更具体的资源文案。
