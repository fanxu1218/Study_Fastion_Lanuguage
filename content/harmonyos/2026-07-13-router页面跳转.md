# 第 8 课：Navigation 与 NavPathStack 页面跳转

- 日期：2026-07-13
- 时效校验：2026-09-14（HarmonyOS API 20 SDK、华为官方 Navigation 文档）
- 知识点：`Navigation`、`NavPathStack`、`NavDestination`
- 适用场景：从列表进入详情、从首页进入设置、从搜索结果进入内容页

承接上一课的列表点击：点击某一行后，真实业务通常不是只改选中态，而是进入一个由导航栈管理的详情页。

> 旧写法 `router.pushUrl` 的全局接口从 API 18 起已废弃。新应用课程采用华为当前推荐的 `Navigation + NavPathStack` 组件导航。

## 1. 用 `NavPathStack` 推入详情页

每个 `Navigation` 绑定一个 `NavPathStack`。调用 `pushPath()` 时，目标 `NavDestination` 会入栈；页面名称由自定义路由表映射到具体组件。

```ts
class DetailParams {
  id: string = '';
  title: string = '';

  constructor(id: string, title: string) {
    this.id = id;
    this.title = title;
  }
}

@Entry
@Component
struct TopicPage {
  pathStack: NavPathStack = new NavPathStack();
  @State topics: Array<DetailParams> = [
    new DetailParams('001', 'UIAbility'),
    new DetailParams('002', '@State'),
    new DetailParams('003', 'List')
  ];

  @Builder
  pageBuilder(name: string, param: Object) {
    if (name === 'DetailPage') {
      DetailPage({
        params: param as DetailParams,
        pathStack: this.pathStack
      })
    }
  }

  build() {
    Navigation(this.pathStack) {
      List() {
        ForEach(this.topics, (item: DetailParams) => {
          ListItem() {
            Text(item.title)
              .fontSize(20)
              .padding(16)
              .width('100%')
              .onClick(() => {
                this.pathStack.pushPath({
                  name: 'DetailPage',
                  param: item
                });
              })
          }
        }, (item: DetailParams) => item.id)
      }
    }
    .title('主题列表')
    .navDestination(this.pageBuilder)
  }
}

@Component
struct DetailPage {
  params: DetailParams = new DetailParams('', '');
  pathStack: NavPathStack = new NavPathStack();

  build() {
    NavDestination() {
      Column({ space: 16 }) {
        Text(this.params.title)
          .fontSize(24)
        Text(`id: ${this.params.id}`)
      }
      .width('100%')
      .height('100%')
      .justifyContent(FlexAlign.Center)
    }
    .title('详情')
  }
}
```

## 2. 页面映射要一致

`pushPath()` 中的 `name: 'DetailPage'` 必须能被 `.navDestination(this.pageBuilder)` 处理。名称写错或没有构建对应的 `NavDestination`，都会导致跳转失败。

如果项目采用系统路由表，则应在 `router_map.json` 与 `module.json5` 中登记 `NavDestination`；不要再把旧 `main_pages.json` 页面路由当作新课程主线。

## 3～5 分钟练习

把列表中再加入一个 `Navigation` 项，点击它后进入详情页，并确认标题和 id 都与点击项一致。

## 参考答案

```ts
new DetailParams('004', 'Navigation')
```

将它追加到 `topics` 数组即可；点击时仍由同一个 `pathStack.pushPath()` 入栈。
