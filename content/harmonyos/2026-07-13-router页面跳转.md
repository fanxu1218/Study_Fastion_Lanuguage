# 第 8 课：router.pushUrl 页面跳转

- 日期：2026-07-13
- 知识点：页面跳转、页面路径注册
- 适用场景：从列表进入详情、从首页进入设置、从搜索结果进入内容页

承接上一课的列表点击：点击某一行后，真实业务通常不是只改选中态，而是跳到详情页。

## 1. 用 `router.pushUrl` 做页面跳转

页面跳转属于路由层行为。点击事件只负责触发跳转，不在当前页面硬塞详情 UI。

```ts
import { router } from '@kit.ArkUI';

interface TopicItem {
  id: string;
  title: string;
}

@Entry
@Component
struct TopicPage {
  @State topics: TopicItem[] = [
    { id: '001', title: 'UIAbility' },
    { id: '002', title: '@State' },
    { id: '003', title: 'List' }
  ];

  build() {
    List() {
      ForEach(this.topics, (item: TopicItem) => {
        ListItem() {
          Text(item.title)
            .fontSize(20)
            .padding(16)
            .width('100%')
            .onClick(() => {
              router.pushUrl({
                url: 'pages/DetailPage',
                params: {
                  id: item.id,
                  title: item.title
                }
              });
            })
        }
      }, (item: TopicItem) => item.id)
    }
    .width('100%')
    .height('100%')
  }
}
```

## 2. 页面路径要注册

`url: 'pages/DetailPage'` 要对应实际页面路径，并在 `main_pages.json` 中登记。新增页面后跳转报找不到页面时，应先检查页面注册。

```json
{
  "src": [
    "pages/Index",
    "pages/DetailPage"
  ]
}
```

## 3～5 分钟练习

新建一个 `DetailPage`，先只显示 `Text('详情页')`；然后让列表项点击跳转到 `pages/DetailPage`，确认点击任意一行都能进入详情页。

## 参考答案

```ts
@Entry
@Component
struct DetailPage {
  build() {
    Text('详情页')
  }
}
```

同时确认 `main_pages.json` 已包含 `pages/DetailPage`。

## 与上一课的联系

上一课的点击事件只修改选中状态；这一课让点击事件触发路由，从列表页进入独立详情页。
