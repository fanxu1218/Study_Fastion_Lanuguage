# 第 71 课：把一条语言失败整理为复现记录

- 日期：2026-10-21
- 课程序号：第 71 课
- 知识点：从回归矩阵提取单项可复现问题

## 用途或适用场景

让其他人能复查 JA-F 的实际显示或朗读差异。

## 核心概念

问题记录关联同一个用例、构建、语言配置和资源键。显示与朗读分开填写；只有已观察的失败才建立真实缺陷，未执行不能推断 UI 或资源层根因。

## 最小代码或操作示例

沿用第 70 课六行矩阵，在原练习应用中选一条真实失败，例如 JA-F：

```text
用例ID：JA-F（仅示例；实际选择已有失败行）
环境：构建/系统/设备、窗口宽度、字体、系统语言、应用偏好语言
前提：原 Handle 状态和失败触发步骤，不手工修改 isClosed()
步骤：打开同一页面 → 走原关闭失败流程 → 查看 Text → 单独检查朗读
期望：ja_JP 的 close_failed / close_failed_desc 对应内容
实际：逐字记录可见文字；另记实际朗读、截图或观察证据位置
范围：同条件中文/英文对照结果；未执行项如实标记
待定位：资源选择 / 译文 / 布局 / 无障碍；尚未确认则保留待定位
```

没有真实失败时记录“本轮未发现/未执行”，可用虚构材料练习模板但不登记为真实缺陷；不改原 Text 或资源。

## 3～5 分钟练习

假设日文显示完整，但没有做朗读测试，哪些栏能得出结论？

## 参考答案

只能记录该环境下显示观察；朗读栏仍为未验证，不能填写“无障碍通过”或判定说明键有错。译文语义还需语言审校。

## 与上一课的联系

继承第 69 课长译文观察和第 70 课语言/结果编号；本课只提取一条失败的复现材料。下一课可沿证据区分资源匹配与布局约束，确认根因后再修改。
