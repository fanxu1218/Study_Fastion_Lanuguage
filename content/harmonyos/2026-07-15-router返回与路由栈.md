# 第 10 课：router.back 与路由栈

- 日期：2026-07-15
- 知识点：`router.back()`、路由栈的进入与返回语义
- 适用场景：详情页返回、表单取消、设置页返回上一级

承接上一课的 `router.getParams()`：详情页能读取参数后，还需要正确处理用户返回上一页。

## 1. `router.back()` 返回上一页

`pushUrl` 会把新页面压入路由栈，`back` 会从当前页回到上一个页面。不要为了“返回列表页”再次 `pushUrl('pages/ListPage')`，否则会新增一个列表页实例，路由栈会越来越深。

```ts
import { router } from '@kit.ArkUI';

@Entry
@Component
struct DetailPage {
  build() {
    Column({ space: 16 }) {
      Text('详情页')
        .fontSize(24)

      Button('返回')
        .onClick(() => {
          router.back();
        })
    }
    .width('100%')
    .height('100%')
    .justifyContent(FlexAlign.Center)
  }
}
```

## 2. 按“进入/返回”理解路由栈

正确的一进一出：

```text
列表页
-> pushUrl 到详情页
-> back 回列表页
```

如果在详情页再次 `pushUrl('pages/ListPage')`：

```text
列表页 -> 详情页 -> 新的列表页
```

这不是返回，而是继续前进。

## 3～5 分钟练习

在上一课的 `DetailPage` 中增加“返回”按钮，点击后执行 `router.back()`。从列表页进入详情页，再点击返回，确认回到原来的列表页，而不是新打开一个列表页。
