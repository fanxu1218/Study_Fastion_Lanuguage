# 第 10 课：NavPathStack 返回与路由栈

- 日期：2026-07-15
- 时效校验：2026-09-14（HarmonyOS API 20 SDK、华为官方 Navigation 文档）
- 知识点：`NavPathStack.pop()`、路由栈的进入与返回语义
- 适用场景：详情页返回、表单取消、设置页返回上一级

承接上一课的参数传递：详情页收到数据后，还需要通过同一个导航控制器正确返回。

## 1. 用同一个 `NavPathStack` 返回

父页面把绑定到 `Navigation` 的 `pathStack` 传给详情组件；详情页调用 `pop()`，移除当前 `NavDestination` 并显示上一层。

```ts
@Builder
pageBuilder(name: string, param: Object) {
  if (name === 'DetailPage') {
    DetailPage({
      params: param as DetailParams,
      pathStack: this.pathStack
    })
  }
}

@Component
struct DetailPage {
  params: DetailParams = new DetailParams('', '');
  pathStack: NavPathStack = new NavPathStack();

  build() {
    NavDestination() {
      Column({ space: 16 }) {
        Text(this.params.title)
          .fontSize(24)

        Button('返回')
          .onClick(() => {
            this.pathStack.pop();
          })
      }
      .width('100%')
      .height('100%')
      .justifyContent(FlexAlign.Center)
    }
    .title('详情')
  }
}
```

## 2. 按“入栈/出栈”理解返回

正确的一进一出：

```text
列表内容
-> pushPath 把 DetailPage 入栈
-> pop 把 DetailPage 出栈
-> 回到原列表内容
```

如果点击“返回”时再次 `pushPath({ name: 'ListPage' })`，那是继续前进，不是返回，栈中还会多出一个页面实例。

## 3～5 分钟练习

在上一课的详情页增加“返回”按钮。进入不同详情后分别返回，确认回到的是原列表，而不是新创建的列表页。

## 参考答案

```ts
Button('返回')
  .onClick(() => {
    this.pathStack.pop();
  })
```
