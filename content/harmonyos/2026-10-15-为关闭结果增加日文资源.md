# 第 68 课：为关闭结果增加日文资源

- 日期：2026-10-15
- 课程序号：第 68 课
- 知识点：同一组资源键的 ja_JP 覆盖

## 用途或适用场景

在已有中文、英文清单上增加日文目标语言，保留原关闭业务流程。

## 核心概念

语言资源通过限定词目录选择；同一 name 在不同语言目录提供不同 value。base 保持完整。沿用 $r 和 this.handle.isClosed()，不写手工语言判断，也不增加关闭结果副本。

## 最小代码或操作示例

在原模块 resources 下新增 ja_JP/element/string.json，使用已有四个键：

```json
{
  "string": [
    { "name": "close_success", "value": "閉じました" },
    { "name": "close_failed", "value": "閉じられませんでした" },
    { "name": "close_success_desc", "value": "リソースは正常に閉じられました" },
    { "name": "close_failed_desc", "value": "リソースを閉じられませんでした。もう一度お試しください" }
  ]
}
```

以第 67 课清单增加日文列；应用未设置偏好语言时，将测试系统语言设为日语（日本），重新运行原成功/失败步骤。不要改动 base、en_US 或 ArkUI 业务代码。

## 3～5 分钟练习

逐项核对日文键名、显示与实际朗读；完成后恢复测试语言。没有目标设备时只记录资源检查，实际结果写“未验证”。

## 参考答案

四个 name 各出现一次，成功和失败仍使用对应的同名资源；日文显示、朗读只有实际观察后才能填通过。翻译文本是教学示例，正式发布仍需语言审校。
