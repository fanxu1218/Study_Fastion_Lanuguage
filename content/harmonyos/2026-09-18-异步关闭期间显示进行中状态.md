# 第 56 课：异步关闭期间显示进行中状态

- 日期：2026-09-18
- 课程序号：第 56 课
- 知识点：异步关闭期间显示进行中状态

## 用途或适用场景

关闭操作未完成时显示进度文字，并在操作结束后重新读取 `Handle` 的结果。

## 核心概念

`closing` 是纯界面交互状态；真正的关闭结果仍来自上一课的 `handle`，`finally` 只恢复进行中状态并触发界面重绘。

## 最小代码或操作示例

```ts
@State closing: boolean = false

async close(): Promise<void> {
  if (this.closing || this.handle.isClosed()) return
  this.closing = true
  try { await this.handle.close() } finally { this.closing = false }
}

build() {
  Button(this.handle.isClosed() ? '已关闭' : this.closing ? '关闭中…' : '关闭')
    .enabled(!this.closing && !this.handle.isClosed())
    .onClick(() => { this.close() })
}
```
