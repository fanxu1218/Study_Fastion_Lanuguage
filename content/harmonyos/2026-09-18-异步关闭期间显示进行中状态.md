# 第 56 课：异步关闭期间显示进行中状态

- 日期：2026-09-18
- 课程序号：第 56 课
- 知识点：异步关闭期间显示进行中状态

## 用途或适用场景

关闭操作未完成时显示进度文字，并在成功后继续阻止重复关闭。

## 核心概念

closing 是纯界面交互状态；真正的关闭结果仍来自 resource，finally 只恢复进行中状态。

## 最小代码或操作示例

```text
@State closing: boolean = false

async close(): Promise<void> {
  if (this.closing || this.resource.isClosed()) return
  this.closing = true
  try { await this.resource.close() } finally { this.closing = false }
}

build() {
  Button(this.resource.isClosed() ? '已关闭' : this.closing ? '关闭中…' : '关闭')
    .enabled(!this.closing && !this.resource.isClosed())
    .onClick(() => { this.close() })
}
```

## 3～5 分钟练习

把进行中文字改为“正在关闭”。

## 参考答案

将 Button 的真值分支改为 `'正在关闭'`。

## 与上一课的联系

继承上一课的 resource.close() 与 resource.isClosed()；本课只增加关闭期间的界面状态，成功后仍由 resource 的事实禁用按钮；完成后下一课可显示关闭失败信息。
