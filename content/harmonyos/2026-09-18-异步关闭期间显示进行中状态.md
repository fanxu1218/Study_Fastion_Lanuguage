# 第 56 课：异步关闭期间显示进行中状态

- 日期：2026-09-18
- 课程序号：第 56 课
- 知识点：异步关闭期间显示进行中状态

## 用途或适用场景

关闭操作未完成时显示进度文字并阻止重复点击。

## 核心概念

closing 是纯界面交互状态；真正的关闭结果仍来自 closeLesson，finally 负责恢复按钮状态。

## 最小代码或操作示例

```text
@State closing: boolean = false

async close(): Promise<void> {
  this.closing = true
  try { await this.closeLesson() } finally { this.closing = false }
}

build() {
  Button(this.closing ? '关闭中…' : '关闭')
    .enabled(!this.closing)
    .onClick(() => { this.close() })
}
```
