# 第 54 课：根据关闭状态禁用按钮

- 日期：2026-09-16
- 课程序号：第 54 课
- 知识点：根据关闭状态禁用按钮

## 用途

让 UI 直接读取 Handle 的关闭事实，避免重复点击。

## 核心概念

Button.enabled 接收 boolean；closed 仍由 Handle 单一持有，UI 只读取。

## 最小代码或操作示例

```text
Button(this.handle.isClosed ? '已关闭' : '关闭')
  .enabled(!this.handle.isClosed)
  .onClick(() => { this.handle.close() })
```

## 3～5 分钟练习

让关闭后按钮文字变为“已关闭”。

## 参考答案

按钮文本使用 this.handle.isClosed 的条件表达式。

## 与上一课的联系

继承上一课的只读 isClosed；本课只让按钮消费该事实；下一课可处理异步关闭中的交互态。
