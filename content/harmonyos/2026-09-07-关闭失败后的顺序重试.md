# 第 47 课：关闭失败后的顺序重试

- 日期：2026-09-07
- 课程序号：第 47 课

## 用途

验证首次释放失败后第二次 close 仍真正重试。

## 核心概念

失败重试与生命周期用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```ts
class Handle { count: number = 0; async release(): Promise<void> { this.count += 1; if (this.count === 1) { throw new Error("fail"); } } }
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

第一次失败、第二次成功，count 为 2；成功后第三次调用不再释放。
