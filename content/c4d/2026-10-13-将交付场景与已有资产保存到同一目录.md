# 第 25 课：将交付场景与已有资产保存到同一目录

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：Save Project with Assets

## 用途或适用场景

把上一课已保存的交付场景整理成能够整体复制的文件夹。

## 核心概念

Save As 生成场景版本；Save Project with Assets 则收集场景实际使用的文件资产。只含已学几何的练习场景可能没有外部资产，此时包内只有场景也是正常结果，不要求凭空创建 tex 文件夹。

## 最小代码或操作示例

```text
1. 打开 lesson-delivery-v01.c4d，确认仍使用第 23 课选定的 Renderer 值。
2. 执行 File > Save Project with Assets…。
3. 选择一个新的练习交付目录，填写名称 lesson-delivery-v01。
4. 在系统文件管理器查看新建目录中的 .c4d 与实际收集的资产。
5. 从新目录打开 .c4d，复核模型和 Renderer 值。
```

如果提示缺少某个已有资产，先用 Yes 定位其真实路径；无法定位时不把此包标记为完整。不要用 No 忽略后宣称打包成功。

## 3～5 分钟练习

只用当前几何场景完成打包，把结果记为“场景文件存在，外部资产数为实际值”；保留原 lesson-delivery-v01.c4d 工作文件。

## 参考答案

新目录能打开同一场景，细分参数未改变；纯几何场景的外部资产数可以为 0。已有纹理等资产才会产生对应子目录，不能把子目录不存在直接当作失败。

## 与上一课的联系
