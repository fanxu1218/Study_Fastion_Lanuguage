# 第 3 课：参数化立方体与圆角

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：几何尺寸、Fillet 与圆角分段

## 用途

把基本立方体做成可继续调整的圆角盒子。

## 核心概念

- Object 页的 Size 修改几何尺寸，不同于 Coordinates 的缩放倍数。
- 参数化对象保留尺寸和圆角参数；本课不转为可编辑网格，避免失去这些参数。

## 最小代码或操作示例

```text
1. 在 Cinema 4D 2026 的新练习场景中创建一个 Cube。
2. 保持坐标缩放 X/Y/Z 为 1；在 Object 页输入 Size X=200 cm、Y=100 cm、Z=100 cm。
3. 启用 Fillet，将 Fillet Radius 设为 10 cm，Fillet Subdivision 设为 3。
4. 旋转视口观察边角，再临时关闭 Fillet 比较硬边与圆角。
5. 重新启用 Fillet；保存为新的练习文件，不覆盖之前场景。
```

## 3～5 分钟练习

把 Size Y 改成 60 cm，圆角半径保留 10 cm；判断尺寸与缩放各有什么变化，再把圆角分段改为 1 观察。

## 参考答案

```text
几何高度变为 60 cm，坐标缩放仍为 1。分段为 1 时边角呈单段切角，而不是多段圆弧；半径不能超过最小尺寸的一半，此时上限为 30 cm。
```
