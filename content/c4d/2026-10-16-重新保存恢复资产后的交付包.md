# 第 28 课：重新保存恢复资产后的交付包

- 日期：2026-10-16
- 课程序号：第 28 课
- 知识点：重连结果的重新收集与读回

## 用途或适用场景

把上一课确认恢复的文件依赖收进一个新的交付目录。

## 核心概念

Relink只更新引用；重新收集后才有新的包内文件。沿用已有Save Project with Assets，检查新场景实际路径，字体和数据库资产仍按检查器状态分别记录。

## 最小代码或操作示例

打开第27课另存的已恢复场景，保留最终Renderer值：

```text
1. 在Project Asset Inspector核对真实恢复项及其正确源文件。
2. File > Save Project with Assets，选择新的 lesson-delivery-v02 位置与名称。
3. 如仍提示缺失，记录具体条目；没有原文件时不选择替代素材。
4. 打开新目录中的.c4d，再检查Status与实际路径。
5. 复核模型、Renderer值和打包产生的tex/vol等实际目录，更新清单。
```

原交付包与重连副本保留，不执行Clear Assets。

## 3～5 分钟练习

核对一项已恢复文件是否实际进入新包；纯几何场景无文件依赖时记录不适用。

## 参考答案

新场景可找到清单中的正确文件，实际路径与新包相符；空列表不代表字体等所有类别均已验证。未实际重开时不填写通过。
