# C4D（Cinema 4D）学习路线

从对象与场景组织出发，逐步学习建模、材质、灯光、动画与渲染。每个工作日更新一节中文短课。

## 课程目录

1. [第 1 课：对象管理器与基础对象](./2026-09-01-对象管理器与基础对象.md) — 认识场景对象、选择关系与父子层级。
2. [2026-09-02：坐标面板与局部变换](./2026-09-02-坐标面板与局部变换.md)——准确摆放父子对象，而不是仅凭视口拖动。
3. [2026-09-03：参数化立方体与圆角](./2026-09-03-参数化立方体与圆角.md)——把基本立方体做成可继续调整的圆角盒子。
4. [2026-09-04：Null分组与整体移动](./2026-09-04-Null分组与整体移动.md)——把两个圆角盒子作为一个整体摆放。
5. [2026-09-07：转为可编辑对象](./2026-09-07-转为可编辑对象.md)——在点、边、面编辑前复制并转换立方体。
6. [2026-09-08：挤出多边形](./2026-09-08-挤出多边形.md)——从可编辑立方体的顶面拉出相连几何。
7. [2026-09-09：Bevel倒角边缘](./2026-09-09-Bevel倒角边缘.md)——为挤出结构增加可控的小倒角。
8. [2026-09-10：ExtrudeInner建立内圈](./2026-09-10-ExtrudeInner建立内圈.md)——在顶面内部建立继续建模的新边界。
9. [2026-09-11：Loop切线细分凹槽](./2026-09-11-Loop切线细分凹槽.md)——用环切为凹槽增加可控细分。
10. [2026-09-14：Subdivision Surface平滑模型](./2026-09-14-SubdivisionSurface平滑模型.md)——用细分曲面非破坏地平滑低模。
11. [2026-09-15：细分曲面编辑笼架](./2026-09-15-细分曲面编辑笼架.md)——在细分预览中继续编辑低模控制笼架。

12. [2026-09-16：Loop支撑线控制锐度](./2026-09-16-Loop支撑线控制锐度.md)——用环切线控制细分曲面的边缘锐度。

13. [2026-09-17：成对支撑线控制凹槽](./2026-09-17-成对支撑线控制凹槽.md)——用成对支撑线同时控制凹槽两侧的锐度。
14. [2026-09-18：检查四边面流向](./2026-09-18-检查四边面流向.md)——用 Loop Selection 确认凹槽附近的支撑边环是否连续。

15. [2026-09-21：Slide调整异常边环](./2026-09-21-Slide调整异常边环.md)——沿相邻边滑动连续支撑线，修正不均匀的边线间距。
16. [2026-09-22：Slide复制一条支撑边环](./2026-09-22-Slide复制一条支撑边环.md)——在同一模型中复制连续支撑线。
17. [2026-09-23：对比支撑线调整前后轮廓](./2026-09-23-对比支撑线调整前后轮廓.md)——用 Q 键切换控制笼与细分结果，检查凹槽轮廓。
18. [2026-09-24：调整视口细分级别复核轮廓](./2026-09-24-调整视口细分级别复核轮廓.md)——调整视口细分级别检查平滑程度。
19. [2026-09-28：区分渲染与视口细分级别](./2026-09-28-区分渲染与视口细分级别.md)——单独调整渲染细分而保留视口设置。

20. [2026-09-29：比较渲染细分级别的细节与耗时](./2026-09-29-比较渲染细分级别的细节与耗时.md)——保持视口设置不变，对比两个渲染细分级别。

21. [2026-09-30：固定渲染细分级别复测耗时](./2026-09-30-固定渲染细分级别复测耗时.md)——固定渲染细分参数重复测量耗时。
22. [2026-10-08：比较固定级别下的多边形统计](./2026-10-08-比较固定级别下的多边形统计.md)——记录固定细分参数下的多边形统计。

23. [2026-10-09：选定交付用渲染细分参数](./2026-10-09-选定交付用渲染细分参数.md)——依据耗时与多边形统计选定交付细分参数。

24. [2026-10-12：保存交付参数场景版本](./2026-10-12-保存交付参数场景版本.md)——用 File > Save As 另存带最终细分参数的交付场景。

25. [2026-10-13：将交付场景与已有资产保存到同一目录](./2026-10-13-将交付场景与已有资产保存到同一目录.md)——使用 Save Project with Assets 保存场景及其实际外部依赖。

27. [2026-10-15：为缺失交付资产重连目录](./2026-10-15-为缺失交付资产重连目录.md)——对上一课检查器中真实缺失的文件资产恢复引用。

29. [2026-10-20：在新位置副本复核交付资产来源](./2026-10-20-在新位置副本复核交付资产来源.md)——验证lesson-delivery-v02副本是否仍依赖包外文件。
