# 第 41 课：在新场景执行文字单条件比较

- 日期：2026-11-05
- 课程序号：第 41 课
- 知识点：同对象的一项可控条件变化

## 用途或适用场景

验证第40课选定的条件与字宽或换行观察是否相关。

## 核心概念

一次比较只改变一个已有且可控制的条件，其余设置与输出环境固定。画面变化只能说明本次条件下的观察，不能跳过证据直接推广为所有接收差异的根因。

## 最小代码或操作示例

沿第39课差异卡及第40课唯一条件计划，在Cinema4D个人场景操作；拟用来源未具备则停止：

```text
1. File > Save As，用未存在的新.c4d名保存副本，确认活动场景与目标文字对象。
2. 读回原文字、视角、输出大小及Project Asset Inspector字体Asset/Status。
3. 仅按上一课计划改变一项条件；若选定的是已安装字体，双击Asset列该对象的字体名，在对话框选择计划中的字体，其余不动。
4. 在原视角/输出条件记录实际字宽、换行与位置，并与原画面并列。
5. 保存新副本并重开，读回唯一设置和字体来源；不符合原条件则标条件不足。
```

不安装字体或插件，不Consolidate Assets，不同时改字距与字体；没有实际差异只作原条件复查。

## 3～5 分钟练习

副本同时换了字体与输出大小，画面一致能归给字体吗？

## 参考答案

不能，比较条件不唯一。恢复其他条件并重新记录，保留本轮实际变化而不作单因判断。
