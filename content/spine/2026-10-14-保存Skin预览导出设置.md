# 第 26 课：保存 Skin 预览导出设置

- 日期：2026-10-14
- 课程序号：第 26 课
- 知识点：导出窗口 Save 保存设置 JSON

## 用途或适用场景

把上一课已复核的 PNG 导出参数保存为可复用设置文件。

## 核心概念

导出窗口左下角 Save 保存当前设置为 JSON，不等于导出 PNG，也不保存整个骨骼项目。本课保持搭配、姿势、比例和边界记录，只保存设置。

## 最小代码或操作示例

继续使用原 Spine 项目和 previews/skins 清单：

```text
1. 打开 Export，保持上一课复核的 PNG 类型、Scale、输出目录和前缀。
2. 用 Preview 再核对当前设置与清单对应同一输出对象。
3. 点击导出窗口左下角 Save，保存到新的
   previews/skins/skins-preview-settings-v01.json。
4. 在文件管理器确认 JSON 存在；在 checklist.txt 追加设置文件路径。
```

保存软件生成的文件，不手写未经核对的设置结构，不覆盖现有 PNG。

## 3～5 分钟练习

确认保存前后的 Preview 像素尺寸一致，清单记录 PNG 和设置 JSON 两种文件的不同用途。

## 参考答案

JSON 保存当前导出配置，已有 PNG 不变；文件存在只证明设置已保存，预览和 PNG 的尺寸核验仍使用第 25 课记录。

## 与上一课的联系

继承第 24 课 checklist、第 25 课像素尺寸与边界记录；本课只保存当前导出设置。下一课可用 Load 重新读取这份 JSON 并对照 Preview。
