# 第 3 课：旋转关键帧与动画模式

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：Animate 模式、活动动画与插值

## 用途

让上臂带动前臂完成一次简单摆动。

## 核心概念

- Setup 用来定义基础骨架，Animate 中选择活动动画后才为该动画记录关键帧。
- 只拖动骨骼不等于已经记帧；要核对旋转参数旁的钥匙按钮和时间线标记。

## 最小代码或操作示例

```text
1. 沿用上一课 upperArm → forearm 层级，切换到 Animate。
2. 在树的 Animations 下创建动画 wave，并确认它是当前活动动画。
3. 关闭自动记帧以便练习手动操作；选择 upperArm，使用 Rotate 工具和 Local 轴。
4. 将时间线移到帧 0，输入旋转 0，点击旋转数值旁的钥匙按钮。
5. 将时间线移到帧 15，输入旋转 30，再点击同一钥匙按钮。
6. 拖动播放头从帧 0 到 15，检查前臂跟随上臂，且存在两个旋转关键帧。
```

## 3～5 分钟练习

在帧 30 把上臂旋转改回 0 并记帧，观察一次往返摆动。

## 参考答案

```text
关键帧为 0→0°、15→30°、30→0°。帧间由插值形成变化；若最后未记帧，重新拖动播放头时可能丢失刚才的未记录修改。
```
