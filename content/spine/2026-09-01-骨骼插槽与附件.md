# 第 1 课：骨骼、插槽与附件

- 日期：2026-09-01
- 课程序号：第 1 课
- 知识点：Bone、Slot 与 Attachment

## 用途

Spine 通过骨骼控制姿势，通过插槽决定绘制顺序，再由附件提供实际显示内容。理解这三层关系，是制作和接入 2D 骨骼动画的基础。

## 核心概念

- Bone 构成角色的层级骨架并传递变换。
- Slot 绑定到骨骼，并保存颜色和绘制顺序等信息。
- Attachment 是插槽当前显示的图片、网格或其他内容。
- 一个插槽可以在动画中切换不同附件。

## 最小代码示例

```json
{
  "bones": [
    { "name": "root" },
    { "name": "head", "parent": "root" }
  ],
  "slots": [
    { "name": "face", "bone": "head", "attachment": "face-normal" }
  ]
}
```

## 3～5 分钟练习

为示例增加一个绑定到 `root` 骨骼的 `body` 插槽，并把默认附件设为 `body-normal`。

## 参考答案

```json
{
  "name": "body",

  "attachment": "body-normal"
```
