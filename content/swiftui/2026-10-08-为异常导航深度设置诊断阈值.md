# 第 22 课：为异常导航深度设置诊断阈值

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：`NavigationPath.count` 阈值

## 用途或适用场景

只记录异常深度，不修改恢复后的路径。

## 核心概念

本课只增加“`NavigationPath.count` 阈值”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```swift
if path.count > 5 { logger.warning("restored path is unusually deep") }
```

## 3～5 分钟练习

分别用 2 层和 6 层路径触发检查。

## 参考答案

2 层不记录，6 层记录警告；路径内容不写入日志。
