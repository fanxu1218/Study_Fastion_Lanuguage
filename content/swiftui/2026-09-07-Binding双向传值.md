- 日期：2026-09-07

- 知识点：@Binding 与单一事实源

## 用途

让子视图编辑父视图持有的计数。

## 核心概念

@Binding 与单一事实源用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```swift
struct StepperView: View { @Binding var count: Int; var body: some View { Button("增加") { count += 1 } } }
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

父视图用 StepperView(count: $count) 传入绑定。
