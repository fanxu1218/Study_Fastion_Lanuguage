# 第 1 课：View 与最小界面

- 日期：2026-09-01
- 课程序号：第 1 课
- 知识点：`View`、`body` 与 `Text`

## 用途

SwiftUI 使用遵循 `View` 协议的类型描述界面。掌握最小 View 结构后，就能继续组合布局、状态和交互。

## 核心概念

- 自定义界面通常声明为遵循 `View` 的结构体。
- `body` 返回当前界面的声明。
- `some View` 隐藏具体返回类型，同时保留静态类型检查。
- `Text` 用来显示一段文字。

## 最小代码示例

```swift
import SwiftUI

struct ContentView: View {
    var body: some View {
        Text("你好，SwiftUI")
    }
}
```
