# 第 21 课：恢复后读取导航层级数

- 日期：2026-09-30
- 课程序号：第 21 课
- 知识点：`NavigationPath.count`

## 用途或适用场景

统计恢复后的导航层级，不记录具体敏感路径内容。

## 核心概念

`count` 只暴露路径元素数量，沿用上一课的成败计数，不复制导航数据。

## 最小代码或操作示例

```swift
if let restored = try? decoder.decode(NavigationPath.CodableRepresentation.self, from: data) {
    path = NavigationPath(restored)
    logger.info("恢复层级：\(path.count)")
}
```

## 3～5 分钟练习

在根页和两层详情页分别观察数量。

## 参考答案

根页为 0，两层详情恢复后为 2；日志不含具体路径值。

## 与上一课的联系

第 20 课统计恢复成败次数；本课只增加成功后的层级数量；下一课可为异常深度设置诊断阈值。
