# 第 21 课：恢复后读取导航层级数

- 日期：2026-09-30
- 课程序号：第 21 课
- 知识点：NavigationPath.count

## 用途或适用场景

仅记录已恢复路径的层级数量，不记录课程 ID 或原始数据。

## 核心概念

在原 restorePath 成功分支中读取已经赋值的 path；不引入未定义的 decoder/data，也不复制第二份导航路径。

## 最小代码或操作示例

```swift
// 第 20 课 restorePath() 的 do 分支，保持原解码与命名：
let value = try JSONDecoder().decode(
    NavigationPath.CodableRepresentation.self, from: savedPath
)
path = NavigationPath(value)
restoreSuccess += 1
logger.info("恢复层级：\(path.count)")
```

## 3～5 分钟练习

恢复根路径与两层路径，记录 count；不要输出路径元素。

## 参考答案

根路径为 0，两层路径为 2；Logger.info 的可见性取决于实际日志查看配置，代码核对不等于设备日志验证。

## 与上一课的联系

继承第 20 课成功赋值后的 restoreSuccess 与第 19 课 logger；本课只在该位置读取 path.count；下一课在同一成功分支检查 count 是否大于 5。
