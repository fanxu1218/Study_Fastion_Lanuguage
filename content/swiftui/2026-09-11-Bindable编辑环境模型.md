# 第 9 课：Bindable编辑环境模型

- 日期：2026-09-11
- 课程序号：第 9 课
- 知识点：@Bindable

## 用途

在视图内为环境中的可观察模型创建双向绑定。

## 核心概念

`@Environment` 取得共享实例，`@Bindable` 提供控件需要的 Binding。

## 最小代码或操作示例

```swift
@Environment(CourseStore.self) private var store
var body: some View {
  @Bindable var store = store
  TextField("标题", text: $store.title)
}
```
