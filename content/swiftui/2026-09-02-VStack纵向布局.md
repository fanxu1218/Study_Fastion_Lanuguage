# 第 2 课：VStack纵向布局

- 日期：2026-09-02
- 课程序号：第 2 课
- 知识点：VStack、alignment 与 spacing

## 用途

将标题和说明组合成纵向信息块。

## 核心概念

- VStack 按声明顺序纵向排列子视图。
- alignment 控制水平对齐；spacing 控制相邻视图间距。

## 最小代码或操作示例

```swift
import SwiftUI
struct ContentView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text("今日课程").font(.title)
            Text("完成一个 5 分钟练习")
        }
        .padding()
    }
}
```

## 3～5 分钟练习
