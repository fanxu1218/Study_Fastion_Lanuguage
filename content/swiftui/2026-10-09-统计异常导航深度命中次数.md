# 第 23 课：统计异常导航深度命中次数

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：诊断计数器

## 用途或适用场景

统计恢复路径超过阈值的次数，不记录路径内容。

## 核心概念

只在上一课的阈值分支递增计数，导航路径仍是事实源。

## 最小代码或操作示例

```swift
if path.count > 5 { deepRestoreCount += 1 }
```

## 3～5 分钟练习

分别恢复 2 层、6 层和 7 层路径。

## 参考答案

计数器最终为 2，路径内容未写入日志或副本。
