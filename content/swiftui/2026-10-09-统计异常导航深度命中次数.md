# 第 23 课：统计异常导航深度命中次数

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：视图中的异常深度诊断计数

## 用途或适用场景

只统计恢复成功后路径超过阈值的次数。

## 核心概念

deepRestoreCount 是当前 LessonView 的诊断 State；path 是导航事实源。仅在 restorePath 成功分支执行一次检查，body 渲染不递增计数。

## 最小代码或操作示例

```swift
// 与第 20 课两个计数放在 LessonView 的属性区：
@State private var deepRestoreCount = 0

// 在 restorePath 成功赋值 path 后，替换第 22 课阈值分支：
if path.count > 5 {
    logger.warning("restored path is unusually deep")
    deepRestoreCount += 1
}
```

## 3～5 分钟练习

在练习中依次恢复 2、6、7 层路径；不在 body 中重复调用恢复方法。

## 参考答案

deepRestoreCount 为 2；正常深度不计数，导航元素没有被修改或记录；此计数是当前视图期间的诊断次数。
