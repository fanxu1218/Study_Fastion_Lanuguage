# 第 20 课：统计导航恢复成败次数

- 日期：2026-09-29
- 课程序号：第 20 课
- 知识点：视图中的内存诊断计数

## 用途或适用场景

记录导航恢复成功或失败次数，不记录敏感路径内容。

## 核心概念

本课沿用 LessonView 的 restorePath()。计数用于当前视图存续期间的内部诊断，不表示持久化统计；用已学 @State 承载，避免在非 mutating View 方法中修改普通储存属性。

## 最小代码或操作示例

```swift
// 在第 19 课 LessonView 内新增：
@State private var restoreSuccess = 0
@State private var restoreFailure = 0

// 在 restorePath 的 do 中，成功 path = NavigationPath(value) 之后：
restoreSuccess += 1
// 在既有 catch 内，日志记录之前：
restoreFailure += 1
// 没有 savedPath 时 guard 直接返回，不记为失败。
```

## 3～5 分钟练习

用一份有效数据和 Data([0]) 分别触发 restorePath；没有 savedPath 时再调用一次。

## 参考答案

前两次分别递增成功与失败；无保存数据不递增。计数不含路径内容，场景重建后不保证继续累计。

## 与上一课的联系

继承第 19 课 LessonView、restorePath 的 do/catch、logger 与清理顺序；本课只增加成功/失败计数；下一课在成功路径赋值后读 path.count。
