# 第 18 课：损坏的导航数据回退到根页

- 日期：2026-09-24
- 课程序号：第 18 课
- 知识点：恢复失败时清理无效场景数据

## 用途或适用场景

场景存储中的路径数据无法解码时，避免每次显示页面都重复尝试同一损坏值。

## 核心概念

解码失败后清除 `savedPath` 并保持根路径；可恢复数据仍只由 `@SceneStorage` 保存，当前导航仍由 `path` 持有。

## 最小代码或操作示例

```swift
// 替换第 17 课 LessonView 中的 restorePath()，其余代码不变。
private func restorePath() {
    guard let savedPath else { return }
    do {
        let value = try JSONDecoder().decode(
            NavigationPath.CodableRepresentation.self, from: savedPath
        )
        path = NavigationPath(value)
    } catch {
        self.savedPath = nil
        path = NavigationPath()
    }
}
```

## 3～5 分钟练习

暂把 `savedPath` 设成无法解码的 `Data([0])`，再调用恢复方法。

## 参考答案

解码失败后 `savedPath` 被清空，`path` 为空，界面回到根页；下一次打开不会重复使用坏数据。
