# Photoshop（PS）学习路线

从图层与非破坏编辑出发，逐步学习选区、蒙版、调色、修图与合成。每个工作日更新一节中文短课。

## 课程目录

1. [第 1 课：图层与非破坏编辑](./2026-09-01-图层与非破坏编辑.md) — 用图层分离内容，并用调整图层保护原始像素。
2. [2026-09-02：矩形选区与局部填充](./2026-09-02-矩形选区与局部填充.md)——只修改画面指定区域，同时保留原图。
3. [2026-09-03：选区转换为图层蒙版](./2026-09-03-选区转换为图层蒙版.md)——隐藏色块的一部分而不删除原始像素。
4. [2026-09-04：亮度对比度调整图层](./2026-09-04-亮度对比度调整图层.md)——可撤回地调整练习图像的明暗。
5. [2026-09-07：调整图层蒙版限定区域](./2026-09-07-调整图层蒙版限定区域.md)——只让亮度调整影响照片的一部分。
6. [2026-09-08：画笔编辑图层蒙版](./2026-09-08-画笔编辑图层蒙版.md)——用黑白灰画笔可逆地细化调整范围。
7. [2026-09-09：蒙版密度与羽化](./2026-09-09-蒙版密度与羽化.md)——整体调整蒙版遮挡强度并柔化边缘。
8. [2026-09-10：复制图层蒙版](./2026-09-10-复制图层蒙版.md)——把完成的遮罩范围复用到另一个图层。
