# 第 13 课：独立智能对象副本

- 日期：2026-09-18
- 课程序号：第 13 课
- 知识点：独立智能对象副本

## 用途或适用场景

让两个外观副本可以分别编辑，而不共享同一嵌入内容。

## 核心概念

普通复制仍引用同一智能对象内容；New Smart Object via Copy 创建独立内容副本。

## 最小代码或操作示例

```text
1. 选中上一课的智能对象图层。
2. 选择 Layer > Smart Objects > New Smart Object via Copy。
3. 编辑新副本内容并保存。
```

## 3～5 分钟练习

修改新副本中的一处文字。

## 参考答案

新副本更新，原智能对象实例保持原内容。

## 与上一课的联系

继承上一课编辑智能对象内容；本课只创建可独立编辑的副本；完成后下一课可比较普通复制与独立副本。
