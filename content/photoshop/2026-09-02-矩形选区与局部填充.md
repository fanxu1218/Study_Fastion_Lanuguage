# 第 2 课：矩形选区与局部填充

- 日期：2026-09-02
- 课程序号：第 2 课
- 知识点：矩形选框、当前图层与取消选择

## 用途

只修改画面指定区域，同时保留原图。

## 核心概念

- 选区限制修改区域，但不决定修改哪一层；仍需检查当前图层。
- 羽化为 0 可获得清晰边界；取消选择只去掉选区，不删除像素。

## 最小代码或操作示例

```text
1. 新建练习文档，在图层面板新建空白像素图层，命名“色块”。
2. 选择矩形选框工具，在选项栏设 Feather=0，Style=Normal。
3. 在画布中拖出一个矩形，确认“色块”图层仍被选中。
4. 使用 Edit > Fill，选择一种颜色并确认。
5. 使用 Select > Deselect 取消选择；切换色块层可见性观察结果。
```

## 3～5 分钟练习

新增“第二色块”空白层，创建一个不同颜色矩形；确认关闭它不会隐藏第一个色块。

## 参考答案

```text
两个矩形分别位于“色块”和“第二色块”层。
每次填充只影响选区内部；隐藏第二层后第一层仍可见，底图未改变。
```
