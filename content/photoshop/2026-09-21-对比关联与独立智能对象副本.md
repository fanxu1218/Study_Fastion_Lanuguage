# 第 14 课：对比关联与独立智能对象副本

- 日期：2026-09-21
- 课程序号：第 14 课
- 知识点：对比关联与独立智能对象副本

## 用途或适用场景

辨认修改原对象时哪份副本会同步。

## 核心概念

Layer Via Copy 共享原智能对象内容；New Smart Object Via Copy 产生独立内容。

## 最小代码或操作示例

```text
1. 保留上一课的独立副本。
2. 从原图层执行 Layer > New > Layer Via Copy。
3. 编辑原智能对象内容并保存，比较两份副本。
```

## 3～5 分钟练习

把原内容颜色改为蓝色。

## 参考答案

普通复制同步变蓝；独立副本保持原颜色。

## 与上一课的联系

沿用第 13 课通过 New Smart Object Via Copy 创建的独立副本；本课只新增普通 Layer Via Copy 作为关联对照；下一课可把独立副本转换为外部链接源。
