# 第 3 课：选区转换为图层蒙版

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：Reveal Selection 与黑白蒙版

## 用途

隐藏色块的一部分而不删除原始像素。

## 核心概念

- 选区限制一次操作，蒙版则持续控制该图层哪些区域可见。
- 蒙版白色显示、黑色隐藏；画笔修改前应选中蒙版缩略图，而不是图像缩略图。

## 最小代码或操作示例

```text
1. 打开上一课练习文档，另存一个副本；选择已有“色块”像素层。
2. 用矩形选框在色块内部选出一半区域，保持羽化为 0。
3. 选择 Layer > Layer Mask > Reveal Selection。
4. 在图层面板确认多出黑白蒙版缩略图，色块只有选中区域可见。
5. 取消剩余选区；单击蒙版缩略图，用白色画笔涂原先隐藏的区域，恢复部分色块。
```

## 3～5 分钟练习

仍选中蒙版，用黑色画笔隐藏刚恢复的部分，再用白色恢复；说明为什么不能在图像缩略图上画。

## 参考答案

```text
蒙版上黑色隐藏、白色恢复，原色块像素仍在。若选中图像缩略图，画笔直接改动色块像素，就不是本课的非破坏隐藏。
```

## 与上一课的联系
