# 第 1 课：val、var 与类型推断

- 日期：2026-08-31
- 课程序号：第 1 课
- 知识点：`val`、`var` 与类型推断

## 用途

变量是 Kotlin 程序保存数据的基础。优先使用不可重新赋值的 `val`，能让状态变化更容易追踪。

## 核心概念

- `val` 声明只读引用，初始化后不能重新赋值。
- `var` 声明可变引用。
- 编译器通常能根据初始值推断类型。
- 需要明确契约时可以写出类型，例如 `val count: Int = 1`。

## 最小代码示例

```kotlin
fun main() {
    val language = "Kotlin"
    var lesson = 1

    println("$language 第 $lesson 课")
    lesson += 1
    println("下一课：$lesson")
}
```

var minutes = 10
