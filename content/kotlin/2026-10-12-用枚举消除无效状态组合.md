# 第 25 课：用枚举消除无效状态组合

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：`enum class` 状态

## 用途或适用场景

避免 `done` 与 `failed` 同时为真这类无效组合。

## 核心概念

本课只沿用上一课的已有数据与命名，并增加上述单一知识点。

## 最小代码或操作示例

```kotlin
enum class LessonStatus { READY, DONE, FAILED }
fun statusText(status: LessonStatus) = when (status) {
  LessonStatus.READY -> "继续学习"
  LessonStatus.DONE -> "已完成"
  LessonStatus.FAILED -> "重试"
}
```

按示例完成一次最小操作，并核对结果。

## 参考答案

每种状态只对应一条文案，不存在冲突组合。
