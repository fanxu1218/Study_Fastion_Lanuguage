# 第 30 课：用密封结果返回状态名称解析

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：用已学 sealed class 表达解析结果

## 用途或适用场景

把名称解析从 main 中提取出来，让调用方明确处理失败。

## 核心概念

成功携带 LessonStatus，失败保留原输入。复用已学 sealed/data class/when；只捕获 valueOf 约定的 IllegalArgumentException，不把失败转换成 READY。

## 最小代码或操作示例

保留 LessonStatus(text)/statusText，在 main 外新增：

```kotlin
sealed class StatusParseResult {
    data class Success(val status: LessonStatus) : StatusParseResult()
    data class Failure(val inputName: String) : StatusParseResult()
}

fun parseStatus(inputName: String): StatusParseResult = try {
    StatusParseResult.Success(LessonStatus.valueOf(inputName))
} catch (error: IllegalArgumentException) {
    StatusParseResult.Failure(inputName)
}
```

用下面代码替换第 29 课 main 中的 try/catch：

```kotlin
when (val result = parseStatus("READY")) {
    is StatusParseResult.Success -> println(statusText(result.status))
    is StatusParseResult.Failure -> println("无效状态名称：${result.inputName}")
}
```

原枚举及其遍历不变。

## 3～5 分钟练习

分别传入 DONE、小写 ready 和空字符串，按结果分支输出。

## 参考答案

DONE 成功得到已完成；其余两项保留无效输入并进入 Failure。不 trim 或自动转大写改变上一课的精确匹配语义。
