# 第 2 课：基本类型与字符串模板

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：数字、布尔值、字符串与模板表达式

## 用途

表达数量、价格和状态，并将数据组合成清晰文本。

## 核心概念

- 常见类型有 `Int`、`Double`、`Boolean`、`Char`、`String`。
- `$name` 插入变量，`${表达式}` 插入计算结果。

## 最小代码示例

```kotlin
fun main() {
    val language = "Kotlin"
    val lesson = 2
    println("$language 第 $lesson 课，学习 ${15 + 5} 分钟")
}
```

## 3～5 分钟练习

声明商品名、单价和数量，用模板输出总价。

## 参考答案

```kotlin
val product = "书"
val price = 20.0
val count = 2
println("$product 总价：${price * count}")
```
