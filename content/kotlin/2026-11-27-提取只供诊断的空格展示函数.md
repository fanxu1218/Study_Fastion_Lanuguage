# 第 58 课：提取只供诊断的空格展示函数

- 日期：2026-11-27
- 课程序号：第 58 课
- 知识点：普通函数复用字符串展示转换

## 用途或适用场景

收拢第57课消息两侧相同的replace操作。

## 核心概念

辅助函数接收已生成的展示字符串；check继续比较原actual和expected对象，parseStatus不接收替换后的文字。

## 最小代码或操作示例

在ContractStatusCheck.kt原package/import之后、checkFailureContract之外添加：
```kotlin
private fun showDiagnosticSpaces(text: String): String =
    text.replace(' ', '·')
```
仅将原check失败消息替换为：
```kotlin
check(actual == expected) {
    "Failure原文契约不符：actual=[${showDiagnosticSpaces(actual.toString())}]；expected=[${showDiagnosticSpaces(expected.toString())}]"
}
```
保留Failure(" READY ")、parseStatus(" READY ")及原唯一main。

## 3～5 分钟练习

在个人副本仅将独立期望改为Failure("READY")观察诊断，再恢复并运行九项及契约。提取前后比较结果应变化吗？

## 参考答案

不应变化。错误期望仍失败并显示原空格位置，恢复后九项和独立契约分别通过。不能把showDiagnosticSpaces用于parseStatus输入或对象相等比较。
