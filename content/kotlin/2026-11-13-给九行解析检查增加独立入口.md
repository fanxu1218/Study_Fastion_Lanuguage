# 第 48 课：给九行解析检查增加独立入口

- 日期：2026-11-13
- 课程序号：第 48 课
- 知识点：检查函数与调用入口分离

## 用途或适用场景

将第47课已核对完整的九行检查从main中明确隔离。

## 核心概念

新入口调用原checkStatusParsing一次，完整执行后再核对固定9；包装入口不改变原解析数据或返回时点。

## 最小代码或操作示例

沿第46课正确Failure和第47课九行覆盖，在原文件顶层新增：
```kotlin
fun testStatusParsing() {
    val checkedCount = checkStatusParsing()
    check(checkedCount == 9) {
        "完成数量不符：期望9，实际" + checkedCount
    }
    println("${checkedCount}项解析检查完成")
}
```
main中用一次testStatusParsing()替换原数量检查与打印，不同时保留旧直接调用。保留原checkStatusParsing(): Int、九行数据、单次parseStatus、消息及循环后return cases.size；运行应完成9项。

## 3～5 分钟练习

main里既调用testStatusParsing又保留旧checkStatusParsing，会怎样？

## 参考答案

会把同一组检查运行两次；本课只保留新入口的一次调用，不能把重复次数当新增覆盖。
