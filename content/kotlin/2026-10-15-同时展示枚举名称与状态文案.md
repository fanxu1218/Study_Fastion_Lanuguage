# 第 28 课：同时展示枚举名称与状态文案

- 日期：2026-10-15
- 课程序号：第 28 课
- 知识点：枚举常量的 name 属性

## 用途或适用场景

为上一课状态文案清单补上固定枚举名称，方便区分程序标识和显示标签。

## 核心概念

name 返回声明中的常量名称；text 是第 26 课自行定义的文案，二者用途不同。ordinal 是位置，调整声明顺序会改变位置，不能把它当稳定业务 ID。这里只增加 name 读取。

## 最小代码或操作示例

保留 LessonStatus(text)、statusText 和原 main，把循环输出改为：

```kotlin
for (status in LessonStatus.entries) {
    println("${status.name}: ${statusText(status)}")
}
```

不增加另一份名称列表，不改变当前状态。

## 3～5 分钟练习

把 READY 的显示文案改为“开始练习”，再次运行；核对名称和文案各自怎样变化。

## 参考答案

第一行变为 READY: 开始练习，其他两行为 DONE: 已完成、FAILED: 重试；只改 text 不改变枚举名称。

## 与上一课的联系

继承第 26 课 text/statusText 和第 27 课 entries；本课只增加 name。下一课可在用户输入固定名称后尝试转换回枚举，并明确无效输入的处理。
