# 第 26 课：给课程状态枚举添加文案属性

- 日期：2026-10-13
- 课程序号：第 26 课
- 知识点：枚举构造器中的只读属性

## 用途或适用场景

让每个既有课程状态携带固定显示文案，减少外部重复映射。

## 核心概念

枚举可以通过构造器声明属性，再由每个枚举值传入自己的值。`text` 是该固定状态的显示标签，不是第二份可变业务状态；三种状态与其既有文案一一对应。

## 最小代码或操作示例

替换第 25 课的枚举声明，并保留 `statusText(status)` 函数名和调用方式：

```kotlin
enum class LessonStatus(val text: String) {
    READY("继续学习"),
    DONE("已完成"),
    FAILED("重试")
}

fun statusText(status: LessonStatus): String = status.text

fun main() {
    println(statusText(LessonStatus.READY))
    println(statusText(LessonStatus.DONE))
    println(statusText(LessonStatus.FAILED))
}
```

已有项目保留自己的 `main`，只替换前两个声明，并在原入口加入调用。

## 3～5 分钟练习

把 `READY` 的文案改为“开始练习”，再次运行三个调用；不要修改 `LessonStatus` 的状态集合。

## 参考答案

依次输出“开始练习”“已完成”“重试”；调用方仍只传入一个枚举值，没有两个布尔值组合。
