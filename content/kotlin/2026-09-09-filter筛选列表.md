# 第 8 课：filter筛选列表

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：List.filter

## 用途

从一组数据中保留满足条件的元素，同时不修改原列表。

## 核心概念

`filter` 对每个元素执行布尔判断，并返回由结果为 `true` 的元素组成的新列表。

## 最小代码或操作示例

```kotlin
val minutes = listOf(5, 15, 20)
val longSessions = minutes.filter { it >= 15 }
println(longSessions)
```

## 3～5 分钟练习

筛选出所有偶数分钟数。

## 参考答案

使用 `minutes.filter { it % 2 == 0 }`，结果是 `[20]`。

## 与上一课的联系

上一课用 `map` 转换每一项；本课用 `filter` 决定哪些项进入新列表。
