# 第 29 课：把固定名称转换为课程状态

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：valueOf 与无效名称异常处理

## 用途或适用场景

把上一课打印出的枚举名称转回 LessonStatus。

## 核心概念

valueOf 要求精确匹配常量名，找不到时抛 IllegalArgumentException。catch 在本课明确报告无效输入，不返回伪造 READY；显示文案 text 不能当枚举名称。

## 最小代码或操作示例

保留第 26 课 LessonStatus(text)/statusText 和原 main，在 main 中追加：

```kotlin
val inputName = "READY"
try {
    val parsed = LessonStatus.valueOf(inputName)
    println(statusText(parsed))
} catch (error: IllegalArgumentException) {
    println("无效状态名称：$inputName")
}
```

try 中尝试转换；只有匹配失败才进入该 catch。inputName 是教学字符串，本课不新增控制台输入工具。

## 3～5 分钟练习

分别把 inputName 改为 DONE、ready、“开始练习”，每次重新运行。

## 参考答案

DONE 显示已完成；小写 ready 和显示文案均明确报告无效名称，不改变原课程状态。READY 的文字由当前 text 决定。

## 与上一课的联系
