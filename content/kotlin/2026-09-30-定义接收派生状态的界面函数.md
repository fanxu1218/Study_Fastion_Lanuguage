# 第 22 课：定义接收派生状态的界面函数

- 日期：2026-09-30
- 课程序号：第 22 课
- 知识点：函数参数声明

## 用途或适用场景

为上一课的命名参数调用补上可执行的函数契约。

## 核心概念

函数只接收已经派生的文字和布尔值，不在界面函数里重复判断业务状态。

## 最小代码或操作示例

```kotlin
fun statusRow(text: String, retryEnabled: Boolean): String =
    if (retryEnabled) "$text · 可重试" else text

val state: State = State.Error("网络失败")
val output = statusRow(text = label(state), retryEnabled = canRetry(state))
```

## 3～5 分钟练习

传入“加载失败”和 `false`。

## 参考答案

结果只为“加载失败”，不会追加重试提示。
