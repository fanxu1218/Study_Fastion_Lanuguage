# 第 5 课：for循环与整数范围

- 日期：2026-09-04
- 课程序号：第 5 课
- 知识点：for、范围与 var 累加器

## 用途

重复累计每日练习的序号。

## 核心概念

1..5 包含两端；1 until 5 不包含 5。只有需要重新赋值的累计变量使用 var。

## 最小代码或操作示例

```kotlin
fun main() {
    var total = 0
    for (day in 1..5) { total += day }
    println(total)
}
```

## 3～5 分钟练习

把范围改为 1 until 5，再改成 1..3。

## 参考答案

原输出 15；改后分别为 10、6。循环依次给 day 绑定范围内整数。
