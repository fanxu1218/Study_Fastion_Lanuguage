# 第 24 课：为失败状态加入重试提示

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：状态文案分支

## 用途或适用场景

让现有文案函数区分完成、失败和继续学习。

## 核心概念

只增加一个紧密的失败参数分支，状态仍由调用方传入。

## 最小代码或操作示例

```kotlin
fun statusText(done: Boolean, failed: Boolean): String =
  if (failed) "重试" else if (done) "已完成" else "继续学习"
```

## 3～5 分钟练习

分别传入失败、完成和进行中组合。

## 参考答案

失败返回“重试”，完成返回“已完成”，其余返回“继续学习”。
