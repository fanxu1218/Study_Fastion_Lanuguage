# 第 51 课：从独立调用文件运行解析检查

- 日期：2026-11-18
- 课程序号：第 51 课
- 知识点：跨包导入已有顶层入口

## 用途或适用场景

复用第50课lessons.checks中的testStatusParsing。

## 核心概念

import让新调用方引用原顶层函数；运行哪个main由运行配置决定，不能把两次启动当更多用例。

## 最小代码或操作示例

在同一模块同一源码集新建RunStatusChecks.kt：
```kotlin
package lessons.runner

import lessons.checks.testStatusParsing

fun main() {
    testStatusParsing()
}
```
保留StatusParser.kt、StatusChecks.kt及原九行数据不变。沿原工程构建，将本次运行配置选为lessons.runner.RunStatusChecksKt的main（JVM工程）；其他目标使用其原顶层入口选择方式。只运行新入口一次，预期9项解析检查完成；不同时启动旧main。

## 3～5 分钟练习

新入口只复制九行数据而不调用原函数，还是本课的复用吗？

## 参考答案

不是；新文件只调用原testStatusParsing，解析与断言仍来自原两文件。
