# 第 50 课：用包名与import连接解析检查

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：跨包显式导入三个顶层声明

## 用途或适用场景

在第49课两文件起点明确解析与检查所属包。

## 核心概念

package决定声明完整名称，import引入另一个包中的可见声明；目录名称本身不能替代package。

## 最小代码或操作示例

在同一源码集个人副本，将StatusParser.kt原package替换为：
```kotlin
package lessons.parser
```
StatusChecks.kt原package替换为下列包与导入（原来无package则在顶部添加）：
```kotlin
package lessons.checks

import lessons.parser.LessonStatus
import lessons.parser.StatusParseResult
import lessons.parser.parseStatus
```
两文件原有的其他必要import保留；原模型、九行数据、checkStatusParsing、testStatusParsing及一次main调用不变。沿原工程构建并将运行配置指向lessons.checks包内原main，预期9项完成。

## 3～5 分钟练习

只移动文件夹而保留两个旧package，可以声称完成跨包导入吗？

## 参考答案

不能，包身份以源码package为准；实际构建与main运行配置也须对应。
