# 第 57 课：只在失败展示中标记空格

- 日期：2026-11-26
- 课程序号：第 57 课
- 知识点：replace返回新字符串用于诊断

## 用途或适用场景

让第56课结果文字中的输入空格可辨认。

## 核心概念

data class的toString结果可以只为展示替换空格；原actual/expected对象及值比较不变，解析器不trim。

## 最小代码或操作示例

在ContractStatusCheck.kt中仅替换check失败消息：
```kotlin
check(actual == expected) {
    "Failure原文契约不符：actual=[${actual.toString().replace(' ', '·')}]；expected=[${expected.toString().replace(' ', '·')}]"
}
```
保留Failure(" READY ")及parseStatus(" READY ")。在个人副本临时将expected改为Failure("READY")，运行原唯一main观察两侧；恢复后回归九项及契约。

## 3～5 分钟练习

可以将parseStatus的输入先replace后再参与检查吗？

## 参考答案

不应；那会改变原输入语义。本课只替换失败消息中的字符串，原两侧对象不变。
