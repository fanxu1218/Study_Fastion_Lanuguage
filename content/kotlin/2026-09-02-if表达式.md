# 第 3 课：if表达式

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：if 返回值与分支完整性

## 用途

直接根据条件生成文本值。

## 核心概念

- if 可以作为表达式赋给变量。
- 作为表达式使用时必须覆盖 else；分支最后的表达式提供结果。

## 最小代码或操作示例

```kotlin
fun main() {
    val score = 60
    val result = if (score >= 60) "及格" else "继续练习"
    println(result)
}
```

## 3～5 分钟练习

增加优秀（>=90），用 59、60、90 核对结果。

## 参考答案

```kotlin
val result = if (score >= 90) "优秀"
    else if (score >= 60) "及格"
    else "继续练习"
```
