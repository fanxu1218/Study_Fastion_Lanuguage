# 第 15 课：读取sealed分支数据

- 日期：2026-09-18
- 课程序号：第 15 课
- 知识点：读取sealed分支数据

## 用途或适用场景

在穷尽 when 中读取 Ready 状态携带的数量。

## 核心概念

智能类型转换让 Ready 分支直接访问 count；else 不需要出现。

## 最小代码或操作示例

```text
sealed interface State { data object Loading : State; data class Ready(val count: Int) : State }
fun label(state: State) = when (state) {
  State.Loading -> "加载中"
  is State.Ready -> "共 ${state.count} 节"
}
```

## 3～5 分钟练习

增加 Error(message) 分支。

## 参考答案

新增 `data class Error(val message: String) : State`，并在 when 中返回 message。

## 与上一课的联系

继承上一课携带数据的 sealed 状态；本课只在 Ready 分支读取 count；完成后下一课可加入错误状态。
