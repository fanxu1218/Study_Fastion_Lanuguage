# 第 38 课：为READY合法名称补解析用例

- 日期：2026-10-30
- 课程序号：第 38 课
- 知识点：合法输入与数量约定同步

## 用途或适用场景

为READY合法名称补解析用例，用于在已有示例中练习合法输入与数量约定同步。

## 核心概念

新增一个已存在枚举值的名称，不扩大解析容错。检查清单从六项增到七项，调用方固定数量应同步更新，逐行check仍保留。

## 最小代码或操作示例

沿第36课checkStatusParsing和第37课调用方检查，在cases的原第一项之前增加：

```kotlin
StatusParseCase("ready", "READY", StatusParseResult.Success(LessonStatus.READY)),
```

READY来自原LessonStatus枚举，不新建状态。原六项及return cases.size位置不动；main只把数量约定改为：

```kotlin
check(checkedCount == 7) {
    "完成数量不符：期望7，实际${checkedCount}"
}
```

检查函数仍只调用一次，完成提示保留。

## 3～5 分钟练习

新增的READY通过，原小写ready失败用例是否应删除？

## 参考答案

不删除。二者验证大小写严格约定的不同边界；七项均执行，不能trim或统一大小写改变parseStatus。
