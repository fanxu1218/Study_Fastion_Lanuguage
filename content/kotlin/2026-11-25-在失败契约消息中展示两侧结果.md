# 第 56 课：在失败契约消息中展示两侧结果

- 日期：2026-11-25
- 课程序号：第 56 课
- 知识点：字符串模板读取已有data class结果

## 用途或适用场景

让第55课check失败时能看见实际值与独立期望。

## 核心概念

data class自动生成可读toString；仅在check失败消息中插值，不改变equals比较、Failure原文或解析器。

## 最小代码或操作示例

在ContractStatusCheck.kt的checkFailureContract中，仅替换原check语句：
```kotlin
check(actual == expected) {
    "Failure原文契约不符：actual=[$actual]；expected=[$expected]"
}
```
保留expected=Failure(" READY ")及parseStatus(" READY ")。运行原唯一main；个人副本仅把expected改为Failure("READY")观察失败消息，再恢复并回归原九项及契约。

## 3～5 分钟练习

消息中的两份Failure文字可以替代原data class相等判断吗？

## 参考答案

不能；展示只帮助定位。check仍比较原对象的值，恢复独立期望中的空格后再运行。
