# 第 9 课：map转换列表

- 日期：2026-09-10
- 课程序号：第 9 课
- 知识点：集合 map

## 用途

把列表每个元素转换成新形式。

## 核心概念

`map` 不修改原列表，Lambda 返回值组成新列表。

## 最小代码或操作示例

```kotlin
val names = listOf("Rust", "Kotlin")
val lengths = names.map { it.length }
```
