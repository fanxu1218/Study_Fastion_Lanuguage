# 第 7 课：只读List与map转换

- 日期：2026-09-08
- 课程序号：第 7 课
- 知识点：List 与 map

## 用途

把一组练习分钟数转换成对应的秒数，而不修改原列表。

## 核心概念

`listOf` 创建只读列表，`map` 对每个元素执行转换并返回一个新列表。

## 最小代码或操作示例

```kotlin
val minutes = listOf(5, 10, 15)
val seconds = minutes.map { it * 60 }
println(seconds)
```

## 3～5 分钟练习

把秒数列表改为每项增加 30 秒。

## 参考答案

使用 `minutes.map { it * 60 + 30 }`，结果为 `[330, 630, 930]`。
