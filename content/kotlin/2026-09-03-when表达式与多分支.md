# 第 4 课：when表达式与多分支

- 日期：2026-09-03
- 课程序号：第 4 课
- 知识点：按值匹配、组合分支与 else

## 用途

把课程状态编号转换成可读名称。

## 核心概念

- when 可以匹配具体值，也可把多个值放在同一分支。
- 用作本课这种 Int 输入的返回表达式时，以 else 覆盖其余值。

## 最小代码或操作示例

```kotlin
fun main() {
    val status = 1
    val label = when (status) {
        0 -> "未开始"
        1 -> "进行中"
        2 -> "已完成"
        else -> "非法编号"
    }
    println(label)
}
```

## 3～5 分钟练习

写一个 when 表达式，将 1、2 映射为“基础”，3 映射为“进阶”，其他值映射为“未分类”。

## 参考答案

```kotlin
val level = 2
val label = when (level) {
    1, 2 -> "基础"
    3 -> "进阶"
    else -> "未分类"
}
println(label) // 基础
```

## 与上一课的联系

上一课用 if 表达式做条件选择；本课用 when 清楚表达多个离散值的对应关系。
