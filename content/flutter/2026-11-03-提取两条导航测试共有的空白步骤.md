# 第 41 课：提取两条导航测试共有的空白步骤

- 日期：2026-11-03
- 课程序号：第 41 课
- 知识点：异步测试辅助函数的观察边界

## 用途或适用场景

让失败后成功与失败后取消复用相同的空白输入起点。

## 核心概念

辅助函数只执行相同输入和界面观察，不负责打开路由、不改变返回记录，也不执行成功或取消动作。调用方必须await，才能保持原顺序。

## 最小代码或操作示例

沿第39/40课两条转换测试，在原测试文件main外新增；沿原material和flutter_test导入：

```dart
Future<void> submitBlankTitle(WidgetTester tester) async {
  await tester.enterText(find.byType(TextField), '   ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  expect(find.byType(LessonTitleEditor), findsOneWidget);
}
```

两项测试都在打开编辑页并pumpAndSettle后，用await submitBlankTitle(tester);替换原空白输入到编辑页存在的整段。随后保留expect(returned, isFalse);，各自有效提交或Navigator无结果pop及终态断言原样保留。运行flutter test，不重新pumpWidget。

## 3～5 分钟练习

能把returned也放进辅助函数并固定设为false吗？

## 参考答案

不能；那会伪造返回观察。returned仍由原onResult回调写入，调用方独立检查。
