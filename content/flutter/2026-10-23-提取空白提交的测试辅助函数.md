# 第 34 课：提取空白提交的测试辅助函数

- 日期：2026-10-23
- 课程序号：第 34 课
- 知识点：异步WidgetTester辅助步骤

## 用途或适用场景

提取空白提交的测试辅助函数。

## 核心概念

辅助函数接收当前tester并完成一次输入/提交/刷新；不重建Widget树，也不把具体断言藏进辅助步骤。调用时必须await。

## 最小代码或操作示例

在原测试文件main外新增（沿用flutter_test与material导入）：

```dart
Future<void> submitBlankTitle(WidgetTester tester, String text) async {
  await tester.enterText(find.byType(TextField), text);
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
}
```

在第31课及第33课测试中，将首次空白输入的enterText/receiveAction/pump三行替换为：

```dart
await submitBlankTitle(tester, '   ');
```

原pumpWidget、所有expect及第33课第二次提交原样保留；不重复声明测试。

## 3～5 分钟练习

运行原flutter test；检查辅助函数里若加入pumpWidget会改变什么。

## 参考答案

原测试应保留同一树中的两次提交。辅助函数不应重新创建页面，否则会抹掉要检查的清错/重提交过程。
