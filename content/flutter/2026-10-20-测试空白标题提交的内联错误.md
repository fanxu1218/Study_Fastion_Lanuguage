# 第 31 课：测试空白标题提交的内联错误

- 日期：2026-10-20
- 课程序号：第 31 课
- 知识点：通过测试输入动作触发 onSubmitted

## 用途或适用场景

在原 Widget 测试中复现空白提交，不离开编辑页面。

## 核心概念

用 receiveAction(TextInputAction.done) 模拟框架收到的完成动作；普通 Enter 键事件不等价。断言错误提示并保留编辑器，继续使用 SDK 自带 flutter_test。

## 最小代码或操作示例

在第 30 课测试文件的 main 内追加，保留原 import 和计数测试：

```dart
testWidgets('空白标题不能提交并显示错误', (tester) async {
  await tester.pumpWidget(const MaterialApp(home: LessonTitleEditor()));
  await tester.enterText(find.byType(TextField), '   ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  expect(find.byType(LessonTitleEditor), findsOneWidget);
});
```

沿用第 23 课原错误文案、第 24 课 onChanged 和后续长度计数，不改组件实现；在根目录执行 flutter test test/lesson_title_editor_test.dart。

## 3～5 分钟练习

把输入改为空字符串，仍用同一完成动作和断言运行。

## 参考答案

两个输入都经 trim().isEmpty 进入原错误分支；页面保留。Widget 断言不证明设备键盘、导航集成或读屏通过。
