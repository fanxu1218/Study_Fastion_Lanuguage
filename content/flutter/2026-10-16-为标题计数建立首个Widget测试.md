# 第 30 课：为标题计数建立首个Widget测试

- 日期：2026-10-16
- 课程序号：第 30 课
- 知识点：testWidgets 中输入并检查计数

## 用途或适用场景

把上一课 40 字限制与剩余计数的稳定状态写成可重复检查。

## 核心概念

Widget 测试在测试环境构建界面；pumpWidget 创建树，enterText 模拟编辑，pump 处理更新，expect 检查找到的文字。它不证明输入法组合或设备读屏行为。

## 最小代码或操作示例

把现有 LessonTitleEditor 及其 State 原样放入 lib/lesson_title_editor.dart，原入口导入该文件；保留第 28 课 buildCounter。确认 pubspec.yaml 已有下列开发依赖，存在时不重复添加：

```yaml
dev_dependencies:
  flutter_test:
    sdk: flutter
```

在 test/lesson_title_editor_test.dart 编写：

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import '../lib/lesson_title_editor.dart';

void main() {
  testWidgets('标题计数覆盖空输入与40字边界', (tester) async {
    await tester.pumpWidget(const MaterialApp(home: LessonTitleEditor()));
    expect(find.text('还可输入 40 个字符'), findsOneWidget);
    await tester.enterText(find.byType(TextField),
        'aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa');
    await tester.pump();
    expect(find.text('还可输入 0 个字符'), findsOneWidget);
    await tester.enterText(find.byType(TextField), '');
    await tester.pump();
    expect(find.text('还可输入 40 个字符'), findsOneWidget);
  });
}
```

在项目根目录执行 flutter test test/lesson_title_editor_test.dart。

## 3～5 分钟练习
