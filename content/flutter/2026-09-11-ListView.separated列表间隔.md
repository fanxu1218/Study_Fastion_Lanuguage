# 第 11 课：ListView.separated列表间隔

- 日期：2026-09-11
- 课程序号：第 11 课
- 知识点：ListView.separated

## 用途

为按需构建的列表统一添加分隔线。

## 核心概念

`itemBuilder` 创建内容，`separatorBuilder` 只负责相邻项之间的间隔。

## 最小代码或操作示例

```dart
ListView.separated(
  itemCount: lessons.length,
  itemBuilder: (_, i) => Text(lessons[i]),
  separatorBuilder: (_, __) => const Divider(),
)
```

## 3～5 分钟练习

把分隔线替换为 8 像素空白。

## 参考答案

返回 `const SizedBox(height: 8)`。
