# 第 12 课：ListView.builder按需构建

- 日期：2026-09-14
- 课程序号：第 12 课
- 知识点：列表构建器与索引

## 用途

展示较长或动态列表，避免一次创建所有子组件。

## 核心概念

`itemCount` 限定数量，`itemBuilder` 根据索引按需返回每一行。

## 最小代码或操作示例

```dart
ListView.builder(
  itemCount: lessons.length,
  itemBuilder: (context, index) {
    return ListTile(title: Text(lessons[index]));
  },
)
```

## 3～5 分钟练习

为每一行增加显示 `第 index + 1 课` 的副标题。

## 参考答案

给 `ListTile` 增加 `subtitle: Text('第 ${index + 1} 课')`。

## 与上一课的联系

上一课用 `ListView.separated` 插入间隔；本课聚焦列表项的按需创建。
