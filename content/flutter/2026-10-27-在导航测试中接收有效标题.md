# 第 36 课：在导航测试中接收有效标题

- 日期：2026-10-27
- 课程序号：第 36 课
- 知识点：有效提交的路由返回结果

## 用途或适用场景

在导航测试中接收有效标题，让本次练习的结果可以按同一条件复查。

## 核心概念

有效标题会pop当前编辑路由，测试必须先push编辑器。把编辑器直接当首页，只适合此前不会返回的空白输入测试；接收结果仍使用已学Navigator.push<String>。

## 最小代码或操作示例

保留第34课辅助函数、第35课空串及原测试。在同一main内追加，沿用原material/flutter_test导入：

```dart
testWidgets('有效标题返回清理后的文本', (tester) async {
  String? savedTitle;
  await tester.pumpWidget(MaterialApp(
    home: Builder(builder: (context) => Scaffold(
      body: ElevatedButton(
        onPressed: () async {
          savedTitle = await Navigator.push<String>(context,
            MaterialPageRoute<String>(
              builder: (_) => const LessonTitleEditor()));
        },
        child: const Text('编辑标题'),
      ),
    )),
  ));
  await tester.tap(find.text('编辑标题'));
  await tester.pumpAndSettle();
  await tester.enterText(find.byType(TextField), '  Flutter 路由  ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pumpAndSettle();
  expect(savedTitle, 'Flutter 路由');
  expect(find.byType(LessonTitleEditor), findsNothing);
  expect(find.text('编辑标题'), findsOneWidget);
});
```

pumpAndSettle用于本例有限导航动画，不能用于永不停止的动画；保留原组件的trim及pop逻辑。

## 3～5 分钟练习

若只断言编辑器消失，是否已证明返回了正确标题？

## 参考答案

没有。还要检查savedTitle等于去首尾空格后的字符串。这里只覆盖路由返回，不证明父列表更新或持久化。
