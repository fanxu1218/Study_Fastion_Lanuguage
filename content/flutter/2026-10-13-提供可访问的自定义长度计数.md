# 第 27 课：提供可访问的自定义长度计数

- 日期：2026-10-13
- 课程序号：第 27 课
- 知识点：TextField.buildCounter 与 Text.semanticsLabel

## 用途或适用场景

把上一课隐藏的默认计数替换为带完整朗读名称的自定义计数。

## 核心概念

回调提供 Flutter 已计算的 currentLength 与 maxLength，不自己调用字符串 length 复制长度事实。buildCounter 返回的 Text 必须也具备可访问名称；可见计数和朗读文本都从回调参数派生。

## 最小代码或操作示例

```dart
// 添加到第 26 课 LessonTitleEditor 的同一个 TextField；
// 保留 maxLength、decoration、onChanged 和 onSubmitted。
buildCounter: (context, {
  required int currentLength,
  required int? maxLength,
  required bool isFocused,
}) => Text(
  '$currentLength/$maxLength',
  semanticsLabel: '标题已输入 $currentLength 个字符，最多 $maxLength 个字符',
),
```

## 3～5 分钟练习

输入“Flutter”，核对计数为 7/40；用 TalkBack 或 VoiceOver 聚焦计数提示，并记录实际朗读。

## 参考答案

可见计数为 7/40，语义标签描述“已输入 7 个字符，最多 40 个字符”；是否及何时朗读应按目标平台实测，不能以生成 Widget 代替真机结果。

## 与上一课的联系

继承第 26 课同一 TextField、40 字限制、errorText 与提交返回路径；本课只用 buildCounter 提供自定义计数及语义名称；下一课可把同一计数文案改成剩余字符数。
