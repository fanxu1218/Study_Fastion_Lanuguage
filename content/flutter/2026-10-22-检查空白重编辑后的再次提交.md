# 第 33 课：检查空白重编辑后的再次提交

- 日期：2026-10-22
- 课程序号：第 33 课
- 知识点：同一测试树内的清错与重新校验

## 用途或适用场景

确认清除旧错误不会把新的空白标题变成有效输入。

## 核心概念

onChanged 清错与 onSubmitted 校验是先后独立的步骤。保留同一 Widget 树，先断言清除，再触发下一次完成动作。

## 最小代码或操作示例

在原测试文件 main 内追加，沿用 import 和 LessonTitleEditor：

```dart
testWidgets('空白重编辑后再次提交仍显示错误', (tester) async {
  await tester.pumpWidget(const MaterialApp(home: LessonTitleEditor()));
  await tester.enterText(find.byType(TextField), '   ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  await tester.enterText(find.byType(TextField), ' ');
  await tester.pump();
  expect(find.text('请输入标题'), findsNothing);
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  expect(find.byType(LessonTitleEditor), findsOneWidget);
});
```

执行原 flutter test 命令；两次提交中间不 pumpWidget，也不改组件校验。

## 3～5 分钟练习

第二次输入改为空字符串，再执行相同动作序列。

## 参考答案

编辑后旧错误消失，再提交时错误重新出现且编辑器仍存在。空串与空格均经原 trim().isEmpty 拒绝，未验证设备输入法或导航集成。
