# 第 40 课：检查空白提交后取消仍返回空结果

- 日期：2026-11-02
- 课程序号：第 40 课
- 知识点：校验失败不改变取消语义

## 用途或适用场景

验证校验失败后仍可以取消同一编辑路由。

## 核心概念

输入校验失败后，取消仍应结束同一编辑路由并返回null。returned区分未返回与已经取消，不能仅凭savedTitle为空作判断。

## 最小代码或操作示例

沿第38课TitleEditorTestHost及第39课同路由错误路径，在原测试main追加：

```dart
testWidgets('空白失败后取消返回null', (tester) async {
  String? savedTitle;
  bool returned = false;
  await tester.pumpWidget(TitleEditorTestHost(onResult: (title) {
    savedTitle = title;
    returned = true;
  }));
  await tester.tap(find.text('编辑标题'));
  await tester.pumpAndSettle();
  await tester.enterText(find.byType(TextField), '   ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  expect(returned, isFalse);
  Navigator.of(tester.element(find.byType(LessonTitleEditor))).pop();
  await tester.pumpAndSettle();
  expect(returned, isTrue);
  expect(savedTitle, isNull);
  expect(find.byType(LessonTitleEditor), findsNothing);
});
```

沿原material/flutter_test导入；编辑器没有AppBar，取消仍采用第37课原Navigator无结果pop，不使用寻找返回按钮的pageBack，不重新pumpWidget。保留有效返回、直接取消和失败后成功测试，运行flutter test；只有有限导航动画。

## 3～5 分钟练习

取消后只检查savedTitle为null，漏掉returned会有什么风险？

## 参考答案

路由根本没退出时变量也可能为null；需要returned为true及编辑页已消失来证明发生了取消。
