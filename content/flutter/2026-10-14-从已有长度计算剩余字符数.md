# 第 28 课：从已有长度计算剩余字符数

- 日期：2026-10-14
- 课程序号：第 28 课
- 知识点：从 buildCounter 参数派生剩余数量

## 用途或适用场景

把上一课的已输入计数改成剩余可输入数量，同时保留完整朗读名称。

## 核心概念

继续由 TextField 提供 currentLength/maxLength，不维护额外计数状态。因为本编辑器 maxLength 固定为 40，剩余量直接相减；回调类型允许 null，因此只在 null 时不显示计数。

## 最小代码或操作示例

替换 LessonTitleEditor 原 TextField 的 buildCounter，保留 maxLength:40、decoration 和两个输入回调：

```dart
buildCounter: (context, {
  required int currentLength,
  required int? maxLength,
  required bool isFocused,
}) {
  if (maxLength == null) return null;
  final remaining = maxLength - currentLength;
  return Text(
    '还可输入 $remaining 个字符',
    semanticsLabel: '标题还可输入 $remaining 个字符，最多 $maxLength 个字符',
  );
},
```

remaining 是本次回调局部值；输入法组合期可能暂时超限，负值应如实检查，不用 clamp 伪造未超限。

## 3～5 分钟练习

输入 Flutter、清空、完成 40 个字符输入，核对稳定输入状态的剩余量；另记录目标输入法组合期的实际结果。

## 参考答案

稳定输入状态分别为 33、40、0；语义名称与显示来自同一 remaining。输入法及读屏行为必须实际记录，文档核对不代替设备证据。
