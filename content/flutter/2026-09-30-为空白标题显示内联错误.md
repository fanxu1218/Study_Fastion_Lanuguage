# 第 23 课：为空白标题显示内联错误

- 日期：2026-09-30
- 课程序号：第 23 课
- 知识点：InputDecoration.errorText

## 用途或适用场景

在详情页解释空白标题为什么不能提交。

## 核心概念

沿用第 22 课 trim 校验和字符串导航结果。errorText 是详情页 State 的未提交输入反馈；这里补全 State 的承载位置。列表页 openLesson、mounted 检查和 renameLesson 沿用第 20 课。

## 最小代码或操作示例

```dart
import 'package:flutter/material.dart';

class LessonTitleEditor extends StatefulWidget {
  const LessonTitleEditor({super.key});
  @override
  State<LessonTitleEditor> createState() => _LessonTitleEditorState();
}
class _LessonTitleEditorState extends State<LessonTitleEditor> {
  String? errorText;
  @override
  Widget build(BuildContext context) => Scaffold(
    body: TextField(
      textInputAction: TextInputAction.done,
      decoration: InputDecoration(labelText: '新标题', errorText: errorText),
      onSubmitted: (text) {
        final value = text.trim();
        if (value.isEmpty) {
          setState(() => errorText = '请输入标题');
          return;
        }
        Navigator.pop<String>(context, value);
      },
    ),
  );
}
// 列表页原 MaterialPageRoute 的 builder 改为：
// builder: (_) => const LessonTitleEditor()
```

## 3～5 分钟练习

在详情页提交三个空格，再提交“Flutter 路由”。

## 参考答案

第一次不返回且显示“请输入标题”；第二次返回清理后的字符串；列表页仍只更新原 index。
