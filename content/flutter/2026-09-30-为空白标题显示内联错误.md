# 第 23 课：为空白标题显示内联错误

- 日期：2026-09-30
- 课程序号：第 23 课
- 知识点：`InputDecoration.errorText`

## 用途或适用场景

拒绝空白提交时在输入框下方解释原因。

## 核心概念

错误文字属于当前输入交互状态；课程列表仍只在合法提交时更新。

## 最小代码或操作示例

```dart
String? errorText;
TextField(
  decoration: InputDecoration(errorText: errorText),
  onSubmitted: (text) {
    final value = text.trim();
    if (value.isEmpty) { setState(() => errorText = '请输入标题'); return; }
    Navigator.pop(context, value);
  },
)
```
