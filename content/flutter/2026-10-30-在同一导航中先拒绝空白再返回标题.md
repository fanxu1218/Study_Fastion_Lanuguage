# 第 39 课：在同一导航中先拒绝空白再返回标题

- 日期：2026-10-30
- 课程序号：第 39 课
- 知识点：校验失败到有效提交的连续转换

## 用途或适用场景

在同一导航中先拒绝空白再返回标题，用于在已有示例中练习校验失败到有效提交的连续转换。

## 核心概念

同一编辑路由内先触发错误，再输入有效标题并提交，才能证明错误没有阻断后续返回；两次操作中不重建Widget树。

## 最小代码或操作示例

沿第37课returned观察及第38课TitleEditorTestHost，在原测试main内追加：

```dart
testWidgets('空白失败后仍可返回有效标题', (tester) async {
  String? savedTitle;
  bool returned = false;
  await tester.pumpWidget(TitleEditorTestHost(onResult: (title) {
    savedTitle = title;
    returned = true;
  }));
  await tester.tap(find.text('编辑标题'));
  await tester.pumpAndSettle();
  await tester.enterText(find.byType(TextField), '   ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pump();
  expect(find.text('请输入标题'), findsOneWidget);
  expect(returned, isFalse);
  expect(find.byType(LessonTitleEditor), findsOneWidget);
  await tester.enterText(find.byType(TextField), '  Flutter 路由  ');
  await tester.testTextInput.receiveAction(TextInputAction.done);
  await tester.pumpAndSettle();
  expect(returned, isTrue);
  expect(savedTitle, 'Flutter 路由');
  expect(find.byType(LessonTitleEditor), findsNothing);
});
```

沿material/flutter_test导入与原宿主；保留原有效、取消测试，执行flutter test。本例只有有限导航动画。

## 3～5 分钟练习

空白后重新pumpWidget再提交，能覆盖本课转换吗？

## 参考答案

不能；那是新实例，绕过同一路由错误后的恢复。应在同一树中输入，并分别证明未返回与最终有效返回。
