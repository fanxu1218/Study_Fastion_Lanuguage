# 第 26 课：报告交付场景的缺失外部文件

- 日期：2026-10-14
- 课程序号：第 26 课
- 知识点：Report Missing Files

## 用途或适用场景

在上一课保存的交付 .blend 中检查仍以外链方式引用的文件是否缺失。

## 核心概念

打包和外链可以同时存在。Report Missing Files 只报告找不到的外部文件，不证明每项资源已经打包；无警告也不证明换到另一台机器后路径仍可用。

## 最小代码或操作示例

打开 lesson-delivery-packed-v01.blend，保持原细分参数：

```text
1. 执行 File > External Data > Report Missing Files。
2. 查看 Info 区域给出的缺失文件警告，记录实际路径；无警告则如实记录。
3. 对上一课已存在的可打包图像，继续检查其路径旁的打包图标。
4. 在交付清单分别记录“打包标记”和“外部路径是否缺失”。
```

纯几何场景没有图像时，图像项记“不适用”；不使用 Unpack 或删除源文件来制造问题。

## 3～5 分钟练习

完成一次报告，并把“未发现缺失外链”与“已打包资源数”分别填写，不合并为一个完成勾。

## 参考答案

有警告则记录真实文件路径；无警告只说明本机本次未发现缺失外部文件。视频等不能打包的依赖仍需按第 25 课规则另行交付。

## 与上一课的联系
