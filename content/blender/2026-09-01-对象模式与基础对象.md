# 第 1 课：对象模式与基础对象

- 日期：2026-09-01
- 课程序号：1
- 知识点：对象模式、Outliner、移动旋转缩放

## 用途

对象模式是整理场景和摆放整体对象的起点。先区分对象操作与几何编辑，能避免在错误模式下找不到命令。

## 核心概念

- 对象模式用于选择、移动、旋转和缩放整个对象。
- 编辑模式用于修改网格的顶点、边和面，按 `Tab` 可以在支持的对象上切换。
- Outliner 展示场景中的对象和集合，适合重命名、查找与组织层级。
- `G`、`R`、`S` 分别是移动、旋转、缩放的常用快捷键。

## 最小操作示例

```text
1. 保留默认立方体，确认左上角模式为 Object Mode。
2. 在 Outliner 中把 Cube 重命名为“主体”。
3. 依次按 G、R、S，移动、旋转并缩放“主体”；每次点击确认。
4. 按 Tab 进入 Edit Mode，再按 Tab 回到 Object Mode。
```

## 3～5 分钟练习

添加一个 UV Sphere，命名为“装饰球”，把它移动到立方体上方，并在 Outliner 中确认两个对象都能被单独选中。

## 参考答案

```text
Outliner 中至少包含：
- 主体（原 Cube）
- 装饰球（UV Sphere）

当前保持 Object Mode，两个对象位置不同且可分别选中。
```
