# 第 40 课：在新副本修订唯一图像路径

- 日期：2026-11-04
- 课程序号：第 40 课
- 知识点：单数据块路径修订与重开读回

## 用途或适用场景

让已确认的包外引用解析到准备好的包内正确图像。

## 核心概念

修订对象是已确认的一个未打包图像数据块。相对路径以当前活动blend所在目录为基准；Save Copy不切换活动文件，不能据此猜基准。

## 最小代码或操作示例

沿第38课接收实际解析和第39课唯一正确源计划，在Blender个人新包中操作；正确图像未具备则停止：

```text
1. File > Save As，用同目录未存在的新文件名保存副本，确认当前活动blend完整路径。
2. Image Editor选择计划中同一未打包图像数据块，保留原Path和Color Space。
3. 只在该图像Path填入上一课已核对的包内相对路径，重新确认实际解析目标；必要时用Reload读取该源。
4. 在原材质条件核对正确内容与Color Space，保存新blend，从完整路径重开再读回。
5. Report Missing Files与实际包内来源分列，原非目标数据块和旧包保持，记录实际影响范围。
```

不全局Make Paths Relative、不改变打包状态、不覆盖旧blend；没有包外引用记不适用。

## 3～5 分钟练习

Missing Files没有报告，能证明图像已位于新包内吗？

## 参考答案

不能，包外仍在线也可无缺失。须从活动blend解析Path并对照包内正确目标。
