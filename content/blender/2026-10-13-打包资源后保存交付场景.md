# 第 25 课：打包资源后保存交付场景

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：Pack Resources 在保存时写入

## 用途或适用场景

使上一课交付 .blend 中已有的可打包外部资源随文件保存。

## 核心概念

File > External Data > Pack Resources 先标记可打包资源，下一次保存才把数据写进 .blend。当前练习只含几何时可以没有外部资源；视频与 Movie Clips 等不支持此种打包，不能宣称命令包含所有文件。

## 最小代码或操作示例

```text
1. 打开 lesson-delivery-v01.blend，保持已有 Viewport 与 Render 细分值。
2. 执行 File > External Data > Pack Resources。
3. 执行 File > Save As…，保存为新的 lesson-delivery-packed-v01.blend。
4. 重新打开新文件，核对模型和 Render 值。
5. 若场景原本已有图像资源，检查其路径旁的“礼盒”图标；
   仅有几何时记录“没有外部资源可打包”，不要新增未学过的材质。
```

## 3～5 分钟练习

完成步骤后，写下“执行打包后是否再次保存”和“实际存在的外部资源种类”。原 lesson-delivery-v01.blend 保留。

## 参考答案

有一次明确的保存操作，新文件保留原细分状态。已有可打包资源才会显示打包标记；纯几何场景不需要出现图像图标。视频类依赖需另行交付，不会被 Pack Resources 自动包含。
