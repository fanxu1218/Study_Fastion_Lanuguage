# 第 2 课：精确变换与数值输入

- 日期：2026-09-02
- 课程序号：第 2 课
- 知识点：轴约束、数值输入与变换面板

## 用途

按确定距离移动对象并复现相同场景。

## 核心概念

- G/R/S 后可输入轴和数值，Enter 确认。
- 变换命令基于当前状态累加；侧栏字段用于检查结果，输入绝对目标值。

## 最小代码或操作示例

```text
1. 使用默认键位，新建练习场景，选中默认 Cube，保持 Object Mode。
2. 确认变换方向为 Global；按 G、X、2、Enter。
3. 按 R、Z、4、5、Enter，将立方体绕 Z 轴旋转 45°。
4. 按 S、0、.、5、Enter，统一缩放到原来的一半。
5. 按 N 打开侧栏，在 Item > Transform 查看数值。
```

## 3～5 分钟练习

从上述结果继续沿全局 Y 移动 -1，记录最终位置、Z 旋转和缩放。

## 参考答案

```text
按 G、Y、-、1、Enter。
Location=(2, -1, 0)；Rotation Z=45°；Scale=(0.5, 0.5, 0.5)。
再次执行 S 0.5 会变为 0.25，不是重新设为 0.5。
```
