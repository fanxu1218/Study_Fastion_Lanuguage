# 第 55 课：逐对象关联活动UV与画面

- 日期：2026-11-25
- 课程序号：第 55 课
- 知识点：共享mesh影响范围内分别保留渲染来源

## 用途或适用场景

整理第54课已有UV选择的保存重开结果。

## 核心概念

UV Maps普通列表选择与Active Render不同；未接Vector的默认纹理坐标需对应活动渲染UV，多个mesh使用者逐对象检查。

## 最小代码或操作示例

在Blender5.2 LTS打开第54课新blend：

```text
1. 选原目标对象，Shader Editor读回原Image Texture与未连接Vector。
2. Object Data Properties > UV Maps读回原UV名称及Active Render相机图标，不改变选择。
3. 逐第53课确定的mesh/材质使用者记录对象与数据身份、实际坐标来源及同视角画面。
4. 将每对象结果与各自独立期望比较；显式Vector连线对象按自身来源另列，不套用默认UV结论。
```
不改UV、节点、Image、Path或Color Space，不打包图像；无软件/素材记未执行。

## 3～5 分钟练习

两对象共享材质但mesh不同，可以只读一个对象的Active Render就代表另一个吗？

## 参考答案

不能；各自mesh可以有不同UV，分别读取并观察画面。

## 与上一课的联系

继承第53课共享范围与第54课已有Active Render选择；本课只逐对象关联坐标和画面。下一课可补查一个仍缺坐标身份的原对象。
