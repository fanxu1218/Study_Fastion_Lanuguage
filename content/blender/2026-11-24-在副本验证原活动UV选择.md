# 第 54 课：在副本验证原活动UV选择

- 日期：2026-11-24
- 课程序号：第 54 课
- 知识点：对象数据范围内的已有UV选择

## 用途或适用场景

执行第53课有正确UV依据且范围已确认的一项计划。

## 核心概念

Vector未接线时Image Texture取对象活动UV；同一mesh的其他使用对象也在数据影响范围内。只选择已有UV，不编辑坐标或共享材质。 UV Maps的Active Render控制默认渲染贴图，与普通列表选中分别记录。

## 最小代码或操作示例

仅在第53课计划确认为未连Vector、正确已有UV且mesh使用范围清楚时，在原Blender5.2 LTS个人包：
```text
1. File > Save As写入未占用的新blend，保留原图像/相对路径，选原有差异对象。
2. Shader Editor确认原Image与Vector仍未连接；Object Data Properties > UV Maps核对计划中的原/目标UV名称。
3. 仅把已确认目标设为UV Maps中的Active Render（相机图标）项；普通列表选中不代替渲染活动设置，保持UV内容、节点、Image、Path和Color Space。
4. 保存并重开新blend，读回实际Active Render项；以同视角/条件逐对象比较目标及原共享mesh/材质对象画面。
```
若使用显式Vector连线、UV缺失或共享范围未知，就不套用选择步骤；不新建/编辑UV、不拆分数据、不打包图像。

## 3～5 分钟练习

只选对对象而忽略它与另一对象共用mesh，能把影响范围写为单对象吗？

## 参考答案

不能；同mesh数据使用者可能受同一选择影响，必须按第53课实际范围分别观察。
