# 第 3 课：复制对象与独立变换

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：Object Mode、Shift-D 与复制后的移动

## 用途

快速摆出两个相同物体，并独立调整它们的位置。

## 核心概念

- 对象模式下 Shift-D 复制并立即进入移动；取消的是移动阶段，不会同时删除副本。
- 默认常规复制会复制网格，但某些数据（例如材质）仍可能共享，不能理解成所有内容都完全独立。

## 最小代码或操作示例

```text
1. 使用 Blender 默认键位和默认复制设置，在新练习场景选择 Cube，保持 Object Mode。
2. 按 Shift-D、X、3、Enter：复制后沿全局 X 移动 3。
3. 在 Outliner 中将原对象命名为 Box_A，新对象命名为 Box_B。
4. 只选 Box_B，按 G、Y、2、Enter。
5. 在 N > Item 中分别检查：Box_A 位置为 (0,0,0)，Box_B 为 (3,2,0)。
```

## 3～5 分钟练习

只选 Box_B，按 Shift-D 后按 Esc；观察 Outliner 数量，再按 G、Z、2、Enter，把新副本移开。

## 参考答案

```text
Esc 只取消复制后的移动，所以第三个对象仍在 Box_B 原位置。随后沿 Z 移动后，新副本位置为 (3,2,2)，Box_B 保持 (3,2,0)。
```
