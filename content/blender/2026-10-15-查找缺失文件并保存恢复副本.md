# 第 27 课：查找缺失文件并保存恢复副本

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：Find Missing Files 的目录搜索

## 用途或适用场景

在上一课报告确有缺失的情况下，恢复练习场景的真实文件路径。

## 核心概念

Find Missing Files 递归搜索选定目录及其子目录，恢复找到的引用；恢复结果采用绝对路径，不等于已打包或可跨机器使用。文件同名时还须确认内容属于原资产。

## 最小代码或操作示例

打开 lesson-delivery-packed-v01.blend 的练习副本，只处理原报告中的真实缺失项：

```text
1. 确认自己拥有缺失资产的原文件，并定位其所在目录。
2. File > External Data > Find Missing Files，选择该目录执行搜索。
3. 再运行 Report Missing Files，核对仍有警告的路径。
4. File > Save As 保存为新的 lesson-delivery-relinked-v01.blend。
5. 重新打开新文件，让资源重新加载，并复核模型和原 Render 值。
```

无缺失时记录不适用；没有原资产时继续待补齐，不删除现有源文件制造故障。

## 3～5 分钟练习

把每个缺失项的查找目录、恢复路径与复核结果写入原清单；分别标注“本机可找到”和“打包状态”。

## 参考答案

实际找到的条目恢复引用；未找到者继续报告缺失。绝对路径在本机有效，不能因此声称交付包独立完整；原 packed 文件保留。
