# 第 57 课：提取空白字符的诊断方法

- 日期：2026-11-26
- 课程序号：第 57 课
- 知识点：静态方法复用展示转换

## 用途或适用场景

收拢第56课消息两侧重复的Replace链。

## 核心概念

helper仅返回展示字符串，调用原比较的actual/expected不改变；提取后仍先比较原文，只在失败分支构造消息。

## 最小代码或操作示例

在原ContractCheck类内、Run方法外添加：
```csharp
private static string ShowWhitespace(string text)
{
    return text.Replace(' ', '·').Replace('\n', '↵');
}
```
Run失败分支只将原throw换为：
```csharp
throw new InvalidOperationException(
    $"原文保留契约不符：actual=[{ShowWhitespace(actual)}]；expected=[{ShowWhitespace(expected)}]");
```
原Ordinal判断、生产格式化器和输入不动。构建/运行原.NET10工程，重做第56课单个换行错期望后恢复，再回归原5项及契约。

## 3～5 分钟练习

应把ShowWhitespace放在原相等判断两侧吗？

## 参考答案

不应；它属于诊断。保持原Ordinal原文比较，消息才调用helper；换行字符仍写为反斜杠n字面量。
