# 第 48 课：恢复两种空格期望复查五项

- 日期：2026-11-13
- 课程序号：第 48 课
- 知识点：原文保留与固定数量分别验证

## 用途或适用场景

结束第47课leading-space诊断练习，恢复正确五行。

## 核心概念

普通字符串中的换行写作反斜杠n；行内前导和末尾空格仍是期望内容，不随换行转义消失。

## 最小代码或操作示例

沿第46课边界消息及第47课反例，在原具名元组表相应位置恢复：
```csharp
("leading-space", new List<string> { "1. C#", "  2. Unity" },
    "有效条目：2\n有效行：[1. C#]\n有效行：[  2. Unity]"),
("trailing-space", new List<string> { "1. Go " },
    "有效条目：1\n有效行：[1. Go ]"),
```
代码中的\n是两个源码字符；粘贴时保留反斜杠，不将普通字符串拆行。沿原.NET10 Program/Main运行，保留另外三行、foreach、CheckTextCase、循环后return cases.Count及Main固定5；不执行旧文件I/O。

## 3～5 分钟练习

五行总数正确，但leading-space的Unity前少两个空格，可以通过吗？

## 参考答案

不能，原逐行字符串比较应失败；只恢复独立正确期望，不Trim生产输出。
