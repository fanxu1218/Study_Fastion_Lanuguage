# 第 29 课：按换行拆分读回的课程清单

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：String.Split 的字符串分隔符数组

## 用途或适用场景

在上一课 savedText 上逐行检查，不再次读取或覆盖文件。

## 核心概念

使用 CRLF、LF、CR 三种完整换行作为分隔符，CRLF 排在单独 CR 前。None 保留空项，因此内部空行、末尾换行和空文本需要如实解释，不在本课删除它们。

## 最小代码或操作示例

沿用 System 和原 savedText，在读回步骤之后追加：

```csharp
string[] savedLines = savedText.Split(
    new[] { "\r\n", "\n", "\r" }, StringSplitOptions.None);
foreach (var line in savedLines)
{
    Console.WriteLine($"行：[{line}]");
}
```

方括号帮助看见空字符串；savedText 与磁盘文件都不改变。

## 3～5 分钟练习

在内存副本测试 `"1. C#\r\n\r\n2. Unity\n"` 和空字符串；保留原文件。

## 参考答案

第一例依次为“1. C#”、空、“2. Unity”、空，共四项；空文本得到一个空字符串项。None 不会自动去空行，也不同于某些语言的 splitlines。
