# 第 33 课：为空的有效清单显示明确提示

- 日期：2026-10-23
- 课程序号：第 33 课
- 知识点：由Count派生零条展示分支

## 用途或适用场景

为空的有效清单显示明确提示。

## 核心概念

读取成功但没有有效行，与文件读取失败不同。只从validLines.Count决定分支，不另存业务空状态。

## 最小代码或操作示例

用以下代码替换第32课数量输出与第31课有效行展示循环；validCount定义和前面的筛选保留：

```csharp
if (validCount == 0)
{
    Console.WriteLine("暂无有效学习条目");
}
else
{
    Console.WriteLine($"有效条目：{validCount}");
    foreach (var line in validLines)
    {
        Console.WriteLine($"有效行：[{line}]");
    }
}
```

保留原UTF-8读取、Split和IsNullOrWhiteSpace，不将I/O异常变成空清单。

## 3～5 分钟练习

用全空白文本与含两条有效行的内存副本走原筛选和展示。

## 参考答案

全空白只显示暂无有效学习条目；两条有效行显示数量2和原行，不丢首尾空格。
