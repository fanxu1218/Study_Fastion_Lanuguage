# 第 31 课：将有效清单原行收集到新列表

- 日期：2026-10-21
- 课程序号：第 31 课
- 知识点：List<string>.Add 保留原文本

## 用途或适用场景

让后续展示只遍历非空白记录，同时保留读回材料。

## 核心概念

IsNullOrWhiteSpace 用于判断，Add 保存原 line；不调用 Trim 改变有效行的首尾格式。派生列表只代表本次处理结果，不回写原数组或文件。

## 最小代码或操作示例

沿用 System，在原文件顶部加入 using System.Collections.Generic;，用下面代码替换第 30 课的展示循环：

```csharp
var validLines = new List<string>();
foreach (var line in savedLines)
{
    if (!string.IsNullOrWhiteSpace(line))
    {
        validLines.Add(line);
    }
}
foreach (var line in validLines)
{
    Console.WriteLine($"有效行：[{line}]");
}
```

savedText 的 UTF-8 读取与 savedLines 的 Split 保留。

## 3～5 分钟练习

内存副本使用 `"1. C#\r\n   \r\n  2. Unity\r\n"`，重新拆行并运行；再试空文本。

## 参考答案

有效列表含 1. C# 和前面仍有两个空格的 2. Unity；空文本有效列表为零项。savedLines 仍保留原空项，不用去空白的结果冒充原始记录。
