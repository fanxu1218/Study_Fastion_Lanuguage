# 第 17 课：位置模式忽略标题

- 日期：2026-09-22
- 课程序号：第 17 课
- 知识点：位置模式中的弃元 `_`

## 用途或适用场景

只按时长分类课程，不限制标题。

## 核心概念

位置模式中的 `_` 可匹配任意值而不绑定变量；第二个位置继续匹配 `Minutes`。

## 最小代码或操作示例

```csharp
var lesson = new Lesson("C#", 5);
var label = lesson switch {
    (_, 5) => "五分钟短课",
    _ => "其他课程"
};
Console.WriteLine(label);
public record Lesson(string Title, int Minutes);
```

## 3～5 分钟练习

把标题改为“Java”，保持时长为 5，再运行。

## 参考答案

仍输出“五分钟短课”，因为第一个位置被弃元忽略。

## 与上一课的联系
