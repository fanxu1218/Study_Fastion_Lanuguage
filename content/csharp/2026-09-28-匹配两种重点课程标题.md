# 第 20 课：匹配两种重点课程标题

- 日期：2026-09-28
- 课程序号：第 20 课
- 知识点：`or` 逻辑模式

## 用途或适用场景

把两种指定标题且时长足够的课程归为同一重点类别。

## 核心概念

属性模式里的 `Title: "C#" or "F#"` 允许任一标题匹配；`Minutes: >= 10` 仍必须满足。需 C# 9 或更新版本。

## 最小代码或操作示例

```csharp
var lesson = new Lesson("F#", 10);
var label = lesson switch {
    { Title: "C#" or "F#", Minutes: >= 10 } => "重点课程",
    _ => "普通课程"
};
Console.WriteLine(label); // 重点课程
public record Lesson(string Title, int Minutes);
```

## 3～5 分钟练习

分别把标题改为“Java”，或把时长改为 5，观察结果。

## 参考答案

两种改法都会输出“普通课程”：前者不满足标题，后者不满足时长。
