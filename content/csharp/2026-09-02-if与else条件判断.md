# 第 3 课：if与else条件判断

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：布尔表达式与分支顺序

## 用途

为控制台成绩程序增加分类行为。

## 核心概念

- if 接收 bool 条件，不能把数字直接当成真假值。
- 较严格的条件应放在较宽松条件之前。

## 最小代码或操作示例

```csharp
using System;
int score = 60;
if (score >= 60) { Console.WriteLine("及格"); }
else { Console.WriteLine("继续练习"); }
```

## 3～5 分钟练习

在 C# 顶级语句控制台项目中增加优秀分支，并测试 59、60、90。

## 参考答案

```csharp
if (score >= 90) { Console.WriteLine("优秀"); }
else if (score >= 60) { Console.WriteLine("及格"); }
else { Console.WriteLine("继续练习"); }
```
