- 日期：2026-09-16

- 知识点：record表达值对象

## 用途

用 record 表达按内容比较的课程数据。

## 核心概念

record 默认提供值相等语义，并可继续使用 init 属性。

## 最小代码或操作示例

```text
public record Lesson
{
    public required string Title { get; init; }
    public int Minutes { get; init; }
}
```

## 3～5 分钟练习

创建两个相同值并比较。

## 参考答案

两个属性值相同的 Lesson 使用 == 比较结果为 true。
