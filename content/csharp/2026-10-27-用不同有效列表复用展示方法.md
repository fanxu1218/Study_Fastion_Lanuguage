# 第 35 课：用不同有效列表复用展示方法

- 日期：2026-10-27
- 课程序号：第 35 课
- 知识点：每次调用从实参派生数量

## 用途或适用场景

用不同有效列表复用展示方法，让本次练习的结果可以按同一条件复查。

## 核心概念

ShowValidLines只读取本次传入的List<string>。调用方继续负责读文件和筛出有效行，不能把未筛选的空白行交给展示方法又期待自动过滤。

## 最小代码或操作示例

保留第34课ShowValidLines和Main的原读取流程。在Main末尾加入临时内存练习：

```csharp
var firstLines = new List<string> { "1. C#", "  2. Unity" };
var secondLines = new List<string> { "1. Go" };
ShowValidLines(firstLines);
ShowValidLines(secondLines);
ShowValidLines(new List<string>());
Console.WriteLine($"第一份仍有{firstLines.Count}条");
```

沿用System与System.Collections.Generic导入；不放入原读行循环，不写文件。

## 3～5 分钟练习

把第二份改为空列表，第一份数量和前导空格会变化吗？

## 参考答案

不会。原练习依次显示2条原行、1条原行、零条提示，第一份仍有2条。第二份改空只改变对应一次输出。
