## 用途或适用场景

返回文本与输出职责分离，用于继续完成本路线原示例的下一步。

## 核心概念

格式化方法只从传入列表构造字符串；Main决定何时输出。保留每行方括号和原始空格，空列表仍返回原提示，文件读取与筛选不搬入方法。

## 最小代码或操作示例

在Program中用以下方法替换ShowValidLines，沿原System与Collections.Generic导入：

```csharp
static string FormatValidLines(List<string> validLines)
{
    int validCount = validLines.Count;
    if (validCount == 0)
    {
        return "暂无有效学习条目";
    }
    string text = $"有效条目：{validCount}";
    foreach (var line in validLines)
    {
        text += $"\n有效行：[{line}]";
    }
    return text;
}
```

Main原ShowValidLines(validLines);改为Console.WriteLine(FormatValidLines(validLines));。第35课三次临时调用同步改名并包Console.WriteLine，或移除这些临时调用；不保留旧方法。

## 3～5 分钟练习

只执行string result = FormatValidLines(new List<string> { "1. Go" });，不WriteLine，会输出什么？

## 参考答案

方法本身没有终端输出；result包含数量、换行与原行方括号。空列表返回零条提示，传入列表不变。
