# 第 7 课：List动态集合

- 日期：2026-09-08
- 课程序号：第 7 课
- 知识点：List<T> 与 Add

## 用途

保存运行时会继续增加的练习记录。

## 核心概念

`List<int>` 约束元素为整数，`Add` 在尾部添加新值，`foreach` 顺序读取每项。

## 最小代码或操作示例

```csharp
var minutes = new List<int> { 10, 15 };
minutes.Add(20);
foreach (int value in minutes)
    Console.WriteLine(value);
```

## 3～5 分钟练习

删除第一项后输出列表。

## 参考答案

执行 `minutes.RemoveAt(0);`，会依次输出 15 和 20。
