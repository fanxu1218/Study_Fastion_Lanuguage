## 核心概念

数组初始化与遍历用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```csharp
int[] minutes = { 3, 5, 7 };\nforeach (int m in minutes) { total += m; }
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

总和为 15；满足 m >= 5 的元素有 2 个。
