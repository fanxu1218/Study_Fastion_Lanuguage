# 第 49 课：为五项格式化检查增加独立入口

- 日期：2026-11-16
- 课程序号：第 49 课
- 知识点：静态void方法包装原检查

## 用途或适用场景

把第48课恢复的五项检查集中到一次入口。

## 核心概念

入口调用CheckFormatValidLines并核对固定5；方法定义本身不执行检查。

## 最小代码或操作示例

在原Program类内、其他方法外新增：
```csharp
static void TestFormatValidLines()
{
    int checkedCount = CheckFormatValidLines();
    if (checkedCount != 5)
        throw new InvalidOperationException("完成数量不符：期望5，实际" + checkedCount);
    Console.WriteLine($"{checkedCount}项格式化检查完成");
}
```
Main中用一次TestFormatValidLines()替换原直接调用、数量检查和打印。保留原五行、foreach、CheckTextCase及循环后的return cases.Count；沿.NET10纯内存入口运行，不恢复旧文件I/O。

## 3～5 分钟练习

Main保留旧调用并增加新调用，是检查十个独立输入吗？

## 参考答案

不是，只是同五项执行两次；只保留一次新入口调用。
