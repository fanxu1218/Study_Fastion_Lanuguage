# 第 11 课：构造函数保证初始状态

- 日期：2026-09-14
- 课程序号：第 11 课
- 知识点：构造函数与只读属性

## 用途

创建对象时强制提供必要数据，避免半初始化状态。

## 核心概念

构造函数与类同名；只有 getter 的属性可在构造函数中赋值，之后保持只读。

## 最小代码或操作示例

```csharp
class Lesson
{
    public string Title { get; }
    public Lesson(string title)
    {
        Title = title;
    }
}
```

## 3～5 分钟练习

添加只读 `Minutes` 属性并通过构造函数初始化。

## 参考答案

在类中声明 `public int Minutes { get; }`，构造函数接收并赋值。
