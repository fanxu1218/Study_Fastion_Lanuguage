# 第 12 课：init属性与对象初始化器

- 日期：2026-09-15
- 课程序号：第 12 课
- 知识点：init 访问器与对象初始化器

## 用途

创建对象时清晰赋值，并阻止创建后随意修改。

## 核心概念

init 属性可在对象初始化阶段赋值，之后保持不可变。

## 最小代码或操作示例

```csharp
class Lesson
{
    public string Title { get; init; } = "";
    public int Minutes { get; init; }
}
var lesson = new Lesson { Title = "C#", Minutes = 5 };
```
