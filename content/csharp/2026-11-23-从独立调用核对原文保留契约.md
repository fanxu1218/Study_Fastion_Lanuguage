- 日期：2026-11-23

## 用途或适用场景

## 核心概念

独立调用方仍使用唯一LessonFormatter；固定期望按契约先写，不能从实际输出复制。新增演练不改变原五项的覆盖数量。

## 最小代码或操作示例

在原.NET10工程中、与Program相同namespace新建ContractCheck.cs（文件未存在时），沿原入口风格不写顶级语句：
```csharp
using System;
using System.Collections.Generic;

internal static class ContractCheck
{
    internal static void Run()
    {
        var lines = new List<string> { "1. C#", "  2. Go" };
        string expected = "有效条目：2\n有效行：[1. C#]\n有效行：[  2. Go]";
        string actual = LessonFormatter.FormatValidLines(lines);
        if (!string.Equals(actual, expected, StringComparison.Ordinal))
            throw new InvalidOperationException("原文保留契约不符");
        Console.WriteLine("原文保留契约检查完成");
    }
}
```
示例字符串中的换行应写成字面转义\n，不能在普通双引号中插入真实换行。在Main原FormatChecks.TestFormatValidLines()之后调用ContractCheck.Run()一次，构建/运行；分别为原5项和一项契约演练。

## 3～5 分钟练习

把expected中Go前两个空格删去，应该修改格式化函数来通过吗？

## 参考答案

不应；文档要求保留原文，独立期望删除空格应使本次演练失败。恢复期望后回归原五项及ContractCheck。
