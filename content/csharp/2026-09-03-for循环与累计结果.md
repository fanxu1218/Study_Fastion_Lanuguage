# 第 4 课：for循环与累计结果

- 日期：2026-09-03
- 课程序号：第 4 课
- 知识点：循环三部分与累加器

## 用途

避免为了多次练习重复写相同的计算语句。

## 核心概念

- for 的初始化只执行一次，条件在每轮前检查，更新在每轮后执行。
- 用循环外的变量保存结果，用循环内的计数器控制次数。

## 最小代码或操作示例

```csharp
using System;
int total = 0;
for (int i = 1; i <= 3; i++)
{
    total += i;
}
Console.WriteLine(total); // 6
```

## 3～5 分钟练习

在已有顶级语句控制台项目中改成累计 1 到 5；把 total 放进循环体会有什么问题？

## 参考答案

```text
将条件改为 i <= 5，结果为 15。若在循环体内声明 total，每轮重新初始化，且循环结束后不能在作用域外访问它。
```
