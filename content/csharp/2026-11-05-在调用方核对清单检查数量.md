# 第 42 课：在调用方核对清单检查数量

- 日期：2026-11-05
- 课程序号：第 42 课
- 知识点：独立固定数量与完成提示的先后

## 用途或适用场景

在打印完成之前发现检查入口返回了错误数量。

## 核心概念

数量检查使用固定5，与五项文本比较相互独立。任一失败必须阻止完成提示，不能把返回值直接当作全部覆盖证明。

## 最小代码或操作示例

沿第40课五项固定检查和第41课int返回值，在原Program.Main用以下代码替换原调用及提示：

```csharp
int checkedCount = CheckFormatValidLines();
if (checkedCount != 5)
{
    throw new InvalidOperationException(
        "完成数量不符：期望5，实际" + checkedCount);
}
Console.WriteLine(checkedCount + "项格式化检查完成");
```

沿原System、Collections.Generic及Program/Main。五个CheckTextCase、最后return 5和固定反斜杠n保持；仅运行纯内存副本，不执行文件I/O。

## 3～5 分钟练习

只把最后return 5临时改成return 4，应该发生什么？随后恢复。

## 参考答案

五项文本比较仍完成，但调用方抛InvalidOperationException，完成提示不执行。恢复5后重新运行，不删除内容比较。

## 与上一课的联系

继承第40课两行边缘空格和第41课返回完成数量；本课只加入调用方固定数量期望。下一课可把同一五份输入与期望整理为具名数据表。
