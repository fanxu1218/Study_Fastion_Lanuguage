# 第 50 课：把纯格式化移到静态类文件

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：同程序集静态方法的限定调用

## 用途或适用场景

让第49课五项检查使用一份独立纯实现。

## 核心概念

静态类通过类名访问方法，不需要new；本次仅改变定义归属，字符串和空格契约不变。

## 最小代码或操作示例

在原.NET10项目中新建LessonFormatter.cs，保持与Program相同namespace（原来无namespace则不添加）。将原FormatValidLines移到以下类中，方法体保持第36课语义：
```csharp
using System.Collections.Generic;

internal static class LessonFormatter
{
    internal static string FormatValidLines(List<string> validLines)
    {
        int validCount = validLines.Count;
        if (validCount == 0)
            return "暂无有效学习条目";
        string text = $"有效条目：{validCount}";
        foreach (var line in validLines)
            text += $"\n有效行：[{line}]";
        return text;
    }
}
```
删除Program旧定义，五行循环内的FormatValidLines(row.Lines)改为LessonFormatter.FormatValidLines(row.Lines)。保留原TestFormatValidLines与Main一次调用，在原项目构建/运行，应仍完成5项；不恢复旧文件I/O。

## 3～5 分钟练习

移动后仍用未限定的FormatValidLines调用，可以靠新增同名方法解决吗？

## 参考答案

不能复制实现；本课用LessonFormatter.FormatValidLines指向唯一纯方法。
