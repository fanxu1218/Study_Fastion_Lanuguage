# 第 58 课：独立核对诊断函数的原文与返回值

- 日期：2026-11-27
- 课程序号：第 58 课
- 知识点：展示函数输入不变的固定期望

## 用途或适用场景

验证第57课ShowWhitespace只生成展示文本。

## 核心概念

同一输入调用后分别检查原文和展示结果；仍由原格式化函数负责业务输出。新增演练不改变原五项计数。

## 最小代码或操作示例

在ContractCheck.Run开始处、原lines声明之前加入：
```csharp
string diagnosticInput = " C# \n";
string diagnosticText = ShowWhitespace(diagnosticInput);
if (!string.Equals(diagnosticInput, " C# \n", StringComparison.Ordinal))
    throw new InvalidOperationException("诊断不应改写输入");
if (!string.Equals(diagnosticText, "·C#·↵", StringComparison.Ordinal))
    throw new InvalidOperationException("空白诊断展示不符");
```
两处普通字符串的换行均写为反斜杠n；保留原ShowWhitespace、Ordinal格式化契约和唯一Main调用。构建/运行原.NET10工程。

## 3～5 分钟练习

在个人副本只把diagnosticText的独立期望临时改成"·C#·"，运行后恢复。应修改ShowWhitespace来通过吗？

## 参考答案

不应；原输入包含真实换行，展示结果应保留↵。临时错期望应失败，恢复后原五项、原文格式化契约及本次诊断演练分别核对。
