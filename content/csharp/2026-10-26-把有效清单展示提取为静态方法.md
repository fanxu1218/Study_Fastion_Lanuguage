# 第 34 课：把有效清单展示提取为静态方法

- 日期：2026-10-26
- 课程序号：第 34 课
- 知识点：列表参数与方法内部派生数量

## 用途或适用场景

列表参数与方法内部派生数量，继续使用本路线的原练习。

## 核心概念

展示方法只读取传入的有效列表，在内部读取Count。读文件、拆行和筛选仍属于调用方，不通过全局变量获取清单。

## 最小代码或操作示例

沿原Program类，在Main外新增；沿用System与System.Collections.Generic导入：

```csharp
static void ShowValidLines(List<string> validLines)
{
    int validCount = validLines.Count;
    if (validCount == 0)
    {
        Console.WriteLine("暂无有效学习条目");
    }
    else
    {
        Console.WriteLine($"有效条目：{validCount}");
        foreach (var line in validLines)
        {
            Console.WriteLine($"有效行：[{line}]");
        }
    }
}
```

Main里用ShowValidLines(validLines);替换第32课validCount定义与第33课展示分支，前面的读取和筛选保留。

## 3～5 分钟练习

在内存中分别传new List<string>()及new List<string> { "1. C#", "  2. Unity" }。

## 参考答案

第一份只显示零条提示；第二份显示数量2及带方括号的原行，前导空格保留。调用后列表不变，I/O异常仍由原调用方报告。
