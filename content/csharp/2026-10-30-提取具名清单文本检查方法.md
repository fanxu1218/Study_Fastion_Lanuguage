# 第 38 课：提取具名清单文本检查方法

- 日期：2026-10-30
- 课程序号：第 38 课
- 知识点：参数化比较与明确失败名称

## 用途或适用场景

提取具名清单文本检查方法，用于在已有示例中练习参数化比较与明确失败名称。

## 核心概念

辅助方法接收实际文本和独立期望，失败报告用例名；FormatValidLines仍只返回文本，不在测试辅助方法中读取文件。

## 最小代码或操作示例

在Program、Main外增加以下方法，用新CheckFormatValidLines替换第37课版本；第36课格式化实现不变：

```csharp
static void CheckTextCase(string name, string actual, string expected)
{
    if (actual != expected)
        throw new InvalidOperationException("清单检查失败：" + name);
}

static void CheckFormatValidLines()
{
    CheckTextCase("empty", FormatValidLines(new List<string>()),
        "暂无有效学习条目");
    CheckTextCase("single", FormatValidLines(new List<string> { "1. Go" }),
        "有效条目：1\n有效行：[1. Go]");
    CheckTextCase("leading-space", FormatValidLines(
        new List<string> { "1. C#", "  2. Unity" }),
        "有效条目：2\n有效行：[1. C#]\n有效行：[  2. Unity]");
}
```

保留System、Collections.Generic与Main一次显式调用。字符串中的反斜杠n沿原格式，不改为系统换行。

## 3～5 分钟练习

删去最后期望中Unity前的空格，应由哪个名称定位？

## 参考答案

应抛包含leading-space的InvalidOperationException；恢复后执行三项。不要修改生产格式去配合错误期望。
