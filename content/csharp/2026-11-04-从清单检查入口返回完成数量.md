# 第 41 课：从清单检查入口返回完成数量

- 日期：2026-11-04
- 课程序号：第 41 课
- 知识点：全部检查之后的整型返回值

## 用途或适用场景

把五项具名清单检查的完成数量交给调用方。

## 核心概念

非void方法通过return返回值；返回语句应放在全部检查之后。固定5只描述当前清单数量，不能替代五项字符串比较。

## 最小代码或操作示例

沿第39课trailing-space和第40课mixed-edge-spaces，在原Program类只作以下调整，五个CheckTextCase调用原样保留：

```text
把方法签名static void CheckFormatValidLines()
改成static int CheckFormatValidLines()。
在第五个CheckTextCase之后、该方法结束大括号之前增加return 5;。
```

Main把原一次检查调用替换为：

```csharp
int checkedCount = CheckFormatValidLines();
Console.WriteLine(checkedCount + "项格式化检查完成");
```

沿原System、Collections.Generic、Program/Main与固定反斜杠n，纯内存副本不运行文件I/O。

## 3～5 分钟练习

把return 5放到第一个检查之前，打印5能证明五项通过吗？

## 参考答案

不能，检查没有执行，后续还可能有不可达代码诊断。恢复到五项之后；任一比较失败就不会正常返回。

继承第39课末尾空格和第40课两行边缘空格，原五项都保留；本课只增加返回数量。下一课可在调用方加独立数量期望。
