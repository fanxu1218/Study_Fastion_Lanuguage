# 第 10 课：class封装课程对象

- 日期：2026-09-11
- 课程序号：第 10 课
- 知识点：类与实例

## 用途

把课程数据和相关行为封装在同一类型中。

## 核心概念

类定义共享结构，`new` 创建各自保存状态的实例。

## 最小代码或操作示例

```csharp
class Lesson {
    public string Title { get; }
    public Lesson(string title) { Title = title; }
}
var lesson = new Lesson("C#");
```

## 3～5 分钟练习

增加返回“课程：标题”的 `Label` 方法。

## 参考答案

方法返回 `"课程：" + Title`。
