# 第 2 课：变量与值类型

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：变量、常用值类型与字符串插值

## 用途

保存数量、价格和真假状态，并生成可读输出。

## 核心概念

- `int`、`double`、`bool` 是常见值类型，`string` 保存文本。
- `$"...{value}..."` 可插入变量或表达式。

## 最小代码示例

```csharp
string language = "C#";
int lesson = 2;
bool finished = false;
Console.WriteLine($"{language} 第 {lesson} 课，完成：{finished}");
```

## 3～5 分钟练习

声明单价和数量，用字符串插值输出总价。

## 参考答案

```csharp
double price = 12.5;
int count = 3;
Console.WriteLine($"总价：{price * count}");
```
