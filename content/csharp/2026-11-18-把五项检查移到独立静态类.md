# 第 51 课：把五项检查移到独立静态类

- 日期：2026-11-18
- 课程序号：第 51 课
- 知识点：检查入口与程序入口分离

## 用途或适用场景

继续使用第50课唯一LessonFormatter，集中保存原检查。

## 核心概念

独立检查类仍调用同一个纯方法；跨类入口需要程序集内可见，内部辅助方法仍可保持私有。

## 最小代码或操作示例

在原.NET10项目新建FormatChecks.cs，沿Program相同namespace（原来无则不添加）：
```text
1. 添加原检查所需using System与System.Collections.Generic。
2. 定义internal static class FormatChecks，把CheckTextCase、CheckFormatValidLines、TestFormatValidLines及它们使用的原五行数据完整移入。
3. 仅把被Main调用的入口声明改为internal static void TestFormatValidLines()；其他方法体和原静态辅助声明不变。
4. 删除Program已移动定义，Main仅调用FormatChecks.TestFormatValidLines()一次。
```
LessonFormatter.cs不变，检查继续调用LessonFormatter.FormatValidLines；在原项目构建/运行，应仍完成5项，不恢复旧文件I/O。

## 3～5 分钟练习

新类入口保留默认private，Program能跨类调用吗？

## 参考答案

不能；本课只将入口设为internal，程序集内调用可见，其余辅助方法不需扩大可见性。
