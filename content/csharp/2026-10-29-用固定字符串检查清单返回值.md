# 第 37 课：用固定字符串检查清单返回值

- 日期：2026-10-29
- 课程序号：第 37 课
- 知识点：字符串相等与显式检查失败

## 用途或适用场景

用固定字符串检查清单返回值，用于在已有示例中验证字符串相等与显式检查失败。

## 核心概念

字符串==按内容做区分大小写的序号比较。用独立期望直接比较FormatValidLines返回值，可以检查换行、方括号与空格；失败显式抛出异常。

## 最小代码或操作示例

沿第35课三份内存输入及第36课FormatValidLines，在Program、Main外增加：

```csharp
static void CheckFormatValidLines()
{
    if (FormatValidLines(new List<string>()) != "暂无有效学习条目")
        throw new InvalidOperationException("空列表检查失败");
    if (FormatValidLines(new List<string> { "1. Go" })
        != "有效条目：1\n有效行：[1. Go]")
        throw new InvalidOperationException("单行检查失败");
    if (FormatValidLines(new List<string> { "1. C#", "  2. Unity" })
        != "有效条目：2\n有效行：[1. C#]\n有效行：[  2. Unity]")
        throw new InvalidOperationException("双行空格检查失败");
}
```

沿原System与Collections.Generic导入。Main显式调用CheckFormatValidLines();，内存练习副本不执行原文件I/O。反斜杠n与生产方法一致，不用系统换行替换。

## 3～5 分钟练习

删掉最后期望中Unity前两个空格，正确实现应发生什么？

## 参考答案

应抛“双行空格检查失败”。恢复期望后检查通过；不应trim生产结果去迎合错误期望。
