# 第 1 课：程序入口与控制台输出

- 日期：2026-08-31
- 课程序号：第 1 课
- 知识点：`Main()` 与 `Console.WriteLine()`

## 用途

C# 控制台程序适合学习语法、编写工具和验证业务逻辑，程序从 `Main()` 方法开始执行。

## 核心概念

- `using System;` 引入常用系统类型。
- `Main()` 是传统控制台程序入口。
- `Console.WriteLine()` 输出一行文本。
- 类和方法用大括号组织代码块。

## 最小代码示例

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("C# 第 1 课");
    }
}
```
