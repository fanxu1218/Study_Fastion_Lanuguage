# 第 43 课：用具名元组整理五份格式化数据

- 日期：2026-11-06
- 课程序号：第 43 课
- 知识点：具名元组表行

## 用途或适用场景

给第42课五项检查准备同一份输入表。

## 核心概念

(string Name, List<string> Lines, string Expected)定义一行的三个字段，不需要新增自定义类。固定Expected保持独立；整理表本身尚未运行断言。

## 最小代码或操作示例

沿第41课五项检查和第42课固定数量，在CheckFormatValidLines开头、原五次调用之前新增局部表：
```csharp
var cases = new List<(string Name, List<string> Lines, string Expected)>
{
    ("empty", new List<string>(), "暂无有效学习条目"),
    ("single", new List<string> { "1. Go" }, "有效条目：1\n有效行：[1. Go]"),
    ("leading-space", new List<string> { "1. C#", "  2. Unity" },
        "有效条目：2\n有效行：[1. C#]\n有效行：[  2. Unity]"),
    ("trailing-space", new List<string> { "1. Go " }, "有效条目：1\n有效行：[1. Go ]"),
    ("mixed-edge-spaces", new List<string> { "  1. C#", "2. Unity  " },
        "有效条目：2\n有效行：[  1. C#]\n有效行：[2. Unity  ]"),
};
```
沿.NET10、Program/Main、System和Collections.Generic；本课保留五次原调用、return 5及调用方固定5，暂不遍历新表。

## 3～5 分钟练习

能把Expected替换为FormatValidLines(Lines)吗？

## 参考答案

不能，期望会跟着被测实现一起变化。保留五份固定文本，尤其方括号内空格。

## 与上一课的联系

继承第41课完成数量和第42课调用方检查；本课只引入具名元组并整理原五份数据。下一课可遍历cases复用CheckTextCase，替换重复调用。
