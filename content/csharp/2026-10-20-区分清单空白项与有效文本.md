# 第 30 课：区分清单空白项与有效文本

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：String.IsNullOrWhiteSpace

## 用途或适用场景

解释 savedLines 中空字符串、空格行与有内容行。

## 核心概念

IsNullOrWhiteSpace 同时识别 null、空字符串和仅含空白字符的字符串；Split 结果本身不产生 null，但空项仍应保留并如实判断。本课不筛掉记录。

## 最小代码或操作示例

接在第 29 课 savedLines 之后，替换原展示循环：

```csharp
foreach (var line in savedLines)
{
    if (string.IsNullOrWhiteSpace(line))
    {
        Console.WriteLine("空白项");
    }
    else
    {
        Console.WriteLine($"有效行：[{line}]");
    }
}
```

savedText、savedLines 和磁盘文件不改变。

## 3～5 分钟练习

在内存副本将 savedText 设为 "1. C#\r\n   \r\n2. Unity\r\n"，重新 Split；再试空文本。

## 参考答案

四项依次为有效、空白、有效、空白；空文本拆成一项空字符串，也判断为空白项。有效行首尾格式仍保留。
