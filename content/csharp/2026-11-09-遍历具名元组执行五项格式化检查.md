# 第 44 课：遍历具名元组执行五项格式化检查

- 日期：2026-11-09
- 课程序号：第 44 课
- 知识点：foreach读取具名字段

## 用途或适用场景

让第43课准备的五行cases真正驱动原检查。

## 核心概念

foreach依次读取一行，用Name定位、Lines计算实际、Expected作固定比较。return位于循环之后；调用方仍独立要求5，不能用当前表长当期望。

## 最小代码或操作示例

保留第43课CheckFormatValidLines内的五行cases。在表声明之后，用下列代码替换原五次手写CheckTextCase调用和return 5：
```csharp
foreach (var row in cases)
{
    CheckTextCase(row.Name, FormatValidLines(row.Lines), row.Expected);
}
return cases.Count;
```
沿原.NET10、System、Collections.Generic与Program/Main。保留第42课Main一次调用、固定5和完成提示；五份Expected尤其方括号内空格不变。仅运行纯内存检查。

## 3～5 分钟练习

把return放进foreach第一轮且仍返回cases.Count，有什么问题？

## 参考答案

后四行不会执行，却仍可能返回5。return须在循环结束后；数量检查不能替代逐行内容比较。

## 与上一课的联系

继承第42课独立数量门槛和第43课同一五行具名表；本课只用foreach替换重复检查。下一课可临时改错一行期望，观察Name是否定位到该行。
