# 第 23 课：处理空筛选结果

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：`Count == 0`

## 用途或适用场景

物化后在展示前明确区分无结果。

## 核心概念

本课只增加“`Count == 0`”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```csharp
Console.WriteLine(featured.Count == 0 ? "暂无课程" : $"共 {featured.Count} 节");
```

## 3～5 分钟练习

让筛选条件分别命中零条和两条。

## 参考答案

输出分别为“暂无课程”和“共 2 节”。
