# 第 3 课：追加片段到主故事线

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：浏览器选择、Append 与时间线顺序

## 用途

把已经导入的素材按顺序放进一个可播放项目。

## 核心概念

- 事件浏览器保存源片段，项目时间线保存编排关系；追加不会移动或删除源媒体。
- Append 把片段加入故事线末尾；本课使用空项目的主故事线，避免和连接剪辑混淆。

## 最小代码或操作示例

```text
1. 在已有练习资源库中新建空项目“追加练习”，打开其时间线。
2. 在浏览器中选中一个视频片段，选择 Edit > Append to Storyline（默认快捷键 E）。
3. 核对片段出现在主故事线。
4. 在浏览器中选中第二段视频，再次按 E。
5. 将播放头移回开头，播放并观察两个片段前后衔接。
6. 如果选择的是片段范围，只会追加所选范围；练习时先确认选择内容。
```

## 3～5 分钟练习

即使播放头放在第一段中间，再次从浏览器追加第三个片段，它应该落在哪里？

## 参考答案

```text
在本课没有选中其他故事线的前提下，第三段追加到主故事线末尾，不插入播放头所在位置。浏览器中的源片段仍保留。
```
