# Final Cut Pro 学习路线

从素材组织出发，逐步学习磁性时间线、音频、字幕、调色与交付。每个工作日更新一节中文短课。

## 课程目录

1. [第 1 课：资源库、事件与项目](./2026-09-01-资源库事件与项目.md) — 建立 Final Cut Pro 的基础工作层级。
2. [2026-09-02：导入媒体与界面区域](./2026-09-02-导入媒体与界面区域.md)——把练习素材加入已有事件，并确认导入成功。
3. [2026-09-03：追加片段到主故事线](./2026-09-03-追加片段到主故事线.md)——把已经导入的素材按顺序放进一个可播放项目。
4. [2026-09-04：修剪片段尾部与波纹移动](./2026-09-04-修剪片段尾部与波纹移动.md)——去掉第一段视频结尾多余的一秒。
5. [2026-09-07：刀片切分片段](./2026-09-07-刀片切分片段.md)——把一个片段在播放头位置分成两段。
6. [2026-09-08：连接片段添加补充画面](./2026-09-08-连接片段添加补充画面.md)——把补充画面同步附着到主故事线。
7. [2026-09-09：Cross Dissolve转场](./2026-09-09-CrossDissolve转场.md)——在相邻镜头间加入平滑交叉叠化。
8. [2026-09-10：精确设置转场时长](./2026-09-10-精确设置转场时长.md)——用数值统一控制交叉叠化的持续时间。
9. [2026-09-11：添加Basic Title标题](./2026-09-11-添加Basic Title标题.md)——给画面添加可编辑的基础标题。
