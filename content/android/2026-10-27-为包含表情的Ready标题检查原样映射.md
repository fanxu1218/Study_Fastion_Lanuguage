# 第 34 课：为包含表情的Ready标题检查原样映射

- 日期：2026-10-27
- 课程序号：第 34 课
- 知识点：纯状态映射与显示能力的边界

## 用途或适用场景

为包含表情的Ready标题检查原样映射，让本次练习的结果可以按同一条件复查。

## 核心概念

lessonText应原样返回Ready.title，包括表情和中文。字符串断言只验证数据映射，不能证明设备字体能显示该字符或读屏如何朗读。

## 最小代码或操作示例

保留第32课空标题和第33课换行测试，在原LessonTextTest内新增，沿org.junit.Test与org.junit.Assert.assertEquals：

```kotlin
@Test fun emojiReadyTitleIsPreserved() {
    val title = "Android 😄 练习"
    assertEquals("Ready标题中的表情必须原样返回", title,
        lessonText(LessonUiState.Ready(title)))
}
```

将源文件按工程原UTF-8编码保存。在app/src/test定向运行该方法，再运行整个原测试类；不改生产函数、Gradle或基础状态期望。

## 3～5 分钟练习

测试通过后，能把真机表情显示和TalkBack朗读也填为通过吗？

## 参考答案

不能。这里只证明Ready字符串被完整传递；字体、布局和朗读都还未验证。空白、换行等原测试仍保留。
