# 第 28 课：用不同标题验证Ready文案不写死

- 日期：2026-10-16
- 课程序号：第 28 课
- 知识点：纯映射函数的差异输入测试

## 用途或适用场景

证明 lessonText 真正读取 Ready.title，而不是始终返回第一条课程名。

## 核心概念

继续使用宿主 JVM 的同一测试类；不同 Ready 输入应得到各自原文。它只证明映射，不代表仓库查询、生命周期或屏幕显示通过。

## 最小代码或操作示例

在第 27 课 LessonTextTest 内追加，保留原 import 与三项测试：

```kotlin
@Test fun readyTextUsesProvidedTitle() {
    assertEquals("Kotlin 流", lessonText(LessonUiState.Ready("Kotlin 流")))
    assertEquals("Rust 借用", lessonText(LessonUiState.Ready("Rust 借用")))
}
```

继续用测试方法旁运行按钮执行该类，源 lessonText 不变。

## 3～5 分钟练习

先运行，再只在练习副本中把源函数 Ready 分支临时改成固定“Python 入门”；检查哪些测试失败后恢复。

## 参考答案

原函数通过；写死标题时新增测试失败，即使旧 readyText 用例仍可能通过。恢复后所有映射测试应再次通过。
