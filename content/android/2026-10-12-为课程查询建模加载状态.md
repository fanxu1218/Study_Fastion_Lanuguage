# 第 24 课：为课程查询建模加载状态

- 日期：2026-10-12
- 课程序号：第 24 课
- 知识点：加载中的 UI 状态

## 用途或适用场景

查询仓库期间显示明确状态，避免把空结果误当加载中。

## 核心概念

本课只沿用上一课的已有数据与命名，并增加上述单一知识点。

## 最小代码或操作示例

```kotlin
sealed interface LessonUiState {
  data object Loading : LessonUiState
  data class Ready(val title: String) : LessonUiState
  data object Missing : LessonUiState
}
```

## 3～5 分钟练习

按示例完成一次最小操作，并核对结果。

## 参考答案

查询前为 `Loading`，命中为 `Ready`，空结果为 `Missing`。

## 与上一课的联系

第 23 课处理仓库空结果；本课只把加载阶段独立建模；下一课可在界面穷尽渲染三种状态。

时效校验：2026-10-12（Android 当前 UI 层状态持有者指南；推荐以状态类表达界面状态，未使用废弃 API。）
