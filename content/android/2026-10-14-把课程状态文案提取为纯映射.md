# 第 26 课：把课程状态文案提取为纯映射

- 日期：2026-10-14
- 课程序号：第 26 课
- 知识点：不访问 View 的穷尽状态映射函数

## 用途或适用场景

将上一课的三个渲染分支集中为一个可以单独检查的函数。

## 核心概念

lessonText 只接收 LessonUiState 并返回文字，不查询仓库、不保存第二份状态。when 表达式仍穷尽三种类型，界面继续从原生命周期收集块调用。

## 最小代码或操作示例

将函数放在 LessonUiState 声明同包的文件中、类外；状态类型沿用第 24 课：

```kotlin
fun lessonText(state: LessonUiState): String = when (state) {
    LessonUiState.Loading -> "正在加载课程"
    is LessonUiState.Ready -> state.title
    LessonUiState.Missing -> "未找到课程"
}
```

第 25 课 collect 块仅把原 when 赋值替换为：

```kotlin
binding.titleText.text = lessonText(state)
```

保留 repeatOnLifecycle 和唯一一次订阅，不把 uiState 复制到 Activity 字段。

## 3～5 分钟练习

分别检查 Loading、Ready("Python 入门")、Missing 的返回文本；再用原 python/未知 ID 路径运行页面。

## 参考答案

映射结果依次为“正在加载课程”“Python 入门”“未找到课程”；页面最终显示与上一课一致。同步仓库返回很快，仍不保证肉眼看到 Loading。

## 与上一课的联系

继承第 24 课互斥 uiState、第 25 课完整 when 和 binding.titleText；本课只提取原文案映射。下一课可为这三个返回值编写本地单元测试。
