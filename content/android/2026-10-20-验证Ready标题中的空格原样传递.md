# 第 29 课：验证Ready标题中的空格原样传递

- 日期：2026-10-20
- 课程序号：第 29 课
- 知识点：纯映射的字符串边界断言

## 用途或适用场景

明确 lessonText 不承担标题规范化职责。

## 核心概念

Ready 文案映射返回 title 原文，标题是否合法由数据入口负责。测试覆盖首尾空格与空字符串，不因展示测试额外 trim 或填默认课程名。

## 最小代码或操作示例

在原 LessonTextTest 内追加，保留第 27～28 课用例和 JUnit4 导入：

```kotlin
@Test fun readyTextPreservesWhitespace() {
    assertEquals("  Kotlin 流  ",
        lessonText(LessonUiState.Ready("  Kotlin 流  ")))
    assertEquals("", lessonText(LessonUiState.Ready("")))
}
```

仍从 app/src/test 运行该类；不改 lessonText、仓库或原 StateFlow 收集代码。

## 3～5 分钟练习

再加入一个仅含三个空格的标题断言，确认函数返回什么。

## 参考答案

期望恰好三个空格。此处只界定映射行为，不代表业务允许空标题，也不把空字符串显示称为完整 UI 验收。

## 与上一课的联系

继承第 27 课 JUnit4 和第 28 课 Ready 差异输入；本课只增加空格/空串边界。下一课可把这些固定输入组织为一个表格循环。
