# 第 3 课：Button与点击监听

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：布局 ID、findViewById 与 setOnClickListener

## 用途

让页面中的按钮响应一次点击并修改提示文字。

## 核心概念

- 先 setContentView，再查找该布局中的控件；ID 用来定位控件，不是显示文案。
- 点击监听在事件发生时执行。本课仅改变界面提示，不代表执行了真实保存或网络业务。

## 最小代码或操作示例

```xml
<!-- 替换 res/layout/activity_main.xml -->
<Button xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/start_button"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="@string/start_lesson" />
```

在 res/values/strings.xml 的 resources 中添加：
```xml
<string name="start_lesson">开始练习</string>
<string name="lesson_started">已开始练习</string>
```

在原 MainActivity 顶部添加 import android.widget.Button，并在 setContentView 后添加：
```kotlin
val button = findViewById<Button>(R.id.start_button)
button.setOnClickListener {
    button.setText(R.string.lesson_started)
}
```
