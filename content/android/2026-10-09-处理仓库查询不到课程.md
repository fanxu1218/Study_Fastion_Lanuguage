# 第 23 课：处理仓库查询不到课程

- 日期：2026-10-09
- 课程序号：第 23 课
- 知识点：空结果状态

## 用途或适用场景

课程 ID 有效但仓库没有对应记录时显示明确状态。

## 核心概念

只把仓库查询结果映射为显示文案，不把课程对象复制进 `SavedStateHandle`。

## 最小代码或操作示例

```kotlin
val message = lesson.map { item -> item?.title ?: "未找到课程" }
```

## 3～5 分钟练习

用不存在的 `lessonId` 触发一次查询。

## 参考答案

仓库仍是课程事实源，界面只收到“未找到课程”文案。

## 与上一课的联系

第 22 课根据课程 ID 加载仓库数据；本课只处理空结果；下一课可为加载中状态建模。
