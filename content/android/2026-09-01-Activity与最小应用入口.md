# 第 1 课：Activity 与最小应用入口

- 日期：2026-09-01
- 课程序号：第 1 课
- 知识点：`Activity`、`onCreate` 与应用界面入口

## 用途

`Activity` 承载用户可以看到和操作的一个 Android 界面。理解它的创建入口，是学习布局、状态和导航的第一步。

## 核心概念

- `Activity` 是 Android 的核心应用组件之一。
- 系统创建 Activity 时会调用 `onCreate`。
- `super.onCreate` 让父类完成必要的初始化。
- `setContentView` 把布局资源设置为当前界面。

## 最小代码示例

```kotlin
import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}
```
