# 第 32 课：给独立标题边界测试加定位消息

- 日期：2026-10-23
- 课程序号：第 32 课
- 知识点：JUnit断言消息与输入契约

## 用途或适用场景

给独立标题边界测试加定位消息。

## 核心概念

JUnit4的三参数assertEquals按message、expected、actual传入。消息帮助定位空串与空格边界，不改变Ready数据或lessonText映射。

## 最小代码或操作示例

只替换第31课两个方法，保留基础状态测试和readyTextCases表：

```kotlin
@Test fun emptyReadyTitleIsPreserved() {
    assertEquals("Ready空字符串必须原样返回", "",
        lessonText(LessonUiState.Ready("")))
}

@Test fun spacesOnlyReadyTitleIsPreserved() {
    assertEquals("Ready三个空格必须原样返回", "   ",
        lessonText(LessonUiState.Ready("   ")))
}
```

沿原org.junit.Test与org.junit.Assert.assertEquals导入，在app/src/test运行；不改Gradle或生产函数。

## 3～5 分钟练习

在个人副本把第二项期望暂改为空串，查看失败消息后恢复。

## 参考答案

失败报告应包含三个空格这一用例说明与期望/实际；恢复原期望后再运行。不能通过trim生产结果来让错误期望通过。
