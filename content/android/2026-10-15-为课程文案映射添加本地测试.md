# 第 27 课：为课程文案映射添加本地测试

- 日期：2026-10-15
- 课程序号：第 27 课
- 知识点：JUnit 4 的纯函数测试

## 用途或适用场景

在宿主 JVM 验证上一课三个状态的文案，无需启动 Activity。

## 核心概念

lessonText 不访问 Android 对象，适合放在 src/test 中执行。JUnit 的 @Test 标记测试入口，assertEquals 比较期望值；本课只测试映射，不宣称生命周期或界面通过。

## 最小代码或操作示例

确认 app 模块已有 JUnit 4 测试依赖；没有时在其 build.gradle.kts 的 dependencies 内添加 `testImplementation("junit:junit:4.13.2")` 并同步。已有同一依赖时不重复添加。

在 app/src/test/java/原应用包路径/LessonTextTest.kt 建立文件，package 与 lessonText 相同：

```kotlin
import org.junit.Assert.assertEquals
import org.junit.Test

class LessonTextTest {
    @Test fun loadingText() {
        assertEquals("正在加载课程", lessonText(LessonUiState.Loading))
    }
    @Test fun readyText() {
        assertEquals("Python 入门", lessonText(LessonUiState.Ready("Python 入门")))
    }
    @Test fun missingText() {
        assertEquals("未找到课程", lessonText(LessonUiState.Missing))
    }
}
```

用测试方法旁运行按钮执行该类；保留第 26 课源函数和第 25 课原订阅。

## 3～5 分钟练习

运行三项测试；在练习副本把 Missing 的期望改为“没有课程”，观察失败后恢复。

## 参考答案

原三项通过，错误期望使 missingText 失败。测试不需要模拟 TextView，也不验证进程恢复、旋转和 Loading 是否肉眼可见。
