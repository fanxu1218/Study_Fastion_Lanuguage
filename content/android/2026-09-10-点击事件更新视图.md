# 第 8 课：点击事件更新视图

- 日期：2026-09-10
- 课程序号：第 8 课
- 知识点：setOnClickListener 与 ViewBinding

## 用途

响应按钮点击并更新文本。

## 核心概念

通过 Binding 取得类型安全引用，在监听器中修改展示属性。

## 最小代码或操作示例

```kotlin
binding.nextButton.setOnClickListener {
    binding.titleText.text = "下一课"
}
```

## 3～5 分钟练习

让按钮在“开始”和“暂停”间切换。

## 参考答案

保存布尔状态，点击时取反并据此设置文本。
