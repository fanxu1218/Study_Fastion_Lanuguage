# 第 25 课：在界面穷尽渲染课程查询状态

- 日期：2026-10-13
- 课程序号：第 25 课
- 知识点：sealed 状态的 when 表达式

## 用途或适用场景

把上一课真实 uiState 流中的三种互斥结果显示到既有 TextView。

## 核心概念

when 必须处理 Loading、Ready、Missing 三个分支；不加吞掉新状态的 else。Activity 只渲染，不复制课程对象或再次查仓库；原生命周期收集方式继续有效。

## 最小代码或操作示例

```kotlin
// import 放文件顶部；其余代码放 onCreate 中 binding 初始化之后。
// 替换原课程状态收集块，不重复订阅；沿用既有 viewModel 获取方式。
// uiState/类型来自第 24 课；binding.titleText 来自第 8 课布局。
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.lifecycleScope
import androidx.lifecycle.repeatOnLifecycle
import kotlinx.coroutines.launch
import kotlinx.coroutines.flow.collect

lifecycleScope.launch {
    repeatOnLifecycle(Lifecycle.State.STARTED) {
        viewModel.uiState.collect { state ->
            binding.titleText.text = when (state) {
                LessonUiState.Loading -> "正在加载课程"
                is LessonUiState.Ready -> state.title
                LessonUiState.Missing -> "未找到课程"
            }
        }
    }
}
```

## 3～5 分钟练习

分别以 python 和不存在的 ID 启动练习，检查命中、缺失文案；暂时删除 Missing 分支，观察编辑器提示后恢复。

## 参考答案

最终分别显示“Python 入门”和“未找到课程”；缺少分支会使 when 表达式不穷尽。Loading 流值存在，但课堂同步仓库返回很快，不保证肉眼可见；真机与旋转验证未由文档核对替代。

## 与上一课的联系

继承第 24 课 uiState、LessonUiState 三种状态，以及第 13 课 repeatOnLifecycle、第 8 课 binding.titleText；本课只增加完整 when 渲染；下一课可为渲染文案提取可测试的纯映射。

时效校验：2026-10-13（Android 当前 Views UI 指南仍推荐 repeatOnLifecycle 收集；该 API 最低 Lifecycle 2.4.0，既有 getStateFlow 需 2.5.0；data object 用 Kotlin 1.9+；TextView 当前 setText(CharSequence) 有效；未使用预览的 when 简写）。
