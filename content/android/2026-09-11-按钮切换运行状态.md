# 第 9 课：按钮切换运行状态

- 日期：2026-09-11
- 课程序号：第 9 课
- 知识点：按钮状态切换

## 用途

用一次点击在“开始”和“暂停”之间切换。

## 核心概念

交互状态应由一个布尔值保存，再由该值更新按钮文字。

## 最小代码或操作示例

```kotlin
var running = false
binding.toggleButton.setOnClickListener {
    running = !running
    binding.toggleButton.text = if (running) "暂停" else "开始"
}
```

## 3～5 分钟练习

把初始状态改为运行中并检查首次点击。

## 参考答案

初始设为 `true`，首次点击后应显示“开始”。
