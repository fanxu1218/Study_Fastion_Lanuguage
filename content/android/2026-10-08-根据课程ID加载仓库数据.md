# 第 22 课：根据课程ID加载仓库数据

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：根据 `lessonId` 查询仓库

## 用途或适用场景

详情页只保存轻量 ID，恢复后由仓库重新加载课程。

## 核心概念

本课只增加“根据 `lessonId` 查询仓库”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```kotlin
val lesson = lessonId.flatMapLatest(repository::observeLesson)
```

## 3～5 分钟练习

把默认 ID 改为 `rust`，确认仓库查询随流更新。

## 参考答案

`lessonId` 变化时重新订阅对应课程，不把课程对象写入 `SavedStateHandle`。

## 与上一课的联系

第 21 课用 `getStateFlow` 暴露课程 ID；本课只新增仓库查询；下一课可处理查询不到课程的状态。
