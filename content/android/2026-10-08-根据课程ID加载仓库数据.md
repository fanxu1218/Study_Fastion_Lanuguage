# 第 22 课：根据课程ID加载仓库数据

- 日期：2026-10-08
- 课程序号：第 22 课
- 知识点：lessonId 驱动仓库 Flow

## 用途或适用场景

恢复轻量课程 ID 后，从数据层重新获取标题。

## 核心概念

本课补全最小 Lesson 与内存演示仓库，避免引用未定义的 repository/observeLesson。仓库是标题事实源，SavedStateHandle 只保存 ID。此仓库模拟已存在数据，不代表网络、数据库或生产实现。本课承接第 21 课“课程 ID 查询”练习：原 running/toggle 运行按钮练习另存副本，当前 Activity 移除旧 running 收集和 toggle 监听；既有 viewModel 获取方式继续使用。第 25 课再接入 uiState 收集，避免 Activity 调用已从本练习 ViewModel 移除的方法。flatMapLatest 在 ID 改变时取消旧查询订阅。

## 最小代码或操作示例

```kotlin
import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel
import kotlinx.coroutines.ExperimentalCoroutinesApi
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flatMapLatest
import kotlinx.coroutines.flow.flowOf

data class Lesson(val title: String)
class LessonRepository {
    fun observeLesson(id: String): Flow<Lesson?> = flowOf(
        when (id) {
            "python" -> Lesson("Python 入门")
            "rust" -> Lesson("Rust 入门")
            else -> null
        }
    )
}
@OptIn(ExperimentalCoroutinesApi::class)
class LessonViewModel(savedStateHandle: SavedStateHandle) : ViewModel() {
    private val repository = LessonRepository() // 仅课堂内存演示
    val lessonId = savedStateHandle.getStateFlow("lessonId", "python")
    val lesson: Flow<Lesson?> = lessonId.flatMapLatest(repository::observeLesson)
}
```

## 3～5 分钟练习

把默认 ID 从 python 改为 rust，以第 13 课已学的生命周期收集方式观察 lesson。

## 参考答案

流结果为 Lesson("Rust 入门")；SavedStateHandle 中依旧只有字符串 ID。未知 ID 返回 null，下节课再映射其文案。

## 与上一课的联系

继承第 21 课的 lessonId 键、python 默认 ID 与 getStateFlow；本课只接入已在代码中定义的仓库查询 Flow；下一课把 null 映射为“未找到课程”。
