# 第 31 课：将空标题边界拆成独立测试

- 日期：2026-10-22
- 课程序号：第 31 课
- 知识点：具名测试方法独立报告边界结果

## 用途或适用场景

避免空串失败使空格输入也失去执行机会。

## 核心概念

一个 @Test 方法对应一项报告；将关键边界分开，可以独立运行和看到结果。原 lessonText 的原样传递语义不变。

## 最小代码或操作示例

在第 30 课 readyTextCases 表中移除 "" to "" 和 "   " to "   " 两行，保留另外三行；在同一 LessonTextTest 内追加：

```kotlin
@Test fun emptyReadyTitleIsPreserved() {
    assertEquals("", lessonText(LessonUiState.Ready("")))
}

@Test fun spacesOnlyReadyTitleIsPreserved() {
    assertEquals("   ", lessonText(LessonUiState.Ready("   ")))
}
```

保留原 JUnit4 导入及第 27 课基础状态测试，在 app/src/test 中运行；不增加参数化框架或修改 Gradle 配置。

## 3～5 分钟练习

只把空串方法期望改成占位文字，分别运行两个具名方法后恢复。

## 参考答案

空串方法失败，空格方法仍可独立运行并通过；恢复后各自保持原字符串。独立报告不代表真实 UI、生命周期或设备验证。
