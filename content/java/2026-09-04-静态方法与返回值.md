# 第 5 课：静态方法与返回值

- 日期：2026-09-04
- 课程序号：第 5 课
- 知识点：参数、局部变量与 return

## 用途

复用上一课的求和逻辑，避免复制循环。

## 核心概念

参数接收调用时的输入；局部 total 每次调用重新初始化；return 把结果交给调用方。本课仅处理小的非负整数。

## 最小代码或操作示例

```java
public class Main {
    static int sumTo(int limit) {
        int total = 0;
        for (int n = 1; n <= limit; n++) total += n;
        return total;
    }
    public static void main(String[] args) {
        System.out.println(sumTo(5));
    }
}
```

## 3～5 分钟练习

分别传入 3、0、5；判断先调用 3 是否会影响下一次调用 5。

## 参考答案

结果依次为 6、0、15。各次调用的局部累计互不影响，0 时循环不执行。
