# 第 20 课：遍历 Map 中的课程键

- 日期：2026-09-28
- 课程序号：第 20 课
- 知识点：`Map.keySet()`

## 用途或适用场景

检查替换课程键后，当前 Map 实际保存了哪些课程。

## 核心概念

`keySet()` 提供当前键的集合视图；`HashMap` 不保证遍历顺序，本例只有一条记录。

## 最小代码或操作示例

```java
public class Main {
  record Lesson(String title, int minutes) {}
  public static void main(String[] args) {
    var notes = new java.util.HashMap<Lesson, String>();
    var oldKey = new Lesson("Java", 5);
    notes.put(oldKey, "已读");
    var note = notes.remove(oldKey);
    var newKey = new Lesson(oldKey.title(), 10);
    notes.put(newKey, note);
    System.out.println(notes.size()); // 1
    for (var key : notes.keySet()) System.out.println(key.title()); // Java
  }
}
```

## 3～5 分钟练习

在遍历前加入 `notes.put(new Lesson("Kotlin", 8), "待读")`，观察输出。

## 参考答案

`size()` 变成 2；遍历会显示 `Java` 与 `Kotlin`，但不能依赖两者顺序。
