# 第 1 课：类、main 与标准输出

- 日期：2026-08-31
- 课程序号：第 1 课
- 知识点：类、`main()` 与 `System.out.println()`

## 用途

Java 代码组织在类中，可执行程序从固定签名的 `main()` 方法开始。

## 核心概念

- `class` 定义类，公开类名应与文件名一致。
- `public static void main(String[] args)` 是常用程序入口。
- `System.out.println()` 输出一行文本并换行。
- Java 语句通常以分号结束。

## 最小代码示例

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Java 第 1 课");
    }
}
```
