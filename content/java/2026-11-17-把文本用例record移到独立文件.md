# 第 50 课：把文本用例record移到独立文件

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：同包顶层record的跨文件访问

## 用途或适用场景

让第49课入口继续复用原TextCase数据模型。

## 核心概念

顶层record与原嵌套record具有不同声明位置；同包调用可沿原简单名称，但原嵌套定义必须移除。

## 最小代码或操作示例

在原Java17个人副本、Main.java同目录新建TextCase.java，将原Main类内的record完整移出，文件内容为：
```java
record TextCase(String name, String expectedText,
                String actualText, boolean expectedMatch) {}
```
两文件保持原相同package；原来无package则两者都不添加。删除Main内部那份record，其余List.of、增强for、两行数量检查、testCaseSensitivity与另外四项不变。
```sh
javac --release 17 Main.java TextCase.java
java Main
```
预期仍输出2项大小写检查完成；不执行旧文件I/O，不添加public或预览特性。

## 3～5 分钟练习

保留Main内部同名record又新增顶层record，能说明原调用已使用新文件吗？

## 参考答案

不能；Main中的简单名称仍可能解析到内部类型，应移除已移动的定义。
