# 第 46 课：把两份比较记录放入固定列表

- 日期：2026-11-11
- 课程序号：第 46 课
- 知识点：List.of准备具名记录集合

## 用途或适用场景

为第45课两份TextCase安排共同的数据容器。

## 核心概念

List.of按实参顺序创建不可修改列表，不接受null；列表准备和逐行执行检查分开。本课保留原两次访问器调用。

## 最小代码或操作示例

沿第44课TextCase声明和第45课访问器，在checkCaseSensitivity两份记录声明之后、原两次checkTextCase之前添加：
```java
java.util.List<TextCase> caseRows = java.util.List.of(
    differentCase, sameCase);
if (caseRows.size() != 2) {
    throw new AssertionError("大小写数据数量不符：" + caseRows.size());
}
```
保留原两次调用、return 2、调用方固定2及另外四项；javac --release 17 Main.java后java Main，仅纯内存检查。List.of自Java9可用，record自16正式可用，沿原Java17。

## 3～5 分钟练习

能向caseRows追加第三行来调整这张表吗？

## 参考答案

List.of返回的列表不可修改，追加会失败；本课固定两项，新增案例应在后续明确改数据及独立数量期望。

## 与上一课的联系

继承第44课两份记录和第45课原比较；本课只把两份记录放入固定列表并核对大小，尚不替换检查调用。下一课可遍历caseRows执行同两项断言。
