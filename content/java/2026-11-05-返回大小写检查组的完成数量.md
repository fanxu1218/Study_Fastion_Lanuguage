# 第 42 课：返回大小写检查组的完成数量

- 日期：2026-11-05
- 课程序号：第 42 课
- 知识点：非void方法在全部检查后返回

## 用途或适用场景

让调用方知道这个具名检查组完成了两项。

## 核心概念

int返回值描述正常完成的数量；显式AssertionError仍会中断失败。返回值不替代两个独立的严格equals期望。

## 最小代码或操作示例

将第41课checkCaseSensitivity替换为下列版本，其他四项及textsMatch保持：

```java
static int checkCaseSensitivity() {
    checkTextCase("different-case", "Java", "java", false);
    checkTextCase("same-case", "Java", "Java", true);
    return 2;
}
```

在checkTextsMatch里用以下两句替换原一次checkCaseSensitivity();：

```java
int caseCount = checkCaseSensitivity();
System.out.println(caseCount + "项大小写检查完成");
```

main仍只调用一次checkTextsMatch。沿原非null约定和显式AssertionError，在纯内存副本javac --release 17 Main.java后java Main，不执行原Files读写。

## 3～5 分钟练习

若same-case抛AssertionError，还会正常打印2项完成吗？

## 参考答案

不会，方法没有正常返回。不能捕获并忽略该错误后仍打印完成。
