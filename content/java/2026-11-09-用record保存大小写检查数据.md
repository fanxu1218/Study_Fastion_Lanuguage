# 第 44 课：用record保存大小写检查数据

- 日期：2026-11-09
- 课程序号：第 44 课
- 知识点：具名不可变数据行

## 用途或适用场景

给第43课两项大小写检查准备可复用的输入记录。

## 核心概念

record自动提供同名访问器；本课只将名称、两份文本和布尔期望放进一行。数据准备与执行断言分开，严格equals语义不变。

## 最小代码或操作示例

沿第42课两项检查和第43课固定数量，在原Main类内、方法外增加：
```java
record TextCase(String name, String expectedText,
                String actualText, boolean expectedMatch) {}
```
在checkCaseSensitivity方法开头、两条原checkTextCase调用之前增加：
```java
TextCase differentCase = new TextCase(
    "different-case", "Java", "java", false);
TextCase sameCase = new TextCase(
    "same-case", "Java", "Java", true);
```
本课保留两条原调用、return 2和调用方数量检查；两行暂不驱动断言。沿Java17纯内存副本编译运行，保留另外四项，不执行Files读写。record自Java16正式可用。
