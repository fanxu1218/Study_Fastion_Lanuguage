# 第 33 课：为读回内容不一致显示明确提示

- 日期：2026-10-23
- 课程序号：第 33 课
- 知识点：完整文本比较后的分支提示

## 用途或适用场景

为读回内容不一致显示明确提示。

## 核心概念

比较结果只描述这次读取与原displayText是否一致；不覆盖文件“修好”差异，也不把提示当作I/O错误处理。

## 最小代码或操作示例

用下面分支替换第32课的结果println，sameText定义与原写入/读取保留：

```java
if (sameText) {
    System.out.println("读回内容一致");
} else {
    System.out.println("内容不一致：请核对文件路径、文本顺序与换行");
}
```

完整重跑选未存在的新版本文件名，保留CREATE_NEW、UTF-8和throws IOException。

## 3～5 分钟练习

在内存练习中令savedText等于displayText + "\n"，重新计算sameText并执行分支，不写文件。

## 参考答案

多一个换行也应进入不一致分支；恢复完全相同文本后进入一致分支。读取异常仍向原IOException路径传播。
