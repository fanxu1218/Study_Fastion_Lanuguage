# 第 32 课：比较读回文本与原展示文本

- 日期：2026-10-22
- 课程序号：第 32 课
- 知识点：String.equals 的完整内容比较

## 用途或适用场景

发现读回字符串中的中文、顺序或换行差异。

## 核心概念

equals 比较字符串字符内容，== 比较引用身份。内容不同与 IOException 是不同结果，读取异常继续由原 throws 报告。

## 最小代码或操作示例

沿第 31 课成功读回的 savedText，在后面追加：

```java
boolean sameText = displayText.equals(savedText);
System.out.println("读回内容一致：" + sameText);
```

保留原 outputPath、UTF-8、CREATE_NEW 和 throws IOException；完整重跑时选用未存在的 v03 文件名，不覆盖旧版本。

## 3～5 分钟练习

在内存中另设 String changedText = savedText + "
";，比较 displayText.equals(changedText)，不写回文件。

## 参考答案

原读回应为true；追加一个换行后为false。println 的输出换行与字符串内容无关，比较失败不应被当成读取异常或自动修复文件。
