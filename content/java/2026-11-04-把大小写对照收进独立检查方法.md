# 第 41 课：把大小写对照收进独立检查方法

- 日期：2026-11-04
- 课程序号：第 41 课
- 知识点：相关检查的具名入口

## 用途或适用场景

让同一大小写契约的正反输入由一个方法维护。

## 核心概念

方法只组织已有两个checkTextCase调用，不改变textsMatch严格equals语义。抽取后原入口调用一次，避免留着原调用造成重复。

## 最小代码或操作示例

沿第39课different-case和第40课same-case，在原Main类的检查方法旁新增：

```java
static void checkCaseSensitivity() {
    checkTextCase("different-case", "Java", "java", false);
    checkTextCase("same-case", "Java", "Java", true);
}
```

在checkTextsMatch中用一次checkCaseSensitivity();替换原这两行，其他四项保持。main仍只调用一次checkTextsMatch，沿非null前提和显式AssertionError；纯内存副本javac --release 17 Main.java后java Main，不运行原Files读写。

## 3～5 分钟练习

提取后保留原两行再调用新方法，会实际执行几次大小写比较？

## 参考答案

四次。删除原两行，仅保留新方法的一次调用；两项名字与各自固定期望不变。
