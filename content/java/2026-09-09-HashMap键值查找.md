# 第 8 课：HashMap键值查找

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：Map 与 HashMap

## 用途

按课程名称快速保存和查找练习时长。

## 核心概念

`Map<K, V>` 描述键值关系；`put` 写入，`getOrDefault` 在键缺失时返回指定默认值。

## 最小代码或操作示例

```java
Map<String, Integer> minutes = new HashMap<>();
minutes.put("Java", 20);
System.out.println(minutes.getOrDefault("Rust", 0));
```

## 3～5 分钟练习

加入 Kotlin 的 15 分钟记录并读取它。

## 参考答案

执行 `minutes.put("Kotlin", 15)`，再用 `minutes.get("Kotlin")` 得到 `15`。
