# 第 34 课：将读回比较与提示提取为方法

- 日期：2026-10-26
- 课程序号：第 34 课
- 知识点：两份字符串参数驱动比较

## 用途或适用场景

两份字符串参数驱动比较，继续使用本路线的原练习。

## 核心概念

方法接收期望文本与本次读回文本，内部用equals派生结果。文件I/O仍留在main，方法不负责覆盖文件或把读取失败变成比较失败。

## 最小代码或操作示例

在原类中、main外新增：

```java
static void showTextComparison(String expectedText, String actualText) {
    boolean sameText = expectedText.equals(actualText);
    if (sameText) {
        System.out.println("读回内容一致");
    } else {
        System.out.println("内容不一致：请核对文件路径、文本顺序与换行");
    }
}
```

在main中，用showTextComparison(displayText, savedText);替换第32课sameText定义和第33课整个提示分支；保留UTF-8、CREATE_NEW、读取及throws IOException。调用前提仍是原流程成功生成和读回的非null字符串。

## 3～5 分钟练习

在内存中分别调用showTextComparison("课程", "课程")及showTextComparison("课程", "课程\n")，不写文件。

## 参考答案

第一项一致，第二项不一致；额外换行属于字符串内容。完整重跑仍选未存在的版本文件名，不能移走旧文件掩盖CREATE_NEW冲突。
