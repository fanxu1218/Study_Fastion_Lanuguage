# 第 55 课：从调用方核对空格比较契约

- 日期：2026-11-24
- 课程序号：第 55 课
- 知识点：独立固定期望验证Javadoc描述

## 用途或适用场景

核对第54课textsMatch“不修剪空格”的行为。

## 核心概念

调用方直接比较返回boolean，预期先按文档写出；新增独立演练不替换原六项，也不新增null语义。

## 最小代码或操作示例

在原四源文件同目录新建ContractTextCheck.java，沿相同package（原无则不加）：
```java
public class ContractTextCheck {
    public static void main(String[] args) {
        boolean actual = TextComparison.textsMatch("Java", " Java ");
        if (actual) {
            throw new AssertionError("精确比较不应忽略首尾空格");
        }
        System.out.println("空格比较契约检查完成");
    }
}
```
在未存在的classes-lesson55目录用javac --release 17 -d编译原四源文件与本文件；成功后分别以java -cp启动ContractTextCheck及RunTextChecks。有package用完整类名。原六项只由后一入口启动一次。

## 3～5 分钟练习

把actual调用两侧都改为"Java"而仍要求false，应通过吗？随后恢复。

## 参考答案

应抛AssertionError，因为相同文本实际为true；恢复原带空格样本后，独立契约及原六项分别通过。
