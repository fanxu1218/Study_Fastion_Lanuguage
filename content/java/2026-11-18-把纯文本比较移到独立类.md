# 第 51 课：把纯文本比较移到独立类

- 日期：2026-11-18
- 课程序号：第 51 课
- 知识点：同包静态方法的类名限定调用

## 用途或适用场景

让第50课TextCase及原六项检查共用独立比较实现。

## 核心概念

静态方法属于类，调用用类名限定；移动方法不改变String.equals的精确比较语义。

## 最小代码或操作示例

在Main.java、TextCase.java同目录新建TextComparison.java，沿原相同package（原来无package则不添加）：
```java
class TextComparison {
    static boolean textsMatch(String expectedText, String actualText) {
        return expectedText.equals(actualText);
    }
}
```
删除Main中原textsMatch定义，将checkTextCase内调用改为TextComparison.textsMatch(expectedText, actualText)。保留原非null输入、四项原检查、两行TextCase和数量入口：
```sh
javac --release 17 Main.java TextCase.java TextComparison.java
java Main
```
仍应输出2项大小写检查完成；不恢复旧文件I/O。

## 3～5 分钟练习

移动后再在Main复制一份比较方法，可以证明检查使用独立类吗？

## 参考答案

不能；保持唯一实现和明确的TextComparison限定调用。
