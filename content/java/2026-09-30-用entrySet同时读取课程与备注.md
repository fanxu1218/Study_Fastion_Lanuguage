# 第 22 课：用entrySet同时读取课程与备注

- 日期：2026-09-30
- 课程序号：第 22 课
- 知识点：`Map.entrySet()`

## 用途或适用场景

遍历时一次取得课程键和备注值，避免再次按键查询。

## 核心概念

`entrySet()` 返回键值映射视图；每个 entry 提供 `getKey()` 与 `getValue()`。

## 最小代码或操作示例

```java
for (var entry : notes.entrySet()) {
  System.out.println(entry.getKey().title() + ": " + entry.getValue());
}
```

## 3～5 分钟练习

加入第二条课程备注并遍历。

## 参考答案

循环各输出一组课程标题和对应备注；不要依赖 `HashMap` 顺序。

## 与上一课的联系

第 21 课用键再调用 `get`；本课只改为 `entrySet` 同时读取；下一课可用 `forEach` 表达同一遍历。
