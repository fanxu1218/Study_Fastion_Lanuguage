# 第 49 课：为大小写检查增加独立入口

- 日期：2026-11-16
- 课程序号：第 49 课
- 知识点：静态void方法组织调用

## 用途或适用场景

将第48课数量检查与原两行执行一起封装。

## 核心概念

包装方法调用原检查一次，完成后才核对固定2；返回集合数量的契约不变。

## 最小代码或操作示例

在Main类内、其他方法外新增：
```java
static void testCaseSensitivity() {
    int caseCount = checkCaseSensitivity();
    if (caseCount != 2) {
        throw new AssertionError("大小写检查数量不符：" + caseCount);
    }
    System.out.println(caseCount + "项大小写检查完成");
}
```
checkTextsMatch中把原调用checkCaseSensitivity、固定2检查及打印整段替换为一次testCaseSensitivity()；保留另外四项。javac --release 17 Main.java后java Main，仍输出2项大小写检查完成。

## 3～5 分钟练习

保留旧直接调用再调用新入口，会增加用例覆盖吗？

## 参考答案

不会，只会重复同两行；保留一次入口调用。
