# 第 4 课：for循环与计数器

- 日期：2026-09-03
- 课程序号：第 4 课
- 知识点：循环条件、变量作用域与累计

## 用途

统计连续几天的练习分钟数。

## 核心概念

- for 中的 int day 只在循环范围内有效。
- total 在循环前创建，才能保留每轮累加后的结果。

## 最小代码或操作示例

```java
public class Main {
    public static void main(String[] args) {
        int total = 0;
        for (int day = 1; day <= 3; day++) {
            total += 5;
        }
        System.out.println(total); // 15
    }
}
```

## 3～5 分钟练习

改成连续 5 天，每天练习 8 分钟；解释 day <= 5 与 day < 5 的差异。

## 参考答案

```text
将上界改为 day <= 5，循环体改为 total += 8，结果为 40。若从 1 开始用 day < 5，只执行 4 次，结果为 32。
```
