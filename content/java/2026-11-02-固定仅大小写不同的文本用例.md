# 第 39 课：固定仅大小写不同的文本用例

- 日期：2026-11-02
- 课程序号：第 39 课
- 知识点：equals区分字母大小写

## 用途或适用场景

为严格文本比较固定大小写边界。

## 核心概念

String.equals要求相同字符序列；大小写不同即不相等。新增用例继续走具名检查，不改用equalsIgnoreCase改变业务约定。

## 最小代码或操作示例

沿第37课checkTextCase与第38课空格用例，在checkTextsMatch原四行之后追加：

```java
checkTextCase("different-case", "Java", "java", false);
```

保留textsMatch中的非null前提和String.equals；main仍只调用一次检查入口。纯内存副本编译运行，不执行原Files读写。

## 3～5 分钟练习

把false误填true，应由哪条信息定位？

## 参考答案

抛出含different-case的AssertionError。恢复false后五项检查通过；不能把输入都转小写迎合错误期望。
