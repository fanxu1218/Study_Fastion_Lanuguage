# 第 24 课：按课程标题排序输出备注

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：`Stream.sorted`

## 用途或适用场景

在不修改原备注表的情况下按标题顺序输出。

## 核心概念

只对原 `notes` 的条目流排序，再复用标题字段与备注值。

## 最小代码或操作示例

```java
import java.util.Comparator;

notes.entrySet().stream()
    .sorted(Comparator.comparing(entry -> entry.getKey().title()))
    .forEach(entry -> System.out.println(entry.getKey().title() + ": " + entry.getValue()));
```

## 3～5 分钟练习

以反向插入顺序加入两条记录。

## 参考答案

输出按课程标题排列，原 `notes` 不变。
