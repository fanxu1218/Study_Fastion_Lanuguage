# 第 54 课：为精确比较方法补充Javadoc契约

- 日期：2026-11-23
- 课程序号：第 54 课
- 知识点：Javadoc的参数名与返回值对应实现

## 用途或适用场景

给第53课独立调用链中的唯一TextComparison.textsMatch补充可查说明。

## 核心概念

/**文档紧邻方法声明；@param使用真实参数名，@return描述boolean。文档不能自动增加null处理、trim或忽略大小写。

## 最小代码或操作示例

在TextComparison.java现有textsMatch声明前插入：
```java
/**
 * 精确比较两个已有非 null 文本，不修剪空格或忽略大小写。
 * @param expectedText 预先写出的非 null 期望文本
 * @param actualText 待比较的非 null 实际文本
 * @return 两个文本内容完全相同时为 true，否则为 false
 */
```
方法体仍是expectedText.equals(actualText)，Main、TextCase和RunTextChecks不变。沿第52～53课使用新的未占用输出目录classes-lesson54，以javac --release 17 -d编译原四源文件，再以java -cp classes-lesson54 RunTextChecks运行一次；有package沿原完整名称。原六项仍只输出一次2项大小写检查完成。

## 3～5 分钟练习

文档写“忽略大小写”但方法体不改，原大小写反例会通过吗？

## 参考答案

不会；String.equals仍精确比较。应修正文档描述，保留原非null输入和独立期望，不改成equalsIgnoreCase。
