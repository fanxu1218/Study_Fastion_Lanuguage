# 第 15 课：record值相等

- 日期：2026-09-18
- 课程序号：第 15 课
- 知识点：record值相等

## 用途或适用场景

按组件值比较两条课程记录，而不是比较对象身份。

## 核心概念

record 自动实现 equals 与 hashCode；相同组件值的两个实例相等。

## 最小代码或操作示例

```text
record Lesson(String title, int minutes) {}
var a = new Lesson("Java", 5);
var b = new Lesson("Java", 5);
System.out.println(a.equals(b));
```

## 3～5 分钟练习

把 b 的 minutes 改为 10 再比较。

## 参考答案

结果变为 false，因为记录组件值不同。

## 与上一课的联系

继承上一课的 record 自动访问器；本课只比较自动生成的值相等语义；完成后下一课可把 record 用作 Map 键。
