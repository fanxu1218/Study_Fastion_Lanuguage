# 第 3 课：if与else分支

- 日期：2026-09-02
- 课程序号：第 3 课
- 知识点：布尔条件与分支顺序

## 用途

按成绩生成不同评价。

## 核心概念

- Java 的 if 条件必须是 boolean。
- else if 按顺序检查，只执行第一个命中的分支。

## 最小代码或操作示例

```java
public class Main {
    public static void main(String[] args) {
        int score = 60;
        if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("继续练习");
        }
    }
}
```

## 3～5 分钟练习

添加优秀（>=90）分支，测试 59、60、90。

## 参考答案

```java
// 替换 main 中原分支
if (score >= 90) { System.out.println("优秀"); }
else if (score >= 60) { System.out.println("及格"); }
else { System.out.println("继续练习"); }
```

## 与上一课的联系

上一课声明基本类型；本课用比较得到的 boolean 控制程序路径。
