# 第 26 课：为同名课程增加时长次级排序

- 日期：2026-10-13
- 课程序号：第 26 课
- 知识点：`Comparator.thenComparingInt()`

## 用途或适用场景

保留标题降序，并只在标题相同时按时长升序展示备注。

## 核心概念

`thenComparingInt` 只在前一个比较器认为两个条目相等时读取整数次级键。把它接在 `byTitle.reversed()` 之后，标题降序、时长升序；若最后才对整个组合调用 `reversed()`，次级顺序也会反转。

## 最小代码或操作示例

继续使用第 25 课的 `Lesson(String title, int minutes)`、`notes` 和 `byTitle`；文件的 import 区需有 `java.util.Map` 和已有的 `java.util.Comparator`。在 `main` 中追加两条同名测试数据，替换排序链：

```java
notes.put(new Lesson("Java", 5), "基础练习");
notes.put(new Lesson("Java", 10), "延长练习");

var byTitleThenMinutes = byTitle.reversed()
    .thenComparingInt(entry -> entry.getKey().minutes());
notes.entrySet().stream()
    .sorted(byTitleThenMinutes)
    .forEach(entry -> System.out.println(
        entry.getKey().title() + " " + entry.getKey().minutes()
        + ": " + entry.getValue()));
```

`byTitle` 仍沿用上一课显式声明的 `Map.Entry<Lesson, String>` lambda 参数，不改变 `notes` 的结构。

## 3～5 分钟练习

再加入 `new Lesson("Kotlin", 7)`，预测三个标题与时长的输出顺序，再运行。

## 参考答案

本课这三条记录的相对顺序是 `Kotlin 7`、`Java 5`、`Java 10`；其他既有条目也按同一比较器显示。同名不同分钟数的record不是同一个Map键；原Map的条目未被排序链改写。
