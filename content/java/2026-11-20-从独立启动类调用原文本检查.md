# 第 53 课：从独立启动类调用原文本检查

- 日期：2026-11-20
- 课程序号：第 53 课
- 知识点：同包调用已有静态检查入口

## 用途或适用场景

复用第52课独立class目录，让启动职责也能由另一个类承担。

## 核心概念

同包类可调用当前可见的静态方法；新main只启动既有checkTextsMatch一次，不复制比较逻辑或六项用例。

## 最小代码或操作示例

在Main.java、TextCase.java、TextComparison.java同目录新建RunTextChecks.java，沿原相同package（原无则不添加）：
```java
public class RunTextChecks {
    public static void main(String[] args) {
        Main.checkTextsMatch();
    }
}
```
沿原无package示例，选择未存在的classes-lesson53目录：
```sh
javac --release 17 -d classes-lesson53 Main.java TextCase.java TextComparison.java RunTextChecks.java
java -cp classes-lesson53 RunTextChecks
```
编译成功才运行；应完成原六项比较，输出一次“2项大小写检查完成”。有package时以原完整包名.RunTextChecks启动，不再同时运行Main。

## 3～5 分钟练习

新main调用Main.main再调用Main.checkTextsMatch，会增加独立用例吗？

## 参考答案

不会，会重复同一组。只保留本课一次Main.checkTextsMatch()，比较与数据仍在原三个类。
