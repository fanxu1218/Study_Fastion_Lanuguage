# 第 52 课：把本轮类文件输出到独立目录

- 日期：2026-11-19
- 课程序号：第 52 课
- 知识点：javac输出目录与java类路径对应

## 用途或适用场景

让第51课三份源码的运行来源明确指向本轮构建。

## 核心概念

javac -d指定class输出位置；java -cp指定运行查找位置。显式列三份源码和独立目录，避免把旧同目录class当本轮结果。

## 最小代码或操作示例

在第51课同目录个人副本，选择未存在的classes-lesson52输出目录：
```sh
javac --release 17 -d classes-lesson52 Main.java TextCase.java TextComparison.java
java -cp classes-lesson52 Main
```
以上沿原无package示例。若原工程已有package，第二条以原完整包名.Main启动；输出目录保持不变。只在编译成功后运行，仍应完成原六项比较并输出“2项大小写检查完成”；不删旧class，不改三个类。

## 3～5 分钟练习

编译到了新目录却运行java Main，能确认用了新class吗？

## 参考答案

不能；该命令的默认查找位置未明确指向新目录，应使用本课-cp。
