# 第 12 课：record表达不可变数据

- 日期：2026-09-15
- 课程序号：第 12 课
- 知识点：record 与组件访问器

## 用途

用紧凑语法表示以数据为主的课程值。

## 核心概念

record 自动提供私有 final 字段、访问器、构造器以及值语义方法。

## 最小代码或操作示例

```java
record Lesson(String title, int minutes) {}

Lesson lesson = new Lesson("Java", 5);
System.out.println(lesson.title());
```

## 3～5 分钟练习

增加 `boolean done` 组件。

## 参考答案

record Lesson(String title, int minutes, boolean done) {}

继承上一课构造方法保证完整状态；本课只换成数据载体 record；下一课可增加紧凑构造器校验。
