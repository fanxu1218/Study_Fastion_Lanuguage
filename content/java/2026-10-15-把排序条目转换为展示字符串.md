# 第 28 课：把排序条目转换为展示字符串

- 日期：2026-10-15
- 课程序号：第 28 课
- 知识点：Stream.map() 的逐项转换

## 用途或适用场景

从上一课 sortedEntries 生成只含文本的展示列表。

## 核心概念

map 把每个条目转换成字符串，toList 保留当前顺序；结果不再保存可写 Map.Entry 引用。它只代表生成时的展示文字，原 notes 仍保存业务备注，后续业务变化需重新派生。

## 最小代码或操作示例

保留第 27 课 sortedEntries，在其后追加：

```java
var displayLines = sortedEntries.stream()
    .map(entry -> entry.getKey().title() + " "
        + entry.getKey().minutes() + ": " + entry.getValue())
    .toList();
for (var line : displayLines) {
    System.out.println(line);
}
```

沿用 Lesson record、byTitleThenMinutes 和 notes，不对原 Map 重新排序。

## 3～5 分钟练习

使用 Kotlin 7、Java 5、Java 10 三条教学记录，核对 displayLines；在练习副本修改 notes 的一条备注，观察已生成字符串是否自动改变。

## 参考答案

顺序仍为 Kotlin 7、Java 5、Java 10；已生成的字符串不会随 Map 修改自动更新，需要重新派生。输出列表不可增删，且不作为第二份可编辑备注。
