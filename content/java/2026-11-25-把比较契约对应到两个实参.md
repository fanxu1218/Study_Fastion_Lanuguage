# 第 56 课：把比较契约对应到两个实参

- 日期：2026-11-25
- 课程序号：第 56 课
- 知识点：实参角色对应Javadoc形参

## 用途或适用场景

解释第55课独立调用为什么返回false。

## 核心概念

方法文档的expectedText/actualText由调用位置决定；返回值精确比较内容，参数命名不会修剪空格。

## 最小代码或操作示例

在ContractTextCheck.main内，用下面三行替换原boolean actual声明，其余if和输出保留：
```java
String expectedText = "Java";
String actualText = " Java ";
boolean actual = TextComparison.textsMatch(expectedText, actualText);
```
对照TextComparison的@param：第一实参对应expectedText，第二个对应actualText。用未占用classes-lesson56以javac --release 17 -d编译原五文件，再分别启动ContractTextCheck及RunTextChecks；有package用完整类名。

## 3～5 分钟练习

只把调用两侧交换，精确相等结果会由false变true吗？

## 参考答案

不会；两个既有非null字符串内容仍不相同。仍按文档记录角色，保留首尾空格及原六项，不引入null语义。

## 与上一课的联系

继承第54课@param/@return及第55课空格调用；本课只显式对应两个实参角色。下一课可从这个调用检查方法返回值与诊断分离。
