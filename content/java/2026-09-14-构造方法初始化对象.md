# 第 11 课：构造方法初始化对象

- 日期：2026-09-14
- 课程序号：第 11 课
- 知识点：构造方法与字段初始化

## 用途

创建对象时一次写入它必须具备的初始状态。

## 核心概念

构造方法与类同名且没有返回类型；`this` 区分字段与同名参数。

## 最小代码或操作示例

```java
class Lesson {
  String title;
  Lesson(String title) {
    this.title = title;
  }
}

Lesson lesson = new Lesson("构造方法");
```

## 3～5 分钟练习

增加 `int minutes` 字段，并通过构造方法初始化。

## 参考答案

构造方法增加 `int minutes` 参数，并写 `this.minutes = minutes;`。

## 与上一课的联系

上一课定义类并创建对象；本课保证对象创建时拥有完整数据。
