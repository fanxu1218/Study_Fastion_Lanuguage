# 第 48 课：在逐行完成后返回集合数量

- 日期：2026-11-13
- 课程序号：第 48 课
- 知识点：实际数据规模与调用方固定期望分开

## 用途或适用场景

让第47课循环后的返回与caseRows对应。

## 核心概念

caseRows.size给出集合数量；只有原循环完整执行后才把它作为本次完成数返回。调用方固定2仍独立，不能随数据自动放宽。

## 最小代码或操作示例

沿第46课List.of及第47课增强for，只将checkCaseSensitivity循环之后的return 2替换为：
```java
return caseRows.size();
```
保留caseRows固定2检查、两份原TextCase、逐行checkTextCase及调用方独立期望2，另外四项检查不动。javac --release 17 Main.java后java Main，仍应输出2项大小写检查完成；只用原纯内存副本。

## 3～5 分钟练习

把return caseRows.size()移到第一轮后，调用方固定2一定能识别漏第二行吗？

## 参考答案

不能，表仍有两项所以可能返回2；必须保留循环后return，逐行断言与数量分别验证。
