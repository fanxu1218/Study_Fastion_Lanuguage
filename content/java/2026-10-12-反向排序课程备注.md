# 第 25 课：反向排序课程备注

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：`Comparator.reversed()`

## 用途或适用场景

在不修改原 Map 的情况下按标题降序输出。

## 核心概念

本课只沿用上一课的已有数据与命名，并增加上述单一知识点。

## 最小代码或操作示例

```java
var byTitle = Comparator.comparing((Map.Entry<Lesson, String> e) -> e.getKey().title());
notes.entrySet().stream().sorted(byTitle.reversed()).forEach(System.out::println);
```

## 3～5 分钟练习

按示例完成一次最小操作，并核对结果。

## 参考答案

输出按标题降序排列，原 `notes` 不变。
