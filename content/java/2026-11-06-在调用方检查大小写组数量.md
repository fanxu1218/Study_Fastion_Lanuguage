# 第 43 课：在调用方检查大小写组数量

- 日期：2026-11-06
- 课程序号：第 43 课
- 知识点：显式失败与固定数量约定

## 用途或适用场景

在完成提示前发现第42课返回数量错误。

## 核心概念

返回2只描述当前正常完成的检查数；调用方另以固定2比较，失败抛AssertionError。它不替代两个equals内容比较。

## 最小代码或操作示例

沿第41课独立检查组及第42课int返回，在checkTextsMatch里替换原数量调用和提示：
```java
int caseCount = checkCaseSensitivity();
if (caseCount != 2) {
    throw new AssertionError("大小写检查数量不符：" + caseCount);
}
System.out.println(caseCount + "项大小写检查完成");
```
checkCaseSensitivity中的两项、其他四项及main一次入口都保持。用纯内存副本javac --release 17 Main.java再java Main，不执行原Files读写。

## 3～5 分钟练习

只临时把return 2改为return 1，会发生什么？随后恢复。

## 参考答案

两项内容比较完成后，调用方抛AssertionError且不打印完成；恢复2后重新运行，不能吞掉数量错误。
