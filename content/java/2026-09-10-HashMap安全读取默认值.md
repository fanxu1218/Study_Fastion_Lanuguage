# 第 9 课：HashMap安全读取默认值

- 日期：2026-09-10
- 课程序号：第 9 课
- 知识点：getOrDefault

## 用途

读取可能不存在的键时提供默认值。

## 核心概念

`getOrDefault` 不会把默认值写入 Map。

## 最小代码或操作示例

```java
Map<String, Integer> scores = new HashMap<>();
scores.put("Java", 90);
int score = scores.getOrDefault("Rust", 0);
```

## 3～5 分钟练习

读取不存在的键，再检查 Map 大小。

## 参考答案

返回 `0`，Map 大小仍为 `1`。
