# 第 57 课：在调用方展示布尔返回结果

- 日期：2026-11-26
- 课程序号：第 57 课
- 知识点：返回值与调用方诊断分离

## 用途或适用场景

让第56课参数角色对应到可见比较结果。

## 核心概念

textsMatch返回boolean，输出由调用方负责；增加诊断不能让比较器依赖控制台，也不能把false打印当断言替代。

## 最小代码或操作示例

在ContractTextCheck.main中，原boolean actual声明之后、if之前只增加：
```java
System.out.println("textsMatch返回：" + actual);
```
原expectedText="Java"、actualText=" Java "及if(actual)抛错保持。用javac --release 17 -d classes-lesson57编译原五源文件（输出目录须未占用），再分别启动ContractTextCheck与RunTextChecks；有package使用完整类名。

## 3～5 分钟练习

仅打印false而删除原if失败分支，还能检测临时错样本吗？

## 参考答案

不能；输出只是诊断，独立契约仍由原if维护。默认样本应显示false，原六项由RunTextChecks单独执行。
