# 第 10 课：定义类与创建对象

- 日期：2026-09-11
- 课程序号：第 10 课
- 知识点：类、字段与对象

## 用途

用类型固定表达课程数据。

## 核心概念

类描述对象结构，构造器在创建实例时初始化字段。

## 最小代码或操作示例

```java
class Lesson {
  String title;
  Lesson(String title) { this.title = title; }
}
Lesson lesson = new Lesson("Java");
```

## 3～5 分钟练习

增加 `minutes` 字段并通过构造器赋值。

## 参考答案

构造器增加 `int minutes` 参数并写入 `this.minutes`。
