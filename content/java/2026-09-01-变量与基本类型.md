# 第 2 课：变量与基本类型

- 日期：2026-09-01
- 课程序号：第 2 课
- 知识点：变量声明、基本类型与 `String`

## 用途

保存数量、价格、真假状态和文本，为条件判断与计算打基础。

## 核心概念

- `int`、`double`、`boolean`、`char` 是常见基本类型。
- `String` 保存字符串；变量必须先声明类型再使用。

## 最小代码示例

```java
public class Main {
    public static void main(String[] args) {
        String language = "Java";
        int lesson = 2;
        boolean finished = false;
        System.out.println(language + " " + lesson + " " + finished);
    }
}
```

## 3～5 分钟练习

声明单价、数量并输出总价。

## 参考答案

```java
double price = 12.5;
int count = 3;
System.out.println(price * count);
```
