# 第 29 课：把课程展示列表合并为多行文本

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：String.join 的 Iterable 重载

## 用途或适用场景

将上一课 displayLines 合并成一段保留排序的文本。

## 核心概念

join 在相邻元素间插入分隔符，不自动添加末尾换行；空列表得到空字符串。它只创建展示文本，不回写 notes，也不重新排序。

## 最小代码或操作示例

保留 displayLines、sortedEntries、Lesson 和原 notes，在 displayLines 后追加：

```java
String displayText = String.join("\n", displayLines);
System.out.println(displayText);
```

这里的 \n 是本课明确选择的换行分隔符；println 自己还会输出末尾换行，不是 join 增加的。

## 3～5 分钟练习

使用原三条记录检查行序；在独立练习中把展示列表换为空列表和单行列表。

## 参考答案

三行顺序仍为 Kotlin 7、Java 5、Java 10；空列表合并结果长度为 0，单行没有额外分隔符。生成后 notes 变化不会自动改变 displayText。
