# 第 31 课：读回刚保存的UTF-8展示文本

- 日期：2026-10-21
- 课程序号：第 31 课
- 知识点：Files.readString 的显式编码重载

## 用途或适用场景

核对文件中的中文和换行与原展示文本一致。

## 核心概念

readString 返回整个文件的字符串，不会自动拆行。沿用 outputPath 和 UTF-8；读取失败继续抛出 IOException，不能将失败替换为空字符串。

## 最小代码或操作示例

保留第 30 课导入和 main 的 throws IOException，在一次成功 writeString 之后追加：

```java
String savedText = Files.readString(outputPath, StandardCharsets.UTF_8);
System.out.println(savedText);
```

重做完整程序时换用未存在的 lesson-display-v02.txt，再经原 CREATE_NEW 写入及本课读回；若只读已有 v01，应在单独读取入口仅执行路径定义和本课两行，保留 IOException 声明，不重复执行 CREATE_NEW。

## 3～5 分钟练习

读取一份含原三行中文记录的新文件，再用空 displayText 写入另一个新版本并读回。

前者顺序仍为 Kotlin 7、Java 5、Java 10，后者 savedText 长度为零。println 自己增加的末尾换行不属于 savedText；原文件均保留。
