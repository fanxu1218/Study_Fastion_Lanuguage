# 第 35 课：让文本比较返回布尔值

- 日期：2026-10-27
- 课程序号：第 35 课
- 知识点：返回结果与调用方反馈的分离

## 用途或适用场景

让文本比较返回布尔值，让本次练习的结果可以按同一条件复查。

## 核心概念

比较方法只返回equals结果，main据此选择提示。文件读取异常仍沿IOException传播，不把读取失败当作字符串不一致。

## 最小代码或操作示例

用下列方法替换第34课showTextComparison，在main中替换其调用；原displayText/savedText、UTF-8及CREATE_NEW流程保留：

```java
static boolean textsMatch(String expectedText, String actualText) {
    return expectedText.equals(actualText);
}
```

main里的原调用改为：

```java
boolean sameText = textsMatch(displayText, savedText);
if (sameText) {
    System.out.println("读回内容一致");
} else {
    System.out.println("内容不一致：请核对文件路径、文本顺序与换行");
}
```

沿旧前提，expectedText是成功构造的非null字符串；不额外trim或改换行。

## 3～5 分钟练习

在内存中分别输出textsMatch("课程", "课程")和textsMatch("课程", "课程
")，不写文件。

## 参考答案

依次为true、false。第二项Java字符串内写反斜杠n转义；多一个换行就是内容不同。完整I/O重跑仍使用未存在的新版本文件名。

## 与上一课的联系

继承第33课分支文案和第34课两参数边界；本课只把比较结果以boolean返回并将提示留给调用方。下一课可对返回值写可重复断言。
