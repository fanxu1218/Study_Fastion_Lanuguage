# 第 27 课：把排序后的课程备注收集为列表

- 日期：2026-10-14
- 课程序号：第 27 课
- 知识点：Stream.toList()

## 用途或适用场景

把上一课的排序结果保存为展示列表，供后续遍历使用。

## 核心概念

toList 是终止操作，保留 sorted 后的顺序，返回不可增删的 List。它不是条目和课程对象的深复制，不能称为不可变业务快照；原 notes 仍为业务数据来源。

## 最小代码或操作示例

保留 Lesson、notes、byTitleThenMinutes 和 import java.util.*，替换原排序输出链：

```java
var sortedEntries = notes.entrySet().stream()
    .sorted(byTitleThenMinutes)
    .toList();
for (var entry : sortedEntries) {
    System.out.println(entry.getKey().title() + " "
        + entry.getKey().minutes() + ": " + entry.getValue());
}
```

sortedEntries 用于本次展示，不用它重建第二份备注状态。

## 3～5 分钟练习

沿用 Kotlin 7、Java 5、Java 10 三条记录；核对列表顺序和 notes.size()，不对结果列表调用 add。

## 参考答案

三条记录相对顺序仍为 Kotlin 7、Java 5、Java 10，原 notes 数量不变；sortedEntries 不能增删，Map.Entry 本身未承诺深复制。
