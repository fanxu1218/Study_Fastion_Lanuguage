# 第 30 课：把展示文本写入新的UTF-8文件

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：Files.writeString 的新建文件写入

## 用途或适用场景

保存 displayText，便于下一步读回核对。

## 核心概念

writeString 写入字符序列；CREATE_NEW 要求文件不存在，已有同名文件时保留原文件并报告异常。编码明确为 UTF-8，不回写业务 notes。

## 最小代码或操作示例

在原源文件增加 import：

```java
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
```

将原 main 声明改为 public static void main(String[] args) throws IOException，在 displayText 生成之后追加：

```java
Path outputPath = Path.of("lesson-display-v01.txt");
Files.writeString(outputPath, displayText, StandardCharsets.UTF_8,
    StandardOpenOption.CREATE_NEW);
System.out.println(outputPath.toAbsolutePath());
```

目录为程序实际工作目录。重复练习换用 v02 文件名，不删除旧文件来掩盖冲突。

## 3～5 分钟练习

第一次写入后再次运行相同文件名，观察原始异常和旧文件内容。

## 参考答案

第一次生成按原顺序的文本；第二次在文件已存在时失败，旧文件保留。writeString 不自行补末尾换行，原 println 的换行不属于 displayText。
