# 第 47 课：遍历固定记录执行大小写检查

- 日期：2026-11-12
- 课程序号：第 47 课
- 知识点：增强for循环逐行读取record

## 用途或适用场景

让第46课caseRows真正驱动原两项断言。

## 核心概念

for逐项取得TextCase，调用既有访问器；数据期望仍固定，循环后才返回完成数量。

## 最小代码或操作示例

沿第45课访问器及第46课List.of/size，在checkCaseSensitivity中，用下面循环替换原两次checkTextCase调用：
```java
for (TextCase row : caseRows) {
    checkTextCase(row.name(), row.expectedText(),
        row.actualText(), row.expectedMatch());
}
```
保留两份原记录、size固定2检查、循环后的return 2、调用方固定2与另外四项。javac --release 17 Main.java后java Main，仍输出2项大小写检查完成；只运行原纯内存副本。

## 3～5 分钟练习

若把return 2移到循环体第一项之后，会怎样？

## 参考答案

第二行不再执行，返回2仍可能误导调用方；return必须留在循环之后，逐行断言不可省略。

## 与上一课的联系

继承第45课同名访问器和第46课两行固定集合；本课只用增强for执行同两项。下一课可在全部完成后返回实际集合数量，同时保留调用方独立期望2。
