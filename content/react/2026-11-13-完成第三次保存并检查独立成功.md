# 第 48 课：完成第三次保存并检查独立成功

- 日期：2026-11-13
- 课程序号：第 48 课
- 知识点：受控Promise完成后的交互恢复

## 用途或适用场景

在第47课third仍等待的同一R8中验证本次完成。

## 核心概念

完成third才结束第三次等待；成功提示、当前草稿、控件可用及调用记录分别断言，不以second的旧结果代替。

## 最小代码或操作示例

在第46、47课同一R8末尾追加，保留原first/second与第三次调用记录：
```jsx
await act(async () => { third.resolve(); });
expect(screen.getByRole('status').textContent).toBe('已保存');
expect(screen.queryByRole('alert')).toBeNull();
expect(input.value).toBe('React 第三稿');
expect(input.disabled).toBe(false);
expect(screen.getByRole('button', {name: '保存'}).disabled).toBe(false);
expect(calls).toEqual([
  ['l1', 'React 修订'],
  ['l1', 'React 第二稿'],
  ['l1', 'React 第三稿'],
]);
```
运行原Vitest R1～R8，不重挂载，不改LessonItem；本课仅完成成功路径。

## 3～5 分钟练习

只resolve已完成的second，能证明third的成功吗？

## 参考答案

不能，third仍未完成；须完成自己的Promise，并等待act处理对应更新后再检查。
