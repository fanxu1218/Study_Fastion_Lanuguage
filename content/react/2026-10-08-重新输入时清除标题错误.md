# 第 23 课：重新输入时清除标题错误

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：受控输入更新错误状态

## 用途或适用场景

用户修改草稿时只清除旧提交错误，不提交业务数据。

## 核心概念

本课只增加“受控输入更新错误状态”，继续沿用上一课的数据、对象和命名，不复制业务事实源。

## 最小代码或操作示例

```jsx
onChange={e => { setDraft(e.target.value); setError(''); }}
```

## 3～5 分钟练习

空白提交后输入一个字符。

## 参考答案

错误提示消失，父组件标题仍要等再次提交才更新。

## 与上一课的联系

第 22 课关联输入与错误；本课只在编辑时清错；下一课可禁用重复提交。

时效校验：2026-10-08（React 19.3 当前 `<input>` 文档；受控输入 `onChange` 用法未见废弃。）
