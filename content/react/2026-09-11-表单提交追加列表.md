# 第 10 课：表单提交追加列表

- 日期：2026-09-11
- 课程序号：第 10 课
- 知识点：onSubmit 与状态更新

## 用途

把受控输入内容追加到课程列表。

## 核心概念

提交事件阻止页面刷新，并用新数组更新列表状态。

## 最小代码或操作示例

```jsx
function submit(e) {
  e.preventDefault()
  setLessons([...lessons, title])
  setTitle('')
}
```

## 3～5 分钟练习

禁止空标题被追加。

## 参考答案

提交开头判断 `if (!title.trim()) return`。

## 与上一课的联系

上一课管理输入状态；本课把输入提交到列表。
