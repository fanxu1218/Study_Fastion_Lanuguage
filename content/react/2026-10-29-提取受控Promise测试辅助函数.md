# 第 37 课：提取受控Promise测试辅助函数

- 日期：2026-10-29
- 课程序号：第 37 课
- 知识点：每项独立的resolve与reject入口

## 用途或适用场景

提取受控Promise测试辅助函数，用于在已有示例中验证每项独立的resolve与reject入口。

## 核心概念

辅助函数只构造一个尚未完成的Promise和对应释放函数。每项测试调用一次取得独立对象，仍在await act中释放并检查真实状态。

## 最小代码或操作示例

沿第35课R6和第36课R7，在同一测试文件、test外新增：

```jsx
function createControlledSave() {
  let resolve;
  let reject;
  const promise = new Promise((finish, fail) => {
    resolve = finish;
    reject = fail;
  });
  return {promise, resolve, reject};
}
```

R6开头改为const save = createControlledSave();，原onRename返回save.promise；原释放部分改为：

```jsx
await act(async () => {
  save.resolve();
  await save.promise;
});
```

R7也在本项内独立创建save，onRename返回save.promise；拒绝部分改为：

```jsx
await act(async () => {
  save.reject(new Error('模拟保存失败'));
  await save.promise.catch(() => {});
});
```

只移除各自原pending和finishSave/failSave构造；R6调用记录、R7错误/输入保留及全部状态断言不变。

## 3～5 分钟练习

把save创建放到两个test之外共用，第二项还会得到未完成Promise吗？

## 参考答案

不会保证；Promise一旦完成不能再次变回pending。必须每项独立创建，保留cleanup与await act。
