# 第 39 课：核对重试保存实际收到的参数

- 日期：2026-11-02
- 课程序号：第 39 课

## 用途或适用场景

确认重试保存把正确id和文本交给原回调。

## 核心概念

重试成功还需证明回调收到正确业务id及当次文本。把原R8计数观察换成参数记录，保留两次独立Promise和同一组件实例。

## 最小代码或操作示例

沿第37课createControlledSave及第38课R8，只替换该测试的计数与onRename部分：

```jsx
const calls = [];
render(<ul><LessonItem item={{id: 'l1', title: 'React'}}
  onRename={(id, title) => {
    calls.push([id, title]);
    return calls.length === 1 ? first.promise : second.promise;
  }} /></ul>);
```

其余输入、首次拒绝、再次点击及second释放顺序不变；将原expect(calls).toBe(2)替换为以下断言，放在第二次点击之后：

```jsx
expect(calls).toEqual([
  ['l1', 'React 修订'],
  ['l1', 'React 修订'],
]);
```

保留R1～R8及cleanup/await act，不新增第九个重复测试，不改LessonItem。
