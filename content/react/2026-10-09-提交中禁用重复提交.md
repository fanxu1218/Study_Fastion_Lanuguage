# 第 24 课：提交中禁用重复提交

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：`disabled` 提交状态

## 用途或适用场景

异步保存尚未结束时阻止再次点击提交按钮。

## 核心概念

只增加提交中的交互状态，让按钮从该状态派生，不复制课程数据。

## 最小代码或操作示例

```jsx
const [submitting, setSubmitting] = useState(false);
// 保存开始时 setSubmitting(true)，结束时恢复 false
<button type="submit" disabled={submitting}>保存</button>
```

## 3～5 分钟练习

把 `submitting` 切到 `true` 后连续点击。

## 参考答案

提交中按钮不可交互；恢复为 `false` 后重新可用。
