# 第 24 课：提交中禁用重复提交

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：一次异步提交期间的 disabled 状态

## 用途或适用场景

保存回调尚未结束时禁用表单输入和保存按钮，结束后恢复。

## 核心概念

提交状态只描述交互过程；课程数据仍由父 lessons 保存。为观察异步阶段，课堂把既有 onRename 包装为明确的 400 毫秒模拟等待；子组件 await 回调，finally 恢复提交状态。不能把同步回调旁边的一条注释当作已经存在的异步流程。

## 最小代码或操作示例

```jsx
import { useState } from 'react';

function LessonItem({ item, onRename }) {
  const [draft, setDraft] = useState(item.title);
  const [error, setError] = useState('');
  const [submitting, setSubmitting] = useState(false);
  async function submit(event) {
    event.preventDefault();
    const title = draft.trim();
    if (!title) { setError('请输入课程标题'); return; }
    setError('');
    setSubmitting(true);
    try {
      await onRename(item.id, title);
      setDraft(title);
    } catch (error) {
      setError(error.message);
    } finally {
      setSubmitting(false);
    }
  }
  return <li><form onSubmit={submit}>
    <label>课程标题 <input value={draft} disabled={submitting}
      onChange={event => { setDraft(event.target.value); setError(''); }}
      aria-invalid={Boolean(error)}
      aria-describedby={error ? `${item.id}-error` : undefined} /></label>
    <button type="submit" disabled={submitting}>保存</button>
    {error && <p id={`${item.id}-error`} role="alert">{error}</p>}
  </form></li>;
}
export default function LessonList() {
  const [lessons, setLessons] = useState([
    { id: 'l1', title: 'React' }, { id: 'l2', title: 'Vue' }
  ]);
  async function onRename(id, title) {
    // 仅课堂模拟等待；没有远程服务器或真实网络写入。
    await new Promise(resolve => setTimeout(resolve, 400));
    setLessons(items => items.map(item =>
      item.id === id ? { ...item, title } : item));
  }
  return <>
    <button onClick={() => setLessons(items => [...items].reverse())}>反转顺序</button>
    <ul>{lessons.map(item =>
      <LessonItem key={item.id} item={item} onRename={onRename} />)}</ul>
  </>;
}
```

## 3～5 分钟练习

保存新标题后，在 400 毫秒模拟等待期间连续点击；等待结束再反转列表。

## 参考答案

等待期间输入与保存禁用；结束后恢复，标题更新在原 ID 上，稳定 key 不变。该演示只在内存保存，不声称网络持久化成功。
