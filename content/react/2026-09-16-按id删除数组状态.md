# 第 13 课：按id删除数组状态

- 日期：2026-09-16
- 课程序号：第 13 课
- 知识点：按id删除数组状态

## 用途

不可变地删除一条课程记录。

## 核心概念

filter 返回新数组；保留 id 不匹配的元素即可删除目标项。

## 最小代码或操作示例

```text
setLessons(items => items.filter(item => item.id !== id))
```
