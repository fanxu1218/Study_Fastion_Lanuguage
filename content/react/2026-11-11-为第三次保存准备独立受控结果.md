# 第 46 课：为第三次保存准备独立受控结果

- 日期：2026-11-11
- 课程序号：第 46 课
- 知识点：第三份Promise与调用次数对应

## 用途或适用场景

延续第45课第三稿编辑状态，为下一次保存准备自己的等待边界。

## 核心概念

测试替身按调用次数返回相应Promise；复用已完成second.promise会使第三次保存无法保持独立pending。本课只准备，不触发第三次保存。

## 最小代码或操作示例

在第44、45课同一R8内，紧接const second = createControlledSave();新增：
```jsx
const third = createControlledSave();
```
在原onRename内保留calls.push([id, title]);，只替换旧return：
```jsx
if (calls.length === 1) return first.promise;
if (calls.length === 2) return second.promise;
return third.promise;
```
保留R8末尾第三稿、空status、无alert、控件可用及calls两条断言；运行原Vitest R1～R8。第三次尚未调用，third不resolve/reject，不改LessonItem。

## 3～5 分钟练习

为什么不能仍让第三次调用返回second.promise？

## 参考答案

second已成功完成，无法控制第三次的等待时段；需独立third才能在后续检验第三次pending。

## 与上一课的联系

继承第44课第三稿编辑和第45课控件恢复；本课只安排第三份独立受控Promise，原两次结果不变。下一课可点击第三次保存并观察其pending状态。
