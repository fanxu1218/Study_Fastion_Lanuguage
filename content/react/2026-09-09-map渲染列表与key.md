# 第 8 课：map渲染列表与key

- 日期：2026-09-09
- 课程序号：第 8 课
- 知识点：数组 map 与 key

## 用途

根据课程数组生成一组结构一致的 React 元素。

## 核心概念

JSX 中可用 `map` 转换数组；同级列表项需要稳定且唯一的 `key`，帮助 React 识别项目。

## 最小代码或操作示例

```jsx
const topics = [{ id: 1, name: '状态' }, { id: 2, name: '列表' }];
return <ul>{topics.map(topic => <li key={topic.id}>{topic.name}</li>)}</ul>;
```
