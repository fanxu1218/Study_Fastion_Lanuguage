# 第 21 课：为空白提交显示明确反馈

- 日期：2026-09-29
- 课程序号：第 21 课
- 知识点：空白标题提交的错误状态

## 用途或适用场景

不保存空白标题，同时显示可见且能被辅助技术感知的错误。

## 核心概念

局部 draft 和 error 属于未提交输入交互；父组件 lessons 仍是已保存标题源。在第 20 课 LessonItem 内加入 error 声明与空白分支赋值，不能只渲染未声明的 error。

## 最小代码或操作示例

```jsx
import { useState } from 'react';

function LessonItem({ item, onRename }) {
  const [draft, setDraft] = useState(item.title);
  const [error, setError] = useState('');
  function submit(event) {
    event.preventDefault();
    const title = draft.trim();
    if (!title) { setError('请输入课程标题'); return; }
    setError('');
    onRename(item.id, title);
    setDraft(title);
  }
  return <li><form onSubmit={submit}>
    <label>课程标题 <input value={draft}
      onChange={event => setDraft(event.target.value)} /></label>
    <button type="submit">保存</button>
    {error && <p role="alert">{error}</p>}
  </form></li>;
}
// 父 LessonList 的 onRename、lessons 与稳定 key 沿用第 20 课。
```

## 3～5 分钟练习

提交三个空格，再提交“React 入门”。

## 参考答案

第一次出现“请输入课程标题”且父列表不变；第二次清错并由 onRename 保存清理后的标题。
