# 第 12 课：不可变追加数组状态

- 日期：2026-09-15
- 课程序号：第 12 课
- 知识点：展开语法与数组状态更新

## 用途

把受控输入提交为新课程，同时保持状态更新可预测。

## 核心概念

React 状态中的数组视为只读；追加时创建新数组而不调用 push 修改旧数组。

## 最小代码或操作示例

```jsx
const [lessons, setLessons] = useState([]);

function addLesson(title) {
  setLessons(items => [...items, { id: crypto.randomUUID(), title }]);
}
```
