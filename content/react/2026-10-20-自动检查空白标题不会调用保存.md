# 第 30 课：自动检查空白标题不会调用保存

- 日期：2026-10-20

## 用途或适用场景

为原 LessonItem 的空白提交建立首个自动化用例。

## 核心概念

测试通过输入和按钮触发组件，不直接改 status。保存调用次数来自回调观察；jsdom 模拟 DOM，不验证真实布局或辅助技术。以下工具仅加入个人练习项目。

## 最小代码或操作示例

在已有 React/Vite 练习项目中安装测试依赖；当前文档要求 Node22.12+、Vite6.4+，先满足条件：

```sh
npm install -D vitest jsdom @testing-library/react @testing-library/dom
```

新建 vitest.config.mjs，使用独立配置避免混入其他构建插件：

```js
import { defineConfig } from 'vitest/config';
export default defineConfig({ test: { environment: 'jsdom' } });
```

原 src/LessonList.jsx 顶部使用 import React, { useState } from 'react'；只将原函数声明改为 export function LessonItem，保留第 26～27 课完整逻辑和父组件默认导出。新建 src/LessonItem.test.jsx：

```jsx
import React from 'react';
import { afterEach, expect, test } from 'vitest';
import { cleanup, fireEvent, render, screen } from '@testing-library/react';
import { LessonItem } from './LessonList.jsx';
afterEach(cleanup);

test('R1 空白标题不调用保存', () => {
  let saveCalls = 0;
  async function onRename() { saveCalls += 1; }
  render(<ul><LessonItem item={{id: 'l1', title: 'React'}}
    onRename={onRename} /></ul>);
  fireEvent.change(screen.getByRole('textbox', {name: '课程标题'}),
    {target: {value: '   '}});
  fireEvent.click(screen.getByRole('button', {name: '保存'}));
  expect(screen.getByRole('alert').textContent).toBe('请输入课程标题');
  expect(screen.getByRole('status').textContent).toBe('');
  expect(saveCalls).toBe(0);
});
```

执行 npx vitest run --config vitest.config.mjs src/LessonItem.test.jsx。
