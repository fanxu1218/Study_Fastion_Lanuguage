# 第 3 课：刀片分割与片段边界

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：Blade Edit Mode 与非破坏分割

## 用途

把一段时间线视频分成可分别选择的两部分。

## 核心概念

- 分割增加剪辑点，不直接改写源视频，也不会自动缩短时间线总时长。
- 分割后切回选择模式，避免下一次点击又切出额外片段。本课不删除或波纹移动片段。

## 最小代码或操作示例

```text
1. 在 Edit 页面使用一条只有单个视频片段的练习时间线副本。
2. 选择工具栏 Blade Edit Mode（默认键位 B）。
3. 在视频片段中部单击一次，观察出现新的垂直剪辑边界。
4. 立即按 A 回到 Selection Mode，分别点击左右两段确认能独立选择。
5. 从剪辑点前播放到后，确认内容仍连续、时间线总时长不变。
6. 若素材带链接音频，同时观察对应音频是否被切开；本课不关闭链接或单独移动音频。
```

## 3～5 分钟练习

再把右半段分一次，得到三段。预测总时长是否变化，并在媒体池预览源素材核对。

## 参考答案

```text
只分割、不删除、不移动时仍覆盖原来的同一段素材范围，总时长不变。媒体池中的源素材没有被切成三个文件。
```
