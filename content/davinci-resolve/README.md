# DaVinci Resolve 学习路线

从项目和素材管理出发，逐步学习剪辑、Fusion、调色、Fairlight 与交付。每个工作日更新一节中文短课。

## 课程目录

1. [第 1 课：项目、媒体池与时间线](./2026-09-01-项目媒体池与时间线.md) — 建立素材与剪辑序列的基础关系。
2. [2026-09-02：时间线选择裁切与播放](./2026-09-02-时间线选择裁切与播放.md)——缩短片段开头或结尾，留下需要的内容。
3. [2026-09-03：刀片分割与片段边界](./2026-09-03-刀片分割与片段边界.md)——把一段时间线视频分成可分别选择的两部分。
4. [2026-09-04：Inspector静态缩放](./2026-09-04-Inspector静态缩放.md)——只放大分割后的一个片段，调整画面构图。
5. [2026-09-07：Transform缩放关键帧](./2026-09-07-Transform缩放关键帧.md)——让右侧片段从原尺寸缓慢放大。

9. [2026-09-11：Inspector调整片段透明度](./2026-09-11-Inspector调整片段透明度.md)——通过透明度混合上下两层画面。
