# 第 17 课：把媒体池缓动片段用于第二镜头

- 日期：2026-09-23
- 课程序号：第 17 课
- 知识点：复用媒体池中的 Adjustment Clip

## 用途或适用场景

为第二个镜头沿用已确认的效果和缓动节奏。

## 核心概念

从 Media Pool 再次取用调整片段，放在第二镜头上方的视频轨道；Adjustment Clip 的效果自上而下作用于覆盖的片段。

## 最小代码或操作示例

```text
1. 在 Media Pool 中找到上一课的“缓动效果模板”。
2. 将它拖到第二个镜头上方的较高视频轨道。
3. 裁切调整片段边界，使它只覆盖第二个镜头并播放检查。
```

## 3～5 分钟练习

让模板只作用于第二个镜头，暂不改关键帧的时间。

## 参考答案

第二个镜头位于调整片段下方且被完整覆盖；其他镜头不受该副本影响。

## 与上一课的联系

继承第 16 课保存在 Media Pool 的“缓动效果模板”；本课只取用并定位一个副本，不调整曲线；完成后下一课可对齐第二个镜头的关键帧时刻。

## 时效校验

时效校验：2026-09-24（Blackmagic Design 当前 DaVinci Resolve 21 Edit 官方页面）。官网确认 Adjustment Clip 可从媒体池复用、置于上层轨道并裁切覆盖范围；未见废弃说明。
