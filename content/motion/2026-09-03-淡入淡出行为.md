# 第 3 课：淡入淡出行为

- 日期：2026-09-03
- 课程序号：第 3 课
- 知识点：行为、帧时长与不透明度

## 用途

给标题增加出现和消失的过程，不逐个手动设置透明度关键帧。

## 核心概念

- Fade In/Fade Out 行为根据时间范围生成淡入淡出；时长参数按帧计，不是秒。
- 保留位置关键帧可以同时移动；本课不额外给不透明度记帧，避免同一参数的多套控制混在一起。

## 最小代码或操作示例

```text
1. 打开上一课练习项目的副本，选择覆盖至少 3 秒的标题组。
2. 确认该组 Opacity 为 100%，没有不透明度关键帧，关闭录制。
3. 从 Library > Behaviors > Basic Motion 选择 Fade In/Fade Out 并应用到标题组。
4. 在 Behaviors 检视器把 Fade In Time 和 Fade Out Time 都设为 15 帧；
   Start Offset、End Offset 保持 0。
5. 确认行为条覆盖标题组时长，从开头播放到结尾，观察标题出现后再消失。
```

## 3～5 分钟练习

把 Fade Out Time 改为 0，预测结尾效果；若项目是 30 fps，15 帧约等于多久？

## 参考答案

```text
淡出设为 0 后，标题不再逐渐隐去，而在范围结束时直接消失。30 fps 下 15 帧约为 0.5 秒；其他帧率不能直接照搬这个秒数。
```

## 与上一课的联系

上一课用关键帧指定位置；本课让行为生成透明度变化，认识两类动画控制方式。
