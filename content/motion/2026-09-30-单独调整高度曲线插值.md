# 第 20 课：单独调整高度曲线插值

- 日期：2026-09-30
- 课程序号：第 20 课
- 知识点：Height 曲线插值

## 用途或适用场景

在保留宽度曲线结果的前提下调整蒙版高度节奏。

## 核心概念

只选择 Height 曲线关键帧并改变插值，Width 曲线作为对照保持不动。

## 最小代码或操作示例

```text
1. 在 Keyframe Editor 仅显示 Width 与 Height。
2. 选择 Height 的中间关键帧。
3. 将 Interpolation 改为 Bezier。
4. 播放并确认 Width 曲线未变化。
```

## 3～5 分钟练习

比较 Height 的 Linear 与 Bezier 运动。

## 参考答案

Bezier 使高度变化更平滑；宽度关键帧和值保持原样。
