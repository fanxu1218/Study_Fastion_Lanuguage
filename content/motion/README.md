# Motion 学习路线

从图层结构出发，逐步学习关键帧、行为、粒子、文字动画和 Final Cut Pro 模板。每个工作日更新一节中文短课。

## 课程目录

1. [第 1 课：项目、群组与图层](./2026-09-01-项目群组与图层.md) — 认识 Motion 合成中的基础层级。
2. [2026-09-02：位置关键帧动画](./2026-09-02-位置关键帧动画.md)——让上一课的标题组从左向右移动。
3. [2026-09-03：淡入淡出行为](./2026-09-03-淡入淡出行为.md)——给标题增加出现和消失的过程，不逐个手动设置透明度关键帧。
4. [2026-09-04：复制图层与独立编辑](./2026-09-04-复制图层与独立编辑.md)——从现有标题制作第二条可独立编辑的标题。
5. [2026-09-07：Link行为同步参数](./2026-09-07-Link行为同步参数.md)——让第二个标题的位置跟随第一个标题。
6. [2026-09-08：Oscillate行为循环摆动](./2026-09-08-Oscillate行为循环摆动.md)——让指定参数按周期重复变化。
7. [2026-09-09：Ramp行为制作透明度渐变](./2026-09-09-Ramp行为制作透明度渐变.md)——让透明度完成一次可控的渐变。
8. [2026-09-10：Randomize制作透明度闪烁](./2026-09-10-Randomize制作透明度闪烁.md)——生成可重复的不规则透明度变化。
9. [2026-09-11：关键帧精确控制透明度](./2026-09-11-关键帧精确控制透明度.md)——用关键帧制作可精确计时的淡入。
