# 第 7 课：Ramp行为制作透明度渐变

- 日期：2026-09-09
- 课程序号：第 7 课
- 知识点：Ramp Parameter Behavior

## 用途

让标题透明度从低到高逐渐变化，而不手动建立关键帧。

## 核心概念

Ramp 在行为持续时间内把指定参数从 Start Value 过渡到 End Value；它产生的值会加到参数原值上。

## 最小代码或操作示例

```text
1. 选择标题图层，在 Opacity 参数上添加 Ramp 行为。
2. 把图层 Opacity 设为 0%，Ramp 的 Start Value 设为 0、End Value 设为 100。
3. 把行为条长度设为 1 秒并播放。
```

## 3～5 分钟练习

提高 Curvature，比较渐变起止阶段的速度。

## 参考答案

较高 Curvature 会让变化更明显地缓入缓出，但行为总时长保持 1 秒。

## 与上一课的联系

上一课用 Oscillate 产生重复变化；本课用 Ramp 完成一次从起点到终点的过渡。
