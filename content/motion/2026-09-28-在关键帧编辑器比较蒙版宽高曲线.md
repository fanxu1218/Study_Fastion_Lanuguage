# 第 18 课：在关键帧编辑器比较蒙版宽高曲线

- 日期：2026-09-28
- 课程序号：第 18 课
- 知识点：Keyframe Editor 参数列表的显示复选框

## 用途或适用场景

辨认同一矩形蒙版的 Width 与 Height 动画是否在预期时间发生。

## 核心概念

Keyframe Editor 左侧参数列表控制右侧显示哪些曲线；切换复选框只改变观察视图，不删除已有关键帧。

## 最小代码或操作示例

```text
1. 选中第 17 课已有 Width、Height 关键帧的矩形 Shape Mask，显示 Keyframe Editor。
2. 在左侧参数列表找到 Size 下的 Width 与 Height，勾选两行的显示复选框。
3. 在右侧对照两条曲线的起点和终点位置，不移动任何关键帧。
```

## 3～5 分钟练习

取消勾选 Height，再重新勾选；比较画布播放结果。

## 参考答案

曲线图中 Height 暂时隐藏又出现；画布上的高度动画仍保留，因为复选框只控制图表显示。

## 与上一课的联系

沿用第 17 课同一 Shape Mask 的 Width 与 Height 关键帧；本课只在 Keyframe Editor 同屏观察两条参数曲线；下一课可单独调整其中一条曲线的插值。
