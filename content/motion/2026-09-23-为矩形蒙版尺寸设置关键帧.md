# 第 16 课：为矩形蒙版尺寸设置关键帧

- 日期：2026-09-23
- 课程序号：第 16 课
- 知识点：Shape Mask 的 Size 参数关键帧

## 用途或适用场景

让上一课已贴合目标的矩形蒙版随画面逐渐变宽。

## 核心概念

简单矩形蒙版的 Mask Inspector 提供 Size 参数；为 Width 记录两个关键帧即可让宽度随时间变化，原有 Feather 不必重做。

## 最小操作示例

```text
1. 选中上一课的矩形 Shape Mask，打开 Mask Inspector 的 Size > Width。
2. 播放头放在蒙版起始处，使用 Width 右侧的 Animation 菜单添加关键帧。
3. 播放头后移约 1 秒，增大 Width；播放检查矩形边缘的变化。
```

## 3～5 分钟练习

把第二个宽度值略微缩小，比较播放时的变化。

## 参考答案

矩形蒙版宽度在两个时间点之间变化，原有反转与羽化设置仍保留。

## 与上一课的联系

沿用第 15 课在 Mask Inspector 中独立调过 Width、保留 Feather 的矩形 Shape Mask；本课只新增 Width 随时间变化的关键帧；下一课可给 Height 设置独立变化。
