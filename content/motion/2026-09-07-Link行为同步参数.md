# 第 5 课：Link行为同步参数

- 日期：2026-09-07
- 课程序号：第 5 课
- 知识点：Link 行为与源参数

## 用途

让第二个标题的位置跟随第一个标题。

## 核心概念

Link 行为与源参数用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```text
1. 给第二个标题 Position 添加 Link。\n2. Source Object 选第一个标题。\n3. Source Parameter 与 Apply To 都选 Position。
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

设置 Offset X=100 后仍跟随，但保持 100 像素偏移。
