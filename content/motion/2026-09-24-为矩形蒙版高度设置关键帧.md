# 第 17 课：为矩形蒙版高度设置关键帧

- 日期：2026-09-24
- 课程序号：第 17 课
- 知识点：Size > Height 独立动画

## 用途或适用场景

让第 16 课逐渐变宽的蒙版同时逐渐变高，贴合移动主体。

## 核心概念

`Height` 与 `Width` 是两个独立参数；只给 Height 增加关键帧，不重做上一课的 Width 动画。

## 最小代码或操作示例

```text
1. 选中第 16 课的矩形 Shape Mask，展开 Mask Inspector > Size。
2. 播放头在起始处，为 Height 用 Animation 菜单的 Add 添加关键帧。
3. 播放头后移约 1 秒，增加 Height，预览宽高同时变化。
```

## 3～5 分钟练习

把 Height 第二个值调小，比较蒙版边界与主体的关系。

## 参考答案

Height 在两个时间点间变化，Width 保持第 16 课自己的关键帧曲线；反转与羽化不变。

## 与上一课的联系

继承第 16 课带 Width 动画的同一个 Shape Mask；本课只新增 Height 的独立关键帧；下一课可在 Keyframe Editor 比较宽高曲线。
