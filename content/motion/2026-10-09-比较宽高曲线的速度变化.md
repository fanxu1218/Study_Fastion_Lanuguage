# 第 22 课：比较宽高曲线的速度变化

- 日期：2026-10-09
- 课程序号：第 22 课
- 知识点：通过参数值曲线斜率比较末段节奏

## 用途或适用场景

结束帧对齐后观察 Width 与 Height 是否平稳结束。

## 核心概念

Keyframe Editor 显示的是参数值随时间的曲线；末段曲线趋于平坦，表示参数变化逐渐减慢。Show Curve Set 用来筛选参数，并非独立的速度曲线视图。本课只观察，不修改关键帧。

## 最小代码或操作示例

```text
1. 选中已有矩形 Shape Mask，在 Keyframe Editor 的 Show Curve Set 中选 Animated。
2. 用参数左侧勾选框只显示 Width 与 Height。
3. 在同一时间范围查看两条参数值曲线的末段，并播放末 20 帧。
4. 记录哪一维较早趋于平坦；未见差异就如实记录“未观察到差异”。
```

## 3～5 分钟练习

写下 Width 与 Height 的结束帧和最终值，再记录一条能在画面中复核的末段节奏差异。

## 参考答案

原结束帧和值保持不变。可以从参数值曲线斜率与播放画面观察变化节奏，但不把界面曲线当作已切换出的独立速度图。

## 与上一课的联系

继承第 21 课对齐的结束帧及既有 Width/Height 曲线；本课只比较参数值曲线的末段斜率。下一课可针对实际观察到的目标曲线调整 Bezier 入切线。
