# 第 27 课：另存带最终蒙版结束帧的项目

- 日期：2026-10-16
- 课程序号：第 27 课
- 知识点：File > Save As的版本保存

## 用途或适用场景

保留上一课已确认的蒙版Out point及关键帧，形成可重开的练习版本。

## 核心概念

Save As创建新版本；保存项目不等于导出成片。仍保持原Width/Height关键帧、Constant和父层范围，不调用会丢弃改动的Revert。

## 最小代码或操作示例

在第26课同一练习项目中，先确认最终结束帧F：

```text
1. 核对所选Shape Mask的Out point=F、最后关键帧帧号及两维终值。
2. File > Save As（Shift-Command-S），使用新的 lesson-mask-out-v01 名称。
3. 在原项目目录选择新位置/名称，保留当前媒体收集设置并记录依赖条件。
4. 确认保存成功，再打开这份新项目，检查F和关键帧值。
5. 在清单追加新项目完整路径、F、共同关键帧结束帧和实际读回结果。
```

本课只保存项目版本，不承诺外部媒体已被收集；原项目和源媒体保留。

## 3～5 分钟练习

重开新项目一次，比较最后关键帧与Out point；无实际操作时只填写期望。

## 参考答案

重开后F与关键帧值应保持，Constant未改变；文件存在和参数读回分别核对。没有导出视频，不能将其登记为成片。
