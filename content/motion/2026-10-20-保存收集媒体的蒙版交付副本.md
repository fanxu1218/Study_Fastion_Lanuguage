# 第 28 课：保存收集媒体的蒙版交付副本

- 日期：2026-10-20
- 课程序号：第 28 课
- 知识点：Save As的Collect Media Copy to Folder

## 用途或适用场景

把最终F结束帧项目及使用的媒体复制到新目录。

## 核心概念

原Save As只保存版本，Copy to Folder才收集使用的媒体。Include Unused Media控制未使用媒体是否一起复制；本课保留未使用媒体，减少丢失依赖的歧义。

## 最小代码或操作示例

打开第27课lesson-mask-out-v01，保留F、Width/Height关键帧和Constant：

```text
1. File > Save As（Shift-Command-S），选择新的lesson-mask-collected-v01名称。
2. Collect Media选择Copy to Folder，勾选Include Unused Media。
3. 选择新的练习位置并Save，保留旧项目和所有源媒体。
4. 在新文件夹确认同名项目与Media目录，记录实际收集文件。
5. 重开新项目，复核F、最后关键帧和两维终值，记录缺失警告。
```

无外部媒体的纯文字/形状项目按实际结果记录，不能虚构已收集文件；字体等环境条件另记。

## 3～5 分钟练习

比较原项目路径与新目录内容，指出哪些证据属于项目参数，哪些属于媒体收集。

## 参考答案

F/关键帧读回支撑参数保留，Media中的实际文件支撑媒体复制；保存成功不能替代两项核对，也不保证所有字体/插件环境齐全。
