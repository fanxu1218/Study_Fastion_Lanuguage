# 第 35 课：把重复值边界拆成独立搜索测试

- 日期：2026-10-26
- 课程序号：第 35 课
- 知识点：测试函数与报告项的一一对应

## 用途或适用场景

测试函数与报告项的一一对应，继续使用本路线的原练习。

## 核心概念

具名表行能定位输入，但同一测试内某行失败仍会停止后续行。将关键边界拆成独立#[test]，可以单独运行并分别看到结果。

## 最小代码或操作示例

保留第32课assert_missing与原五项测试。用下列三个方法替换第33～34课finds_last_in_fixed_cases，沿用assert_found：

```rust
#[test]
fn fixed_single_score() {
    assert_found(&[8], 8, 0);
}

#[test]
fn fixed_all_equal_scores() {
    assert_found(&[8, 8, 8], 8, 2);
}

#[test]
fn fixed_separated_scores() {
    assert_found(&[8, 3, 8], 8, 2);
}
```

先运行cargo test fixed_，再运行cargo test；不保留旧表测试造成重复覆盖。

## 3～5 分钟练习

在个人副本把all_equal期望2改成1，运行cargo test fixed_，观察其他两项，再恢复。

## 参考答案

all_equal失败，另外两项独立报告；恢复后重跑。原五项加三个独立方法共八项；不依赖方法执行顺序或共享可变状态。

## 与上一课的联系
