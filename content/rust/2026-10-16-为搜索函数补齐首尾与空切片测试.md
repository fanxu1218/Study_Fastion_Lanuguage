# 第 30 课：为搜索函数补齐首尾与空切片测试

- 日期：2026-10-16
- 课程序号：第 30 课
- 知识点：边界输入的固定期望

## 用途或适用场景

让 find_last 的首项、尾项及无元素行为有独立回归证据。

## 核心概念

继续断言 Match 的整数成员，不要求自定义类型实现 Debug/PartialEq。三项边界共用上一课函数，不修改最后一次命中的搜索语义。

## 最小代码或操作示例

保留第 28 课声明与第 29 课两项测试，在同一文件顶层追加：

```rust
#[test]
fn finds_first_position() {
    match find_last(&[8, 3, 5], 8) {
        Ok(item) => {
            assert_eq!(item.index, 0);
            assert_eq!(item.value, 8);
        }
        Err(SearchError::NotFound) => panic!("expected first item"),
    }
}

#[test]
fn finds_last_position() {
    match find_last(&[3, 5, 8], 8) {
        Ok(item) => {
            assert_eq!(item.index, 2);
            assert_eq!(item.value, 8);
        }
        Err(SearchError::NotFound) => panic!("expected last item"),
    }
}

#[test]
fn empty_slice_is_missing() {
    match find_last(&[], 8) {
        Err(SearchError::NotFound) => (),
        Ok(_) => panic!("empty slice must not match"),
    }
}
```

在原 Cargo 目录执行 cargo test；上一课的重复值测试仍保留。

## 3～5 分钟练习

运行全部五项；将首项测试的索引期望临时改为 1，观察失败后恢复。

## 参考答案

五项原期望通过；改错期望后只有相应边界检查失败。重复值仍返回最后索引 3，空切片不产生 Match。
