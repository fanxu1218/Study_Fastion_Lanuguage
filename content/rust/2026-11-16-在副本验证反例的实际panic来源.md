# 第 50 课：在副本验证反例的实际panic来源

- 日期：2026-11-16
- 课程序号：第 50 课
- 知识点：准备修订与目标断言回归

## 用途或适用场景

实施第49课已有输入契约支持的单处计划。

## 核心概念

反例通过还需确认panic出自目标断言；expected子串相同不能替代来源位置。

## 最小代码或操作示例

沿第48课首个panic和第49课计划，在原Cargo工程个人副本操作：
```text
1. 保存未存在的完整工程副本，保留原复现报告。
2. 仅实施已证实偏离输入契约的那一处准备修订；缺依据就不改。
3. 用原完整名称执行cargo test 完整名称 -- --exact --show-output。
4. 确认实际运行1项及panic文件/行，再运行原十项测试。
```
完整名称替换为原真实名称；不改should_panic的expected、不加入忽略标记或catch_unwind。

## 3～5 分钟练习

测试显示ok，但panic仍发生在另一个准备语句，可以写目标断言已覆盖吗？

## 参考答案

不能，须保留该实际位置，目标来源仍未验证。
