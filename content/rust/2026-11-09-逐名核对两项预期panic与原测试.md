# 第 45 课：逐名核对两项预期panic与原测试

- 日期：2026-11-09
- 课程序号：第 45 课
- 知识点：发现列表与实际执行分开

## 用途或适用场景

确认两项辅助方法反例确实执行，而非被筛选遗漏。

## 核心概念

--list只发现测试名称，不执行；--exact要求完整名称一致。预期panic用例显示ok表示满足panic和消息条件，并非它没有panic。

## 最小代码或操作示例

沿第43课assert_missing_rejects_a_match和第44课assert_found_rejects_a_missing_value，在原Cargo项目运行：
```sh
cargo test -- --list
cargo test
```
从第一条输出逐字复制两项完整名称，分别用于cargo test 完整名称 -- --exact；“完整名称”是需替换的占位文本，不直接照抄。每次核对实际运行1项；整套运行核对原八项和两项反例共十项。将发现名称、实际执行数及结果分列，无环境仅列源码名称。

## 3～5 分钟练习

目标筛选输出0 passed、0 failed，能算反例通过吗？

## 参考答案

不能，实际未执行。回查--list的完整模块路径，再精确运行；不删消息限定或改业务搜索。
