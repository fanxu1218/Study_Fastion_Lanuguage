# 第 41 课：为意外未命中分支补充搜索条件

- 日期：2026-11-03
- 课程序号：第 41 课
- 知识点：命中辅助方法的错误分支诊断

## 用途或适用场景

命中用例意外返回NotFound时，直接找到输入。

## 核心概念

assert_found的Ok分支已有上下文，Err分支也应保留同一组搜索条件。补消息不改变find_last的Result契约，也不把失败改成忽略。

## 最小代码或操作示例

沿第39课assert_found和第40课assert_missing，只替换assert_found中的Err分支：

```rust
Err(SearchError::NotFound) => panic!(
    "expected a match: scores={:?}, target={}, expected_index={}",
    scores, target, expected_index
),
```

其余match分支、find_last和八项测试名不变。先cargo test -- --list确认完整名称，再以原命中用例完整名称配合--exact执行，核对确有1项，最后cargo test。

## 3～5 分钟练习

在命中用例副本中把target临时改成不在切片中的9，应保留哪些诊断信息？随后恢复。

## 参考答案

测试名、scores、target=9及原expected_index；应失败而非吞掉NotFound。恢复输入后运行目标和原八项。

## 与上一课的联系

继承第39课命中成功分支消息和第40课未命中辅助消息；本课只补assert_found剩余Err分支的上下文。下一课可按两类失败报告核对输入信息是否完整。
