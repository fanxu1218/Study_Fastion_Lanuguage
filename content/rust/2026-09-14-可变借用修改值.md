# 第 12 课：可变借用修改值

- 日期：2026-09-14
- 课程序号：第 12 课
- 知识点：`&mut` 与可变引用

## 用途

让函数临时修改调用方的数据，同时不取得所有权。

## 核心概念

同一作用域内，一个值只能有一个可变引用；参数类型 `&mut T` 明确修改权限。

## 最小代码或操作示例

```rust
fn add_lesson(count: &mut i32) {
    *count += 1;
}

fn main() {
    let mut count = 11;
    add_lesson(&mut count);
    println!("{count}");
}
```

## 参考答案

参数写成 `text: &mut String`，函数体调用 `text.push('!')`。
