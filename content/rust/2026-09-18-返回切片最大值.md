# 第 16 课：返回切片最大值

- 日期：2026-09-18
- 课程序号：第 16 课
- 知识点：返回切片最大值

## 用途或适用场景

从借用的整数切片读取最大值，不取得集合所有权。

## 核心概念

函数接收 &[i32]；iter().max() 返回 Option<&i32>，空切片自然得到 None。

## 最小代码或操作示例

```text
fn max_value(values: &[i32]) -> Option<i32> {
    values.iter().copied().max()
}
```

## 3～5 分钟练习

传入 &[3, 8, 5] 并断言结果。

## 参考答案

`assert_eq!(max_value(&[3, 8, 5]), Some(8));`

## 与上一课的联系

继承上一课的切片参数；本课只从借用数据返回最大值；完成后下一课可处理空切片提示。
