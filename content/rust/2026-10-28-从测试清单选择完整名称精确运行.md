# 第 37 课：从测试清单选择完整名称精确运行

- 日期：2026-10-28
- 课程序号：第 37 课
- 知识点：libtest的清单与精确名称过滤

## 用途或适用场景

libtest的清单与精确名称过滤，用于继续完成本路线原示例的下一步。

## 核心概念

--exact要求匹配完整测试名。先读--list输出，再复制名称；以后若移入模块，完整名称会包含模块前缀，不能继续凭旧短名判断执行成功。

## 最小代码或操作示例

沿第35～36课原八项顶层测试，在同一Cargo目录执行：

```sh
cargo test -- --list
cargo test fixed_all_equal_scores -- --exact
cargo test
```

本例先从清单核对顶层fixed_all_equal_scores，再确认第二条实际运行1项；末条仍运行原八项。--后的参数交给测试程序，保留原测试名与生产函数。

## 3～5 分钟练习

若清单显示tests::fixed_all_equal_scores，第二条怎样调整？

## 参考答案

使用cargo test tests::fixed_all_equal_scores -- --exact，并确认报告确实执行该项。零项不是通过目标测试；最后仍全量运行。
