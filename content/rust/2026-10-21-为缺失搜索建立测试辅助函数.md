# 第 32 课：为缺失搜索建立测试辅助函数

- 日期：2026-10-21
- 课程序号：第 32 课
- 知识点：复用错误分支断言

## 用途或适用场景

让空切片和无目标两项测试共享同一错误契约。

## 核心概念

普通辅助函数调用唯一的 find_last，并显式匹配 NotFound；不为自定义类型增加不必要的 Debug/PartialEq，也不把 Ok 忽略掉。

## 最小代码或操作示例

在第 31 课 assert_found 旁增加；将原同名空切片测试替换，其他测试保留：

```rust
fn assert_missing(scores: &[i32], target: i32) {
    match find_last(scores, target) {
        Err(SearchError::NotFound) => (),
        Ok(_) => panic!("expected no match"),
    }
}

#[test]
fn empty_slice_is_missing() {
    assert_missing(&[], 8);
}
```

将第 29 课原无目标测试的函数体改为 assert_missing(&[3, 8, 5, 8], 9);，保留其原测试名，不重复声明。运行 cargo test。

## 3～5 分钟练习

只在副本把缺失目标 9 改为 8，观察失败后恢复。

## 参考答案

8 实际命中，辅助函数必须 panic；原空切片和目标 9 两项通过。辅助函数无 #[test]，测试数量仍为原五项。

## 与上一课的联系
