# 第 31 课：提取搜索命中的测试辅助函数

- 日期：2026-10-20
- 课程序号：第 31 课
- 知识点：复用带参数的命中断言

## 用途或适用场景

减少首尾命中测试中的重复字段断言。

## 核心概念

辅助函数接收测试输入及独立的预期索引，仍调用唯一的 find_last。普通函数不加 #[test]，由已有测试调用；缺失用例保留自己的错误分支。

## 最小代码或操作示例

在原文件顶层、main 外新增，并替换第 30 课两个命中测试的函数体：

```rust
fn assert_found(scores: &[i32], target: i32, expected_index: usize) {
    match find_last(scores, target) {
        Ok(item) => {
            assert_eq!(item.index, expected_index);
            assert_eq!(item.value, target);
        }
        Err(SearchError::NotFound) => panic!("expected a match"),
    }
}

#[test]
fn finds_first_position() {
    assert_found(&[8, 3, 5], 8, 0);
}

#[test]
fn finds_last_position() {
    assert_found(&[3, 5, 8], 8, 2);
}
```

原函数定义只保留一份；保留第 29 课重复值/缺失及第 30 课空切片测试，执行 cargo test。

## 3～5 分钟练习

把重复值测试也改成调用 assert_found，并给出固定预期索引。

## 参考答案

调用 assert_found(&[3, 8, 5, 8], 8, 3)。辅助函数不成为第六项测试；原五项仍各自运行。
