# 第 17 课：空切片的最大值提示

- 日期：2026-09-21
- 课程序号：第 17 课
- 知识点：空切片的最大值提示

## 用途或适用场景

为空列表提供明确提示。

## 核心概念

沿用 max_value 的 Option<i32>；只在调用处匹配 Some 和 None。

## 最小代码或操作示例

```text
let scores: [i32; 0] = [];
match max_value(&scores) {
    Some(value) => println!("最高分：{value}"),
    None => println!("暂无分数"),
}
```

## 3～5 分钟练习

把 scores 改为 [3, 8, 5]。

## 参考答案

应输出“最高分：8”。

## 与上一课的联系

沿用第 16 课的 `max_value(values: &[i32]) -> Option<i32>`；本课只新增对空切片结果的 `match`；完成练习后下一课可用同一模式处理元素查找。
