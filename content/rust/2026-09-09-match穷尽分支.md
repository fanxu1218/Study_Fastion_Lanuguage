# 第 9 课：match穷尽分支

- 日期：2026-09-09
- 课程序号：第 9 课
- 知识点：match 表达式

## 用途

根据离散值选择结果，并让编译器检查所有情况是否已覆盖。

## 核心概念

`match` 的每个分支返回兼容类型；`_` 可以匹配此前没有覆盖的其余值。

## 最小代码或操作示例

```rust
let level = 2;
let label = match level {
    1 => "基础",
    2 => "核心",
    _ => "进阶",
};
println!("{label}");
```

## 3～5 分钟练习

增加 `3 => "项目"` 分支，并把 `level` 改为 3。

## 参考答案

程序输出“项目”，其他未列出的数值仍由 `_` 分支处理。

## 与上一课的联系

上一课用 `loop` 重复计算并返回值；本课用另一个表达式按值选择并返回结果。
