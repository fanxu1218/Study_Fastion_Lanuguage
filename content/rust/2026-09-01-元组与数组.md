# 第 3 课：元组与数组

- 日期：2026-09-01
- 课程序号：第 3 课
- 知识点：复合类型、元组解构与数组索引

## 用途

元组组合少量不同类型的值，数组保存固定数量的同类型值。

## 核心概念

- 元组可通过解构或 `.0`、`.1` 访问。
- 数组写作 `[T; N]`，索引从 `0` 开始且不可越界。

## 最小代码示例

```rust
fn main() {
    let user = ("Ada", 20);
    let scores = [90, 85, 92];
    let (name, age) = user;
    println!("{name} {age} {}", scores[0]);
}
```

## 3～5 分钟练习

创建城市与温度元组，再输出三项温度数组的第二项。

## 参考答案

```rust
let weather = ("上海", 28.5);
let temperatures = [28.5, 29.0, 27.5];
println!("{} {}", weather.0, temperatures[1]);
```
