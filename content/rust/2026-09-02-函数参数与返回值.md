# 第 4 课：函数参数与返回值

- 日期：2026-09-02
- 课程序号：第 4 课
- 知识点：fn、参数类型与尾表达式

## 用途

把重复计算封装为有输入和输出的函数。

## 核心概念

- 参数要声明类型，-> 指明返回类型。
- 最后一个不带分号的表达式可以作为返回值；加分号会使它成为语句。

## 最小代码或操作示例

```rust
fn total(price: i32, count: i32) -> i32 {
    price * count
}
fn main() {
    println!("{}", total(12, 3));
}
```

## 3～5 分钟练习

编写 double，接收 i32 并返回它的两倍，在 main 中调用。

## 参考答案

```rust
fn double(value: i32) -> i32 {
    value * 2
}
// main 中：println!("{}", double(7)); // 14
```
