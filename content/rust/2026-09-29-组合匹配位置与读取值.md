# 第 22 课：组合匹配位置与读取值

- 日期：2026-09-29
- 课程序号：第 22 课
- 知识点：`Option::zip`

## 用途或适用场景

用 `Option::zip` 组合位置和值。

## 核心概念

沿用第 21 课 scores、last 和按匹配索引 get 的操作。zip 只有两项都为 Some 时才组合，result 保持 Option<(usize, &i32)>；不能将 last 与固定 scores.get(3) 组合，否则值可能不属于匹配位置。

## 最小代码或操作示例

```rust
let scores = [3, 8, 5, 8];
let last = scores.iter().rposition(|value| *value == 8);
let value = if let Some(index) = last { scores.get(index) } else { None };
let result = last.zip(value);
assert_eq!(result, Some((3, &8)));
```

## 3～5 分钟练习

依次把目标改为 5 和 9，重新计算 last/value/result，观察位置和值。

## 参考答案

查询 5 得到 Some((2, &5))；查询 9 时 last/value 都缺失，result 为 None；不能继续读取固定位置 3。

## 与上一课的联系

继承第 20～21 课 scores=[3,8,5,8]、last 和安全读取；本课只用 zip 组合同一匹配位置和值。下一课保留元组 result，并用 map 另生成显示文本。
