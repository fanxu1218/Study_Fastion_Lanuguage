# 第 38 课：观察精确测试的成功输出

- 日期：2026-10-29
- 课程序号：第 38 课
- 知识点：libtest成功输出捕获

## 用途或适用场景

观察精确测试的成功输出，用于在已有示例中验证libtest成功输出捕获。

## 核心概念

默认测试报告隐藏通过测试的打印内容。--show-output在测试结束后展示通过项输出，保留完整名称过滤和断言；日志不能代替断言。

## 最小代码或操作示例

沿第36～37课原八项顶层测试，在fixed_all_equal_scores内部、原检查之前临时加：

```rust
println!("检查全部相同分数的最后匹配位置");
```

在原Cargo目录运行：

```sh
cargo test fixed_all_equal_scores -- --exact --show-output
cargo test
```

第一条应实际执行1项并在成功输出区显示该句；第二条保留全量八项覆盖。观察后可移除临时println，不改find_last或期望。

## 3～5 分钟练习

若名称拼错，命令成功但0项且没有这句输出，应如何记录？

## 参考答案

记录目标未执行，先按--list清单恢复完整名称。只看退出码或新增日志均不能证明断言执行。
