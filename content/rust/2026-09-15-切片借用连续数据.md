# 第 13 课：切片借用连续数据

- 日期：2026-09-15
- 课程序号：第 13 课
- 知识点：字符串切片与生命周期关联

## 用途

读取 String 的一部分而不复制或取得所有权。

## 核心概念

切片保存起点和长度，并借用原数据；借用期间原 String 不能发生使引用失效的修改。

## 最小代码或操作示例

```rust
fn first_word(text: &str) -> &str {
    text.split_whitespace().next().unwrap_or("")
}

let title = String::from("Rust slice");
println!("{}", first_word(&title));
```

## 3～5 分钟练习

把函数改成返回最后一个单词。

## 参考答案

text.split_whitespace().last().unwrap_or("")
