# 第 7 课：while循环与可变状态

- 日期：2026-09-07
- 课程序号：第 7 课
- 知识点：while 条件循环

## 用途

在条件成立时重复推进计数。

## 核心概念

while 条件循环用于保持示例中的数据或操作关系清晰；本课只处理这一项，不引入额外状态或自动化。

## 最小代码或操作示例

```rust
let mut n = 1;\nwhile n <= 3 { println!("{n}"); n += 1; }
```

## 3～5 分钟练习

修改示例中的一个输入值，先预测结果，再在对应运行环境或软件副本中执行。

## 参考答案

依次输出 1、2、3；循环体必须推进 n。
