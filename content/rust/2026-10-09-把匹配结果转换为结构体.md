# 第 25 课：把匹配结果转换为结构体

- 日期：2026-10-09
- 课程序号：第 25 课
- 知识点：`Option::map` 结构化转换

## 用途或适用场景

让调用方分别读取匹配位置和值，而不是解析文案。

## 核心概念

只把已有 `Option<(usize, &i32)>` 映射成结构体。

## 最小代码或操作示例

```rust
struct Match { index: usize, value: i32 }
let found = result.map(|(index, value)| Match { index, value: *value });
```

## 3～5 分钟练习

分别传入命中与未命中结果。

## 参考答案

命中得到 `Some(Match)`，未命中仍是 `None`。

## 与上一课的联系

第 24 课把缺失结果收敛为文案；本课回到可复用数据并只做结构化转换；下一课可把 `None` 转为领域错误。

## 时效校验

时效校验：2026-10-09（Rust 1.98 当前标准库；`Option::map` 未见废弃。）
