# 第 33 课：用固定命中表覆盖单项与重复值

- 日期：2026-10-22
- 课程序号：第 33 课
- 知识点：表格循环复用已有测试辅助函数

## 用途或适用场景

同时核对单项命中与全部相同值时的最后位置。

## 核心概念

每行显式给出输入、目标和预期索引，继续由 assert_found 调用唯一 find_last。表格行不是独立测试报告项，某行失败会结束本测试。

## 最小代码或操作示例

在原五项测试旁增加一项；沿用第 31 课 assert_found 和第 32 课 assert_missing：

```rust
#[test]
fn finds_last_in_fixed_cases() {
    let cases: &[(&[i32], i32, usize)] = &[
        (&[8], 8, 0),
        (&[8, 8, 8], 8, 2),
        (&[8, 3, 8], 8, 2),
    ];
    for &(scores, target, expected_index) in cases {
        assert_found(scores, target, expected_index);
    }
}
```

输入切片、元组、for 和整数沿用已学语法；不新增一份搜索实现，运行 cargo test。

## 3～5 分钟练习

把中间行预期改成0，运行后恢复2。

## 参考答案

该行必须失败，证明语义是最后一次命中；恢复后通过。原空切片和缺失目标仍由 assert_missing 覆盖，新增后为六项测试。
