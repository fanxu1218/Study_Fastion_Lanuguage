## 用途或适用场景

为搜索命中断言补充输入上下文，用于在已有示例中练习assert_eq的自定义失败消息。

## 核心概念

assert_eq!可在两个比较值之后接格式字符串与参数。辅助方法给失败附上scores、target和期望索引，仍由独立测试名区分用例。

## 最小代码或操作示例

保留第37～38课精确运行及八项测试，用下面的方法替换原assert_found；find_last与SearchError不变：

```rust
fn assert_found(scores: &[i32], target: i32, expected_index: usize) {
    match find_last(scores, target) {
        Ok(item) => {
            assert_eq!(item.index, expected_index,
                "index: scores={:?}, target={}", scores, target);
            assert_eq!(item.value, target,
                "value: scores={:?}, expected_index={}", scores, expected_index);
        }
        Err(SearchError::NotFound) => panic!("expected a match"),
    }
}
```

先按原完整名称运行fixed_all_equal_scores，再cargo test；保留--show-output观察方式，日志不代替断言。

## 3～5 分钟练习

在个人副本把all_equal期望2改为1，失败时应同时保留哪些信息？

## 参考答案

原测试名、左右比较值，以及scores=[8,8,8]和target=8的上下文。恢复2后运行目标及全部八项。
