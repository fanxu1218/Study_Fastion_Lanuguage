# 第 23 课：转换组合后的匹配结果

- 日期：2026-09-30
- 课程序号：第 23 课
- 知识点：`Option::map`

## 用途或适用场景

把上一课组合出的索引和值转换成可显示文本。

## 核心概念

`map` 只在 Some 时执行闭包，None 原样传播。result 仍保存上一课的索引和值，独立的 text 保存 Option<String>；保留数据 result 供第 25 课结构化转换。

## 最小代码或操作示例

```rust
let scores = [3, 8, 5, 8];
let last = scores.iter().rposition(|value| *value == 8);
let value = if let Some(index) = last { scores.get(index) } else { None };
let result = last.zip(value);
let text = result.map(|(i, v)| format!("{i}: {v}"));
assert_eq!(text.as_deref(), Some("3: 8"));
```

## 3～5 分钟练习

把目标改为 9，断言结果。

## 参考答案

目标 9 未命中，result 和 text 均为 None；命中 8 时 text 为 Some("3: 8")，result 仍可供后续数据转换。
