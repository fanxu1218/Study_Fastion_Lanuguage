# 第 36 课：按名称定向运行搜索边界测试

- 日期：2026-10-27
- 课程序号：第 36 课
- 知识点：名称过滤的覆盖范围

## 用途或适用场景

按名称定向运行搜索边界测试，让本次练习的结果可以按同一条件复查。

## 核心概念

cargo test后的名称默认按子串过滤；过滤运行只覆盖匹配方法。看到成功还要看实际执行数量，零项测试不能证明目标通过。

## 最小代码或操作示例

沿第35课原八项顶层测试，不改生产函数或测试名。在原Cargo目录执行：

```sh
cargo test fixed_
cargo test fixed_all_equal_scores
cargo test
```

原课程未把测试包进mod tests，第二条应匹配顶层fixed_all_equal_scores。第一条运行三个fixed_边界，第二条运行其中一项，最后全量运行原八项；以实际测试报告为准。

## 3～5 分钟练习

把第二条名称故意拼成fixed_all_equal_score_typo，若命令成功但报告0项，应登记什么？然后恢复正确名称。

## 参考答案

登记未执行目标测试。恢复后应明确看到fixed_all_equal_scores的一项结果；定向通过不能代替八项全量结果。
