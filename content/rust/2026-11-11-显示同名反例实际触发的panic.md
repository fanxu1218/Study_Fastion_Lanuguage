# 第 47 课：显示同名反例实际触发的panic

- 日期：2026-11-11
- 课程序号：第 47 课
- 知识点：成功反例的输出观察

## 用途或适用场景

检查第46课已定位反例的panic是否来自预期辅助断言。

## 核心概念

should_panic成功表示发生了符合消息子串的panic；测试显示ok不代表未panic。--show-output让成功测试的捕获输出在结束后显示。

## 最小代码或操作示例

沿第45课逐名运行与第46课完整名称，在原Cargo项目执行：
```sh
cargo test -- --list
```
复制其中一项原反例完整名称，用它替换下列占位文本（不要连尖括号执行）：
```text
cargo test <完整测试名称> -- --exact --show-output
```
核对实际运行1项，保存panic原文、位置及should_panic(expected=...)的对应子串；再cargo test复查原十项。不删expected，不改变原业务输入；若首个panic来自其他语句，保留实际来源。

## 3～5 分钟练习

输出是另一个准备语句panic，即使恰有相同子串，就能证明辅助断言按预期触发吗？

## 参考答案

不能。还需核对触发位置和调用链；消息命中只满足框架匹配条件，不等于已证明目标来源。

## 与上一课的联系
