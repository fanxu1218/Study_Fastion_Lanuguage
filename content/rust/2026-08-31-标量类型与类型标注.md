# 第 2 课：标量类型与类型标注

- 日期：2026-08-31
- 课程序号：第 2 课
- 知识点：整数、浮点数、布尔值、字符与显式类型标注

## 知识点

认识 Rust 常用标量类型，并在编译器无法推断或需要明确范围时写出类型标注。

## 用途

数值范围和精度会影响计算结果与内存使用。明确类型可以让函数参数、解析结果和跨模块接口更加清晰。

## 核心概念

- `i32` 是常用有符号整数类型，`u32` 只能表示非负整数。
- `f64` 是默认浮点类型，适合一般小数计算。
- `bool` 表示 `true` 或 `false`。
- `char` 使用单引号并表示一个 Unicode 字符。
- 可用 `let count: u32 = 3;` 显式标注类型。

## 最小代码示例

```rust
fn main() {
    let lesson_count: u32 = 2;
    let study_hours: f64 = 1.5;
    let completed: bool = false;
    let level: char = '初';

    println!("第 {lesson_count} 课，学习 {study_hours} 小时");
    println!("完成：{completed}，级别：{level}");
}
```

## 3～5 分钟练习

创建 `age: u8`、`temperature: f32` 和 `is_weekday: bool` 三个变量，并用一条 `println!` 输出它们。

## 参考答案

```rust
fn main() {
    let age: u8 = 20;
    let temperature: f32 = 26.5;
    let is_weekday: bool = true;

    println!("年龄：{age}，温度：{temperature}，工作日：{is_weekday}");
}
```
