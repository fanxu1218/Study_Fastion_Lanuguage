# 第 11 课：借用避免转移所有权

- 日期：2026-09-11
- 课程序号：第 11 课
- 知识点：不可变引用

## 用途

让函数读取值而不取得所有权。

## 核心概念

`&T` 是借用；借用结束后原变量仍可继续使用。

## 最小代码或操作示例

```rust
fn print_title(title: &String) {
    println!("{title}");
}
let title = String::from("Rust");
print_title(&title);
println!("{title}");
```

## 3～5 分钟练习

把参数改为 `&str` 并保持调用成功。

## 参考答案

签名用 `fn print_title(title: &str)`，调用仍传 `&title`。

## 与上一课的联系

上一课移动 String 所有权；本课通过借用保留原值。
