# 第 1 课：变量绑定与可变性

- 日期：2026-08-28
- 课程序号：第 1 课
- 知识点：`let` 变量绑定、默认不可变与 `mut`

## 知识点

使用 `let` 创建变量绑定，理解 Rust 为什么默认不可变，以及什么时候使用 `mut`。

## 用途

明确数据是否允许变化，可以让状态修改更容易追踪，也是理解 Rust 所有权和并发安全的基础。

## 核心概念

- `let name = value;` 创建变量绑定。
- Rust 变量默认不可变，赋值后不能直接改写。
- 确实需要修改时，在变量名前加 `mut`。
- 语句通常以分号结束，`println!` 是输出文本的宏。

## 示例代码

```rust
fn main() {
    let course = "Rust";
    let mut lesson_count = 1;

    println!("课程：{course}，当前第 {lesson_count} 课");

    lesson_count = 2;
    println!("下一课编号：{lesson_count}");
}
```

## 5 分钟练习

创建不可变变量 `language` 和可变变量 `study_minutes`，先输出初始值，再把学习分钟数增加 5 后重新输出。

## 参考答案

```rust
fn main() {
    let language = "Rust";
    let mut study_minutes = 10;

    println!("{language}: {study_minutes} 分钟");
    study_minutes += 5;
    println!("{language}: {study_minutes} 分钟");
}
```
