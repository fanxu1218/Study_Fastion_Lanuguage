# 第 6 课：for循环与范围

- 日期：2026-09-04
- 课程序号：第 6 课
- 知识点：for、可变累加器与包含端点的范围

## 用途

计算从 1 到 5 的总和。

## 核心概念

1..=5 包含 5；1..5 不包含 5。累加器需要 mut，循环变量由 for 依次绑定。

## 最小代码或操作示例

```rust
fn main() {
    let mut total = 0;
    for n in 1..=5 { total += n; }
    println!("{total}");
}
```

## 3～5 分钟练习

把范围改为 1..5，再改为 1..=3，预测并运行。

## 参考答案

依次为 10 和 6；原示例为 15。差别来自右端点是否包含。
