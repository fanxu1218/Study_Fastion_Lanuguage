# 第 8 课：loop与break返回值

- 日期：2026-09-08
- 课程序号：第 8 课
- 知识点：loop、break 与表达式返回值

## 用途

持续执行任务，直到满足条件时退出并得到一个结果。

## 核心概念

`loop` 表示无限循环；`break 值` 既结束循环，也把值作为整个循环表达式的结果。

## 最小代码或操作示例

```rust
let mut count = 0;
let result = loop {
    count += 1;
    if count == 3 {
        break count * 10;
    }
};
println!("{result}");
```

## 3～5 分钟练习

把退出条件改成 `count == 5`，先预测输出再运行。

## 参考答案

循环在第 5 次结束，`result` 为 `50`。

## 与上一课的联系

上一课用 `while` 在条件成立时循环；本课用 `loop` 把退出条件写在循环体内并返回结果。
