# 第 28 课：把匹配结果生成收进搜索函数

- 日期：2026-10-14
- 课程序号：第 28 课
- 知识点：返回 Result<Match, SearchError> 的函数

## 用途或适用场景

让调用方传入分数切片和目标值，复用上一课的命中数据与缺失错误。

## 核心概念

函数借用 scores，不取得数组所有权。仍寻找最后一次出现的位置，将同一位置和值组合为 result，再映射成 Match 并转换为 Result；只有函数封装是本课新增概念。

## 最小代码或操作示例

保留第 25 课 Match 和第 27 课 SearchError，将搜索步骤放到 main 外：

```rust
fn find_last(scores: &[i32], target: i32) -> Result<Match, SearchError> {
    let last = scores.iter().rposition(|value| *value == target);
    let value = match last {
        Some(index) => scores.get(index),
        None => None,
    };
    let result = last.zip(value);
    let found = result.map(|(index, value)| Match { index, value: *value });
    found.ok_or(SearchError::NotFound)
}
```

在原 main 中沿用 scores=[3,8,5,8]，把 checked 的赋值换为 find_last(&scores, 8)，保留上一课完整 match 输出。

## 3～5 分钟练习

依次查询 8、5、9，再用空切片查询 8，记录成功或缺失分支。

## 参考答案

8 返回索引 3、值 8；5 返回索引 2、值 5；9 和空切片返回 NotFound。不需要 unwrap，也不会读取固定索引 3。
