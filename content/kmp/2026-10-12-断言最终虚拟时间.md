# 第 67 课：断言最终虚拟时间

- 日期：2026-10-12
- 课程序号：第 67 课
- 知识点：currentTime 最终断言

## 用途或适用场景

确认上一课两项任务完成后，虚拟时钟停在 100 毫秒。

## 核心概念

代码放在 commonTest 的既有测试类中；这里补全本课依赖的列表、任务与导入。虚拟时间 API 只用于测试；实验性接口显式 @OptIn。

## 最小代码或操作示例

```kotlin
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlinx.coroutines.ExperimentalCoroutinesApi
import kotlinx.coroutines.delay
import kotlinx.coroutines.launch
import kotlinx.coroutines.test.advanceTimeBy
import kotlinx.coroutines.test.advanceUntilIdle
import kotlinx.coroutines.test.currentTime
import kotlinx.coroutines.test.runCurrent
import kotlinx.coroutines.test.runTest

@OptIn(ExperimentalCoroutinesApi::class)
@Test
fun checksFinalVirtualTime() = runTest {
    val completed = mutableListOf<String>()
    launch { delay(100); completed += "first" }
    launch { delay(100); completed += "second" }
    advanceUntilIdle()
    assertEquals(setOf("first", "second"), completed.toSet())
    assertEquals(100L, currentTime)
}
```

## 3～5 分钟练习

把两次 delay 同时改为 150，并只更新最终时间断言。

## 参考答案

完成集合不变；currentTime 的期望改为 150L。
