# 第 42 课：onEach 观察状态变化

## 知识点

使用 `onEach()` 在 Flow 的每个值继续向下游传递前，执行一次观察操作。

## 用途

共享层常需要记录状态日志或调试数据流。`onEach()` 可以观察每个状态，同时保持原值不变，让 UI 继续消费同一条状态流。

## 核心概念

- 上游每发出一个值，`onEach` 都会执行一次。
- 执行完成后，原值会继续传给下游。
- `map` 用来转换值，`onEach` 更适合日志等不改变数据的操作。
- `onEach` 不会主动启动冷 Flow，仍需由 `collect()`、`stateIn()` 等触发收集。
- 不要在 `onEach` 中复制或伪造业务状态。

## 示例代码

在共享 ViewModel 中记录每个搜索状态，再把原状态转换为 `StateFlow`：

```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.onEach
import kotlinx.coroutines.flow.stateIn

sealed interface SearchUiState {
    data object Idle : SearchUiState
    data object Loading : SearchUiState
    data class Content(val count: Int) : SearchUiState
    data class Error(val message: String) : SearchUiState
}

interface SearchLogger {
    fun record(state: SearchUiState)
}

class SearchViewModel(
    searchStates: Flow<SearchUiState>,
    logger: SearchLogger,
) : ViewModel() {
    val uiState: StateFlow<SearchUiState> = searchStates
        .onEach { state ->
            logger.record(state)
        }
        .stateIn(
            scope = viewModelScope,
            started = SharingStarted.WhileSubscribed(5_000),
            initialValue = SearchUiState.Idle,
        )
}
```

当上游依次发送 `Loading` 和 `Content` 时，日志会分别记录它们；`uiState` 仍会收到相同的 `Loading` 和 `Content`。

## 5 分钟练习

补全代码，让 `logger.record(state)` 观察每个商品状态，但不改变传给 UI 的值：

```kotlin
val uiState: StateFlow<ProductUiState> = productStates
    .________ { state ->
        logger.record(state)
    }
    .stateIn(
        scope = viewModelScope,
        started = SharingStarted.WhileSubscribed(5_000),
        initialValue = ProductUiState.Loading,
    )
```

## 参考答案

```kotlin
val uiState: StateFlow<ProductUiState> = productStates
    .onEach { state ->
        logger.record(state)
    }
    .stateIn(
        scope = viewModelScope,
        started = SharingStarted.WhileSubscribed(5_000),
        initialValue = ProductUiState.Loading,
    )
```

这里不需要 `emit()`，因为 `onEach` 会自动把原值继续传给下游。
