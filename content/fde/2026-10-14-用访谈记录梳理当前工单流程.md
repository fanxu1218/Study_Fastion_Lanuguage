# 第 3 课：用访谈记录梳理当前工单流程

- 日期：2026-10-14
- 课程序号：第 3 课
- 知识点：把当前操作整理为有输入和产出的步骤

## 用途或适用场景

把上一课访谈提纲的模拟回答整理为客服目前怎样处理工单的流程。

## 核心概念

先记录现有流程，再设计改进。每一步写清收到什么、做什么、留下什么；没有材料支持的步骤标为待确认。12 分钟与 8 分钟仍是未验证假设，不把模拟访谈当作真实客户结论。

## 最小代码或操作示例

沿用问题卡和 Q1～Q4，在文本编辑器中整理以下虚构访谈材料：

```text
模拟材料：客服说“我读工单，查知识文档，起草回复，再检查依据后发送”。
当前流程（教学草稿）：
1. 收到工单 -> 阅读问题 -> 需答复的问题
2. 需答复的问题 -> 查知识文档 -> 参考文档及相关段落
3. 问题+参考段落 -> 起草回复 -> 回复草稿
4. 草稿+参考段落 -> 人工核对并发送 -> 已发送回复
待确认：找不到有效文档时怎样处理；是否由同一客服核对和发送。
证据来源：模拟访谈材料；真实项目需访谈记录或经允许的操作观察。
```

## 3～5 分钟练习

给“找不到有效文档”补一条待确认问题；不要直接把未知流程写成自动升级或由 AI 回答。

## 参考答案

可问：“最近一次找不到依据时，你怎样继续处理，留下了什么记录？”在取得回答和依据前，流程缺口仍标为待确认。

### 补充练习：把异常样本留在流程里

用 3 分钟把以下虚构片段加入当前流程：“客服查到两份有效期不同、处理规则冲突的知识文档，但还没有说明最终怎样回复。”只记录已知步骤、产出和缺口。

参考答案：

```text
已知输入：同一工单、两份规则冲突的文档。
已知操作与产出：查资料 -> 留下两份文档的标识、版本和冲突段落。
未知后续：怎样判定有效版本、谁能确认、实际如何继续处理，均待核对。
追问与材料：最近一次遇到这种情况怎样处理？核对经允许查看的处理记录。
```

流程可以保留未闭合的分支；不能把“自动选最新文档”写成当前已有行为。这个异常样本会在后续文档有效性和评估课中继续使用，本课不提前补造解决方案。

继承第 1 课客服工单问题卡、第 2 课 Q1～Q4 与“回答/依据/待确认”记录；本课只整理当前步骤及产出。下一课可在这份流程上核对使用者、业务负责人和系统负责人，不提前设计 AI 原型。
