# 第 22 课：为测试矩阵记录辅助技术版本

- 日期：2026-09-30
- 课程序号：第 22 课
- 知识点：无障碍验证环境字段

## 用途或适用场景

让双平台朗读结果能追溯到具体 VoiceOver 或 TalkBack 环境。

## 核心概念

只扩展验证记录，不把人工验证结果伪造成运行时业务状态。

## 最小代码或操作示例

```ts
type A11yCheck = {
  platform: 'ios' | 'android';
  readerVersion: string;
  result: 'pass' | 'fail' | 'not-run';
};
```

## 3～5 分钟练习

记录一条 Android 未执行结果。

## 参考答案

例如 `{ platform: 'android', readerVersion: 'TalkBack 版本待确认', result: 'not-run' }`。
