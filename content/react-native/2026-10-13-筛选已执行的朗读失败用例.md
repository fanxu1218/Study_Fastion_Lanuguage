# 第 26 课：筛选已执行的朗读失败用例

- 日期：2026-10-13
- 课程序号：第 26 课
- 知识点：Array.filter 派生失败列表

## 用途或适用场景

在测试矩阵较长时集中查看已执行、但实际朗读与期望不同的记录。

## 核心概念

只筛选原始记录，不修改 actual，也不把未执行项归入失败。filter 返回新数组；继续保留平台、版本和步骤以供复查。

## 最小代码或操作示例

```ts
// 沿用第 24～25 课 A11yCheck 和实际填写的 caseRow。
const caseRows: A11yCheck[] = [caseRow];
const failedRows = caseRows.filter(row =>
  row.actual !== null && row.expected !== row.actual
);
console.log(failedRows);
```

## 3～5 分钟练习

复制一条模拟记录，使 actual 为不同文字；再保留一条 actual=null。把两条放进 caseRows 后运行筛选。

## 参考答案

failedRows 只含那条已执行且不一致的模拟记录；null 行仍留在 caseRows，等待设备测试；数组筛选不能证明组件或双平台朗读通过。

## 与上一课的联系
