# 第 13 课：刷新失败显示Alert

- 日期：2026-09-16
- 课程序号：第 13 课
- 知识点：刷新失败显示Alert

## 用途

在刷新异常时给出原生提示并复位状态。

## 核心概念

Alert.alert 显示平台对话框；finally 保证 refreshing 回到 false。

## 最小代码或操作示例

```text
try {
  await reload()
} catch {
  Alert.alert("刷新失败", "请稍后重试")
} finally {
  setRefreshing(false)
}
```

## 3～5 分钟练习

增加“知道了”按钮。

## 参考答案

Alert.alert("刷新失败", "请稍后重试", [{ text: "知道了" }])
