# 第 43 课：执行选定业务id的一轮朗读补查

- 日期：2026-11-06
- 课程序号：第 43 课
- 知识点：补查计划到独立设备观察

## 用途或适用场景

落实第42课具备条件的那一行R-01计划。

## 核心概念

补查只覆盖当次真实构建与业务id。label/hint定义和设备朗读分别保存；同条件无法恢复时，仍可保留单次观察但不能声称严格前后归因。

## 最小代码或操作示例

沿第41课结论范围与第42课单行计划，在已有原个人构建环境操作：
```text
1. 核对计划中的真实业务id、构建、系统、TalkBack、语言和steps。
2. 条件齐全才按原入口定位该id，不用当前可见行号替代。
3. 记录实际label/hint来源，执行原动作，独立抄录真实朗读原文。
4. 同轮观察原相邻id，保留结果及位置，避免错配条目。
5. 将实际记录附回原R-01行；条件不足写缺项，不从旧记录复制实际朗读。
```
不安装覆盖、不改caseRows、不加announce；无设备只核对计划，不登记已执行。

## 3～5 分钟练习

本轮目标id朗读正确，能把另一未执行id也写通过吗？

## 参考答案

不能。每个业务id有独立来源和动作，本轮结论限定到实际观察范围。
