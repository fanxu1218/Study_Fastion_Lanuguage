# 第 50 课：比较补查轮的同id朗读差异

- 日期：2026-11-17
- 课程序号：第 50 课
- 知识点：可比条件与实际结果逐项对应

## 用途或适用场景

收窄第49课补查后R-01仍存在的差异。

## 核心概念

同id与相同条件共同限定比较范围；未知旧版本不能由新轮填补。

## 最小代码或操作示例

沿第48课唯一条件和第49课新轮，在原个人材料只读整理：
```text
1. 并列原/新轮id、steps、构建、语言、系统和TalkBack实际版本。
2. 只在来源已确认的共同条件下比较逐字朗读及label/hint来源。
3. 标出首个真实不同字段；旧值未知的条件继续标无法同条件比较。
4. 相邻id保持独立结果，不把目标id结论扩展到整表。
```
不改caseRows、不加announce或覆盖安装；没有设备记录则保留待观察。
