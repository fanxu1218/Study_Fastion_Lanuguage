# 第 14 课：Alert提供重试动作

- 日期：2026-09-17
- 课程序号：第 14 课
- 知识点：Alert提供重试动作

## 用途

在刷新失败提示中让用户直接重试。

## 核心概念

Alert 按钮的 onPress 可调用现有刷新函数；状态仍由刷新流程统一管理。

## 最小代码或操作示例

```text
Alert.alert("刷新失败", "请稍后重试", [
  { text: "取消", style: "cancel" },
  { text: "重试", onPress: reload }
])
```

## 3～5 分钟练习

把取消按钮放在第一项。

## 参考答案

保持取消按钮 style 为 cancel，重试按钮调用 reload。
