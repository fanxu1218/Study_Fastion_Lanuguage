# 第 25 课：记录无障碍用例通过状态

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：从实际观察派生通过状态

## 用途或适用场景

区分未执行、朗读一致、朗读不一致，避免把两份空值视作通过。

## 核心概念

复用第 24 课 caseRow 的原始观察。passed 仅在 actual 已填写且严格一致时为 true；result 是派生展示，不作为第二份手工状态保存。

## 最小代码或操作示例

```ts
// 接在第 24 课 caseRow 后。
const passed = caseRow.actual !== null && caseRow.expected === caseRow.actual;
const result = caseRow.actual === null ? 'not-run' : passed ? 'pass' : 'fail';
console.log(result);
```

## 3～5 分钟练习

在副本练习中依次让 actual 为 null、与 expected 相同的文字、不同文字。练习数据注明模拟，不写回真实测试记录。

## 参考答案

依次得到 not-run、pass、fail；未执行时 passed=false，但它与 fail 不等价，须连同 result 一起理解。
