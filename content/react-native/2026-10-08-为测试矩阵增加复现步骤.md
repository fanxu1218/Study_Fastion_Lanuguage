# 第 23 课：为测试矩阵增加复现步骤

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：无障碍复现字段

## 用途或适用场景

让双平台测试可沿相同步骤复查。

## 核心概念

只在第 22 课 A11yCheck 上增加 steps；平台名称、readerVersion 和 not-run 语义保留。待确认字段不写成已验证版本。

## 最小代码或操作示例

```ts
type A11yCheck = {
  platform: 'ios' | 'android';
  readerVersion: string;
  result: 'pass' | 'fail' | 'not-run';
  steps: string;
};
const caseRow: A11yCheck = {
  platform: 'android',
  readerVersion: 'TalkBack 版本待确认',
  result: 'not-run',
  steps: '开启 TalkBack；触发刷新失败；等待并记录实际播报',
};
```

## 3～5 分钟练习

为 iOS 行写出 VoiceOver 复现步骤，尚未执行时保留 not-run。

## 参考答案

记录仍含 platform、readerVersion、result，只增加 steps；没有实际设备观察不能改为 pass。

## 与上一课的联系

继承第 22 课 A11yCheck 的三个字段；本课只加 steps；下一课保留这些环境与步骤信息，增加原始 expected/actual 观察。
