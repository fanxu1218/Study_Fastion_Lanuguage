# 第 29 课：从朗读原始表派生执行数量

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：互斥结果的派生汇总

## 用途或适用场景

在失败分组和待办之外，显示当前记录的总数、已执行数与通过数。

## 核心概念

只有 actual!==null 才已执行；actual="" 仍是实际观察。计数继续取自 caseRows、pendingRows、failedRows，不保存可手工改写的 pass/fail 数量。

## 最小代码或操作示例

接在第 28 课 pendingRows 后，保留原筛选与 A11yCheck：

```ts
const totalCount = caseRows.length;
const pendingCount = pendingRows.length;
const failedCount = failedRows.length;
const executedCount = totalCount - pendingCount;
const passedCount = executedCount - failedCount;
console.log({total: totalCount, pending: pendingCount, executed: executedCount,
  passed: passedCount, failed: failedCount});
```

这些值只汇总已有记录，不表示所有平台、系统版本或测试用例都已覆盖。

## 3～5 分钟练习

沿用三条模拟记录：null、与 expected 相同、actual="" 且 expected 非空；检查计数等式。

## 参考答案

total=3、pending=1、executed=2、passed=1、failed=1；满足 total=pending+passed+failed。模拟记录不能写成真实设备通过结果。
