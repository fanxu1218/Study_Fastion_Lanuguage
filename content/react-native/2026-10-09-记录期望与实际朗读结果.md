# 第 24 课：记录期望与实际朗读结果

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：expected 与 actual 原始观察

## 用途或适用场景

同时保留期望、实际朗读以及上一课的环境与复现步骤。

## 核心概念

actual=null 明确表示未执行。现在以原始观察作为依据，移除手工维护的 result 字段，下一课从 actual 派生状态，避免原始观察与通过标记不一致。下面是待执行记录模板，不是设备测试结果。

## 最小代码或操作示例

```ts
type A11yCheck = {
  platform: 'ios' | 'android';
  readerVersion: string;
  steps: string;
  expected: string;
  actual: string | null;
};
const caseRow: A11yCheck = {
  platform: 'android',
  readerVersion: 'TalkBack 版本待确认',
  steps: '开启 TalkBack；触发刷新失败；等待并记录实际播报',
  expected: '刷新失败，请重试',
  actual: null,
};
```

## 3～5 分钟练习

在实际测试后填写辅助技术版本和 actual 的原始朗读；尚未测试则保留 null。

## 参考答案

每条记录保留 platform、readerVersion、steps、expected、actual；未执行不会用预期文字充当实际结果。

## 与上一课的联系

继承第 23 课的环境和 steps；本课只增加 expected/actual，测试状态留待下一课从观察派生；下一课明确区分 not-run、pass、fail。
