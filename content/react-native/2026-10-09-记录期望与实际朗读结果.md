# 第 24 课：记录期望与实际朗读结果

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：无障碍测试结果字段

## 用途或适用场景

让双平台测试矩阵能直接比较预期与实际播报。

## 核心概念

只为上一课测试行增加 `expected` 与 `actual`，不改变组件行为。

## 最小代码或操作示例

```ts
const caseRow = { platform: "Android", expected: "已加载", actual: "已加载" }
```

## 3～5 分钟练习

为 iOS 行填写一次真实朗读结果。

## 参考答案

每行同时记录平台、辅助技术、步骤、预期和实际结果。

## 与上一课的联系
