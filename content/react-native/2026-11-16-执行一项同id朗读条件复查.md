# 第 49 课：执行一项同id朗读条件复查

- 日期：2026-11-16
- 课程序号：第 49 课
- 知识点：恢复条件后的设备观察

## 用途或适用场景

落实第48课有原值来源的一项计划。

## 核心概念

新轮绑定业务id和实际设备条件；无法恢复的旧条件继续未知，不能倒填。

## 最小代码或操作示例

沿第47课字段比较及第48课单条件计划，在已有个人设备环境操作：
```text
1. 固定原业务id、steps、label/hint来源、构建和可恢复条件。
2. 记录本轮系统、语言及TalkBack版本；恢复计划条件。
3. 按原steps聚焦该id，逐字记录实际朗读和动作顺序。
4. 相邻id独立观察，将新轮结果与原轮各自来源并列。
```
不改caseRows或增加announce，不安装覆盖；无已有设备或条件则保留待执行。

## 3～5 分钟练习

新轮结果正确，旧TalkBack版本仍未知，能合并成修订前后同条件验证吗？

## 参考答案

不能；新轮仅支持自身范围，旧条件缺口保留。
