# 第 46 课：执行同业务id的单条件朗读补查

- 日期：2026-11-11
- 课程序号：第 46 课
- 知识点：新轮设备观察与原条件对应

## 用途或适用场景

落实第45课R-01中可恢复的一项条件。

## 核心概念

每轮绑定自身设备、TalkBack和条目身份；恢复条件后的结果只覆盖实际读到的id，不能回填旧轮。

## 最小代码或操作示例

沿第44课比较范围与第45课条件来源，在已有目标设备和原安装构建中操作：
```text
1. 固定原业务id、构建、系统、语言、steps及label/hint来源。
2. 核对计划中唯一条件的真实值；无法恢复就注明独立新轮。
3. 按原顺序聚焦该id，逐字记录实际朗读，并单独观察原相邻id。
4. 保留同轮TalkBack版本与动作依据，不从显示文字推算朗读。
5. 将新记录附所选缺项，其他id和旧环境未知值继续保留。
```
不改caseRows、不announce、不安装覆盖；无设备或所需读屏条件则只准备待查行。

## 3～5 分钟练习

目标id已朗读，相邻id未查，能说整列表提示正确吗？

## 参考答案

不能，只能确认目标的本轮观察；相邻id保留未执行。
