# 第 13 课：v-model.number转换数值

- 日期：2026-09-16
- 课程序号：第 13 课
- 知识点：v-model.number转换数值

## 用途

让时长输入直接同步为数值。

## 核心概念

v-model.number 使用 parseFloat 转换输入；无法解析时保留原字符串。

## 最小代码或操作示例

```text
<script setup>
import { ref } from "vue"
const minutes = ref(5)
</script>
<template><input v-model.number="minutes" type="number"></template>
```

## 3～5 分钟练习

显示 minutes 的两倍。

## 参考答案

<p>{{ minutes * 2 }}</p>
