# 第 30 课：从筛选视图派生可见课程数

- 日期：2026-10-20
- 课程序号：第 30 课
- 知识点：computed 依赖另一个computed

## 用途或适用场景

显示筛选后可见项数，保留完整 lessons。

## 核心概念

数量读取 visibleLessons.value.length，随筛选或源记录变化重新派生。它不等于源数据总数，不应另用 ref 手工增减。

## 最小代码或操作示例

沿用原 ref/computed 导入和第 29 课选择框，在 setup 中追加：

```js
const visibleCount = computed(() => visibleLessons.value.length)
```

在原列表前增加：

```vue
<p>当前可见 {{ visibleCount }} 条课程</p>
```

若使用 createApp({setup(){...}}) 而非script setup，将 visibleCount 加入现有 return 对象；原 visibleLessons、稳定id/note及删除事件不变。

## 3～5 分钟练习

用10/B、20/C、30/A三条原记录，把阈值从20改到30，再删除30/A。

## 参考答案

可见数依次为2、1、0；原阈值为30时删除后还有10/B与20/C两条源记录。显示0不意味着lessons为空。
