# 第 23 课：为每行加入局部输入

- 日期：2026-10-08
- 课程序号：第 23 课
- 知识点：稳定 key 下的未提交备注

## 用途或适用场景

给已学列表项加一份可编辑备注，观察重排时对应关系。

## 核心概念

note 是本页记录的未提交输入交互状态，不另建按索引的备注数组。创建记录时初始化为空字符串，让所有行的 v-model 绑定都有明确起点；保留 id/minutes。

## 最小代码或操作示例

```js
// 在第 21 课 submit 中，把 push 替换为：
lessons.value.push({ id: nextId++, minutes: minutes.value, note: '' })

```

将第 22 课的每行模板替换为：

```vue
<li v-for="item in lessons" :key="item.id">
  <label>记录 {{ item.id }} 备注 <input v-model="item.note"></label>
  {{ item.minutes }} 分钟
</li>
```

## 3～5 分钟练习

本次练习从空 lessons 开始提交两条时长，填写不同备注，再用第 22 课按钮反转。

## 参考答案

每条备注随 item.id 移动；所有新行 note 初值为空字符串；本课没有网络保存或独立子组件私有状态。

## 与上一课的联系

继承第 22 课 lessons 反转与稳定 id；本课只给每个创建的记录加 note 初值和 v-model 输入；下一课按 id 删除一行，观察其余备注。
