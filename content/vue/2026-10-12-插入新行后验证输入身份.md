# 第 25 课：插入新行后验证输入身份

- 日期：2026-10-12
- 课程序号：第 25 课
- 知识点：稳定 key 下的插入

## 用途或适用场景

在中间插入新记录，保留现有 ID 与备注归属。

## 核心概念

新行仍从第 21 课唯一的 nextId 分配 id，不能硬编码 4；否则在已有四条记录或重复操作时 key 会碰撞。note 按第 23 课初始化为空字符串。

## 最小代码或操作示例

```js
// 在原 <script setup> 中新增：
function insertLesson() {
  lessons.value.splice(1, 0, { id: nextId++, minutes: 25, note: '' })
}
```

放在列表外，原模板中新增：

```vue
<button type="button" @click="insertLesson">在第二行位置插入</button>
```

## 3～5 分钟练习

提交三条不同 ID，填 A/B/C；连续点击插入两次，核对 key 和备注。

## 参考答案

两个新行分别获得不同 id、空 note；原 A/B/C 仍属于原 id；nextId 不因删除或插入而回退。

## 与上一课的联系

继承第 24 课删除后剩余的 lessons、第 21 课 nextId 和第 23 课 note 初值；本课只增加 splice 插入；下一课按 minutes 排序并继续保留同一 ID。
