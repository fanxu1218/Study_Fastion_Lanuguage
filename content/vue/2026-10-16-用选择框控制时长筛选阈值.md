# 第 29 课：用选择框控制时长筛选阈值

- 日期：2026-10-16
- 课程序号：第 29 课
- 知识点：v-model 绑定筛选条件

## 用途或适用场景

把上一课固定 20 分钟阈值改成可在页面选择的 10、20、30。

## 核心概念

minMinutes 是纯交互筛选条件，lessons 仍是记录事实源。用数值 option 绑定得到数字，不引入空数字输入或隐式转换；筛选继续从 sortedLessons 派生。

## 最小代码或操作示例

沿用已有 ref/computed 导入，在原 setup 顶层声明并替换 visibleLessons：

```js
const minMinutes = ref(20)
const visibleLessons = computed(() =>
  sortedLessons.value.filter(item => item.minutes >= minMinutes.value)
)
```

在原提交表单外、列表前增加：

```vue
<label for="min-minutes">最短时长</label>
<select id="min-minutes" v-model="minMinutes">
  <option :value="10">10 分钟</option>
  <option :value="20">20 分钟</option>
  <option :value="30">30 分钟</option>
</select>
```

保留原 li 的 visibleLessons、稳定 id、备注绑定和删除事件。

## 3～5 分钟练习

提交 30/A、10/B、20/C，依次选择 20、30、10；确认 B 的备注再出现。

## 参考答案

依次显示 20/C和30/A、仅30/A、10/B和20/C和30/A；lessons 未被筛选删除，备注仍跟随原 id。
