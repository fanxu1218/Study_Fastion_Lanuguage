# 第 9 课：watch响应副作用

- 日期：2026-09-10
- 课程序号：第 9 课
- 知识点：watch

## 用途

在响应式值变化后执行记录或请求。

## 核心概念

`computed` 用于派生值；`watch` 用于变化后的外部动作。

## 最小代码或操作示例

```vue
<script setup>
import { ref, watch } from 'vue'
const keyword = ref('')
watch(keyword, value => console.log(value))
</script>
```

## 3～5 分钟练习

监听计数，只在大于 3 时打印提示。

## 参考答案

在回调内判断 `value > 3`。
