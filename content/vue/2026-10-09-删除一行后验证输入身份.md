# 第 24 课：删除一行后验证输入身份

- 日期：2026-10-09
- 课程序号：第 24 课
- 知识点：按 id 删除记录

## 用途或适用场景

删除一行后保持其余行的备注仍属于原业务 ID。

## 核心概念

用参数接收被点击行的 id，不依赖未定义的 removedId。filter 生成新数组，保留未删对象的 id/minutes/note。备注是否正确还需实际列表练习观察，模型测试本身不是 DOM 身份证据。

## 最小代码或操作示例

```js
// 在原 <script setup> 中新增：
function removeLesson(removedId) {
  lessons.value = lessons.value.filter(item => item.id !== removedId)
}
```

在第 23 课同一个 `li` 内增加：

```vue
<button type="button" @click="removeLesson(item.id)">删除</button>
```

## 3～5 分钟练习

提交三条记录并填写 A/B/C，删除中间一行。

## 参考答案

剩下第一、第三个 id；备注为 A/C，原对象 id 不重编号。
