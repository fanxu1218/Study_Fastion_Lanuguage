# 第 32 课：在无匹配说明中显示当前阈值

- 日期：2026-10-22
- 课程序号：第 32 课
- 知识点：模板插值读取同一筛选条件

## 用途或适用场景

让筛选为空时的提示说明正在使用的最短时长。

## 核心概念

模板对 setup 返回的 ref 自动解包。提示读取同一个 minMinutes，不复制阈值，不改变 lessons 或筛选结果。

## 最小代码或操作示例

保留第 31 课两种空说明，只将第二行替换为：

```vue
<p v-else-if="visibleCount === 0">
  没有达到 {{ minMinutes }} 分钟的课程
</p>
```

它必须紧接原 v-if="lessons.length === 0" 的段落。原选择框已用 minMinutes；createApp setup 入口保留原 return 中的 minMinutes、lessons、visibleCount。

## 3～5 分钟练习

原记录10/B、20/C，先选30，再选20；最后删除全部源记录。

## 参考答案

先显示没有达到30分钟的课程；选20后该提示消失并显示一条可见记录；清空源记录后仍显示尚未添加课程。文本中的阈值与实际筛选共用同一来源。

## 与上一课的联系
