# 第 26 课：按时长排序后保留记录身份

- 日期：2026-10-13
- 课程序号：第 26 课
- 知识点：排序与稳定 key

## 用途或适用场景

把同一批练习记录按时长排序，同时保持备注属于原 ID。

## 核心概念

排序只改变顺序，不重新分配 id 或按索引转存 note。用复制数组的 sort 结果替换 lessons；模板继续使用 :key=item.id，本课不引入另一份课程状态。

## 最小代码或操作示例

```js
// 放在原 <script setup> 中，保留 submit/removeLesson/insertLesson。
function sortByMinutes() {
  lessons.value = [...lessons.value].sort((a, b) => a.minutes - b.minutes)
}
```

放在现有列表外：

```vue
<button type="button" @click="sortByMinutes">按时长升序</button>
<!-- 原 li 的 :key="item.id" 和 v-model="item.note" 保持不变。 -->
```

## 3～5 分钟练习

依次提交 30、10、20 分钟并写 A/B/C；可先按上一课插入一条 25，再点击排序。

## 参考答案

未插入时顺序变为 10/B、20/C、30/A；插入 25 后空备注新行位于 20 与 30 之间；原 id/note 不变。相同时长不靠位置生成身份。

## 与上一课的联系

继承第 25 课同一 lessons、nextId、唯一 id 和空备注新行；本课只按 minutes 重排，沿用原 key 与 v-model；下一课可用 computed 展示不改变原数组顺序的排序视图。
