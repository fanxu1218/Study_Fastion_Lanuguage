# 第 27 课：用 computed 展示排序视图

- 日期：2026-10-14
- 课程序号：第 27 课
- 知识点：computed 中复制后排序

## 用途或适用场景

按时长展示已有记录，同时保留原 lessons 的输入顺序。

## 核心概念

computed 返回派生数组；先复制数组再 sort，避免在计算中修改原状态。数组里的记录对象仍是原对象，因此 v-model=item.note 继续写入唯一 lessons 数据源，id 不变。

## 最小代码或操作示例

在现有 vue 导入中加入 computed；把第 26 课排序按钮和 sortByMinutes 函数移除，改为自动派生：

```js
const sortedLessons = computed(() =>
  [...lessons.value].sort((a, b) => a.minutes - b.minutes)
)
```

原列表只替换 v-for 数据源，保留整行已有输入、删除事件和 :key：

```vue
<li v-for="item in sortedLessons" :key="item.id">
  <!-- 此处保留原行内 minutes、v-model="item.note" 与删除按钮。 -->
</li>
```

不要额外创建第二份可编辑课程数组。

## 3～5 分钟练习

重新加载练习后按 30、10、20 提交并写 A/B/C，核对展示顺序；在调试器查看 lessons 原顺序，再编辑 B 的备注。

## 参考答案

展示为 10/B、20/C、30/A，lessons 原顺序仍为 30、10、20；B 的备注修改落在原 id 对象中。插入、删除继续使用已有唯一 ID。
