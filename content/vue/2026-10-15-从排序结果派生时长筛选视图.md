# 第 28 课：从排序结果派生时长筛选视图

- 日期：2026-10-15
- 课程序号：第 28 课
- 知识点：computed 与 Array.filter 的只读筛选

## 用途或适用场景

只展示至少 20 分钟的练习，同时保留原列表、备注和稳定 ID。

## 核心概念

继续使用 sortedLessons，再派生 visibleLessons；filter 生成新数组，不删除源记录。条目仍引用 lessons 中的原对象，所以备注编辑和按 ID 删除继续作用于原记录。

## 最小代码或操作示例

在第 27 课 sortedLessons 后追加：

```js
const visibleLessons = computed(() =>
  sortedLessons.value.filter(item => item.minutes >= 20)
)
```

仅把现有 li 的 v-for 数据源改为 visibleLessons；保留 :key="item.id"、v-model="item.note" 和原删除按钮，不新增第二份可编辑数组。

## 3～5 分钟练习

提交 30、10、20 并分别写 A/B/C；观察筛选显示，再把阈值临时改为 10，核对备注恢复。

## 参考答案

阈值 20 显示 20/C、30/A；改为 10 后显示 10/B、20/C、30/A。10 分钟行此前只是未展示，没有从 lessons 删除。
