# AI 应用与智能体开发课程

这是一条从 AI 基础认知逐步进入 RAG、Agent 编排、工程化部署与模型优化的中文短课路线。课程参考《AI应用与智能体开发 v6.0》目录重新设计，正文为本站原创补充，不复制原 PDF 的宣传性描述。

## 第一版目标

- 目标课数：180 节。
- 完结标准：覆盖基础、核心能力、综合项目、工程化与发布四个层级。
- 每课只增加一个主要知识点，包含最小示例、3～5 分钟练习、参考答案、时效校验和官方参考。

## 八阶段学习路径

1. **AI 应用基础与提示词（第 1～18 课）**：模型与应用边界、Token、提示词、结构化输出、工具与安全边界。
2. **Python 与 FastAPI 全栈基础（第 19～48 课）**：Python 数据模型、异步、HTTP、Pydantic、FastAPI、数据库与日志。
3. **RAG 与基础智能体（第 49～82 课）**：文档加载、切分、Embedding、向量库、检索、RAG 评估与 LangChain Agent。
4. **LangGraph、MCP 与多智能体（第 83～116 课）**：状态图、路由、循环、人机协作、持久化、Tool Calling、MCP、A2A 与多 Agent。
5. **AI 工程化与业务系统融合（第 117～140 课）**：鉴权、缓存、消息、可观测性、限流、容错、数据治理与传统系统智能化。
6. **企业智能体中台与综合项目（第 141～162 课）**：AgentCenter、知识服务、业务工具、网关、多租户与端到端项目。
7. **评估、微调与推理服务（第 163～176 课）**：数据集、评估指标、BERT、LoRA、SFT、模型对比、vLLM 与性能验证。
8. **交付、发布与项目复盘（第 177～180 课）**：安全复核、部署清单、项目文档与技术复盘。
