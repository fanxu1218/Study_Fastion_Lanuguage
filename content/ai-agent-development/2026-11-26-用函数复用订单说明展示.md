# 第 33 课：用函数复用订单说明展示

- 日期：2026-11-26
- 课程序号：第 33 课
- 知识点：def参数接收不同列表

## 用途或适用场景

复用第32课已完成的空列表判断与逐项展示。

## 核心概念

函数体在调用时执行；形参order_summaries接收本次列表，避免在函数内固定读取summaries。只展示，不改列表，订单仍为虚构本地数据。

## 最小代码或操作示例

在order_ids.py中，原summaries准备之后、第一次展示之前定义：
```python
def show_order_summaries(order_summaries):
    if len(order_summaries) == 0:
        print("暂无订单说明")
    else:
        for summary in order_summaries:
            print(f"订单说明：{summary}")
```
用show_order_summaries(summaries)替换第32课整个展示分支；保留中间的原数量输出及no_summaries=[]，用show_order_summaries(no_summaries)替换文件末尾第31课独立分支。两处各调用一次，不保留旧分支。

## 3～5 分钟练习

运行原文件；能否在函数体中把形参改为直接读取summaries？

## 参考答案

不能；第二次调用需要检查自己的空列表。第一处仍展示A100/A101各一次，第二处只显示一次暂无提示，两个原列表均不变。
