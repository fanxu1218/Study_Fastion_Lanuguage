# 第 34 课：从展示函数返回订单说明数量

- 日期：2026-11-27
- 课程序号：第 34 课
- 知识点：return把计算结果交给调用方

## 用途或适用场景

让第33课的调用方取得已展示列表的数量。

## 核心概念

print负责显示，return把值交回本次调用；执行到return后函数结束。数量仍由传入列表计算，不保存另一份订单状态。案例为虚构本地数据。

## 最小代码或操作示例

在order_ids.py中用下面完整定义替换第33课函数：
```python
def show_order_summaries(order_summaries):
    if len(order_summaries) == 0:
        print("暂无订单说明")
    else:
        for summary in order_summaries:
            print(f"订单说明：{summary}")
    return len(order_summaries)
```
用下面两行替换第一次show_order_summaries(summaries)及其紧随的原“说明条数”输出，避免重复调用：
```python
summary_count = show_order_summaries(summaries)
print(f"说明条数：{summary_count}")
```
末尾原no_summaries=[]、空样本条数输出及show_order_summaries(no_summaries)保留；后一调用会返回0，只是调用方尚未接收它。运行python3 order_ids.py。

## 3～5 分钟练习

如果把return缩进到else内部，空列表调用返回0还是None？临时观察后恢复示例缩进。

## 参考答案

返回None，因为空分支执行完后没有经过return；恢复到if/else之后的同级位置，两种列表分别返回2和0。原A100/A101说明各展示一次，原列表不变。
