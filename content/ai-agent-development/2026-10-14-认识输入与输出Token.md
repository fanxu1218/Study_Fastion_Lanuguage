# 第 3 课：认识输入与输出 Token

- 日期：2026-10-14
- 课程序号：第 3 课
- 知识点：模型处理文本的 Token 单位

## 用途或适用场景

继续观察订单 A100 查询助手的一次说明生成，区分送入模型的内容与生成的内容。

## 核心概念

Tokenizer 按模型的规则把文本拆成 Token，再转换成编号。Token 不一定等于一个汉字或一个单词；不能用字符数直接代替真实用量。输入和输出分别计数，本课不计算价格或实现分词器。

## 最小代码或操作示例

在文本编辑器中给上一课流程追加一次调用记录：

```text
送入模型：订单 A100，业务系统状态为“已发货”，请简要说明。
模型输出：订单 A100 已发货，请留意物流进度。
教学用模拟统计：input_tokens=18，output_tokens=12，total_tokens=30
证据状态：仅为算术练习，未调用模型，非上述中文的真实分词结果。
```

实际应用应保存所用模型及服务返回的用量；模型输入还可能包含指令、历史消息或工具结果，不能只数界面上用户问题的字数。

## 3～5 分钟练习

把模拟输出用量改为 15，写出新总量；说明为什么不能把上述输入文字的字符数填进 input_tokens。

## 参考答案

模拟总量为 18+15=33。真实 Token 数取决于所用模型的分词规则和完整输入，字符数不是用量证据。
